# 新题型 UAT 体验卷

来源：用户提供的《新题型测试.docx》。`paper.json` 保存整理后的内容，`testing-protocol.png` 是从 Word 原样提取的表格图片。此 JSON 是本样卷的数据文件，需通过同目录 `publish.py` 上传资源、创建题库和发布试卷，不是通用试卷导入包。

共五道计分题：图表单选（A），共享案例三个单选（B、D、B），四对连线（投资者→不知晓、供应商→中立、销售团队→抵制、高层→主导）。图表使用中文题干，保留英文原图；原文英文与中文题干不重复计分。

整理调整：

- 案例补充预测型外部团队与接口交付窗口的背景，使第二小题与共享材料衔接。
- 材料和第三小题中展示交付成果、讨论需求优先级的会议统一为“迭代评审”；第一小题中反思站会过程的“迭代回顾”保留。
- 删除第二小题解析中材料未提及的“实时看板”描述，修正第一小题“会议上中”笔误。
- 匹配题用四个对应等级作为文字候选，“支持”保留在解析中。补充各场景的具体认知与行为，避免仅凭职位判断参与等级；答案映射保持原文。

发布工具只允许连接 `kg_graph_uat`，使用现有应用服务进行资源上传、题目录入、组卷与发布；不会修改正式环境，也不会自动 seed 到其他环境。重复执行会复用同名样卷及题目，避免重复创建。

UAT 后端容器内运行（将本目录复制到容器后）：

```sh
PYTHONPATH=/app python /tmp/mixed-question-demo/publish.py --actor admin
```
