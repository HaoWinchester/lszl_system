# 订阅第七步补充：会员权益弹窗体验优化

本次基于 `kg_graph_modularized_subscription_step7_renew_upgrade_fix.zip` 继续补充第七步。

## 调整内容

1. 会员权益弹窗取消单独的“选择并购买”按钮。
   - 整张会员卡片变为可点击购买/续费入口。
   - 支持鼠标悬浮效果和键盘 Enter/Space 选择。

2. 权益展示文案配置化。
   - 系统设置 → 订阅套餐配置中新增：
     - 权益展示文字（每行一条，仅影响展示）
     - 每日训练 / 用量展示文案（仅影响展示）
   - 未填写时继续按底层权益和用量限制自动生成。
   - 该配置只影响前端文案展示，不改变底层权益判断逻辑。

3. 会员权益弹窗视觉对齐优化。
   - 每日训练 / 用量说明卡片保持水平对齐。
   - 权益展示列表区域使用统一高度和底部对齐。
   - 取消会员权益弹窗中的有效期文字展示，使套餐卡片更简洁。

## 保持不变

- 套餐底层权益逻辑不变。
- 学员订阅状态、到期逻辑不变。
- 管理员、教师/教研绕过订阅限制的规则不变。
- 游客不进入订阅体系的规则不变。
- 正式支付接口仍未接入，购买入口仍为后续支付/管理员开通预留。
