# 基线重构 C-1.4.1：悬浮模块鼠标交互修复

## 问题

C-1.4 将左右工具区移动到 `.stage` 内后，画布的 pointerdown 事件仍把这两个区域当作画布空白区处理。事件被 `preventDefault()` 并由画布捕获，导致升级会员、账号菜单、图谱信息等鼠标点击失效。

## 修复

1. 左右悬浮模块增加 `data-stage-ui="true"` 标记。
2. 图谱编辑器的 `isUI()` 增加左右悬浮模块和账号菜单识别。
3. 鼠标滚轮位于悬浮模块内时，不再触发画布缩放。
4. 显式恢复悬浮模块及其子元素的 pointer events。
5. 保持画布空白处拖拽、缩放和双击新增节点行为不变。
