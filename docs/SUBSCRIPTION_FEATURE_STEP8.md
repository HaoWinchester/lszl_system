# 第八步：订阅功能 UI 基础层

本步骤基于第七步校准后的订阅模型继续开发，目标是把“月度、季度、半年、终身”订阅从纯数据模型推进到可使用的前端管理流程。

## 本步新增能力

### 1. 用户中心：我的订阅

用户点击右上角账号名称进入用户中心后，会看到“我的订阅”信息：

- 学员：显示当前套餐、状态、精确到秒的有效期、倒计时天数、来源和续费入口，不在用户中心直接展示价格。
- 管理员 / 教师：显示“当前身份免订阅”。
- 游客：显示“游客体验，不进入订阅体系”。

### 2. 用户管理：学员订阅管理

管理员在用户管理页选择某个学员后，可以在用户资料下方管理该学员订阅：

- 查看当前套餐、状态、到期时间、来源和更新时间。
- 手动保存套餐、状态、开始日期、到期日期和备注。
- 按当前套餐开通或续期。
- 设为免费学员。
- 停用订阅。

非学员角色不会显示订阅编辑表单，因为管理员和教师免订阅，游客不进入订阅体系。

### 3. 系统设置：订阅套餐配置

系统设置页的“订阅套餐”从静态展示升级为可配置展示：

- 套餐名称
- 短名称
- 原价
- 折扣系数（%）
- 现价自动展示
- 标签文案
- 权益说明
- 是否启用展示
- 是否推荐套餐

配置保存在 `kg_subscription_plan_settings_v1`，不会修改基础权益和有效期逻辑。

## 相关 localStorage key

- `kg_student_subscriptions_v1`：学员订阅状态。
- `kg_subscription_plan_settings_v1`：套餐展示配置。
- `kg_subscription_plan_model_v2_migrated`：旧套餐模型兼容迁移标记。

## 仍然保留的边界

当前仍是纯前端本地原型：

- 没有接支付。
- 没有后端订阅校验。
- 不适合直接作为正式收费依据。

正式商业化时，应把用户订阅、订单、支付状态、退款、续期和到期校验迁移到服务器端。

## 下一步建议

第八步完成后，可以继续做：

1. 把关键功能按钮接入 `data-subscription-feature` 和 `KGSubscription.requireFeature()`。
2. 增加套餐购买页或升级弹窗。
3. 接入支付前的订单模型。
4. 后续再拆分题库管理和首页工具栏大文件。

## 第七步补充后的权益边界

- 订阅套餐增加季度会员。
- 所有学员套餐都包含学习包导入和学习包导出。
- 免费学员不再限制学习包导入/导出次数；免费学员首页图谱卡牌上限为 50。
- 学员套餐不包含发布试卷，发布试卷仍属于教师/教研角色职责。
- 套餐价格配置改为填写原价和折扣系数，现价和折扣标签自动计算。
