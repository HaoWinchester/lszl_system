# 基线重构 C-1.1 修复版

本修复版针对 `kg_graph_modularized_baseline_refactor_C1_1.zip` 做了完整的存储、切换、退出和布局回归检查。

## 已修复问题

1. **本地存储写入失败却返回成功**
   - 原实现中，`KGAppStorage.writeJSON()` 返回 `false` 后，图谱文件服务仍可能继续返回文件对象。
   - 会导致界面显示“新建/保存成功”，但刷新或切换后数据丢失。
   - 修复后所有文件库写操作都会校验真实结果；失败时返回 `null/false`，并保留 dirty 状态。

2. **保存失败后仍允许切换文件或退出账号**
   - 修复后，切换图谱和退出登录前保存失败会中止操作，避免覆盖或丢失当前修改。

3. **图谱标题与文件页签名称不同步**
   - 在“图谱信息”中修改标题后，会同步更新当前文件名、顶部页签和画布工具栏标题。

4. **旧版悬浮工具栏位置与新顶部工具栏重叠**
   - 旧版本保存的 `top: 18px` 等位置会被自动重新约束到顶部浮动工具栏下方。
   - 拖动时也不能再覆盖当前文件信息栏。

5. **达到文件数量上限时错误丢弃新文件**
   - 原实现可能在超过 200 个文件时静默截断，同时仍返回“创建成功”。
   - 修复后第 201 个文件会明确拒绝创建，已有 200 个文件保持不变。

6. **异常文件切换缺少回滚**
   - 文件内容无法应用时，恢复原当前文件，不留下“页签已切换、画布未切换”的不一致状态。

7. **页签刷新时横向滚动位置可能跳回**
   - 非主动切换导致的页签刷新会保留原滚动位置。
