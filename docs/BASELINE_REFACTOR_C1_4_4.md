# 基线重构 C-1.4.4

## 目标

修复移动端账号入口缺失和触摸设备无法关闭文件页签的问题。

## 修改内容

1. 在手机、平板及触摸设备上，将账号入口固定吸附在屏幕顶部右侧。
2. 移动端账号入口显示为“账号”。
3. 点击后显示下拉菜单，提供：
   - 用户中心（移动端显示“用户”）
   - 帮助中心（移动端显示“帮助”）
   - 升级会员（移动端显示“升级”）
   - 登录或退出登录（移动端显示“登录”或“退出”）
4. 桌面端保留完整菜单文字和原有右上角悬浮布局。
5. 移动端页签栏为顶部账号入口预留空间，避免覆盖文件页签。
6. 在触摸设备和无 hover 设备上，文件页签关闭按钮常显且可直接点击。

## 保持不变

- 不修改图谱文件数据结构。
- 不修改自动保存和旧数据迁移逻辑。
- 不修改用户、权限、套餐、订单和卡密数据结构。
- 关闭页签仍只关闭当前页面页签，不删除图谱文件。
