# 文件管理 v8.4.22：文件卡片布局与操作状态修复

## 规则

- 只有图谱文件可以使用标签；文件夹不支持收藏和标签。
- 每个图谱文件最多一个标签。
- 文件拥有标签时自动进入“我的收藏”；移除标签后自动退出。
- 标签删除后，关联文件自动变为未收藏。

## 轻量交互

- 文件卡片不再显示收藏星标。
- 已打标签的文件在右下角显示彩色标签图标；点击可直接更换、移除或创建标签。
- 未打标签的文件不显示角标，可通过右键“添加标签”、详情抽屉或批量工具栏打签。
- “我的收藏”页面显示全部标签，可按单个标签筛选收藏文件。

## 兼容迁移

- v8.4.0 只有收藏状态、没有标签的文件自动归入内置“收藏”标签。
- 旧文件存在多个标签时只保留第一个有效标签。
- 文件夹上的收藏状态会被忽略并在后续写入时清除。

## v8.4.13 标签圆点交互

- 文件卡片右下角使用圆点作为标签入口。
- 已打标签显示标签颜色实心圆；未打标签仅在卡片悬浮、选中或键盘聚焦时显示空心圆。
- 标签选择菜单不使用复选框；“不打标签”代表清除标签。
- 创建标签使用二级菜单，支持悬浮、点击及键盘焦点展开，创建后立即应用到当前文件。
