# 微信账号关联验证记录

## 已实现

- 账号密码注册成功后提示绑定微信，可稍后绑定。普通密码登录、微信注册/登录不重复提示。
- 首次网页微信扫码不自动创建账号；验证已有账号密码后绑定原账号，或明确选择创建新微信账号。
- 已绑定微信直接进入原账号，共享原账号会员和学习记录。
- 用户中心提供找回原账号会员入口，需要当前账号会话、再次扫码确认当前微信、原账号密码。
- 恢复只迁移网页微信登录身份，不删除账号、不自动合并学习记录。来源存在小程序身份、非免费订阅或任何历史订单时转人工核对；目标已有其他微信时禁止覆盖。
- 一次性凭证十分钟有效、五次错误密码后失效，并发只允许一次成功；退出或取消操作注销凭证。
