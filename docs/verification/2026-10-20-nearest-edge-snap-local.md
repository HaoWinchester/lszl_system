# 关系线端点按最近边中心吸附（仅本地）

用户反馈：拖动关系线端点吸附卡牌时仍跳回固定点，要求按拖动位置最近的边中心吸附。本次只修改端点重绑逻辑及共用几何模块，不改页面布局、连线外观或未拖动连线；等待本人本地验看，未发布 UAT。

## 实现

- 复用 graph/edge-geometry.js 的线段距离计算，在卡牌世界坐标的四条边中选择最近边。
- bindLinkEndpoint 使用拖动中的自由端点坐标选择 fromPort/toPort，覆盖该端原有方向。另一端保留，旧连线不迁移。
- 显式方向仍使用原有卡牌轮廓坐标；圆形、三角形的轮廓算法未改。原有手动曲线保留规则、空白处解绑、取消与历史逻辑不变。

## 验证

- 修改前定向用例复现旧方向未更新；修改后几何、端点手势及固定端口 51 项通过，前端图谱入口 8 组通过。
- 隔离真实 API 浏览器：两端分别拖向四边，在缩放/适应后的坐标中核对实际 SVG 端点与卡牌 DOM 边中心一致；每种方向撤销/重做通过；取消恢复旧方向，重新绑定其他卡牌正常。
- 由实际拖动选择 bottom 端口，API 保存后刷新仍为 bottom，实际连线仍位于下边中心。原有自动端口连线不变。
- 浏览器 fixture 44218 退出 0，临时数据库清理无遗留；证据 artifacts/nearest-edge-snap-20261020/final-api/ 与 final-api.log。
