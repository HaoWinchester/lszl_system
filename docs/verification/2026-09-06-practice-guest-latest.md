# 不限比例发布、游客做题大厅、最新标签与月度会员描述

## 范围

- 游客目录开放学生可见的已发布试卷摘要；仅教师可见、已撤回试卷不公开。题目详情和题目快照仍要求登录，游客响应不含发布人、权限配置或自定义元数据。
- 大厅始终保留试卷库、题量设置、挑战/学霸/复仇模式。游客点击模式打开共享登录框。登录与退出都刷新目录并清除旧缓存。
- 试卷库和“更多”抽屉共用试卷卡片；实际发布时间距当前不足 72 小时显示“最新”。未来时间、缺失时间、恰好 72 小时及更早的试卷不显示。
- 不限比例发布：两个发布入口共用实际领域统计，按已选题目冻结分布；不再以固定 42% / 50% / 8% 拒绝发布。未分类题目仍会指出具体题号。自动组卷阶段的配额校验保留。练习报告将相对题数转为总计 100 的百分比，支持零题领域。
