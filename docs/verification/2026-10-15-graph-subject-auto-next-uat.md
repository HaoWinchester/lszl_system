# UAT 配题科目、自动切题与大厅样式修正

本批承接 v9.0-p4.1.332 的用户 UAT 反馈，等待用户本人验收；main 不变。

## 根因与行为

- 用户报告基本所有图谱匹配不到题。UAT 只读核查：3406 道有效题均为 PMP；203 张图谱使用 `PMP / 项目管理`，原实现把自由描述与题库科目做严格相等比较，导致全部被过滤。8 张真实卡片旧查询均为 0，去除错误条件后各至少 3 道。
- 按用户补充，批量配题新增“匹配科目”下拉，默认 PMP，其他选项从服务端有效题目的科目读取；预览使用显式科目，切换清空旧预览。后端规范化斜杠第一段、空白和大小写，保留 PMP/PMI-ACP 隔离；旧客户端不传科目时仍兼容图谱描述。预览响应和签名记录所选科目。
- 新服务在 UAT 容器内存中执行只读预览，未修改部署代码或业务数据：`PMP知识点关系图谱` 的 11 张有内容卡片各返回 3 个候选，2 张无有效内容的未命名卡片仍返回 0。
- 普通练习关闭实时反馈后，完成作答沿用 520ms 定时器进入下一题；多选和配对确认前不跳。手动导航、反馈开关变化、打开退出确认会取消待执行切题。末题边界及原有全部作答完成/结算规则保留。
- 用户截图的学习记录/收藏标签、行操作按钮被公共 CSS 的高优先级圆角与全局阴影/悬停位移覆盖。仅对大厅 recent 区域显式重置，恢复紫色文本与下划线标签；同时统一四模式卡片高度，保留焦点轮廓。

## UI 对照方式与限制

原批准参考是 `artifacts/pmp-review-20261014/practice-ui-concept.png`。此前发布记录的 0.000% 是源/发布页面一致性，不能作为设计稿还原验收；本次明确区分两种比较。

- 实际页面与原稿使用同一 1505×1045 视口，保留真实隔离测试数据，未遮罩任何区域。按通道差值大于 24 的像素统计，整页为 9.6148%，近期学习局部为 6.1353%。局部保持原像素比例，共同裁剪到 1175×223，标签与操作按钮均包含在内。
- 这些数值是差异记录，不是“像素级一致”通过结论。原图为概念位图；页头、字体与面板尺寸仍有差异，原图三模式而用户要求保留四模式，账号/经验/时间/试卷/记录状态也不同。此次修复用户标出的圆角胶囊、阴影与模式卡片不齐问题，没有将其他既有页面结构重写成静态示例。
- 对照与证据：`artifacts/graph-batch-subject-fix/ui-reference-vs-after-comparison.png`、`ui-recent-reference-vs-after-comparison.png`、`ui-live-before-recent.png`、`ui-live-after-recent.png`、`ui-design-comparison.json`、`ui-evidence.md`。
- 本次实现未调用 Image 2.0 或其他生图工具；沿用已批准参考，不对原图的历史生成模型作无证据断言。

后续页面交付必须同时保存批准 UI 稿、相同视口的实际截图、逐区域对照与像素差异图；明确动态数据、已有产品约束及未还原细节，控件本身不能被遮罩。源/发布包一致性检查继续保留，但不得替代设计稿对比。
