# 小程序 1.0.7 弱网体验优化

## 范围与原因

用户在体验版切换 Tab 时明显等待，改用蜂窝网络后改善。现有主导航已采用单页常驻四个组件，导航本身不等待接口；首页和个人中心原先等待全部接口后才显示主要内容，放大了慢接口的影响。

本次仅修改小程序。首页和个人中心采用共享的独立区域加载方法，先返回的区域先显示；菜单保持可用，刷新失败保留已有内容。成长页复用现有 30 秒刷新策略，学习数据变更仍立即使其失效。试卷首批及后续分页从 100 调整为 20，完整列表仍可继续加载。

HTTP 层仅合并同地址、同账号、同时进行中的无请求体 GET，不缓存已完成的业务响应，不合并写操作。旧账号的成功或 401 响应不会覆盖新账号数据或清除新登录。

- GET 成功/失败后可重新请求，写操作不合并，账号切换期间旧响应被拒绝，旧 session 校验不将新账号送回登录页。

## 验收边界

自动化和模拟器检查属于开发自检，不等于用户 UAT 通过。未测量用户手机及原 Wi-Fi 网络的切换耗时，不承诺固定提速比例。请用户关闭手机小程序调试，重新进入体验版 1.0.7，分别用原 Wi-Fi 和蜂窝网络检查首次进入、反复切换、做题返回后的数据更新。

本次客户端包上传即为小程序验收部署，未改后端/PC，服务器无需重新部署。按仓库规则将代码合入 UAT；main 与正式服务器维持原状，待用户明确验收。
