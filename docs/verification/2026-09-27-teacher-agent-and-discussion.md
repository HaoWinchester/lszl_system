## 服务器复用及内存
- 模型固定 glm-5.3-flash[1m]，使用服务器已有 Claude Code 和 GLM Coding Plan 配置，无普通按量接口回退。实际 Compose 容器调用成功；不能把普通 docker --env-file 对引号的不同解析误判为 Compose 凭据失败。
- worker 直接从已构建 API 镜像复制 Python runtime；实际 Python 二进制 SHA256 与 50 个包名称/版本集合指纹相同。Office/OCR apt 层命中 CACHED，Python 复制耗时 1.3 秒，无重复下载；worker 和转换器共用同一镜像。Claude 二进制只读挂载复用。
- 旧 DOC/PPT 通过该镜像、真实内网转换器端到端验证，分别保留 153/53 个中文字；临时验证容器已清理，没有安装重复依赖。
- 非 root UID 10001，read-only、cap_drop ALL；转换器仅内部网络，无端口和共享卷。全局单个重任务，worker 640 MiB、转换器 384 MiB 限额。
- UAT 浏览器期间 90 次、约 197 秒采样：worker 最大采样值 305.2 MiB，转换器 37.7 MiB，API 190.4 MiB；主机最低 MemAvailable 1424 MiB。三容器 OOM、异常重启均为 0。内核没有 memory.peak，以上是采样最大值，不是精确历史峰值。
