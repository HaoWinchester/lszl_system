# 课堂登录失效、文字草稿与画布恢复

用户授权修复 R1，完成开发验证后部署 UAT，由用户验收。R3 指知识图谱内部做题，本次保持其业务行为。不得以开发测试代替用户 UAT 验收，不合入 main。

## 原因与修复

- 正式事故日志显示主动 `/auth/logout` 后，回忆进度仍连续发送 35 次 PUT 并收到 401；重新登录后恢复。日志不足以判定最初触发退出的具体操作。旧实现还存在固定七天 Cookie 不续期，以及网络/5xx/解析异常被错误缓存成游客的独立风险。
- 认证恢复统一到公共模块：真正的当前会话 401 暂停写入、保留原账号与课堂；网络/5xx 不清身份，迟到的旧请求不覆盖新登录。前台活跃页面显式续期，服务端按账号和会话撤销旧 Cookie，覆盖退出、替换登录、微信切换及迟到响应竞态。
- 保留原文字编辑器、画布、未提交表单和保存队列。切换工具立即执行，不等待网络保存；同账号重登后恢复保存，修订冲突仍返回冲突，不覆盖较新数据。
- 所有同源业务请求统一携带会话标识，跨账号/文件/工作区和延迟 JSON 响应均有上下文校验，避免旧课堂写入新账号。跨标签页身份变化会暂停原课堂。
- 主动退出先处理草稿；保存失败、超时或期间新增输入会保留课堂。图谱节点表单、多题结构表单、个人卡片内联编辑、分组/连线标签、回忆自建子卡片都纳入草稿保护。
- 未提交表单不会因重新登录自动生成节点，保留输入，仍需用户明确保存/生成；未保存业务内容仅保留当前页面内存，关闭或离开页面提示风险，不新增浏览器业务数据存储。
- 新增数据库迁移 `1b6f9a2d4c80` 和会话撤销记录；没有修改图谱内部做题的题型、跳题或解析规则。
