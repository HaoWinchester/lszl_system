## 新增验证内容

在 pytest 自动创建、迁移并销毁的 PostgreSQL 隔离数据库中，复用现有试卷 fixture 创建三题免费卷，并给冻结题目快照加入英文题干与选项。微信 code 换 openid 的提供方仍为模拟，以下 HTTP、FastAPI、数据库、客户端服务与页面处理函数使用实际实现：

1. 过期会话得到 401，清理本地身份并跳转登录。
2. 新微信身份进入绑定/注册，注册后可验证会话。
3. 该新学生账号必须能找到指定免费卷；不能用空数组通过测试。
4. 首页加载完成，首页数据及成长部分均无错误。
5. 练习设置页创建会话；做题页三道题均有中文、英文和双语选项。
6. 答错第一题并保存退出；删除本地草稿后，重新打开仍能从服务器恢复到第二题，已答数为 1。
7. 答对后两题，等待自动交卷完成；报告为 2 对、1 错，历史可打开报告，今日成长计数为 3。
8. 退出后已绑定微信再次登录；错误密码和失效绑定凭证可以恢复，表单错误不触发重启页面。
9. 注册服务器提交成功、本地会话保存失败后，重新微信登录可恢复同一账号，不重复注册。
10. 另一个新学生账号无法读取第一账号的会话或报告（404），历史中也不会出现该记录。

联测首次扩展时曾过早在异步自动交卷结束前读取状态；确认原因后改为等待页面完成或出现错误。此处调整的是测试等待条件，不是业务缺陷修复。
