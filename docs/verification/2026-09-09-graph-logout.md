# 图谱退出保存修复

## 原因与行为

正式 v220 的无当前文件账号进入自由图谱，bootstrap 的 fitView(true) 将预览图谱标记为待保存；queueSave 因 current=null 同步返回失败，退出因此被拦截。用户浏览器实际控制台错误为“远端图谱文件尚未初始化”，并非浏览器存储空间不足。

- 初次居中不触发保存；无文件预览仅改变视口时不创建文件、不阻止退出。
- 真正编辑预览后，复用文件 API 创建、选择并保存当前图谱。选择请求失败保留已创建文件，重试不重复创建；页签同步显示该文件。
- 自动保存返回同一个未完成写入 Promise，保存过程中产生的新修改继续保持 dirty。
- 退出、手动保存、自动防抖保存、标题保存均等待真实结果。失败保留会话及修改；退出前继续保存请求期间的新修改。
- 连续改标题使用最新标题作为文件名，排队保存执行时读取当前 revision，避免假成功和过期版本冲突。
- 不改后端、会员或微信认证业务。
