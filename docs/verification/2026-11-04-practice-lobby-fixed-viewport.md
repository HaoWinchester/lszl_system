# 大厅一屏展示与操作区对齐

## 用户反馈与范围

用户截图要求：开始按钮与练习题量、试卷顺序在同一垂直位置；大厅页面不出现整页滚动。保留既有字体、颜色、功能以及先前知识图谱做题弹窗与按需加载优化。

## 局部实现

- 开始操作区复用fieldset与相同legend行高，隐藏占位标题，三个控件保持37px且上下对齐；继续练习出现“新开一轮”时首个按钮仍对齐。移动失败重试按钮到三个操作区之后，避免异常进度状态拆散网格。
- 固定大厅外壳为100dvh，解除子区域默认最小高度；常见桌面短视口只收紧留白和卡片最小高度，使完整内容一屏显示。
- 较窄或较矮窗口通过大厅内容区滚动保持所有按钮可达，不裁切业务内容。页头与侧边导航保持可用，整页不滚动。
- 滚动限制仅作用于data-practice-view=lobby，答题与报告保持原来的长内容滚动。

## 开发自检证据

- 新viewport浏览器契约覆盖10种视口×普通/继续状态：1504×801、1440×900、1366×768、1280×768、1280×720、1024×768、768×844、390×844、320×568、390×480。验证整页不滚动、按钮基线、桌面一屏、窄屏末端按钮可达，以及游戏/报告真实鼠标滚动仍可用。
- fidelity回归包含1440/768/390/320宽度、搜索右对齐、按钮等高和垂直对齐、失败重试布局、复仇规则位置与键盘滚动。
- 真实隔离API的demand浏览器、答题卡和侧边导航/帮助浏览器通过。初始仍为2个脚本；首屏数据仍是12条摘要。
- 使用本地候选HTML/CSS配合UAT只读真实目录做预检，7种视口通过。1504×801、1366×768、1280×768均无大厅内容溢出；窄屏内部滚动后末端操作可达，复仇提示向上且不改变页面高度/scrollY，无JS错误。
- 前端404项、Python契约9项、部署门槛4项及design5项通过。首次测试中同时递增版本造成3项运行上下文变化失败；完成构建同步后，稳定输入下完整重跑通过，未放宽断言。
- 独立只读审查通过；额外实测1024×480滚动后普通帮助弹层上下点位均可命中，未出现内容区裁切。
- 证据保存在artifacts/practice-lobby-viewport/。新增viewport契约已纳入正式release验证脚本。
