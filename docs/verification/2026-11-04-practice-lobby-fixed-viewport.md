# 大厅一屏展示与操作区对齐

## 用户反馈与范围

用户截图要求：开始按钮与练习题量、试卷顺序在同一垂直位置；大厅页面不出现整页滚动。保留既有字体、颜色、功能以及先前知识图谱做题弹窗与按需加载优化。

## 局部实现

- 开始操作区复用fieldset与相同legend行高，隐藏占位标题，三个控件保持37px且上下对齐；继续练习出现“新开一轮”时首个按钮仍对齐。移动失败重试按钮到三个操作区之后，避免异常进度状态拆散网格。
- 固定大厅外壳为100dvh，解除子区域默认最小高度；常见桌面短视口只收紧留白和卡片最小高度，使完整内容一屏显示。
- 较窄或较矮窗口通过大厅内容区滚动保持所有按钮可达，不裁切业务内容。页头与侧边导航保持可用，整页不滚动。
- 滚动限制仅作用于data-practice-view=lobby，答题与报告保持原来的长内容滚动。
