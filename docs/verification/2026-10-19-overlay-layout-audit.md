# 工具栏与弹窗布局检查（仅本地 v355）

用户要求全面检查其他工具栏、弹窗的位置跑偏、屏幕越界和遮挡问题；仅更新本地，不部署 UAT。本轮保留原有入口、模式及卡片配色，只修复可复现的布局与点击问题。

## 已修复的原因与表现

| 问题 | 原因与修复 |
|---|---|
| 右键“层级”子菜单底部选项点不到 | 原实现仅左右翻转，没有完整纵向收边；按实际子菜单高度约束位置。 |
| 固定调色窗缩窗后越屏 | 手动拖动后缺少宿主尺寸变化重定位；增加 resize、visualViewport 和 ResizeObserver，销毁时清理监听。 |
| 颜色窗口被卡片工具栏盖住 | 调色窗口层级低于节点工具栏；恢复合理层级，同时让公共定位避让全局快捷栏。 |
| 节点、连线、文字工具栏被全局快捷栏覆盖 | 公共布局此前只考虑画布内障碍；统一纳入文档级可见快捷栏，全局快捷栏也避让主工具栏与底部 dock。 |
| 主工具栏拖到右侧后菜单跑到屏幕底部 | 多个障碍的候选次序优先命中远处空位；侧向菜单先遍历横向候选，优先处理触发器所在工具栏，再考虑纵向。使用两组真实失败坐标补回归。 |
| 模板预览拖动、缩窗后操作按钮出屏 | 原拖动仅保留标题栏可见；改为约束完整窗口，并在 resize/fullscreen 时重新收边。 |
| 模板预览全屏后被模板中心覆盖 | 通用 overlay 错把其他弹窗移入全屏预览子元素；共享模块识别独占 dialog，全屏时只迁移所属浮层。画布事件隔离同步识别 dialog，避免吞掉按钮点击。 |
| 画布全屏打开“学习入口”后全部无法操作 | 弹窗未进入全屏宿主，且 inert 禁用了弹窗自身祖先；只禁用祖先路径各层的兄弟元素，退出时准确还原既有 inert/aria-hidden 和焦点。 |
| 详情窗拖动后缩窗，窗口和关闭按钮出屏 | 对拖动过的详情窗增加缩窗/全屏重新定位，并约束手动宽度。 |
| 搜索面板左侧输入区被主工具栏挡住 | 搜索打开前关闭临时菜单，并调整到主工具栏上方；实际点击输入框左侧并输入验证。 |
| 800px 偏好设置右半边及关闭按钮出屏 | 响应式 CSS 将面板扩至 784px，JS 仍按 320px 定位；改为按实际 border-box 宽度计算。 |
| 长文字草稿越界、临时画布输入框被遮挡 | 编辑器使用可滚动的可视框收边；保留自然文字尺寸、换行与世界坐标。临时画布明确传入所属浮层宿主。 |
| 画笔工具栏与缩略图/缩放控件重叠 | 按实际可见 dock 矩形上移画笔工具栏；多题画布和深度回忆小窗口底部控件错层摆放。390px 深度回忆统计条同时收边。 |

这些是定位、宿主、响应式尺寸和叠层实现问题，不是需求要求改掉原来的功能或视觉样式。整合复测还发现并修复了本轮新增避让逻辑的两处候选优先级问题。
