# 未做题优先短练与后续优化分析

## 本轮已实现

用户明确选择：同一试卷优先没做过的题，剩余不足时用已做题补足所选题量。只在本地开发预览，不推送、不部署 UAT。

- 默认网页/小程序共享服务端选题；按用户与发布版本统计实际已保存作答。答错算已做；未提交、跳过、超时占位不算；隐藏历史报告不抹掉已做记录。
- 试卷顺序/随机均先选未做题，其余补复习；一轮不重复，同一版本做完后显示整轮复习。新版发布重新计算覆盖，不跨版本猜测题目是否相同。
- 案例保持完整，通过公共选题模块在所选题量内尽可能多选未做子题；若无法容纳任何未做案例则提示可用题量，避免静默全选旧题。
- 每次会话冻结本轮未做/复习数量，网页、小程序练习与报告显示相同提示；继续原会话不重选。
- 修正精简 enter 响应漏传 selectionSummary；修正小程序从报告再次进入时把上一轮题数当作全卷题数；重练按钮改为“开始新一轮练习”。

- 案例、多题型、判题相关回归 21 项通过；覆盖多选/配对答案形状、用户与版本过滤、隐藏报告、未提交草稿排除。
- 前端 `pnpm test`：299 项 Node、9 项 Python 与部署脚本夹具通过。运行夹具不等于部署；未调用发布脚本。
- 小程序全量 308 项通过；网页新提示、旧做题契约及关闭按钮专项通过。
- 独立只读审查发现案例超出题量时静默选旧题，已修复并补回归；复查无新增阻塞项。
- 真实本地浏览器、独立数据库中的 23 题试卷：通过界面连续完成三轮，第1轮10新、第2轮10新且与第1轮无交集、第3轮3新+7复习；第4轮10复习。手机390px无横向溢出，提示与服务端冻结摘要一致。

## 后续建议（只读分析，未开发）

| 优先级 | 问题 / 价值 | 建议与边界 | 证据 |
|---|---|---|---|
| 高 | 10题短练仍显示模拟考试 PASS/FAIL，样本不足却给出领域等级，容易误解掌握程度 | 区分“短练习小结”和“模拟考试报告”；没有覆盖的领域标记未评估 | backend/app/services/practice_session_service.py build_report 附近，new-legacy/src/113-practice-result-report.js 固定报告标题 |
| 高，低成本 | 教师工作台把曾发布后撤回的卷仍计为已发布 | 按当前发布状态计数，历史发布版本另行展示 | new-legacy/src/91-teacher-workbench-app.js paperPublished 使用 status 或 publishedVersion；backend/app/services/paper_release_service.py withdraw 保留历史版本号 |
| 高 | 内容完整性检查未形成教师可处理清单；不同题型解析校验不一致 | 发布前列缺失解析/答案/语言内容，点击跳转修订；按实际开放语言检查，不强迫全部补英文 | backend/app/services/question_answer_service.py、paper_release_service.py；本轮只读审计569题中英文解析缺失79 |
| 中高 | 反馈有处理/回复能力，但题目和版本标识只放在可编辑文本里 | 保存结构化上下文，提供原版本/当前题跳转和修复版本关联；教师处理权限需单独确定 | new-legacy/src/103-support-center.js、105-feedback-management-app.js |
| 中高 | 报告建议泛化，做完后缺少明确下一步 | 按本次错题直接进入已有复盘/补救验证，避免重复建设错题系统 | practice_session_service.py 报告建议、113-practice-result-report.js 报告动作、100-practice-mode.js 已有补救链路 |
| 后续 | 使用分析有时长和访问，暂不能解释练习完成和中断 | 增加聚合开始→完成、暂停→恢复指标；不把时长当专注度，不开放个人轨迹 | new-legacy/src/36-system-settings.js 新口径表格与趋势 |

上述后续项来自静态代码核对，未作为本轮功能擅自实施；建议先做前三项。
