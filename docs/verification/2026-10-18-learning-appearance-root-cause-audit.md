## 已复现并修复的缺陷

1. **服务器行 ID 与 payload.id 不一致时，直链可能创建空别名并覆盖原画布**：加载后、页面 ensure 前规范化 URL；移除创建冲突后盲 PUT。未知碰撞明确报错并保留原数据。
2. **切账号后旧保存/删除回调可能使用新身份**：保存队列绑定 owner/generation，切换时取消请求、清除旧队列和映射；延迟删除、页面切换的 catch/finally 同样检查身份/session。后端 create/update 拒绝显式 payload.userId 与当前用户不一致，兼容原来无此字段的历史调用。
3. **切账号页面提前激活缓存**：新账号服务端加载完成前锁定编辑、清除旧显示；仅当前 session/owner 可以激活服务器画布。
4. **加载失败仍允许编辑缓存**：初始化 GET 错误向页面报告；缓存只供查看，禁止未经服务端加载的保存。访客正常 401 不作为异常。
5. **空服务器列表回传本地摘要、或复活过期缓存**：不再自动上传列表摘要；空的权威列表清理当前用户过期正文与目录。
6. **BFCache 返回后停止自动保存**：pagehide 不销毁 store 订阅，pageshow 恢复页面离开状态。
7. **刷新覆盖未保存修改，服务器读取触发反向保存**：有待保存内容时拒绝 refresh；加载过程中新增的编辑保留并排队，不用旧 GET 覆盖；忽略 server-hydrated 通知产生的回写。
8. **取消颜色预览仍残留手工配色标记，影响后续预设**：取消时完整恢复 appearance 与 manualAppearanceFields，包括字段原本不存在、值为 undefined、空数组和已有手工字段的情况。
9. **初始光标 RAF 覆盖用户已建立的选区**：真实浏览器固定延迟回调复现选择被折叠，可能令快速替换变追加；仅同一编辑 session 且尚未聚焦时执行初始定位。
10. **图谱升级会员按钮也存在 hidden 被覆盖**：实测三个页面的所有 hidden 元素，发现该按钮可见；增加对应按钮的明确隐藏规则，不改正常订阅行为。

以上保存缺陷在本次修复前已存在；不能将全部问题都说成 v343 新引入。新的身份锁与缓存失败保护也经过独立复核，审查中发现的旧 finally 提前解锁已一并修复。

- **文字边缘反馈**：原实现刻意不显示拖动点；动态画笔光标的 `cursor:inherit!important` 又覆盖了缩放点光标。共享画笔模块恢复悬停显示的八个白底蓝边点，保留较大的透明命中区，边缘 grab、拖动 grabbing、缩放点对应方向箭头。编辑中的文字边框和点可直接移动草稿，保留焦点、选区和输入法状态；结束编辑后的点仍执行原有缩放。缩放时点保持屏幕 8px，全屏复用既有 overlay 挂载能力。
- **曲线方向**：已只读查看原生博思的财务计划扇形分支，自动曲线使用水平出入切线，上下镜像。实际用户图谱读取到历史 curveControls；拖端点时原流程会固化自动曲线，改接另一卡又保留旧控制点。现在自动曲线持续随端点计算，已有绑定改接不同卡时重算曲线；同一卡手调、自由端点、折线及撤销保留。不会批量重写用户历史手调路径。实测额外发现改接后右侧详情仍显示旧节点标题，补充局部详情刷新并增加真实浏览器回归。
