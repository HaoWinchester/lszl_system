## 开始前

1. 使用桌面 Chrome，先将**浏览器页面缩放**设为 100%。本文所说“画布缩放”指页面内左下角的缩放控件，二者不同。
2. 登录管理员或教师账号。准备一份专用验收图谱、两份多题画布 A／B、一组可以进入深度回忆的测试题；删除、重置和断网实验都只用这些测试内容。
3. 图谱准备两张有文字的卡片和一条连线；多题画布准备至少三张可编辑卡片，其中两张组成同一分组。若编辑工具未显示，图谱切到可编辑的专业模式。
4. 有条件时准备升级前保存的图谱、多题画布和回忆记录，并留一张原状态截图，用于检查兼容性。
5. 深度回忆使用**尚未生成回忆卡的新题或专用空白进度**检验新匹配规则。已保存的历史卡片会保持原样，不能用历史卡片未自动改变来判断新规则失败。
6. 每项完成后勾选其标题；**仅通过才勾选**。失败记编号和实际现象；缺样例、缺账号或缺设备记“待补”，不能计为通过。

建议反馈格式：`编号｜通过／未通过／待补｜实际现象｜截图或录屏`。

## A. M0：旧内容与基础操作

M0 的旧测试校准、发布文件完整性已由开发检查负责，这里只检查用户能感受到的内容与操作是否保持正常。

- [ ] **A01　三页入口可正常使用**

**操作：** 登录后依次进入知识图谱、多题归纳、深度回忆；后两页选择实际可访问的试卷或题目。每页执行一次选卡、拖动画布、缩放，最后刷新。

**预期：** 无白屏、长期加载或按钮失效；卡片能正常显示，拖动和缩放有响应，刷新后仍能进入相应内容。无可访问试题时记“待补题目”，不计通过。

- [ ] **A02　升级前保存的内容没有丢失〔需要旧样例〕**

**操作：** 打开旧图谱、旧多题画布、旧回忆记录；与原截图核对卡片文字、连接关系、笔迹、自定义内容。未编辑时刷新一次再看。

**预期：** 原内容仍在；不会因升级自动删除卡片、清空笔迹或替换用户填写的回忆内容。没有旧样例时记待补。

- [ ] **A03　笔迹保存与撤销正常**

**操作：** 三页分别画一条普通笔迹和一条荧光笔迹；撤销一次、重做一次；等保存完成后刷新。记录：图谱 □　多题 □　回忆 □。

**预期：** 撤销／重做只影响相应操作，卡片及连线不丢失；刷新后两条笔迹恢复，位置与内容对应。未保存成功前不要刷新。

## B. M1：删字、输入与全屏（T01）

- [ ] **B01　删除文字不误删卡片**

**操作：** 在图谱中双击卡片文字进入原位编辑；把光标放到文字末尾，按 Backspace；再把光标放到文字中间，按 Delete（键盘没有独立 Delete 时可用对应前向删除键）。打开详细编辑窗口，在标题／说明输入框中重复删字。

**预期：** 只删除输入框中的文字，不弹“删除卡片及关系线”确认；整张卡片和连线仍在。

- [ ] **B02　整卡删除仍有确认，取消有效**

**操作：** 结束文字编辑，点击空白处，再单击测试卡片选中；按 Delete／Backspace；在确认框中选择取消。

**预期：** 此时可以出现整卡删除确认；取消后卡片和关联线保留。区别于 B01，光标不在输入框中时才执行对象删除。

- [ ] **B03　中文输入与编辑快捷键不误操作画布**

**操作：** 在图谱文字、画笔文字和回忆自定义卡输入框中使用中文输入法；按空格选词、回车确认候选。选中一段文字后执行复制、粘贴、撤销。

**预期：** 中文候选确认不提前提交、不新增卡片、不删除对象；空格不拖动画布；复制粘贴和撤销作用于正在编辑的文字。三页对应输入位置均检查。

- [ ] **B04　图谱全屏详细编辑可打开、保存与取消**

**操作：** 点击画布内的全屏按钮；选中卡片，在详情面板的操作菜单中点编辑。修改说明并保存，再打开确认；随后改成另一段内容并点取消。鼠标放在编辑窗口内滚动。

**预期：** 编辑窗口在全屏中可见且可点击；保存的内容保留，取消的修改不保留；滚动编辑窗口时，底层图谱不被意外缩放。

- [ ] **B05　三页全屏画笔文字可输入、保存与取消**

**操作：** 每页进入画布全屏，打开画笔中的文字工具，在空白位置点击并输入“UAT 全屏文字”。保存一次；再新建一段文字，输入后点击取消。记录：图谱 □　多题 □　回忆 □。

**预期：** 输入框出现在点击位置附近且可操作；保存的文字留在画布上；取消的文字不新增；退出、再进全屏后工具仍可用，没有多余输入框或按钮残留。

- [ ] **B06　全屏设置与未完成编辑能正确恢复**

**操作：** 三页分别进入全屏，打开左下角画布设置；临时换一种背景色，退出全屏后点取消。另开一个画笔文字输入框，输入一段文字后退出全屏，继续编辑，再保存或取消。

**预期：** 设置窗口在全屏中可点，退出后仍可操作；取消恢复本次设置前的状态。退出全屏不会丢失正在输入的文字，不会重复生成输入框；最终保存／取消各自生效。

## C. M1：多题背景与水滴改色（T02）

注意区分右侧的**画布主题**与左下角设置里的**背景颜色／背景类型**：前者不能顺带覆盖后者。

- [ ] **C01　切换七种主题时背景不变**

**操作：** 在多题画布 A 的画布设置中选择护眼黄、网格背景并确认。依次选择平台默认、羊皮纸、极光绿、暗夜霓虹、樱花粉、海盐蓝、奶油拿铁。每次观察画布底色与网格。

**预期：** 卡片和界面主题按选择变化；画布仍为原来的护眼黄网格，不跟着主题换底色、图案或渐变。此条针对多题归纳，不要求深度回忆背景采用同样规则。

- [ ] **C02　主题、背景和卡片颜色分别保存**

**操作：** 在 A 保留护眼黄网格，选择一个容易辨认的主题，再给一张卡片设置自定义颜色。等待保存后刷新，再离开并重新打开 A。

**预期：** 背景仍是护眼黄网格，卡片自定义颜色仍在，学习主题保持已选状态；三者不会互相覆盖。

- [ ] **C03　A／B 背景独立，小地图不串色**

**操作：** A 设置护眼黄＋网格；B 设置浅蓝色＋纯色。按 A→B→A 切换；在 A 收起并展开小地图，刷新 A；再打开 B。

**预期：** A 始终保持黄网格，B 始终保持蓝纯色；收起／展开小地图、刷新或切换画布不会把 B 的背景带到 A。

- [ ] **C04　设置取消与只改背景类型**

**操作：** A 当前为护眼黄网格。打开设置，预览浅粉色和纯色后取消；再次打开，只把网格改为点状并确认；最后重开 A。再到 B，检查其蓝纯色是否保留。

**预期：** 第一次取消恢复黄网格；第二次确认后为黄点状，颜色不变；重开仍为黄点状，B 未被污染。设置弹窗如果阻挡切换画布，不需要强行切换或运行脚本。

- [ ] **C05　普通模式水滴按钮可给多张卡改色**

**操作：** 从空白区域拖出框选范围，选中两张未组成同一分组的卡片；点击选区工具栏中的水滴图标；选择红色，点击空白处关闭面板，再撤销一次。

**预期：** 水滴点击后出现正常大小的颜色面板；打开和选色时选区不丢失；两张卡片改为红色，未选卡片不变；关闭面板不会多记一笔重复操作，一次撤销恢复改色前状态。

- [ ] **C06　全屏水滴面板也能操作**

**操作：** 进入多题画布全屏，框选两张卡片，再点击水滴、选择绿色；关闭面板，退出全屏，等待保存后刷新。

**预期：** 面板在全屏中完整显示，色块可点，不被画布挡住；两张卡片改色成功，退出全屏和刷新后仍保留。

- [ ] **C07　同一分组改色与旧背景兼容〔部分需要旧样例〕**

**操作：** 选中同一分组中的两张卡片，用水滴更换分组颜色；关闭面板后撤销一次。另打开升级前带有海盐蓝／渐变背景的旧画布，先核对原背景，再切换主题并重开。

**预期：** 分组填色按选择变化，一次撤销恢复，卡片成员关系不变；旧画布原有底色、图案或渐变不会在首次打开时被强制换成默认灰底。没有旧画布时，只勾分组部分记录通过，整项标“旧背景待补”。

## D. M1：关键词匹配与自定义回忆卡（T03）

D01—D03 需要知道测试题的知识点关联情况。**没有匹配样例就记待补，不通过修改程序状态伪造样例。** 显式有效关联优先于文字匹配；历史卡片保持原样。

- [ ] **D01　没有匹配的关键词生成自定义卡〔需要无匹配题〕**

**操作：** 选一道关键词没有对应知识点、也没有预先有效关联的测试题。在空白回忆进度中点“揭示关键词”，点击这个关键词，再打开生成的卡片。

**预期：** 生成可编辑自定义卡；出现“卡牌标题”“我的回忆内容”和“保存我的回忆”；内容为空供自己输入，不会套用无关知识点解释。

- [ ] **D02　部分同名与多个候选不自动乱配〔需要匹配边界样例〕**

**操作：** 分别测试两类关键词：①只有部分字相同，如关键词“进度”，知识库只有“进度基准”，且无有效显式关联；②关键词精确对应多个候选知识点，且无有效显式关联。在新进度中点击关键词。

**预期：** 两种情况都生成自定义卡，不因包含相同字或取第一个候选而绑定系统卡。例子必须满足前述前提；若存在有效显式关联，不能按“部分匹配误绑”判断。

- [ ] **D03　合法关联与唯一精确匹配仍正常〔需要正向匹配题〕**

**操作：** 分别选一道具有明确有效关联的题、一道只对应唯一同名／别名知识点的题，在各自新进度中点击关键词。

**预期：** 显式关联指向指定知识点；唯一精确匹配指向正确系统知识点。不会把原本有正确关联的关键词全部变成自定义卡。

- [ ] **D04　自定义根卡可编辑、复用并保存**

**操作：** 使用 D01 的卡片，标题改为“我的影响分析”，内容填“先判断影响，再决定措施”，点“保存我的回忆”。关闭卡片窗口，再点同一关键词；刷新后再打开卡片。另把标题清空，尝试保存。

**预期：** 同一关键词复用原卡，不重复新增；刷新后标题和内容保留；空标题不能覆盖已保存的有效标题。

- [ ] **D05　自定义子卡与输入法正常**

**操作：** 打开一张回忆卡，在“输入你想到的知识点”中用中文输入法输入一个没有匹配的词；先用回车确认中文候选，再点“生成”。打开新子卡，编辑内容并保存，刷新检查。

**预期：** 确认中文候选时不提前生成卡片；点击生成后创建可编辑自定义子卡；父子关系、标题和内容重开后保留。

- [ ] **D06　历史卡片不自动改绑，主动转换可撤销〔需要旧记录〕**

**操作：** 打开一份已有系统根卡、子卡和连线的旧回忆记录；点击原关键词。再打开系统根卡，点“转为自定义卡牌”；观察子卡和连线，然后立即点“撤销转为自定义”。

**预期：** 仅打开旧记录或点击原关键词，不自动替换原卡；主动转换后可编辑，原子卡和连接关系保留；本次撤销恢复原系统卡及关系。

- [ ] **D07　切题和重置不会带入旧撤销记录**

**操作：** 在专用测试题中把系统卡转为自定义；切到下一题，再切回来。随后使用这份测试进度的重置功能，重新揭示关键词并生成卡片。

**预期：** 切题返回后，已保存的自定义内容保持，但不再提供上一会话的“撤销转为自定义”；重置后不残留旧卡片、旧笔迹或旧转换撤销状态，新卡不会被旧撤销误操作。

## E. M1：文字清晰度与缩放（T04）

以下各项都要在**知识图谱、多题归纳、深度回忆**分别执行。1% 时文字本来就很小，不能用“每个字都能看清”作为标准；重点检查放大后不持续模糊、回到原比例能恢复，缩放与点击位置一致。

- [ ] **E01　普通模式缩放后字形恢复清楚**

**操作：** 选含中文标题和正文的画布，依次调整到 1%、10%、20%、50%、100%、200%、400%，最后回到 100%；每次停止缩放后等待约一秒观察。保留 100% 和 400% 截图。图谱 □　多题 □　回忆 □。

**预期：** 放大后的文字不会一直像低清截图放大；停止缩放和回到 100% 后没有持续模糊、重影、错位。极小倍率允许自然变小、不可逐字辨读；不能出现放大后仍沿用模糊小字缓存的现象。

- [ ] **E02　全屏重复缩放，结果一致**

**操作：** 三页分别进入画布全屏，重复 E01 的倍率序列；退出全屏，再观察 100% 文字。图谱 □　多题 □　回忆 □。

**预期：** 全屏与普通模式均能正常显示文字；切换全屏不会让文字持续模糊，或造成文字、卡片边框分离。

- [ ] **E03　1% 和 400% 都能保存并恢复**

**操作：** 三页分别缩至 1%，等待保存完成后刷新／重开，检查倍率；再放至 400%，重复保存和重开。图谱 □　多题 □　回忆 □。

**预期：** 两端倍率都能保存、恢复；深度回忆不会拒绝 1% 或自动把它改成 20%；原卡片、连线和笔迹不丢失。若保存提示失败，记录提示，不能先刷新后当作缩放不恢复。

- [ ] **E04　放大后点击与拖动不偏移**

**操作：** 三页分别在 200% 和 400% 下点击卡片、拖动卡片、打开输入框；再回到 100% 检查位置，等待保存后重开。图谱 □　多题 □　回忆 □。

**预期：** 点击可见卡片就选中该卡片；拖动与鼠标位置一致；输入框不跑到远处；相关连线正常跟随，重开后位置与保存时一致。本项不验收后续的手工曲线控制点改造。

- [ ] **E05　真实业务大图没有明显交互退化〔需要大图〕**

**操作：** 用一份日常较大的图谱或画布，记录约有多少张卡片；连续平移、缩放、选卡、打开编辑，停止后观察文字，并与原来的使用体验比较。

**预期：** 不出现持续卡死、空白、频繁闪烁或明显新增的拖动卡顿；停止缩放后文字正常恢复。开发中的简单样本帧率不代替这项真实业务体验检查。

## F. 补充验收：设备、权限与保存失败

这些是补充检查，不要默认为已通过；若与日常使用环境相关，建议纳入本次验收。

- [ ] **F01　Safari／浏览器 125% 缩放〔开发尚未验证〕**

**操作：** 如日常使用 Safari，重复 B04—B06、E01—E04。另在 Chrome 菜单把**浏览器页面缩放**设为 125%，重复三页 100%／200%／400% 画布缩放、全屏编辑与设置。分别记录浏览器、页面倍率及截图。

**预期：** 浮层可见可点，文字无持续模糊，点击和拖动不偏移；不能把画布 125% 当成浏览器页面 125%。没有对应环境则记待补。

- [ ] **F02　只读账号或只读回忆仍不能编辑〔需要受限账号／记录〕**

**操作：** 用实际只读账号或打开明确标为只读的回忆记录，查看已有卡片／笔迹；尝试画笔、改色、编辑、转换自定义和重置。

**预期：** 在原本允许查看的范围内可浏览；原本不允许的修改入口隐藏、禁用或被拒绝，不能保存更改。不能通过本次修复获得额外访问权限。普通学生账号不自动等同于只读账号。

**操作：** 只在测试内容中执行。在 Chrome 开发者工具 Network 中切为 Offline，修改自定义回忆卡或画笔文字并尝试保存；观察失败后输入内容。保持页面打开，切回 Online，使用页面已有保存／重试入口；保存成功后再刷新。
