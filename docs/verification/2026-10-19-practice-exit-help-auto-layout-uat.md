# 弹幕退出清理和帮助及自动布局修复

用户授权修复退出弹幕残留、挑战/学霸问号悬浮说明、思维导图自动应用布局，开发自检通过后部署 UAT；大厅其他暂缓需求保持现状。

## 修改范围

- 练习统一 `setView` 在离开答题视图时清理 danmaku 来源；共享评论模块同时移除自建宿主。取消退出或保存失败不切视图，不提前清理。成功退出后重新进入可恢复当前题评论。
- 现有 `practice-answer-page.js` 只为挑战/学霸帮助绑定同一套悬浮、焦点和点击操作；点击固定或关闭，Esc/外点立即关闭，短延迟允许鼠标跨过图标与浮层之间的空隙。普通练习帮助及其他大厅 DOM/CSS 不改。
- 公共思维导图控件删除应用按钮，方向、根节点和作用范围变更执行原布局事务；未布局时先显示选择提示，打开面板不改图。保留无选区错误、撤销/重做、样式保护及原持久化。
- 新增回归接入标准发布门禁；迁移既有三个浏览器脚本对旧应用按钮的调用，未降低业务断言。

## 开发自检

- 原实现上的退出清理、hover 帮助、自动布局回归均先失败；独立复查又用连续鼠标轨迹发现 hover 空隙问题，补测先失败后修复。
- 现有侧栏/评论浏览器流程及新增取消退出、保存退出、结束退出、重新进入、两个帮助连续鼠标移动/焦点/点击/Esc/外点，在 1440×960、390×844 通过。
- 实际隔离 PostgreSQL/FastAPI 弹幕浏览器 11 组通过，包含取消退出、单次暂停保存 503、重试成功退出与恢复；同时覆盖评论收藏、点赞、权限及退出账号清理。
- 思维导图实际 API/浏览器通过四方向位置、每次操作撤销/重做、无选区失败及恢复、范围隔离、主题保护、保存刷新；图谱完整交互浏览器通过。
- 弹幕组件浏览器 7 项通过；前端 365 项 Node、9 项 Python 契约及 4 组部署脚本套件通过；设计契约 5 项通过。随后 hover 细节修复由定向回归验证，最终状态须以发布 full 门禁为准。
- 独立复查唯一重要问题已修复并复核。没有新增依赖或数据库迁移。
