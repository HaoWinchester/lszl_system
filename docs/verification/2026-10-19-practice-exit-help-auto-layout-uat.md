# 弹幕退出清理和帮助及自动布局修复

用户授权修复退出弹幕残留、挑战/学霸问号悬浮说明、思维导图自动应用布局，开发自检通过后部署 UAT；大厅其他暂缓需求保持现状。

## 修改范围

- 练习统一 `setView` 在离开答题视图时清理 danmaku 来源；共享评论模块同时移除自建宿主。取消退出或保存失败不切视图，不提前清理。成功退出后重新进入可恢复当前题评论。
- 现有 `practice-answer-page.js` 只为挑战/学霸帮助绑定同一套悬浮、焦点和点击操作；点击固定或关闭，Esc/外点立即关闭，短延迟允许鼠标跨过图标与浮层之间的空隙。普通练习帮助及其他大厅 DOM/CSS 不改。
- 公共思维导图控件删除应用按钮，方向、根节点和作用范围变更执行原布局事务；未布局时先显示选择提示，打开面板不改图。保留无选区错误、撤销/重做、样式保护及原持久化。
- 新增回归接入标准发布门禁；迁移既有三个浏览器脚本对旧应用按钮的调用，未降低业务断言。
