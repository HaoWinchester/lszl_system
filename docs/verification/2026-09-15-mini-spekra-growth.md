# 小程序视觉与成长改版验证

## 需求与范围
用户确认整体视觉与交互对标 Spekra，同时加入每日目标及连续练习。沿用既有幻谱知习小程序、原认证和作答链路。

## 验证矩阵
| 区域 | 正向操作 | 失败/恢复/边界 |
|---|---|---|
| 首页 | 继续上次、无会话开始、错题入口、今日目标、最近试卷 | 部分接口失败仍可练习；已结束会话转报告；重试 |
| 练习 | 科目筛选、搜索、模式选择、试卷详情、题量设置、开始 | 空结果、无权限、重复点击、tab 跳转保留模式、直接打开 |
| 作答 | 单选/多选/排序/匹配/案例/图片、翻页、标记、显示答案、交卷 | 保存退出失败重试、版本冲突、未答提醒、跨端恢复、重复保存 |
| 成长 | 今日计数、自动达标、修改目标、周历、里程碑、记录入口 | 次日生效、同题去重、跨日/跨月/跨年、断续、服务失败、其他用户隔离 |
| 我的 | 身份、会员、学习记录、错题、外观、法律、退出 | 会员限制、退出失败恢复、登录过期、新用户空数据 |
| 公共视觉 | 四个一级导航、二级返回、暖白/森林绿/橙色主按钮 | 深色模式、大字体、窄屏、长题、底部安全区、内容不被固定栏遮挡 |
