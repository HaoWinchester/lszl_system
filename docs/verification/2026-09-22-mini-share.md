# 小程序 1.0.8 好友分享修复

## 问题与范围

正式版 1.0.7 页面未实现 onShareAppMessage，用户无法发送给朋友。本次新增 domain/app-share.ts 公共分享适配器，由 app.json 的全部 13 个页面入口使用。主 Tab 宿主页提供原生页面分享回调，四个面板的旧直接入口仍按原逻辑转入宿主页。

所有页面分享固定标题、/pages/tabs/index 路径以及 assets/share-logo.jpg。封面复用 PC 品牌 Logo，不使用微信默认的当前页面截图；不携带登录令牌、用户名、作答记录或 sessionId。不更改认证、会员权限或做题业务。

本次支持发送给朋友；朋友圈分享不在本次修复范围。

## 验证

- 新增 14 项分享回归：遍历全部 13 个入口验证回调、公开入口、打包封面和私人参数隔离；重复调用仍产生独立安全载荷；未登录接收方沿原逻辑进入登录页。
- 初始代码下分享入口断言失败；实现后 npm test --prefix miniprogram 共 276 项通过、0 失败。
- git diff --check 通过。
- 微信开发者工具中首页、练习、成长、我的四个 Tab 逐一打开“发送给朋友”，均显示正确标题和品牌封面；取消后可继续操作。
- 做题页独立验证同一分享卡片，无题目/答案/个人中心截图；未替用户作答，验证结束保存退出已有练习。
