## 第一组：连线、端点、共享主干与工具栏

下面“线条类型”指选中线后浮动工具栏上的路径图标，悬停可见名称。多选线可在空白处框选，也可按住 Ctrl/Command 或 Shift 追加选择；混合选中卡片/文字/线时，先用“多选”筛选关系线。

| 勾选 / 编号 | 进入与操作 | 预期效果 |
| --- | --- | --- |
| ☐ G01 单线折线 | 图谱中建立 A→B，令两卡不在同一水平/垂直线上；选线 →“线条类型”→“折线”。放大查看每一段。 | 每段严格水平或垂直，转角为直角，没有轻微斜段。 |
| ☐ G02 批量折线（原第1项） | 建立方向、位置不同的多条线；多选这些线后统一设为“折线”。 | 所有选中线都变为正交折线，不出现部分线倾斜或漏改。 |
| ☐ G03 图二的走线（原第4、8项） | A 放左上、B 放右下；从 A 的下端点连接到 B 的上端点，再设为折线。 | 从 A 下方竖直引出，中间水平走线，再竖直接入 B 上方，形态对应你提供的图二；没有沿卡片边缘先横走再绕远的错误形态。 |
| ☐ G04 手选端点（原第6项） | 分别尝试 A下→B上、A右→B左，再选择一组不是最近距离的端点连接。松开后查看两端。 | 连接保持在你拖出的端点和放下的端点，程序不擅自换成其他边或中心位置。 |
| ☐ G05 拖动箭头重新绑定（原第2项） | 选中 A→B，拖动末端手柄到 C 的某个明确端点后松开；再移动 C。 | 末端绑定 C 的所选端点，移动 C 时连线跟随；B 不再控制这个末端。起点也重复一次。 |
| ☐ G06 绑定保存与恢复 | 对 G04/G05 的卡片再拖动几次，保存并刷新页面；再次移动卡片。 | 端点、卡片关系及箭头方向均保留，没有刷新后换边、断开或重新绑定。 |
| ☐ G07 同一条线简化（原第5、9项的 A） | 把同一条折线中相邻的两段/三段拖到同一水平线；再做一次竖直共线。 | 连续同向共线部分看起来成为一段，冗余拐点消失；起终点仍在原卡片端口。为满足端口方向所需的真实折返仍保留。 |
| ☐ G08 多条关系共用主干（原第5、9项的 B） | 建 A→C、B→C，把两条折线的中间水平段拖到重合；再加 D→C，重复一次。另做一次竖直重合。 | 重合部分显示一条清晰主干；各卡片到主干的分支和各自箭头保留，关系不会被合没。 |
| ☐ G09 主干关系仍独立 | 接着 G08，依次移动 A、B、C；保存刷新；选中一条分支关系修改颜色或端点。 | 各关系仍可独立选中和调整；其他关系不被删除/改绑。移开某卡后仍能看出它原有的独立连接。 |
| ☐ G10 复杂图与批量转换 | 在原问题图或副本中，选中多条“变更请求”相关连线切换折线；重点看你截图红框两卡及上下分支。 | 不出现错接端点、穿入卡片、莫名拉出超长绕路线或斜段；汇入主干时各分支关系仍可辨识。 |
| ☐ G11 线条设置距离（原第3项） | 点击不同位置的线，打开线条类型/颜色等设置；把工具栏移到其他位置再打开。 | 设置跟随对应触发按钮，就近打开，不跑到远处；靠窗口边缘时仍可看见并操作。 |
