# 画笔入口与当前画布截图：253 UAT

范围：知识图谱、多题归纳、深度回忆。按用户要求先完成开发与 UAT 部署，尚未获得本次 UAT 业务验收，不合入 main、不发布正式环境。

## 交互

- 画笔面板默认隐藏。图谱入口位于左侧工具箱；回忆与归纳入口位于右上角浮栏。
- 总入口再次点击关闭面板并退出绘画。颜色/粗细设置支持重复点击画笔收起、点击外部收起；外部绘画不会被吞掉。
- 画笔与荧光笔分别记忆颜色、粗细，图标同步颜色。
- 单击橡皮擦后点击笔迹擦除一笔；双击橡皮擦按钮清空当前画布笔迹，不确认，可撤销。移除单独清空按钮。
- 三页截图按钮下载当前视口 PNG，保留可见内容、图片、连线和笔迹，排除工具浮层；有并发保护、失败提示和内存上限。屏外失效图片不阻塞截图。
- 图谱笔迹写入现有文件正文，复用节点的撤销历史。切换/新建/关闭文件期间暂停绘画，避免等待保存期间丢笔迹；只读和切换锁同样覆盖键盘撤销/重做。

## UAT 发现的面板遮挡修正（254）

253 已部署 UAT，实际浏览器发现图谱画笔展开后遮挡下一行截图入口，自动滚动暴露入口会使工具面板在第一次橡皮擦点击后移动，导致双击不能清空。修正为图谱面板向工具箱右侧展开，并在滚动时同步定位。共享模块保持视口边界限制，回忆/归纳原定位不变。

新增回归先在旧实现失败，修正后通过：面板展开时截图入口可命中，截图前后画布位置不变，随后双击清空成功。使用修正的前端 bundle 连接 UAT 真实接口预览，图谱、多题归纳、深度回忆均通过绘制、截图、清空/撤销和保存刷新测试；该预览不等于 254 已部署。独立复核无阻塞项，254 完整发布校验及部署结果待补充。
