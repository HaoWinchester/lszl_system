## 本轮行为

| 需求 | 实现与边界 |
|---|---|
| 弹幕布局和设置 | 顶部两轨，去暂停图标；数量、播放时长、透明度按账号保存设备偏好，默认8条、一般上限20，教师/管理员有200/600内部压测选项。 |
| 举手重播与表情 | 复制后延迟一次重播，不再次发评论或点赞；退出和账号变化清理队列。默认折叠12种Unicode表情，保留草稿和原发布链路。 |
| 答题音效 | 默认关闭的原生短音，答对/错不同；关闭实时对错时不泄漏结果，恢复、复习、重复作答和迟到请求不误播。 |
| 浮动菜单 | 深灰56px圆形入口默认收起；保存、弹幕设置、音效与原动作统一可达，操作、外点、Esc和切视图收回；原保存状态与失败重试保留。 |
| 知识星空 | 本人全部历史有效保存作答按冻结考点聚合，30天渐暗；亮度代表练习新鲜度，不冒充掌握程度。未知考点只计数；分页、失败重试与迟到账号响应隔离。 |
| 推荐码与双边会员 | 随机码、注册链接、注册绑定与本人邀请人数；通过有效码注册成功后双方各7天，未过期有限会员顺延，过期从服务器当前时间起，终身不降级、暂停不解封、角色不变化。绑定、用户及双方奖励同事务，重放不重复发、旧绑定不追补，客户端不能指定天数或收款对象。 |
| 共享订阅与认证边界 | 奖励、购买、兑换、管理员更新和首次订阅创建复用账号锁；账号切换丢弃旧订阅响应，同账号重叠刷新共享有效结果。独立登录框首次即时聚焦，重复打开不抢输入焦点。 |
| 既有模板安全 | 保留异步全屏退出、加载及迟到响应期间的账号保护。新增成人/国学模板、首页展示、深链、自动种子和专属测试均按最新指示撤出，UAT从未发布这批内容。 |

普通保存不一定含评分字段，因此看板以服务器验证选项后首次写入的acceptedAt计入；忽略客户端伪造时间，再次保存不刷新旧题时间。交卷保留首次时间，对外答案不泄漏内部字段。升级前没有可靠逐题时间的旧未评分记录不补造时间。
