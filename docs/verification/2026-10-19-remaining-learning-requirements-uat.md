## 本轮实现

| 需求 | 具体行为与验证边界 |
|---|---|
| 弹幕两排、去暂停、配置 | 顶部两轨道；移除暂停图标；可设置数量、时长和透明度，按账号保存设备偏好。一般数量上限20，管理员/教师提供200、600内部压力选项。 |
| 举手后重播 | 复制当前短评论，延迟一次重播；不重复发布评论、不自动点赞。复制失败保留重试，退出或销毁时清理排队与重播节点。 |
| 预设表情 | 默认折叠的12种文字表情，插入当前选择位置，保留草稿与原发布链路。不是图片贴纸库。 |
| 答题音效 | 原生 Web Audio 短音，答对/答错不同；默认关闭，可在功能菜单切换。关闭实时对错时静音；恢复、成绩复习及重复作答不重播；账号、退出及迟到音频请求均清理。 |
| 答题浮动功能菜单 | 深灰56px圆形入口，桌面/触屏默认收起；保存、弹幕设置、音效和原评论/收藏/退出可达。动作、外点、Esc及切视图收回，原保存失败状态与重试保留。 |
| 星空知识网络 | 本人全部历史中具有可靠逐题时间的有效保存作答，按冻结考点聚合；做题点亮，30天渐暗，列表分页。亮度表示练习新鲜度；无考点只计总数，不伪造知识节点。 |
| 推荐码 | 数据库随机码、可选注册链接与注册绑定、本人邀请人数统计；注册整体事务、唯一约束和账号隔离。无奖励规则答复，按已说明默认只做基础链路，不发会员、优惠或返佣。 |
| 成人/国学模板及首页 | 管理、逻辑、人际、国学四套原创框架，每套13卡、12线；经原模板发布/预览/加载流程提供。启动幂等保留既有维护、下架及副本；首页链接定向进入模板中心，明确点击才加载，不替换当前文件。 |

星图新增服务端首次 `acceptedAt`：普通保存不带评分字段，不能用“有correct才统计”的口径漏计。时间由后端校验选择后记录，忽略客户端伪造值；再次保存不刷新旧题时间，正式交卷保留首次时间，对外答案不泄漏额外字段。升级前无可靠时间的旧未评分记录不从最后保存时间补造，可以在后续真实交卷获得提交时间。

完整皮肤截图又发现全局圆角变量覆盖圆形入口、保存图标缺失；已给FAB设置本地圆形变量、扩展共享save图标与sprite，并让浏览器夹具按实际head加载全部皮肤/图标及UTF-8。四视口红绿回归和六宽度候选复验通过；v365仅中间候选、未部署。

六宽度旧测试要求渐变按钮和大厅/答题字号相等，与v364既有纯色按钮及分层设计token冲突；按现有CSS契约迁移断言（含rem→px解析），不修改产品字号或按钮样式。新测试保留混合题型、材料滚动/折叠、标记筛选/保存刷新及导航边界。

整包v366在390px学习记录入口失败，已停止发布。实际根因是新导航动作超过窄屏宽度后继承右对齐，前方按钮出现负坐标且无法滚达；移动端导航改为左对齐，保持原横向滚动布局。新增320/390/768每个导航按钮原生滚动可达的红绿检查，真实练习矩阵1–15、66条断言通过。没有用强制点击、跳过断言或放大视口绕过。弹幕SVG检查补等待外部symbol加载后仍保留非零图形断言，避免在资源完成前读取getBBox。

帮助回归又确认窄屏固定top110使图标与内容相距613px；共享帮助模块改为首次展开时按触发器上下就近定位并夹在视口内，resize重算。保持原400ms关闭语义，避免页面平滑滚动期间反复移动目标。全皮肤UTF-8夹具保留20step移入、停留超过关闭宽限后仍可读、键盘和点击固定/关闭检查。
