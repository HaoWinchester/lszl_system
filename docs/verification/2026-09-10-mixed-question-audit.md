# 混合题型复核与修复

复核基线：`40bce3e`（功能分支 `codex/mixed-question-types`）。
范围：已确认的图表题、一对一匹配题、共享材料案例题，与单选／多选混入同一试卷。

## 发现及修复

1. **教师编辑案例时丢失未保存的序号和总题数。** 修改两个数字后移除图表，会重新绘制编辑器；旧的 `capture()` 没有保存这两个输入，所以回到旧值。现在公共编辑器在重绘前保存案例字段。独立浏览器测试先复现失败，修复后通过。
2. **无关拖放清除已有配对。** 空 `DataTransfer` 被当成“取消配对”。现在拖放入口先校验候选属于当前题，非法拖放不修改答案；取消按钮仍可主动清除配对。浏览器回归覆盖空拖放。
3. **匹配题无法进入同题型复仇验证。** 旧过滤条件要求至少两个选择题选项，而匹配题合法值为 `options: []`。现在复用统一可作答判断，并跳过已锁定答案的候选题。行为测试覆盖合法匹配验证题选择。
4. **复仇不显示上次错配。** 会话引用只携带旧选择题答案字段，网页同样只查选项。现在会话传递 `previousWrongPairs`，网页保留映射并显示每个条目的候选文字。API 回归覆盖创建和恢复会话，网页行为测试覆盖显示。
