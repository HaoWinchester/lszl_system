# 用户体验修复本地验证

日期：2026-09-30。工作区：`.worktrees/learning-experience-20260928`；分支 `codex/learning-experience-20260928`；前端版本 `v9.0-p4.1.266`。根据用户“先修改”落实前次 UX 审查的 11 项建议。本轮只在本地修改、同步和验证，没有推送、部署或合入集成分支。

## 修复对应关系

| 审查项 | 已落实行为 |
| --- | --- |
| UX-01 | 试卷切换、筛选、新建和离开前提供保存、放弃、继续编辑；保存失败保留输入。后台重绘、配额保存和延迟响应不会覆盖新输入或抢回旧选择。 |
| UX-02 | 助手待发送文字和附件在新建、换会话、离开、刷新前保护；不会自动上传或发送。 |
| UX-03 | PC 增加搜索和科目筛选；小程序在后端完整授权目录中搜索后分页，可找到首屏之外的试卷；旧请求不会覆盖新结果。 |
| UX-04 | 桌面左侧目录、右侧编辑；当前试卷和保存状态持续可见；断点与导航对齐，留出默认悬浮栏空间。 |
| UX-05 | 工作台新增导入、发布练习、准备回忆三个任务入口；优先继续最近草稿，普通练习不被回忆配置缺项阻断。 |
| UX-06 | 助手新增显式上传材料按钮，说明文件限制及选择后点发送才上传；快捷话语填入后有反馈。 |
| UX-07 | PC 退出文案区分保存和结算；小程序退出提供继续做题，结束通过独立按钮并再次确认。 |
| UX-08 | 统一文件整理助手、多题归纳等名称，补充模式的用途说明；保留原玩法与内部枚举。 |
| UX-09 | 深度回忆无题时显示下一步；教师和管理员可检查试卷发布与模式，学员可前往普通练习。 |
| UX-10 | 七个教师页面共享导航生成模块，核心五入口一致；内容中心和课程与任务归入教学工具，补充当前位置。 |
| UX-11 | 小程序启动区固定显示模式、题量、顺序和未做题优先规则；继续旧进度与新设置明确区分。 |
