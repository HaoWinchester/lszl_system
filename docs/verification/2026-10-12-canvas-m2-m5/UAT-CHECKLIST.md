## 准备

1. 使用独立验收文件；准备管理员、教师、有效会员学生、非会员学生账号。不同账号使用不同浏览器配置或隐身窗口，避免串号。
2. 图谱 A 准备卡片甲、乙、丙、丁，关系甲→乙、乙→丙，丁独立；再加一条跨分支关系。设置不同样式、长中文标题、详细说明、备注和图片。图谱 B 为空。保留 A 初始截图。
3. 准备多题归纳和深度回忆的专用测试内容；三页的表格、画笔文字、清晰度检查均分别执行，不以一页通过代替其他两页。
4. 教师准备两套不同题库中的题目，包含选择题、其他已有题型、带图题和仅在会员试卷中发布的题。请明确区分原本公开题与仅会员内容：公开题不因也出现在会员试卷中就变成受限题。
5. 准备 XMind 样本：可使用仓库内的 [XMind 24.04 实际生成样本](../../../backend/tests/fixtures/xmind/xmind-24.04-desktop-rich.xmind)（2 张工作表、9＋5 个主题、PNG、长备注和字号样式）及 [XML 格式测试样本](../../../backend/tests/fixtures/xmind/xml-only-synthetic.xmind)（2 张工作表、3＋1 个主题、PNG、备注和虚线样式）。后者是人工构造并经当前 XMind 桌面版打开验证的样本，不代表旧版软件导出验证。另备损坏文件、非 XMind 文件及含不支持对象的文件；实际支持范围以导入报告和开发证据为准。
6. 准备 Excel 区域：中文、英文、数字、空单元格、单元格内换行、合并单元格。仅检查显示文本和合并结构，不要求运行 Excel 公式。
7. 删除、断网、重置、取消和冲突试验只在专用文件进行；先记录初始内容。需要重开验证时等待页面确认保存成功。

## 1. 曲线与固定连接点

- [ ] **AC01-1　在线控制点**：选中曲线，分别拖动两个线上控制点，再松手。**预期：** 曲线跟随调整，两个手柄始终在线上，无松手跳回。
- [ ] **AC01-2　整体移动**：选中甲、乙及内部曲线，整体拖到另一位置。**预期：** 两张卡与曲线一起移动，相对线形不变，旧位置无残留控制点。
- [ ] **AC01-3　视图和历史**：调整曲线后缩放、平移、撤销、重做，再保存重开。**预期：** 线形及控制点一致；按 Esc 取消拖动恢复原位置，已有撤销／重做记录不丢失。
- [ ] **AC02-1　固定侧**：将甲→乙的起点选右侧、终点选上侧；把两卡交替移到对方不同方向。**预期：** 起点始终在甲右侧、终点始终在乙上侧，不自动换边。
- [ ] **AC02-2　边界贴合**：调卡片宽高、修改长标题、缩放；再检查圆形和三角形卡片。**预期：** 固定点贴合实际形状边界，不漂移到外接矩形以外；原有手动尺寸规则保持一致。
- [ ] **AC02-3　保存与兼容**：保存重开固定端点图谱；恢复自动连接，撤销一次；打开旧文件。**预期：** 固定设置保存，撤销能恢复固定设置，旧线仍按自动方式正常连接。

## 2. 临时相关画布

- [ ] **AC03-1　范围**：选乙打开相关画布，再选甲、乙共同打开；最后单选孤立的丁打开。**预期：** 只显示所选节点及直接关联节点的并集；没有无关节点，孤立节点也能打开。
- [ ] **AC03-2　编辑隔离**：在临时画布改名、移动、添加／删除卡片及关系，添加文字和表格，执行撤销／重做后关闭；重开正式文件。**预期：** 临时操作有效，原图谱正文、位置、关系、文字、表格及历史均不变。
- [ ] **AC03-3　丢弃与切换**：修改临时内容后关闭并重新打开；再分别切文件、登出后重登。**预期：** 不恢复上次临时修改，不污染其他文件或账号；重新打开读取正式图谱当前内容。

## 3. 三页文字清晰度

以下各项记录：知识图谱 □　多题归纳 □　深度回忆 □。1% 等极小比例下文字自然很小，检查是否异常栅格模糊和回到正常比例后的清晰度，不要求极小字号可逐字阅读。

- [ ] **AC04-1　比例**：放置中文、英文、数字、画笔文字和表格；依次查看画布 1%、25%、50%、100%、200%、400%。**预期：** 在对应显示尺寸下边缘正常，无异常重影或持续模糊。
- [ ] **AC04-2　反复缩放**：连续缩小、放大十次，回到 100%，与初始截图比较。**预期：** 清晰度恢复一致，不累积模糊，文字和表格位置不变。
- [ ] **AC04-3　全屏和屏幕**：分别在普通与高像素密度屏幕检查普通／画布全屏模式，记录截图及比例。**预期：** 内容清晰、无裁切或重影；缺少设备的组合标待补。

## 4. XMind 导入

- [ ] **AC05-1　内容映射**：选择含多工作表的 `.xmind`，检查预览和保真提示，确认导入；逐项对照原文件的标题、层级、长备注、图片和支持的样式。**预期：** 每个选定工作表形成独立可编辑图谱，中文正常；不支持内容明确列出，需接受提示才继续。
- [ ] **AC05-2　往返**：修改导入卡片后保存，关闭重开。**预期：** 层级、图片、备注、支持的外观与修改均保留；现有文件没有被覆盖。
- [ ] **AC05-3　失败与取消**：分别导入损坏、错误扩展名、受保护或不支持内容的样本；取消一次预览。**预期：** 提示具体原因；失败或取消不留下半份文件，不破坏当前图谱。
- [ ] **AC05-4　支持范围**：对照开发证据中实际声明的 JSON／XML 格式样本，逐份执行导入；记录来源和差异。**预期：** 每类声明都有对应证据；保真缺口被明确记录，不以“导入成功”代替内容核对。

## 5. 跨文件复制

- [ ] **AC06-1　完整片段**：甲、乙配置图片、长备注、样式、固定端点、手调曲线；连同独立文字和表格选中，从 A 复制到 B。**预期：** 支持的所选内容完整，相对位置、内部线形和端点保持；图片可见。
- [ ] **AC06-2　范围正确**：只复制甲、乙，不选择丙。**预期：** 乙→丙不形成悬空线，丙及其他未选对象不被带入。
- [ ] **AC06-3　独立副本**：在 B 连续粘贴两次，改其中一份，保存重开；回到 A；再用两个标签页显式复制粘贴。**预期：** 两份互不覆盖，来源 A 不变，保存后内容完整；账号切换后不残留上个账号的应用内剪贴板。
- [ ] **AC06-4　文本优先**：在卡片标题、详细输入框、画笔文字、表格单元格中选一段文字复制粘贴。**预期：** 只复制文字，不产生卡片副本、不误删对象。

## 6. 思维导图布局和系统主题

- [ ] **AC07-1　四种布局**：同一图谱依次选向左、向右、左右展开、向下树形；包含孤立点、跨边和环时再试。**预期：** 方向符合名称，节点和关系数量不变；再次应用同一布局位置稳定，卡片不重叠。
- [ ] **AC07-2　六种主题**：依次选简洁线框、蓝色圆角、彩色分支、黑白树形、纸感便签、胶囊节点；先手动改某卡颜色，再分别尝试默认保护及显式覆盖。**预期：** 系统主题有可见差异；默认保护手动外观，显式覆盖才替换；正文、备注、图片、题目关联保持。
- [ ] **AC07-3　历史和保存**：布局调整带手调曲线及跨分支边的图谱，撤销、重做、保存重开。**预期：** 关系不丢失，端点跟随卡片，历史与重开结果一致。

## 7. 模板中心

- [ ] **AC08-1　发布**：管理员、教师分别发布免费和会员知识图谱模板。**预期：** 无审核等待即可进入模板中心；普通系统主题仍可直接使用，不混为付费模板。
- [ ] **AC08-2　发布权限**：学生检查模板中心。**预期：** 无可用发布入口；开发 API 权限证据同时确认直接请求被拒绝。教师只能维护自己的模板，管理员可维护全部。
- [ ] **AC08-3　加载权限**：会员学生加载会员模板，非会员学生尝试相同操作；两者再加载免费模板。**预期：** 会员可加载会员模板，非会员被明确拦截；符合原有使用权限的免费模板可加载，预览不泄露受限完整内容。
- [ ] **AC08-4　副本独立**：加载到新文件，修改、保存重开，再核对原模板及教师源文件；更新或下架原模板后再次检查既有副本。**预期：** 新文件完整独立、不覆盖当前图谱；原模板不受副本编辑影响，既有合法副本保留。

## 8. 全屏与题目抽屉

- [ ] **AC09-1　详细编辑**：图谱全屏下打开卡片详细编辑，修改并保存，再打开。**预期：** 编辑窗口可见、可操作、内容已保存。
- [ ] **AC09-2　反复切换**：多次进出全屏；在详情中滚动、关闭，再拖动画布。**预期：** 浮层和画布焦点正常，无遮挡、重复窗口或失效按钮。
- [ ] **AC09-3　题目与全屏**：全屏打开做题抽屉，切换题目、作答、看解析；退出全屏再继续。**预期：** 抽屉位于可见全屏区域，题目材料和解析可操作，不被详情层挡住。
- [ ] **AC10-1　关联与追加**：教师、管理员分别从卡片搜索另一教师题库和会员题，勾选关联；保存重开后继续追加，并重复选择已关联题。**预期：** 可跨题库搜索、持久化追加，重复题不重复加入。
- [ ] **AC10-2　学生完整练习**：教师将带会员题关联的图谱发布为免费模板；会员和非会员学生分别加载，查看完整题目、图片，作答并查看解析。**预期：** 两类学生都能完成已关联题的完整流程；不同题型遵循现有判题规则，提交后正确展示结果和解析。
- [ ] **AC10-3　授权不扩大**：非会员学生通过普通试卷／题库入口访问尚未授权的会员内容；再试另一个账号私有图谱。**预期：** 仍按原权限拦截。开发证据还须覆盖伪造题号／文件号／绑定号／资源号直接请求；页面隐藏不算鉴权通过。
- [ ] **AC10-4　学生不可维护**：学生查看有关联和无关联题目的卡片。**预期：** 只能练习已有题，不出现可用搜索、勾选、新增、删除关联功能；直接维护接口也被拒绝。
- [ ] **AC10-5　异常与恢复**：教师打开无题卡片，搜索无结果，再断网尝试关联，恢复后重试；另验证已被显式撤销的关联。**预期：** 空态清楚、失败不伪装成功、重试不重复；失效关联不能继续新提交，抽屉切卡不串题。

## 9. 删除文字与自动保存

- [ ] **AC11-1　原位删字**：双击图谱卡片标题，连续 Backspace／Delete。**预期：** 只删文字，不弹整卡删除确认，卡片和连线仍在。
- [ ] **AC11-2　输入隔离**：在详细输入框、画笔文字、表格单元格中删除选中文字，使用中文输入法确认候选。**预期：** 只编辑当前文字，不删除画布对象，不提前提交候选。
- [ ] **AC11-3　对象删除**：结束输入，选中测试卡片，明确删除；先取消，再执行确认。**预期：** 原对象删除规则有效，取消保留对象，确认才删除。
- [ ] **AC12-1　失焦保存**：三页分别输入画笔文字，点击外部，等待保存并重开；再断网编辑并点击外部。**预期：** 不需要保存／取消按钮，正常修改可重开恢复；失败保留草稿并可重试，Esc 可取消本次编辑；新空文本不生成空对象。
- [ ] **AC12-2　四边调整**：三页输入长中文及中英混排，分别拖四边和四角。**预期：** 文本框宽高改变、自动换行，字号随面积变化而变大或变小；不再靠字号滑轨调整。
- [ ] **AC12-3　大小往返**：调整文字后撤销、重做、缩放、保存重开。**预期：** 宽高、字号、内容与换行保持，文字清晰；一次拖动对应一次撤销。
- [ ] **AC12-4　格式与输入法**：编辑中点击文字自己的格式工具、改变颜色，继续输入中文，再点击外部。**预期：** 格式工具不误结束会话，中文候选不触发画布快捷键，最终内容完整。

## 10. 多题归纳与深度回忆回归

- [ ] **AC13-1　保留背景**：多题归纳设置背景颜色及图案，连续换多个主题。**预期：** 主题变化不覆盖原背景颜色或图案。
- [ ] **AC13-2　分别持久化**：保存重开，再显式改背景并保存。**预期：** 主题与背景分别保存，主动改背景仍然有效。
- [ ] **AC14-1　水滴改色**：框选两张可编辑卡片，点水滴，选择颜色。**预期：** 面板正常打开，两张卡改色，未选卡和背景不变。
- [ ] **AC14-2　不同选区**：分别选普通卡片、同组卡片、不同类型混合选区和不可编辑对象。**预期：** 支持的选区执行改色，不支持的情况有明确反馈；不出现无响应或改错对象。
- [ ] **AC14-3　全屏与历史**：全屏改色后撤销、重做、退出并保存重开。**预期：** 面板可见可点，历史和重开颜色正确。
- [ ] **AC15-1　正确匹配**：用尚未生成回忆记录的已知准确关键词样本创建卡牌。**预期：** 显示对应知识点，内容不串到其他知识点。
- [ ] **AC15-2　未匹配**：用无对应知识点的关键词生成卡牌，手工输入并保存重开。**预期：** 生成可编辑自定义卡牌，用户输入被保留且可继续修改。
- [ ] **AC15-3　歧义和旧内容**：检查近义、同名、多候选词，以及已有自定义回忆记录。**预期：** 不静默绑定错误知识点，不覆盖旧自定义内容；旧记录不因新规则自动重绑。

## 11. 三页可编辑表格

以下每项均分别记录：知识图谱 □　多题归纳 □　深度回忆 □。

- [ ] **AC16-1　基本操作**：通过行列选择插入 4×6 表格，输入中英文，移动、调总体大小及行高列宽；缩放并进入全屏。**预期：** 行列数量正确，文字清晰，位置和尺寸跟随操作，不误拖底层画布。
- [ ] **AC16-2　合并拆分**：相邻格分别输入不同文字，选择矩形区域合并，核对内容提示；拆分、撤销、重做并保存重开。**预期：** 合并保留各格非空文字，拆分后内容保留在左上格，撤销恢复完整原结构；合并结构可保存。
- [ ] **AC16-3　Excel 粘贴**：复制准备的 Excel 区域，分别粘贴到画布空白和已有表格单元格；含空格、多行文本、合并区域再试。**预期：** 行列、空单元格、换行及支持的合并结构正确；超限或冲突时明确失败，不部分写入；不运行公式或加载外部资源。
- [ ] **AC16-4　焦点与只读**：在单元格里选中文字、删字、复制粘贴；再进入实际只读场景尝试编辑。**预期：** 编辑只影响单元格，剪贴板不误生成图谱对象；只读时不能改内容或结构。
- [ ] **AC16-5　三页持久化**：分别插入、编辑、移动、合并、撤销／重做，保存重开；再执行重置取消和确认。**预期：** 三页各自完整恢复；取消重置保留表格，确认后按重置范围清除。另在临时画布编辑表格并关闭，正式文件不变。
