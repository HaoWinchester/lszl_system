## 二、测试场景与结果（76 场景）

### 1. 权限边界（13 场景，全部 PASS）
- v1 观众：浏览模板目录 403、发布 403、表格入口不可用、无发布入口（UI）
- s1 学生：发布/上下架 403、全库搜索 403
- t2 教师乙：用他人源文件发布 404、维护他人模板 404、修改他人文件绑定 404、UI 无下架按钮
- s2 访问 s1 文件绑定 404；未登录 401；admin-console 可访问

### 2. 模板中心 R08/T15（20 场景，全部 PASS）
- 发布：t1 表单发布免费+会员模板（UI 截图 UI-12/13）、t2 越权拒绝
- 加载：s1 免费成功、s2/s3/s4/s5/t2/admin 会员成功、s1 会员 403、s6 过期 403（UI 截图 UI-05/11）
- 门控与保留：下架后目录不可见+新加载 404+旧副本仍可读；重新上架
- 幂等：同请求重放同一副本、同请求换模板 409
- 预览安全：描述预览不含 graphData

### 3. 卡片题目与做题抽屉 R10/T13/T14（12 场景，全部 PASS）
- t1 绑定 2 题、重复绑定不重复；t2 在自己卡片上下文跨题库搜到教师甲题目
- s1 加载副本含冻结绑定 → 抽屉 UI 作答（截图 UI-08）→「回答正确」+解析（截图 UI-09）
- 错误作答判分不正确；同请求作答幂等；学生搜索被拒

### 4. 跨文件复制授权 R06/T16（8 场景，全部 PASS）
- s1 受控粘贴生成新 ID、绑定继承、继承卡可作答
- 伪造 questionIds 不产生授权；来源 revision 过期 409 无半成品；他人来源 404

### 5. 三页可编辑表格 R16/T17-T19（19 场景，PASS 见下）
- 图谱页 s1：插入面板 3×3、中英文输入、合并拼接、单次撤销、TSV 粘贴、保存重开（截图 UI-17/18）——7 PASS
- 多题页 s2：3×3 建表、「错题归纳」保存重开（截图 UI-20/21）——2 PASS
- 回忆页 s3：回忆画布插表、重开保留（截图 UI-23/24）——2 PASS
- Excel 粘贴：空画布粘贴 5×4 含合并（**v316 FAIL → 发现真实 bug → 修复 → v317 复测 PASS**，截图 UI-25）
- 只读：v1 表格入口不可用
- 已知失败闭环：v316 上「粘贴建表丢单元格内容」为真实 bug（`insertFromGrid` 只建结构），已修复 `8d8e8bd0` 并部署 v317 复测通过；测试同步补内容断言防回归 `59a61fed`

### 6. 回归与杂项（4 场景，全部 PASS）
- Delete 不误删整表；普通文本粘贴不误建表；admin-console；无页面 JS 错误
