# 知识星空与画布交互：本地交付记录

本轮按用户最新授权完成剩余色盘与阅读/临时画布调整，统一提供本地验看。当前仅本地分支 codex/knowledge-universe-scroll，未推送、未部署 UAT、未修改 main。正式源版本及 active release 仍为 v9.0-p4.1.378；本地预览采用独立缓存标识，避免旧浏览器缓存遮蔽修改。

## 改了什么

| 位置 | 功能与行为 |
| --- | --- |
| 多题归纳：顶部/画笔工具栏 | 恢复原紧凑排版，图标保留悬浮提示；仅按最新要求把色盘移到撤销/重做之前。原主题选项、操作与入口不变。 |
| 多题归纳：画笔自定义颜色 | 复用已有卡牌/分组悬浮色板，提供预设、色相/明度、HEX、最近使用；笔/高亮/文字颜色通过原保存路径生效。键盘也可开启，切换工具/画布/账号后迟到选色不能串用。 |
| 共用悬浮色板 | 取色按钮改为通用 SVG 滴管图标，保留原屏幕取色功能和不支持时隐藏的规则。 |
| 图谱阅读模式 | 去掉卡牌悬浮小工具栏；单击看详情，双击卡牌进入原临时相关画布入口，卡内链接/按钮/输入独立处理。其他模式原编辑行为保留。 |
| 临时相关画布 | 阅读、编辑及合法只读上下文均能拖动临时卡牌，缩放后坐标正确、连线跟随；关闭/重开还原，不改原图节点、关系和锁定。只读账号仍不能修改正式图谱内容。 |
| 练习大厅：知识星空 | 展示后台当前已发布完整知识树，未练节点暗色；支持科目筛选、全部/已练/未练统计与节点详情。没有固定三个或60个节点上限。 |
| 知识星空：亮度与滚动 | 完成练习后按近期正确率、连续答对及有效练习次数综合计算熟练度，越熟练越亮，答错会回落；普通滚轮/纵向触摸滚动弹窗，Ctrl/Meta 滚轮及双指用于缩放。 |
