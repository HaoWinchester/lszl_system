# 文件管理 v8.3

## v8.3.0 文件夹
支持多级文件夹、面包屑、移动、回收站和恢复。

## v8.3.1 轻量移动

### 拖拽
- 拖到文件夹卡片：移动到该文件夹。
- 拖到面包屑：移动到对应层级。
- 拖到左侧“我的文件”：移动到根目录。
- 非法循环移动由底层 `moveFolder` 拦截。

### 多选
使用 Ctrl/Command 点击切换选择，Shift 点击追加选择。拖动任一已选项目会移动整个选择集。选择集包含父子文件夹时，仅提交最上层文件夹。

### 快速目标与撤销
右键菜单在“移动到”下方列出根目录和最近使用的文件夹。完整目录树仍由“选择其他位置”打开。移动成功后提供短时撤销；批量中途失败会回滚已移动项目。


## v8.3.2 可见多选模式

顶部“选择”按钮用于进入多选模式。进入后，每个文件和文件夹左上角都会显示复选标记，点击卡片或标记即可切换选中状态。批量工具栏提供移动、导出、移入回收站与取消。右键菜单中的最近目标最多显示 4 个，并始终提供“选择其他位置…”入口。

## v8.3.3 交互精简

- 右键菜单中的“移动到”使用二级面板，主菜单不再直接展开最近目录。
- 二级面板显示根目录、最多 4 个最近目标和“选择其他位置…”。
- 文件详情默认收起；选中项目时底部显示轻量摘要。
- 可通过工具栏“详细信息”、右键“查看详情”或 Alt+Enter 打开右侧抽屉。
- 详情抽屉的开合状态保存在本地设置中。


## v8.3.4 稳定性与性能

- 完整性检查在空闲阶段执行并缓存；常规渲染仅显示缓存结果。
- 手动刷新文件列表时会强制重新检查。
- 多选右键操作保留已选项目，外部变化后自动剔除无效选择。
- 文件夹拖放增加自身与后代目录预判。
- 二级移动菜单支持完整基础键盘导航。
- 页面首次加载时自动定位当前打开图谱。


## v8.3.5 账号菜单层级

顶部工具栏使用独立堆叠层级，账号菜单位于文件卡片上方，但仍低于右键菜单、详情抽屉和模态框。
