# v8.2.4 文件管理器第一阶段

## 页面与入口

文件管理使用独立页面 `file-manager.html`，主要实现位于：

- `src/27-graph-file-manager.js`
- `styles/file-manager.css`

首页文件页签栏最左侧的房子按钮现在是文件管理入口。点击时先调用 `KGGraphFileAutosave.saveBeforeSwitch()`；只有保存成功才跳转，避免未保存内容丢失。

## 已完成功能

- 最近打开、我的文件、回收站
- 网格和列表两种显示方式
- 文件名、描述、标签搜索
- 更新时间、最近打开、名称、文件大小、创建时间排序
- 新建空白图谱并进入编辑器
- 打开、重命名、创建副本
- ZIP 学习包和 JSON 导入
- ZIP 学习包导出
- 移入回收站、恢复、永久删除、清空回收站
- 文件详情、当前文件标识、节点/关系/大小统计
- 浏览器存储配额估算和 v2 文件库占用展示
- 浅色/深色主题与响应式布局
- 右键菜单、双击打开、Ctrl/Command + K 搜索

## 数据访问原则

常规文件列表通过 `KGGraphFileStore.listFiles()` 读取轻量索引，不会在每次渲染缩略卡片时加载 `graphData`。完整正文只会在以下场景读取：

- v8.2.1 及更早文件首次补齐预览时，在浏览器空闲阶段每批最多处理 8 个文件
- 打开图谱
- 导出学习包
- 创建副本（由存储服务读取源文件）

卡片封面由存储层根据图谱正文生成轻量 `preview` 元数据，包含最多 18 个节点、30 条关系、节点颜色和少量核心节点标题。文件管理列表只读取该预览索引，不会在每次渲染时加载完整 `graphData`。

新建和保存图谱时会同步更新预览；v8.2.1 及更早版本的文件会在首次进入文件管理页时，利用浏览器空闲时间批量补齐预览。

## 导入规则

导入沿用 `KGHomePackageService` 的 ZIP/JSON 大小、条目数、解压大小、CRC 和 manifest 校验；文件管理器还会检查：

- 根内容必须是图谱对象，或包含 `graphData` 的文件对象
- 必须存在 `nodes` 和 `links` 数组
- 节点不超过 2500 个
- 关系不超过 5000 条
- 同批导入重名文件会自动添加序号
- 导入始终创建新文件，不覆盖已有文件

## 下一阶段建议

第二阶段可在当前独立页面继续加入文件夹、批量选择、批量移动、收藏和标签管理。底层应继续通过 `KGGraphFileStore` 服务接口访问，避免页面直接读写 localStorage。
## v8.2.1 回归修复

- 长文件名重名时采用保留后缀空间的截断算法。
- 未打开的导入文件和非当前副本使用 `lastOpenedAt = 0`，最近打开列表只展示实际打开过的文件。
- 回收站恢复先校验内容存在，再更新索引。
- 卡片更多按钮的双击和键盘事件不会冒泡为打开文件。
- 批量导入增加并发保护、忙碌遮罩和单次刷新。
- 支持当前页及跨标签页账号切换后的文件空间刷新。


## v8.2.2 交互与缩略图修复

- 文件选择不再重建整个卡片列表，连续双击事件可以被浏览器正常识别。
- 头像按钮新增可访问的下拉菜单，支持鼠标和键盘操作。
- `KGGraphFileStore.buildGraphPreview()` 根据真实图谱生成轻量预览。
- `KGGraphFileStore.refreshFilePreviews()` 用于旧文件预览的一次性补齐。
- 预览随新建、保存和重命名后的 revision 自动保持一致。


## v8.2.3 缩略图性能优化

- 文件详情栏不再重复显示缩略图。
- 文件索引中的预览带有 `structureHash`，只有影响预览的图谱结构变化才会重新生成。
- 文件列表使用 `IntersectionObserver` 懒加载 SVG 预览；不支持该 API 的浏览器自动回退为立即渲染。


## v8.2.4 页签会话状态

编辑器关闭页签后，会按当前登录用户将关闭记录写入 `sessionStorage`。在编辑器与独立文件管理页之间往返，或刷新编辑器页面时，已关闭页签保持关闭。通过文件管理器打开文件会清除该文件的关闭记录并恢复页签。关闭记录仅影响页签显示，不会删除图谱文件。


## v8.2.7 内联重命名

文件重命名改为卡片和列表原位置编辑，支持 Enter 保存、Esc 取消、失焦保存，并在编辑期间禁用双击打开。


## v8.2.8 稳定性补丁

- 文件列表刷新时保留正在编辑的文件名、光标位置和文本选区，不再隐式提交。
- 编辑中的文件若被其他页面删除，取消编辑并给出提示。
- 存储空间统计使用请求序号和 owner 双重校验，忽略过期异步响应。


## v8.3.0 文件夹与层级管理

### 存储模型

文件索引继续使用 `folderId` 指向父文件夹。文件夹元数据独立存储在 `kg_graph_folders_v1`，字段包括 `id`、`owner`、`name`、`parentId`、时间、排序和回收站状态。文件夹不会复制或嵌入图谱正文。

### 页面功能

- 根目录与多级子文件夹
- 面包屑导航
- 文件和文件夹移动
- 文件夹卡片双击进入、右键菜单和内联重命名
- 文件夹及其子级递归移入回收站与恢复
- 单独恢复失去有效父文件夹的图谱时回到根目录
- 清空回收站同时清理图谱和文件夹索引

移动文件夹时，存储层会拒绝将文件夹移动到自身或任意子文件夹，避免循环层级。
