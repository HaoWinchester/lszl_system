# 做题模式答题卡、断点续做与 PMP 风格模拟成绩报告设计

2026-08-28 后续决策：用户确认已发布试卷按原题目开始练习，不再在学习入口强制领域配比。本文关于“开始会话按领域重新抽题、领域不足拒绝”的旧要求被替代；新组卷/发布校验和冻结评分配置保持不变。见 [线上 start 422 修复记录](../../verification/2026-08-28-practice-start-inventory-hotfix.md)。

## 1. 决策摘要

本轮改造聚焦 `practice-mode.html` 的挑战、学霸、复仇三种做题模式，统一补齐四项学习体验：

1. 桌面端常驻、窄屏折叠的全题答题卡，支持点击任意题号自由跳题；
2. 已提交题目锁定，只能回看本人答案、正确答案和解析；
3. 未完成练习支持保存退出与跨登录恢复，学霸模式退出期间暂停时间池；
4. 交卷后生成幻谱品牌的 PMP® 风格模拟成绩分析报告，并提供本次错题复盘。

成绩报告采用用户确认的 V8 视觉方向：幻谱 Logo、模拟 PASS/FAIL、模拟分数、领域饼图、领域表现、本次错题入口和非官方声明。领域饼图遵循官方报告的信息逻辑：扇区大小表示领域占比，颜色表示该领域的表现等级；它不表示答对、答错和未答比例。

PMI 不公开固定合格分数，系统不得声称使用“PMI 官方及格线”。报告统一写作“模拟考试结果”，PASS/FAIL 按本卷冻结的模拟判定规则计算。

## 2. 目标与非目标

### 2.1 目标

- 用户做题时始终知道总题数、当前题、已答、未答、答对和答错数量。
- 用户可以从答题卡自由跳转到任意题目，并快速定位错题和未答题。
- 已提交答案不可修改，回看不改变本次成绩或错题事实。
- 10、20、60、180 等较长练习可以安全保存退出并继续。
- 三种做题模式复用同一会话、导航、保存和成绩报告能力。
- 结果页同时回答“是否模拟通过”“总体得分如何”“哪个领域薄弱”“具体错在哪里”。
- 所有进度、成绩、错题和报告按账号隔离，并绑定不可变试卷发布版本。

### 2.2 非目标

- 不复刻 PMI Logo、官方证书或让模拟报告看起来像认证证明。
- 不声称模拟 PASS/FAIL 等同于 PMI 官方考试判定。
- 不改变挑战模式生命值、学霸模式时间池、复仇模式补救验证的核心规则。
- 不允许用户修改已提交答案或在成绩页重新判分。
- 不把长期错题集和本次错题复盘合并为同一个列表。
- 不依赖 `localStorage`、`sessionStorage` 或 IndexedDB 作为练习会话、成绩或报告的业务事实来源。

## 3. 当前实现与缺口

- 当前做题页有进度条，但没有全题答题卡；上一题、下一题仅在部分模式显示。
- 当前状态主要以 `state.index`、`state.answered` 和 `state.correct` 等前端内存值维护，用户无法查看全部题目的状态分布。
- 当前退出确认明确提示进度不能继续，并把本次练习记录为 `abandoned`。
- 现有 `/api/v1/learning/practice/sessions` 只追加保存完成或放弃后的展示摘要，不能保存可恢复的题目顺序、逐题答案和运行状态。
- 现有统一判题接口已经能够由服务器判定正误，并联动 `practice_mistakes`；该事实边界应继续复用。
- 题目正式数据已经具备 `subjectFacets`，组卷服务已经识别 `exam-domain` 的 `people`、`process`、`business-environment` 分类。
- 当前快捷组卷默认权重是 `42/50/8`；本轮继续沿用该产品配比，不随本功能切换到后续新版考试大纲配比。
- 当前结果页只显示正确率、耗时和经验值，没有领域诊断、错题入口或可再次打开的报告快照。

## 4. 做题页交互设计

### 4.1 常驻答题概览

桌面端在题目卡右侧增加常驻“答题概览”。它包含：

- `当前题号 / 总题数`；
- 已答、未答、答对、答错数量；
- 全部题号网格；
- “只看未答”“只看错题”快捷筛选；
- “交卷”按钮。

窄屏不强行压缩题干。答题概览收为底部抽屉，顶部保留紧凑入口 `答题卡 已答/总数`。打开后展示同一套题号、统计和交卷操作。

### 4.2 题号状态

题号只使用以下可判定状态：

| 状态 | 含义 | 可执行操作 |
| --- | --- | --- |
| `unanswered` | 尚未成功提交答案 | 进入并作答 |
| `current` | 当前正在查看 | 取决于其基础状态 |
| `correct` | 已提交且服务器判定正确 | 只读回看答案与解析 |
| `wrong` | 已提交且服务器判定错误 | 只读回看答案与解析 |

“当前题”使用外圈或焦点态，不覆盖正确、错误等基础颜色。颜色之外同时提供图标、文本或 `aria-label`，避免只依赖颜色表达状态。

### 4.3 自由跳题与答案锁定

- 点击任意题号立即切换到对应题目。
- 未答题正常作答；已答题展示本人答案、正确答案和完整解析，所有选项禁用。
- 已答题不能再次提交、修改本次统计或撤销错题记录。
- 上一题、下一题在三种模式中统一保留，并与答题卡使用同一导航入口。
- 随机顺序只决定本次会话冻结的 `questionOrder`；恢复后顺序不再重新随机。

### 4.4 提交答案

用户选择答案后先调用服务器。服务器成功返回前：

- 当前题不标记为已答；
- 不自动跳题；
- 保留当前选择并锁定重复提交；
- 失败时显示题内重试入口。

服务器成功后同时完成判题、会话答案写入、完成态更新和错题状态推进，然后前端刷新题号状态、统计、反馈和解析。

### 4.5 交卷

- 仍有未答题时，交卷确认显示“还有 N 题未作答”，提供“返回定位未答题”和“仍然交卷”。
- 全部题目答完后自动进入交卷流程，不再要求用户额外寻找按钮。
- 提前交卷时，未答题按零分计算并保留 `unanswered` 统计。
- 成功交卷后会话冻结为 `completed`；任何页面都不能再次修改答案。

### 4.6 三种模式的一致性

- 挑战模式继续按现有规则扣减生命值；失败后是否继续完成全卷沿用当前规则。
- 学霸模式继续维护时间池、生命值和连胜；自由跳题不重置这些状态。
- 复仇模式继续执行待复仇、需补救、等待验证和已掌握状态机；答题卡文案可按复仇语义显示，但仍复用同一题号组件。

## 5. 保存退出与恢复

### 5.1 退出选择

退出弹窗提供两个明确动作：

- `保存并退出`：将会话改为 `paused`，完整保存后返回练习大厅；
- `放弃本次练习`：二次确认后改为 `abandoned`，不可恢复。

关闭标签页、刷新或异常崩溃不能完全依赖卸载事件。系统在每次答案成功后保存完整业务事实，并按短间隔保存当前题号、计时和生命值等运行状态。

### 5.2 恢复入口

- 练习大厅在对应试卷和模式上显示“继续上次练习”，包含已答/总题数和上次保存时间。
- 同一账号、试卷发布版本和模式最多存在一个 `active` 或 `paused` 会话。
- 用户再次点击开始时，可继续该会话，或明确放弃旧会话并创建新会话。
- 可以在不同试卷或不同模式下各自保留未完成会话，互不覆盖。

### 5.3 恢复内容

恢复时必须还原：

- 冻结的题目顺序和当前题号；
- 每题的未答、正确、错误状态及本人答案；
- 生命值、连胜、经验值和模式阶段；
- 学霸模式剩余时间；
- 复仇模式的补救或验证上下文；
- 语言模式和自动解析开关等与本次会话相关的显示状态。

学霸模式从成功暂停时起停止消耗时间；恢复后从保存的剩余毫秒继续。离线时长不计入时间池，但报告可保留累计实际作答时长。

## 6. PMP 模拟卷领域配比

### 6.1 当前统一默认配比

本轮新建 PMP 模拟卷继续统一使用当前产品默认配比：

```text
人员 people                         42%
过程 process                       50%
商业环境 business-environment       8%
```

教师不需要逐卷配置领域配比。系统用最大余数法把比例转换为精确整数题数，保证各领域题数之和等于用户选择的总题数；余数相同时按稳定的领域顺序分配，保证同一输入结果可复现。实际采用的整数题数和 `42/50/8` 配比标识进入试卷发布快照，历史成绩不受未来配比切换影响。

PMI 2026 年 7 月版考试内容大纲中的 `33/41/26` 属于后续产品迁移事项，不在本轮范围内。未来切换时应单独评估生效时间、存量试卷兼容和报告标识，不能直接覆盖已发布试卷。

试卷顺序模式先按领域配额选出题目，再按发布快照中的试卷顺序排列；随机顺序模式在选题完成后使用本次会话种子打乱，并冻结结果。

### 6.2 分类与发布校验

- 领域事实读取题目快照 `metadata.subjectFacets` 中 `dimensionId = exam-domain` 的值。
- 新的 PMP 模拟卷只有在所有入卷题目都具备合法领域分类时才能发布到做题模式。
- 缺少某一领域足够题量时，发布预检显示目标数量、可用数量和缺口，不静默用其他领域填充。
- 已发布旧试卷继续绑定原快照，不追溯修改比例、题目或历史成绩；旧试卷缺少领域数据时，历史报告显示“领域数据不完整”，不伪造饼图。

## 7. 模拟判分规则

### 7.1 PASS/FAIL

PMI 官方未公开固定及格分数，因此系统采用每份试卷发布快照中冻结的模拟判定规则，结果统一写作：

```text
模拟考试结果：PASS
模拟考试结果：FAIL
```

判定规则由试卷内容方在发布前设置并进入不可变 release snapshot。它不能在考试结束后回改历史结果。若缺少模拟判定规则，新试卷不能发布到做题模式。

### 7.2 分数和领域等级

- 总分按发布快照中每题分值计算；未答题得 0 分。
- 显示分数换算为 100 分制，同时保留原始得分和满分供报告快照审计。
- 领域得分只使用该领域的计分题。
- “需提升、低于目标、达到目标、高于目标”的分界同样来自发布快照中的模拟诊断规则。
- 页面和 API 不得把这些模拟分界称为 PMI 官方 cut score。

## 8. 成绩报告设计

### 8.1 报告结构

报告按以下顺序展示：

1. 幻谱 Logo、报告标题、学员、试卷、日期和报告编号；
2. 模拟 PASS/FAIL、模拟分数和简短结论；
3. 考试领域构成饼图与四档表现图例；
4. 总体表现区间和你的位置；
5. 总题数、答对、答错、未答、正确率和累计作答时长；
6. 人员、过程、商业环境的领域表现表；
7. 本次错题题号、数量和“开始逐题复盘”；
8. 下一步学习建议；
9. 非官方声明和报告页码。

成绩报告使用 `new-legacy/assets/logo.jpg` 作为幻谱品牌图。正式实现前应确保该资产进入版本管理和 release 构建产物，不能依赖原型目录中的副本。

### 8.2 领域饼图语义

- 扇区大小表示本卷发布快照中的领域目标占比；本轮新建模拟卷默认为 `42/50/8`。
- 扇区颜色表示用户在该领域的模拟等级。
- 外侧引导线显示领域名称和比例。
- 上方图例固定为需提升、低于目标、达到目标、高于目标。
- 答对、答错和未答通过数字统计展示，不复用这个饼图。

### 8.3 本次错题

成绩页只展示错题数量、题号和复盘入口，不把所有题干和解析铺成长页面。点击后进入只属于当前会话的复盘界面：

- 答题卡默认只显示本次错题；
- 题目展示本人答案、正确答案和解析；
- 只能浏览，不能重新提交或改变报告；
- 可以从答题卡跳到任意错题；
- 本次错题同时已进入长期 `practice_mistakes`，但复盘筛选不混入其他会话的历史错题。

### 8.4 历史访问

- 成绩报告可以从学习记录再次打开。
- `completed` 报告使用交卷时冻结的 report snapshot，不随以后题目、诊断规则或前端文案改变判定事实。
- `paused` 会话只显示继续入口，不生成成绩报告。
- `abandoned` 会话可作为历史事实保留，但不生成 PASS/FAIL 报告。

## 9. 数据模型

新增 `practice_sessions`，职责是保存可恢复会话和冻结结果，不继续把可变进度塞入追加式 `learning_events`。

| 字段 | 说明 |
| --- | --- |
| `id` | 服务端生成的会话 ID |
| `owner_id` | 当前账号，所有查询和写入按 owner 隔离 |
| `paper_id` / `release_id` | 试卷与不可变发布版本 |
| `mode` | `challenge/scholar/revenge` |
| `status` | `active/paused/completed/abandoned` |
| `question_order` | 冻结题目引用顺序和选择种子 |
| `answers` | 按题目保存本人答案、正误、提交时间和完成证据 |
| `runtime_state` | 当前索引、生命、连胜、剩余时间、复仇阶段和显示状态 |
| `stats` | 已答、正确、错误、未答、经验和累计作答时长 |
| `scoring_snapshot` | 本卷冻结的模拟 PASS/FAIL 与领域等级规则 |
| `report_snapshot` | 仅完成后写入的冻结报告事实 |
| `revision` | 乐观并发版本，从 1 开始 |
| 时间字段 | `started_at/last_saved_at/paused_at/completed_at/abandoned_at` |

约束：

- `owner_id + paper_id + release_id + mode` 最多存在一个 `active/paused` 会话；
- `completed/abandoned` 终态不可回到可编辑状态；
- `release_id` 使用 `RESTRICT`，未完成和历史会话引用期间不可删除发布快照；
- `revision` 不匹配返回 409，不允许旧标签页静默覆盖新进度。

练习完成后继续追加现有 `PRACTICE_SESSION_COMPLETED` 学习事件，用于经验汇总和兼容现有统计；该事件由会话完成事务产生，不再由浏览器单独上报可伪造摘要。

## 10. 服务与 API 边界

### 10.1 公共服务

新增职责明确的 `practice_session_service`，管理生命周期、并发、恢复和报告冻结。现有服务器判题、错题状态机和发布题目访问能力抽成或保持为可复用公共入口，挑战、学霸、复仇和其他做题调用方不得复制判题实现。

### 10.2 API

```text
POST   /api/v1/learning/practice/sessions/start
GET    /api/v1/learning/practice/sessions/active
GET    /api/v1/learning/practice/sessions/{session_id}
PATCH  /api/v1/learning/practice/sessions/{session_id}/state
POST   /api/v1/learning/practice/sessions/{session_id}/answers
POST   /api/v1/learning/practice/sessions/{session_id}/pause
POST   /api/v1/learning/practice/sessions/{session_id}/complete
POST   /api/v1/learning/practice/sessions/{session_id}/abandon
GET    /api/v1/learning/practice/sessions/{session_id}/report
```

所有写请求携带 `revision`。服务器从登录会话确定 owner，忽略客户端 owner、correct、score、PASS/FAIL 和目标等级字段。

`answers` 接口读取冻结发布题目并完成一个原子事务：判题、写入会话答案、更新统计、推进错题状态、写学习事件证据。现有无会话的统一判题接口继续服务多题画布等调用方，但内部必须复用同一判题与错题服务。

### 10.3 前端公共模块

新增共享的做题会话适配器和答题卡组件，由三种模式共同调用。`100-practice-mode.js` 只负责模式编排，不直接持有另一套持久化或判题事实。

## 11. 数据流

### 11.1 开始或恢复

1. 用户选择试卷、题量、顺序和模式。
2. 前端查询相同账号、release 和 mode 的可恢复会话。
3. 用户选择继续时读取冻结顺序和状态；选择重开时先明确放弃旧会话。
4. 新会话由服务器按默认领域配比选题、冻结顺序与模拟判定规则。
5. 前端依据服务端 snapshot 渲染题目、答题卡和模式状态。

### 11.2 作答

1. 用户选择一个未答题答案。
2. 前端提交 `sessionId + questionId + selectedAnswer + revision`。
3. 服务端校验 owner、状态、release、题目归属和未答状态。
4. 服务端判题并原子更新会话、错题和事件证据。
5. 前端使用响应刷新题卡、答题卡和解析。

### 11.3 保存退出

1. 前端先提交最新运行状态。
2. 服务端校验 revision 并把会话改为 `paused`。
3. 成功后前端停止计时并返回大厅。
4. 保存失败时留在当前页，不显示已经退出或已保存。

### 11.4 交卷

1. 前端展示未答确认并提交 complete。
2. 服务端锁定会话，重新汇总冻结答案，不采用客户端统计。
3. 服务端计算模拟结果、领域等级和错题引用，写入 report snapshot。
4. 同一事务把状态改为 `completed` 并追加完成事件。
5. 前端读取报告快照渲染成绩页。

## 12. 失败、并发与恢复

- 未登录：不创建业务会话，使用现有登录弹窗；登录后重新开始或加载账号会话。
- 判题失败：保留选择，不完成、不跳题，显示重试。
- 自动保存失败：显示“进度尚未保存”，继续重试；保存退出必须等待明确成功。
- 409 冲突：停止当前计时交互，提示另一页面已更新，提供加载最新进度；不自动覆盖。
- release 不可用：因 FK 和不可变发布规则，已有会话仍可读取；服务异常时显示重试而非切换到新版本。
- 领域题量不足：开始或发布预检返回结构化缺口，禁止偷偷跨领域补题。
- 报告生成失败：会话不能显示 completed 成功页；事务回滚到可重试交卷状态。
- 重复 answer、pause、complete 请求：以会话 revision 和题目完成事实保证幂等，不能重复计分或累计错题次数。

## 13. 兼容与迁移

- 现有完成/放弃摘要继续可在学习记录中显示，但没有完整报告快照时只展示旧版摘要，不伪造领域报告。
- 新版会话上线后，学习记录优先读取 `practice_sessions`，并兼容历史 `PRACTICE_SESSION_COMPLETED` 事件。
- 现有发布版本保持不可变；本轮新建模拟卷继续使用当前 `42/50/8` 默认组卷权重。
- `33/41/26` 的后续切换不包含在本轮迁移中，不能借本功能发布隐式改变组卷业务规则。
- 正式 Logo 源为 `new-legacy/assets/logo.jpg`；实现和发布时必须通过权威源同步链路进入 release。

## 14. 验收与测试

### 14.1 后端

- 新建、恢复、暂停、完成、放弃和终态不可逆。
- 账号 A/B 隔离、未登录拒绝和跨账号 404。
- 相同 paper/release/mode 只允许一个可恢复会话。
- revision 冲突、重复请求和并发答案幂等。
- 判题、会话答案、错题状态和学习事件同事务一致。
- 交卷以服务器答案重算，客户端伪造 correct、score、PASS 无效。
- 默认 `42/50/8` 最大余数分配总数准确且稳定，配比和整数题数写入发布快照。
- 领域不足、未分类题、缺失模拟判定规则的失败响应。
- completed report snapshot 在题目或规则后续变化后保持不变。

### 14.2 前端契约

- 三种模式只加载一个答题卡和会话适配器入口。
- 题号四态、统计、筛选和 `aria-label` 正确。
- 已答题选项禁用且解析可读。
- 保存失败、判题失败、409、未答交卷确认均有恢复入口。
- 不包含用浏览器存储保存会话、成绩或报告的业务键。

### 14.3 真实浏览器

- 挑战、学霸、复仇分别完成自由跳题和已答回看。
- 答错后题号变红、错题数增加且长期错题同步；答对题号状态正确。
- 保存退出、刷新、重新登录和另一设备恢复后状态一致。
- 学霸模式暂停期间时间不减少，恢复后继续倒计时。
- 未答交卷返回定位和仍然交卷两条路径。
- 10、20、60、180 题下答题卡布局、滚动和筛选可用。
- 桌面常驻侧栏与窄屏底部抽屉均可自由跳题。
- 成绩报告显示幻谱 Logo、模拟 PASS/FAIL、V8 领域饼图、领域表和本次错题入口。
- 本次错题复盘只包含当前会话错题，且不能修改答案。
- 所有新增可见按钮、链接、筛选和弹窗通过控制矩阵扫描。

## 15. 发布约束

- 前端源修改只落在 `new-legacy/` 或职责明确的同步适配层，不手工编辑 active release。
- 正式发布必须使用 `manage-new-legacy.js update new-legacy --skip-browser`。
- 候选 release 文件数不得少于当前 active release，且必须包含做题页、成绩报告所需 Logo 和关键页面。
- 发布前运行后端测试、`frontend pnpm test`、定向设计契约和三模式真实浏览器遍历。

## 16. 已确认的产品决策

- 答题卡选择桌面常驻侧栏方案，窄屏使用底部抽屉。
- 用户可以点击任意题号自由跳题。
- 已答题只能查看答案和解析，不能改答案。
- 挑战、学霸、复仇三种模式全部使用统一答题卡。
- 未完成练习可以保存退出并继续；学霸模式暂停时间池。
- 成绩报告使用幻谱 Logo 和 PMP 风格信息结构。
- 领域饼图按官方信息逻辑展示领域占比和目标等级，而非正确/错误占比。
- 本轮新建模拟卷继续统一使用 `42/50/8` 默认配比，教师不逐卷配置配比。
- `33/41/26` 仅记录为后续迁移事项，不进入本轮实现或当前报告数据。
- PASS/FAIL 明确为模拟判定，不声称采用未公开的 PMI 官方及格分数。
