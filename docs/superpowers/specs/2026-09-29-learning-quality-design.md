# 短练报告与教师发布质量

用户已批准上一轮列出的前三项，且要求仅本地预览，不部署 UAT。

1. 短练报告：根据会话冻结的题量、模式与试卷信息区分短练和模拟考试。短练展示实际正确率、错题、覆盖与下一步，不给考试 PASS/FAIL；未覆盖领域显示未评估。完整模拟考试保留现有评分。网页、小程序一致；历史报告兼容。
2. 工作台：已发布按当前 status 判定，撤回但保留 publishedVersion 的试卷算草稿。归档、删除继续排除。
3. 发布检查：扩展现有发布链路，给出具体题目、缺失项和修改入口；答案与解析覆盖单选、多选、配对；中文基础内容检查，英文仅在明确开放英文时作为必需项，无显式语言配置时英文缺失为提醒。复用现有判题校验，服务端为权威，发布时再次验证；拒绝不能绕过的缺失答案和解析。草稿允许不完整，既有发布版本不受影响。校验失败可修改、重试、退出，保持权限隔离。

不增加新依赖、不迁移数据库、不修改生产/UAT。优先局部扩展已有公共模块，前端源仅 new-legacy 或适配器源。使用当前独立工作树与本地数据库。

验收：短练无通过/不通过误导、空领域未评估、模拟报告保留；撤回后统计正确；多种题型缺失项可定位、修复后可重新发布；无权者不可检查/发布。现有相关回归与真实浏览器验证，记录未验证项。
