# 缺图题目临时替换设计

## 目标

暂时下线《PMP 有分歧不站队试卷01》中依赖缺失表格图片的题目，同时保持学员侧试卷仍为 60 题，不改变既有成绩、报告和已发布历史版本。

## 已核实对象

- 目标试卷：`paper-e8ab20b0-77b2-40ea-b0c7-e8a57efedcf3`
- 当前发布版本：`paper-e8ab20b0-77b2-40ea-b0c7-e8a57efedcf3-v1-msvlb1b0`
- 待屏蔽题目：`q_cdebc94b84c149c889b1d5a0312ba7cc`，教师题号 `PMP-000111`
- 当前位置：数据库 `order_index=50`，即学员侧第 51 题
- 题干开头：`表格显示了一个敏捷项目的需求及其预期投资回报率（ROI）……`
- 替补来源试卷：《梦好PMP 先内后外试卷01》
- 替补来源版本：`paper-2823e3c4-7b44-49ac-934f-28a42190848c-v1-msvle3vk`
- 替补题目：`q_1c3489935ed9449c9cf4bbb0555f6420`，教师题号 `PMP-000245`

替补题题干、四个选项、正确答案和解析完整，不依赖图片；其内容哈希未出现在目标卷中，并且题目元数据包含“有分歧不站队”原则，适合目标卷主题。

## 方案比较

### 方案 A：直接移除，发布 59 题版本

不采用。做题页目前只提供 10、20、60、180 题选项。59 题会禁用 60 题练习，直接请求 60 题还会得到 `PRACTICE_QUESTION_SHORTAGE`。

### 方案 B：在页面按题干字符串过滤

不采用。它会让前端成为业务数据来源，并导致发布目录题量、分页、练习会话和实际渲染数量不一致。

### 方案 C：替换一题并生成新的 60 题发布版本

采用。新版本在相同顺序位置使用替补题，仍保留 60 道冻结题目；旧版本转为 `superseded` 并继续作为历史快照可读。

## 数据与版本变更

1. 在目标试卷草稿的 `paper_questions` 中，用替补题替换待屏蔽题，保持 `order_index=50` 和原分值。
2. 将待屏蔽题的题库生命周期标记为安全删除，使其不再进入后续选题；保留题目实体和恢复信息，不做物理删除。
3. 基于目标卷当前发布设置创建版本 2：
   - 保留名称、说明、权限、开放模式、角色和发布元数据；
   - 复制其余 59 道冻结快照；
   - 第 51 题使用替补来源版本中已经验证的冻结快照；
   - `question_count` 保持 60；
   - 旧版本原子切换为 `superseded`，新版本成为唯一 `published` 版本。
4. 同步 `exam_papers` 的发布投影、修订号和教学内容修订，使管理端和学员目录立即读取新版本。

当前原则系列历史版本缺少新版组卷预检所需的考试领域标注，因此不能把这次维护伪装成重新组卷。实现应提供一条有明确源版本、目标版本和题目 ID 的受控替换事务；它只复用已经发布且完整的冻结快照，不放宽常规发布接口的领域预检。

## 学员行为

- 新进入试卷的学员只看到版本 2，仍可选择 60 题并正常开始练习。
- 已完成的版本 1 会话、成绩、错题和报告仍绑定版本 1，不被改写。
- 已开始但未完成的版本 1 会话继续读取版本 1 冻结快照并可续做；如果其中包含待屏蔽题，该旧会话仍保留原题，避免静默改变进行中的考试。
- 当前测试数据库中该卷没有 `active` 或 `paused` 会话，只有一条已完成挑战记录。生产执行前必须再次查询生产数据库；该查询结果只作为执行报告，不改变上述兼容策略。

## 安全与回滚

- 事务开始前校验目标发布版本仍为唯一 active 版本、版本号仍为 1、目标题仍在 `order_index=50`，替补题仍来自指定版本且快照完整。
- 任一前置条件不一致时不写入并返回明确错误。
- 全部关系表、发布版本、生命周期和教学修订在同一数据库事务中提交，避免学员看到半切换状态。
- 回滚不修改历史行：从保留的版本 1 快照创建后续恢复版本，并恢复题库生命周期；不把版本 2 原地改回版本 1。

## 验收与测试

自动化测试必须覆盖：

1. 预检能识别正确目标、替补和位置，并拒绝过期版本、错误题目、重复替补或不完整快照。
2. 执行后目标卷只有一个 active 版本，版本号递增且题量仍为 60。
3. 新版本不含 `PMP-000111`，且只含一次 `PMP-000245`，位置为第 51 题。
4. 旧版本仍保留原 60 题并可读取，已完成报告不变。
5. 学员发布目录显示目标卷 60 题；以 60 题开始新练习成功。
6. 事务失败时不留下新版本、部分题目替换或生命周期半更新。

执行后还需只读核对数据库引用、调用发布目录与取题接口，并完成一次学员账号的 60 题开始练习验证。
