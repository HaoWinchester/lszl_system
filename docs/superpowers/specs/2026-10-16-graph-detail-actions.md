# 知识卡片详情操作精简

用户已明确要求：知识图谱的“做题”按钮先隐藏，“设为连线起点”按钮去除。最短路径是修改现有卡片详情渲染：做题入口使用hidden保留内部能力；移除连线起点按钮DOM及事件绑定，保留其他连线入口；调整批量配题成功文案，不再指向隐藏入口。编辑、删除、相关范围和关系详情继续工作。

验证直接检查真实图谱页面卡片详情（含锁定、切换/重绘）：做题不显示、不能通过正常键盘点击进入；起点按钮不存在；详情其他操作和渲染无错误。既有抽屉功能测试通过共享测试助手调用保留入口，明确属于隐藏功能内部回归，不宣称用户可见工作流。

只改权威new-legacy源，标准同步与候选发布，开发自检后合入uat并部署，main保持不变等待用户验收。
