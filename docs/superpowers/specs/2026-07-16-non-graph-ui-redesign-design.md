# 非图谱页面“沉稳智能工作台”改版设计

## 目标

在不改变知识图谱编辑器、后端接口、权限与业务行为的前提下，重做登录、文件管理、题库、训练、回忆、会员、用户管理和系统设置页面，使产品同时具备成熟知识管理软件的专业感与现代智能学习产品的反馈能力。

设计比例为“沉稳智识 70% + 现代智能 30%”：结构、排版和导航保持克制稳定；学习进度、掌握状态和智能提示使用更鲜明的数据表达。

## 范围

### 包含

- 为所有非图谱 React 页面建立统一的应用外壳、导航和页面头部。
- 统一颜色、字号、间距、圆角、边框、阴影、按钮、表单、状态标签和空状态。
- 根据角色显示有权限的导航入口，但保持相同入口的顺序稳定。
- 优化文件管理、题库、训练、回忆、会员、用户管理、系统设置与登录页的信息层级。
- 保留现有响应式能力并改善窄屏下的导航与内容组织。

### 不包含

- 不修改 `GraphEditor` 内 iframe 的页面、画布、节点、连线、工具条或交互。
- 不修改 `legacy/` 源文件或派生的图谱引擎资源。
- 不修改 API 契约、数据库模型、角色权限或订阅规则。
- 不在本次改版中新增 AI 推理、自动出题或统计接口。

## 视觉语言

### 核心色

- 深海军蓝 `#10233f`：侧栏、品牌区、关键标题。
- 专业蓝 `#356dff`：主按钮、选中导航、主要链接。
- 智能青绿 `#18a78c`：掌握、完成、学习进度与智能提示。
- 雾灰背景 `#f4f7fa`：应用画布。
- 白色 `#ffffff`：主要工作表面。
- 正文 `#182230`、次级正文 `#5f6b7a`、弱提示 `#8b97a6`。
- 边框 `#dce3eb`、浅表面 `#edf2f7`。
- 琥珀和红色只表达警告、风险和破坏性操作。

### 排版与密度

- 使用系统中文无衬线字体，避免引入网络字体依赖。
- 页面主标题 22–24px、区块标题 16–18px、正文 14px、辅助信息 12px。
- 标题字重 650–700，正文 400–500；避免大段全粗体。
- 管理与编辑页面采用中高信息密度；学习页面增加留白并强化当前任务。

### 表面与动效

- 控件圆角 8px，普通容器 12px，重要概览容器 14px。
- 普通内容区依靠背景、间距和细边框分层，不使用大面积阴影。
- 菜单、弹窗、悬浮反馈使用克制阴影。
- 渐变只用于登录品牌区、会员价值区、学习概览和空状态装饰。
- 动效时长 140–220ms，并遵守 `prefers-reduced-motion`。

## 应用外壳与导航

新增共享 `WorkspaceShell`，供 `/files`、`/question-bank`、`/training`、`/recall`、`/users`、`/settings` 和 `/member` 使用。

- 桌面端左侧为 232px 深色导航，可收起为 72px 图标栏。
- 导航按“工作空间、学习中心、管理中心”分组。
- 工作空间：知识图谱、文件管理。
- 学习中心：题库、考题训练、深度回忆。
- 管理中心：用户管理、系统设置，仅向管理员显示。
- 底部显示会员入口、当前账号和退出操作。
- 顶部栏高度 64px，展示页面标题、上下文信息、主要操作和移动端菜单按钮。
- 点击知识图谱直接进入现有全屏 iframe，不在图谱外包裹新外壳。

学生、教师与管理员使用同一套视觉系统。学生页侧重下一步学习行动；教师和管理员页保持更高的信息密度。无权限入口直接隐藏，不显示不可用假按钮。

## 页面设计

### 登录

- 桌面端采用左右分栏：左侧品牌价值与知识网络装饰，右侧为紧凑登录卡片。
- 移动端只保留品牌标识和登录卡片。
- 默认账号说明降级为开发提示，不与主操作竞争。
- 错误信息放在字段区附近，登录中状态保留明确反馈。

### 文件管理

- 使用统一外壳，移除页面内部重复的品牌侧栏和账号导航。
- 页面头部集中放置搜索、新建图谱和导入操作。
- 内容区保留网格/列表切换、筛选、排序、批量选择和回收站能力。
- 文件卡片以白色正文区域和低饱和知识网络封面组成；彩色只用于封面与状态。
- 文件夹、存储配额和回收站作为左侧上下文面板，而非第二套全局导航。
- 空状态明确给出唯一主要行动。

### 题库

- 使用三栏专业编辑台：左侧题库/题目导航，中间编辑工作区，右侧完成度与发布状态。
- 顶部集中显示当前题库、科目和主要操作。
- 关键词、知识点、推理逻辑使用同一组标签页和一致的编辑组件。
- 完成度用青绿色进度表达；缺失项使用中性提示，不用大面积虚线空框。
- 组卷发布保持独立工作区，不与题目基础信息等权堆叠。

### 考题训练

- 采用专注任务模板。开始前显示试卷选择与训练说明；开始后突出题干、选项、进度和证据栏。
- 顶部显示当前进度、剩余题目和退出入口，弱化全局工具。
- 答案状态、线索和解析使用一致语义色，不能只靠颜色传达。
- 无可用试卷时给出返回题库或联系教师的明确路径。

### 深度回忆

- 保留知识网络式回忆体验，但重做页面外层与浮动控制的视觉语言。
- 顶部显示本次目标、已完成数和掌握趋势。
- 回忆卡片突出问题、作答和自评，辅助工具收纳到次级区域。
- 空状态和完成状态使用学习概览容器，提供下一步训练行动。

### 用户管理

- 使用列表工作台模板：顶部统计概览、筛选与邀请/新建操作，下方为用户列表与详情编辑。
- 角色、状态、订阅使用紧凑状态标签。
- 危险操作集中在详情底部，并与保存操作明确分离。
- 日志和数据面板使用表格/时间线，不堆叠装饰卡片。

### 系统设置

- 左侧为设置分类，中间为表单，右侧仅在需要时显示说明或预览。
- 保存操作固定在页面头部或底部操作栏，避免每个区块都有重复保存按钮。
- 系统状态、审计与危险设置使用清晰分区。
- 字段说明紧邻控件，错误信息不依赖弹窗。

### 会员

- 使用沉稳的价值概览区和清晰套餐对比。
- 当前套餐、到期时间和可用权益优先于营销文案。
- 推荐套餐可使用专业蓝到青绿的轻渐变，但其他套餐保持白色表面。
- 兑换码与订单记录作为次级内容，不与购买主流程争抢注意力。

## 状态设计

- 加载：优先使用局部骨架或按钮内加载状态，不阻塞整个页面。
- 空状态：说明当前原因，并提供一个主要行动和最多一个次要行动。
- 错误：在相关区域内显示可恢复提示；保留现有 toast 作为操作反馈。
- 成功：短暂反馈即可，避免常驻绿色大卡片。
- 破坏性操作：继续使用确认流程，按钮与普通操作保持视觉隔离。

## 响应式与可访问性

- 1280px 以上使用完整侧栏和多栏工作台。
- 800–1279px 使用可收起侧栏，三栏页面降为两栏或抽屉详情。
- 800px 以下使用顶部菜单与单栏内容；文件管理继续遵循现有移动端只读规则。
- 所有交互控件保留可见焦点，触摸目标不小于 44px。
- 导航、标签页、弹窗和状态信息使用正确语义与 ARIA 属性。
- 正文和控件满足可读对比度，状态不只依赖颜色区分。

## 实现边界

- 先新增共享外壳与设计 token，再逐页接入，避免一次性重写业务逻辑。
- 页面组件保留现有 API 调用、状态变量与事件函数，主要调整 JSX 外壳、类名组合和 CSS。
- 图谱路由、iframe 桥接和 legacy 资源不进入改动范围。
- 通过现有 TypeScript、设计契约测试和浏览器截图回归验证。

## 验收标准

- 所有非图谱页面具有一致的导航、页面头部、颜色、排版和控件风格。
- 教师/管理员和学员能在同一设计系统下获得适合各自任务的信息密度。
- 知识图谱编辑器的 DOM、视觉和交互未被改变。
- 现有核心操作、权限、API 调用和响应式规则继续可用。
- TypeScript 构建、前端测试和桌面/窄屏页面截图回归通过。
