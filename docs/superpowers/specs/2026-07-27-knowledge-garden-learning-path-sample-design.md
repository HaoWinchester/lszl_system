# 知识乐园：学习路径局部样片设计

## 目标

为学生端验证一套活泼、沉浸但适合成人备考的视觉语言。首个样片仅覆盖学习路径页的顶栏、阶段招牌与横向学习路径节点；知识图谱编辑画布、业务逻辑、路由、接口、数据与交互语义均不修改。

## 范围与边界

- 仅修改 `new-legacy/styles/guided-learning-path.css`。
- 保留所有现有 HTML、JavaScript、ID、class、链接、按钮事件、解锁状态和无障碍语义。
- 保留当前横向拖拽路径、阶段切换、节点点击、当前位置按钮、键盘焦点和移动端行为。
- 不改训练、深度回忆、会员、文件或管理页面；它们将在样片获确认后统一沿用视觉 token。

## 视觉方向

视觉主题为“知识乐园”：暖奶油色画布配珊瑚橙、湖蓝、柠檬黄、薄荷绿的阶段色。装饰仅通过 CSS 渐变、伪元素和阴影实现，避免新增资源、内容或可操作控件。

### 顶栏

顶栏改为贴近页面上方的圆角导航胶囊：品牌标识使用珊瑚色，模式切换表现为贴纸式分段控件，账户入口保持现有按钮和菜单行为。页面背景改为柔和奶油色，并使用低对比图案提供空间层次。

### 阶段招牌

现有阶段切换按钮保留原尺寸、可点击区域、动态阶段色和按压逻辑。视觉上改为带内高光、双色投影和圆角的章节招牌；描述和标题保持原文案与结构。

### 学习路径

保留现有轨道尺寸、节点坐标和解锁状态。轨道呈现为低对比的彩色虚线漫游路线；节点成为带立体底座的圆形徽章：已完成节点明亮，当前节点使用轻柔脉冲环，锁定节点使用低饱和云朵灰。悬浮节点说明沿用当前 DOM，仅提升为贴纸气泡的纸感层次。

### 交互与可访问性

不引入新的操作。已有悬浮、按压、`focus-visible`、禁用与移动端规则继续可见；动画仅限于当前节点的既有脉冲和低幅度过渡，尊重 `prefers-reduced-motion`。

## 验收标准

1. 所有现有学习路径按钮、链接、节点和阶段选择仍可操作，且没有脚本改动。
2. 桌面端保留全景横向路径和拖拽滚动；窄屏不出现文字裁切、遮挡或横向页面溢出。
3. 当前、已完成、锁定与管理员开放四类节点仍能清晰区分。
4. 键盘焦点可见，禁用节点不可点击，降低动态效果偏好下不播放非必要动画。
5. 变更只落在样式文件，并通过现有样式/浏览器回归检查。
