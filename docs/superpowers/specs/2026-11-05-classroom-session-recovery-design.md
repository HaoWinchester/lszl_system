# 课堂会话失效与草稿恢复

用户已确认按排查方案修复全部问题，自检后部署 UAT，等待用户验收，不合入 main。

## 行为约定

- 登录失效只暂停写入，保留当前账号上下文、画布对象、文字草稿、待保存队列和修订号，不切到游客空画布，不自动刷新页面。
- 首个当前会话的 401 触发一次公共恢复状态；403 权限错误和网络/5xx 不冒充退出；旧请求的 401 不影响新登录。
- 所有画布使用同一公共会话恢复入口。重新登录原账号后恢复待保存内容，仍采用原修订号检测冲突；不把旧账号草稿提交到新账号。
- 切换画笔立即完成，不等待文字持久化。保留未保存文字，可返回文字工具继续编辑或重试；输入法、取消、只读账号和正常保存语义保持兼容。
- 主动退出统一先提交文字和画布。失败、超时、会话失效则取消退出，保留课堂；退出来源记录不含密码、Cookie 或正文。
- 活跃前台页面定期调用显式会话续期接口；保留旧的延迟只读响应不能恢复退出会话的保护。服务端撤销记录保证迟到的续期响应和旧 Cookie 无法恢复已退出身份。
- 数据库仍是已保存数据的事实源；未保存内容仅保留本页内存，离开/关闭有未保存提示，不增加浏览器业务数据持久化。
- 保持页面布局、尺寸、配色、已有图谱内部做题行为；仅失效时展示恢复提示。

## 验证矩阵

| 场景 | 页面 | 结果 |
| --- | --- | --- |
| 编辑文字时 Cookie 失效 | 图谱、回忆、多题画布 | 原文字/画布保留，保存暂停，提示原账号重登 |
| 保存返回 401、503、超时 | 三类画布 | 切换画笔立即完成，保留未保存提示，可重试 |
| 原账号重登 | 三类画布 | 不重载/清空当前课堂，原修订号保存，刷新后可从数据库读取 |
| 尝试其他账号 | 恢复中页面 | 阻止把草稿保存给其他账号 |
| 主动退出与保存失败 | 所有账号入口/三类画布 | 失败不发送退出请求，保存成功后才退出 |
| 只读与跨文件/题目 | 三类画布 | 不绕过权限，不把旧草稿写入新上下文 |
| 网络查询失败/迟到响应 | 公共认证入口 | 不缓存假游客，不覆盖新登录 |
| 续期/退出/替换登录竞态 | 后端 | 活跃会话续期；撤销 Cookie 永远不可认证 |
