# 画笔与知识图谱交互补齐

用户已在对照结果后授权“修改”。本规格落实对照中已确认的八类缺口，沿用现有原生前端和共享画笔模块。

## 行为与数据

1. 共享画笔在图谱、深度回忆、多题画布、临时相关画布中统一提供：可直接打开的设置、常用颜色、粗细、笔迹透明度；文字有数字字号和加粗。颜色常驻小色点，参数通过明确设置按钮展开；不依赖双击才可发现。保留右侧关闭、Esc、右键退出、空格临时平移、已有撤销和只读规则。
2. 短文本使用内容测量得到自然宽度和行高，新建/自动宽度文字删字后收缩；用户手动设置的换行宽度继续保留，不把老文件的明确宽度擅自重排。输入框 padding 随画布缩放，编辑框与保存后的选框一致。编辑中仍可从边框拖动，输入法、保存失败、取消和异步版本检查保留。
3. 橡皮擦按路径连续擦除整笔，从空白处按下也能在经过笔迹时擦除。一次完整拖动仅有一个撤销动作。Esc、pointercancel、blur、切换工具取消未完成擦除，恢复原笔迹；只读绝不产生修改。跨越低采样/快速移动路径也应命中。
4. 普通笔迹可在选择工具下点击选中、拖动、删除，选中后能调整颜色、粗细、透明度。修改只作用于当前笔迹，撤销/重做与数据库重载一致。缩放和旋转不在本轮新增范围。保留文字选中/编辑/八向尺寸功能。
5. opacity 是可选的每笔字段，旧数据缺省维持 pen=1/highlighter=.3/text=1；前后端严格拒绝非法值和任意额外字段，主要存储/导出调用链不能丢失该字段，不新增数据库迁移或浏览器持久化业务缓存。
6. 图谱左侧“文本”和画笔“文字”的新建入口共用共享画笔文字流程，已有独立图谱文本图元继续可读可编辑、保留格式和文件兼容。不得静默批量迁移历史图元。统一入口的提示、焦点、保存和取消行为。

## 图谱界面

7. 主工具栏改为窄单列（桌面约 48–56 CSS px），保留现有功能与选择/手型、心流、关系能力；专业模式格式控制收进明确的更多/格式入口，优先使用现有上下文工具栏。窄屏可折叠/滚动，不能溢出或遮住底部缩放。
8. 连线颜色/样式/端口弹层避让目标曲线/卡片，使用共享定位模块；空间不足选侧边/对侧并限制高度，不能只提高 z-index。现有手动停靠、全屏和缩放继续可用。
9. 曲线主中点明显可见，辅助点在悬停/聚焦/调整时渐进显示；仍保留原有控制点身份、命中区与可键盘发现性，不能破坏既有曲线/折线/端点拖拽、重叠选择和撤销。路径按钮补可访问名称、aria-pressed，工具栏图标反映当前直线/曲线/折线/混合态。

## 边界与验证

不改做题大厅、试卷页、分享策略、模板和无关业务。仅写当前工作区，用 codex 功能分支；所有业务修改落 new-legacy 权威源/后端共享校验。新增行为先补能失败的回归，再改实现。验证共享画笔三个正式页面和临时画布，覆盖成功/取消/只读/失败重试/重载。正式发布走 manage-new-legacy update，再合入、代理推送和部署 uat，等待用户验收，不合入 main。
