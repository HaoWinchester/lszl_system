# 教师 Claude Code 对话客户端改造

用户已明确参考 ChatGPT 页面，并补充：每账号最多一个 Claude Code 活动进程，切换历史使用对应 session ID；同时修复完成试卷并评论后重进报错。沿用本轮既有 UAT-only 授权。

## 用户体验
- 浅色中性界面，左侧历史、新对话、底部账号；中央单列消息与空态引导，底部固定圆角输入区。桌面消息宽约 760px、侧栏 260px；手机侧栏为抽屉，无横向滚动。
- 选择、拖拽、粘贴图片后显示附件卡和上传进度。发送统一完成待上传附件，再提交用户消息；失败保留文本/附件，不发送缺附件的请求。可仅上传文件后询问内容，不强制先提取题目。
- 服务端真实事件流展示等待、正在读取具体文件、工具调用、逐字回复、完成/失败。不得虚构思考链；工具详情折叠。停止、刷新恢复、切换会话不串流。
- 预览与执行回执成为消息中的结果入口，可打开侧面预览；普通对话不被永久双栏表单挤压。导入/发布继续复用服务端校验和用户已有权限。

## 运行和数据边界
- 账号最多一个活动模型进程，数据库锁/任务租约跨 API 与 worker 实例生效；不同浏览器标签也不能绕过。切换先停止并等待旧进程退出，再恢复目标 Claude session ID，保留部分回复和历史。
- CLI session ID、历史和工作目录持久化；空闲可以释放进程，下一条恢复相同 session，不把每次随机临时目录调用伪装为持久会话。现有旧会话可迁移对话文字与附件清单。
- 继续服务器已有 Claude Code、glm-5.3-flash[1m]、GLM Coding Plan；不回退按量 API。复用已有 Python/Office/OCR runtime，不新增无关依赖。
- 初始全局最多一个重任务。文件仍 20MiB/个、5个/批、50MiB/会话、200页/文档、500题/计划，解析与模型输出有界，不一次读取整个题库。
- 教师只能读本会话授权上传文件；CLI 不能直接访问服务器密钥、其他教师文件或任意 shell。通过限权文件/图片/导入工具读取完整内容的分页片段，不只固定前10段摘要。普通问答不自动生成/修改发布方案。
- 图片格式增加 PNG/JPEG/WebP，验证真实图像格式和像素/尺寸，复用本地 OCR；视觉解读能力必须实际验证 GLM 路由，不能把 OCR 文字当成已理解图像。图片来源保留可见。
- 会话、事件与结果落库，原件及 CLI 历史持久化私有存储。事件不输出密钥、路径、原始 stderr 或内部思考链；只渲染用户可见文本与工具执行摘要。
- 原答案/原则/联想词保留，明确更正才修改；默认私有，发布执行复用旧权限/幂等/CAS。旧发布快照不变。

## 试卷重进
UAT admin 唯一成绩记录对应3题试卷；历史“进入练习”漏同步题量，沿用10题导致422 PRACTICE_QUESTION_SHORTAGE。复用选卷同步入口，保留成绩和评论；覆盖历史重进、刷新、返回入口及小试卷，不修改原始用户记录。

## 验收
实际服务器验证多轮、附件立即发送、问文件内容、切换A/B会话及恢复、停止、多标签、跨账号隔离和进程数。测试普通文档、题库、扫描页和图片，不以结构化导入样例代替自然问答。对照 ChatGPT 排版浏览器实测1440/390视口；回忆/归纳仍无弹幕。只部署 UAT，需用户本人验收后才 main/生产。
