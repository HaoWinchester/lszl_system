# BoardMix 风格全局视觉升级设计

## 目标

将现有知识图谱系统升级为以“画布为中心”的专业知识工作台。整体借鉴 BoardMix 的信息层级和交互气质，而不复制其品牌、文案、图标或具体界面：浅色无限画布、轻量浮动工具、柔和对象色、就近反馈，以及克制且一致的应用壳层。

本次改造覆盖图谱编辑器、文件管理、题库、训练、回忆、会员、用户管理、系统设置和登录页。用户可见的功能、权限、接口、数据模型及核心操作路径保持不变。

## 非目标与约束

- 不修改 `legacy/` 源文件。
- 图谱编辑器仍通过 `GraphEditor.tsx` 的 iframe 承载 `public/legacy/workbench.html`；视觉修复只通过 React 外壳、派生的 public legacy 资源和 bridge 可控注入完成。
- 不以浏览器存储替代后端数据，不引入假按钮或仅提示 toast 的交互。
- 不复制 BoardMix 的 logo、插画、界面截图、专有文案或像素级布局。
- 所有现有路由、角色守卫、保存、导入导出、缩放、拖拽、快捷键和数据隔离行为必须保持有效。

## 全局视觉语言

### 色彩

采用明亮中性底色，避免当前多页面各自使用蓝紫渐变或强玻璃卡片。

| Token | 用途 | 目标值 |
| --- | --- | --- |
| `--kg-canvas` | 无限画布及应用背景 | `#f6f7f9` |
| `--kg-surface` | 面板、菜单、弹窗 | `#ffffff` |
| `--kg-surface-subtle` | 选中与悬停底色 | `#f1f4f8` |
| `--kg-border` | 细分隔与边界 | `#e3e7ec` |
| `--kg-text` | 主文本 | `#242a33` |
| `--kg-muted` | 次级文本 | `#737d89` |
| `--kg-primary` | 主操作与焦点 | `#2f6df6` |
| `--kg-success` / `--kg-warning` / `--kg-danger` | 语义状态 | `#1fa978` / `#dc9b35` / `#dc5f57` |

对象分类允许使用低面积的蓝、黄、绿、珊瑚和紫色。色彩表达信息或状态，而不是为容器制造装饰。

### 排版和图标

- 统一采用系统中文无衬线字体栈：`PingFang SC`、`Microsoft YaHei`、系统 sans-serif。
- 标题使用清晰的字重和间距建立层级，不用大写字距标签或渐变文字。
- React 页面统一以 `lucide-react` 作为线性图标来源；替换字符图标、表情符号和风格不一致的手写 SVG。
- 保留图谱画布中具有业务含义的 SVG 连线、节点与缩放控件；其线宽、尺寸和悬停状态按 token 收敛。

### 形状、阴影和动效

- 控件圆角为 6–10px，常规面板圆角为 10–12px；不再使用 22–28px 的大圆角卡片。
- 常态面板使用细边框；仅浮动工具栏、菜单和模态使用轻短阴影（最大 8px blur），不叠加厚边框与重阴影。
- 悬停使用 120–180ms 的颜色、阴影和 transform 微变化；尊重 `prefers-reduced-motion`。
- 焦点态使用清晰的主色 2–3px 环，保证键盘访问和可见性。

## 信息架构与页面组件

### 共享应用壳层

1. 顶栏：紧凑、白底、细底边；左侧为返回/产品/当前上下文，右侧为协作、账号与主操作。
2. 侧栏：窄而稳定，条目为图标 + 文本；选中态使用低饱和主色底，不使用大面积渐变。
3. 浮动工具：画布类页面把低频操作收在靠近内容的浮动面板，不占用主工作区。
4. 表单和菜单：白底、12px 左右圆角、语义图标和明确的 hover/focus/disabled 状态。
5. 反馈：保存、加载、空状态、失败、权限不足均就近呈现，文案说明明确可恢复动作。

### 图谱编辑器 `/`

- 保留原版无限画布、拖拽、缩放、连线、选中样式与快捷键。
- 将外层及派生 iframe 样式收敛为浅灰画布、轻顶栏、窄浮动工具条、底部缩放坞和就近属性面板。
- 节点和关系保持原有业务色义；加强选中、悬停、保存中、协作/账号等状态的层级。

### 非画布页面

- 文件管理：从重卡片网格转为文件浏览器，强调列表/缩略图、筛选、上下文菜单和右侧检查器。
- 题库、训练、回忆：保留原有信息与流程，使用统一顶栏、局部面板和低对比背景；回忆页面维持画布感。
- 用户、系统设置、会员：从多重玻璃卡片改成工作台式左侧导航 + 内容面板；仅关键操作使用主色。
- 登录：更轻的入口页，保留现有认证流程及错误反馈，减少与主应用无关的装饰。

## 实施顺序

1. 建立全局 token、基础控件和图标适配层。
2. 收敛图谱编辑器外壳与 public legacy 派生样式，验证原版交互不回退。
3. 改造文件管理，使其成为全站非画布页面的样板。
4. 将共享壳层与控件规范迁移到题库、训练、回忆、会员、用户、系统设置和登录。
5. 逐页做截图、键盘可达性、窄屏响应和真实交互回归。

## 验证标准

- 每页使用同一组 token、圆角、边界、图标和焦点状态；不残留无语义的 emoji 图标、紫蓝渐变或厚重玻璃卡。
- 所有可点击控件仍有真实行为：导航、模态、API、状态更新或文件操作。
- 每项修改至少验证正常、空/失败或取消恢复路径。
- `pnpm exec tsc -b` 通过；涉及后端契约时运行对应后端测试。
- 以浏览器截图和实际操作回归图谱编辑器、文件管理及每个改造页面的关键路径。
