# 管理后台 Focus / Vega PC 端 UI 统一设计

## 1. 决策摘要

管理后台 8 个页面统一接入与学习端试点相同的 Focus / Vega 视觉体系。实现采用“共享皮肤 + 三个页面族适配”的方式：共享层提供统一令牌和组件视觉，后台通用页、用户管理页、基础系统设置页分别处理自身结构差异。

本轮只覆盖 PC 端，不新增、不重做移动端适配。登录、账号操作内部、会员套餐、购买和支付相关区域继续保持现状。允许修复 PC 端已有的对齐、换行、尺寸不一致和局部排版错乱，但不重排主要业务区块，不改变功能与数据行为。

## 2. 页面范围

### 2.1 后台通用页面族

- `admin-console.html`：管理后台总览
- `admin-operations.html`：操作记录
- `admin-settings.html`：系统设置与诊断
- `admin-subjects.html`：科目与知识树
- `feedback-management.html`：反馈管理
- `message-management.html`：消息管理

这些页面继续共享既有后台导航、后台头栏和 `admin-*` 内容组件结构。

### 2.2 用户管理页面族

- `user-management.html`

保留当前三栏管理工作区、用户列表、用户详情和辅助面板结构，只统一视觉并修复 PC 端列宽、表单、操作区和卡片对齐。

### 2.3 基础系统设置页面族

- `system-settings.html`

保留当前侧栏页签和设置面板结构，只统一视觉并修复 PC 端标题区、侧栏、内容面板、表单和操作区对齐。

## 3. 当前问题

现有后台混用了三套主要视觉语言：

- 后台通用页以青绿色为主，并保留部分渐变、较大圆角和较重阴影。
- 用户管理页使用紫橙渐变按钮和偏紫色的独立卡片体系。
- 基础系统设置页使用亮蓝背景、蓝色导航和另一套面板规格。
- 反馈和消息页面又分别使用紫色或蓝色描边，未继承统一主色。
- 页面容器宽度、标题区高度、按钮高度、卡片圆角、表单标签间距、KPI 卡片高度和多栏间距不一致。
- 部分 PC 窄屏状态下存在操作按钮挤压、长文本换行不齐、表格或多栏区域宽度分配不稳的问题。

## 4. 目标与非目标

### 4.1 目标

- 8 个后台页面使用同一套 Focus / Vega 颜色、边框、圆角、阴影、排版和交互状态。
- 建立一致的后台导航、标题区、按钮、表单、卡片、表格、标签、空状态和业务弹窗视觉。
- 使用本地 Lucide SVG 替换后台范围内未冻结的 Unicode、emoji 和不统一的手写操作图标。
- 修复 PC 端肉眼可见的未对齐、间距不一、卡片高度不齐、按钮挤压、表格溢出和多栏比例失衡。
- 保留原生 HTML、CSS、JavaScript 架构和现有页面业务行为。

### 4.2 非目标

- 不引入 React、Vue、shadcn/ui 运行时或新的组件框架。
- 不修改 API、认证、权限、角色、订阅、支付、数据存储或业务流程。
- 不重新规划后台信息架构，不移动主要业务区块，不改变页面内容顺序。
- 不修改登录弹窗、登录流程、账号菜单内部操作、会员套餐、会员购买、兑换、支付或订单界面。
- 不为 `390px` 等移动视口新增或重做布局规则，不以移动端截图作为本轮验收条件。
- 不直接修改 active release site 作为源代码。

## 5. 技术方案

### 5.1 共享皮肤

新增共享样式：

```text
new-legacy/styles/admin-focus-vega.css
```

8 个页面在现有页面样式之后加载共享皮肤，并在 `body` 上声明：

```html
data-admin-skin="focus-vega"
```

共享样式只负责语义令牌和跨页面组件视觉，不承载具体页面的网格布局。所有规则必须以 `body[data-admin-skin="focus-vega"]` 为作用域，避免影响主画板、学习页和其他业务页面。

### 5.2 三个页面族适配层

新增三个只消费共享令牌的适配文件：

```text
new-legacy/styles/admin-focus-vega-common.css
new-legacy/styles/admin-focus-vega-users.css
new-legacy/styles/admin-focus-vega-settings.css
```

- `common` 处理 6 个后台通用页的导航、头栏、页面标题、KPI、业务面板、表格和多栏工作区。
- `users` 处理用户管理页的三栏比例、列表密度、详情表单、辅助面板和操作按钮组。
- `settings` 处理基础系统设置页的侧栏、页签、设置卡片、颜色字段和操作区。

适配层可以调整既有网格列宽、`gap`、`padding`、对齐、换行、最小宽度和滚动边界，但不得通过 DOM 重排改变主要区块顺序。

### 5.3 本地 Lucide 图标

后台新增精简的本地图标资源和原生适配器，只登记实际使用的图标：

```text
new-legacy/assets/icons/lucide-admin.svg
new-legacy/src/108-admin-ui-icons.js
```

适配器输出统一的 `currentColor`、`fill="none"`、`stroke-width="2"` SVG。静态按钮通过 `data-admin-icon` 接入，JavaScript 动态渲染区域通过白名单 API 生成图标。未知名称必须回退到安全的通用图标，不允许出现空白按钮，也不使用 CDN。

## 6. Focus / Vega 视觉规则

### 6.1 共享令牌

后台沿用学习端试点的主色和中性色：

```css
body[data-admin-skin="focus-vega"] {
  --admin-background: #fafafa;
  --admin-foreground: #18181b;
  --admin-card: #ffffff;
  --admin-card-foreground: #18181b;
  --admin-primary: #6d5dfc;
  --admin-primary-foreground: #ffffff;
  --admin-secondary: #f4f4f5;
  --admin-secondary-foreground: #27272a;
  --admin-muted: #f4f4f5;
  --admin-muted-foreground: #71717a;
  --admin-accent: #f1efff;
  --admin-accent-foreground: #4c3fd1;
  --admin-border: #e4e4e7;
  --admin-ring: #6d5dfc;
  --admin-success: #15803d;
  --admin-warning: #b45309;
  --admin-destructive: #dc2626;
  --admin-radius-control: 8px;
  --admin-radius-panel: 10px;
  --admin-shadow-float: 0 4px 12px rgb(24 24 27 / 0.08);
}
```

### 6.2 组件规则

- 紫色只用于主操作、选中、焦点和当前导航；成功、警告、危险使用各自语义色。
- 普通卡片使用白底、`1px` 中性边框和轻微阴影；常态内容不使用渐变背景。
- 普通按钮和卡片不使用胶囊形状；胶囊只保留给状态标签和确有语义的筛选项。
- 主按钮、次按钮、危险按钮、图标按钮统一高度、边框、圆角和图标间距。
- 输入框、选择器、文本域统一标签间距、控件高度、边框和 `focus-visible` ring。
- 表格统一表头背景、行高、单元格内边距、空状态和横向溢出行为。
- 菜单和业务弹窗可使用轻浮层阴影；页面常态卡片不得使用厚重多层阴影。
- 英文辅助标签不再依靠高饱和颜色制造层级，统一使用小号中性文字或主色弱化文本。

## 7. PC 端排版修正规则

### 7.1 验收视口

- `1440 × 900`：主要验收视口。
- `1366 × 768`：常见笔记本验收视口。
- `1024 × 768`：PC 窄宽验收视口。

本轮不以移动端视口为验收目标，不新增移动端布局设计。

### 7.2 允许修正

- 统一后台内容容器的最大宽度、左右边距和页面段落间距。
- 统一顶部导航与业务头栏高度，修复双层粘性头栏的重叠和跳动。
- 统一页面标题、说明文字和右侧操作区的基线与垂直居中。
- 让同一 KPI 行、同一卡片行和同一按钮组高度与间距一致。
- 修复用户管理三栏在 1024–1440px 范围内的列宽、最小宽度和滚动边界。
- 修复科目管理、反馈管理、消息管理和系统设置中的多栏比例、工具栏换行和表格溢出。
- 修复表单标签、输入框、下拉框、文本域和底部操作按钮的对齐。
- 对长用户名、长标题、长状态文字设置合理的截断或换行规则。

### 7.3 不允许修正

- 不把左栏、主栏、右栏移动为新的信息架构。
- 不删除、合并或新增业务字段和操作。
- 不为了视觉统一改变按钮行为、表单提交、权限可见性或路由目标。
- 不用固定高度裁掉业务内容；需要滚动时必须保留可访问的滚动区域。

## 8. 冻结区域

### 8.1 登录与账号操作

以下区域的 DOM、业务行为和内部视觉保持现状：

- `#authModal`、`.auth-backdrop`、`.auth-modal` 及其后代。
- 登录、注册、微信登录、退出和会话处理脚本。
- 后台账号胶囊和账号菜单的内部按钮、图标与状态表达。

允许调整账号胶囊外层在头栏中的对齐和外部间距，但不得改变其内部尺寸、颜色、文案或交互。

### 8.2 会员购买与支付

以下区域保持现状：

- 订阅套餐、会员详情、兑换码、订单、支付方式、二维码和支付结果界面。
- `.subscription-*`、`.membership-*`、`.payment-*`、`.wechat-pay-*` 等相关区域。
- `[data-open-subscription-detail]` 等会员购买入口的行为。

共享皮肤和页面族适配层不得包含冻结区域内部选择器。

## 9. 交互与无障碍

- 所有可交互控件保留现有 `id`、`name`、`data-*`、链接目标和 JavaScript 事件钩子。
- 按钮、链接、表单控件保留可见的 `hover`、`active`、`focus-visible` 和 `disabled` 状态。
- 图标独立表达操作时必须提供可访问名称；装饰性 SVG 使用 `aria-hidden="true"`。
- 加载、错误、成功和空状态只统一视觉，不改变原有数据流与恢复路径。
- 尊重 `prefers-reduced-motion`，不新增影响操作效率的动画。

## 10. 验收与测试

### 10.1 静态契约

新增契约测试，验证：

- 8 个页面全部声明 `data-admin-skin="focus-vega"`。
- 每页最后加载共享皮肤和正确的页面族适配文件。
- 新 CSS 全部位于后台皮肤作用域内。
- 新 CSS 不包含登录、会员购买和支付冻结区域内部选择器。
- 后台操作图标只使用本地资源，不引用 CDN、远程字体、emoji 或未登记的手写操作 SVG。
- 现有业务钩子、主要结构锚点和页面入口保持存在。

### 10.2 PC 浏览器回归

对 8 页分别在 `1440 × 900`、`1366 × 768`、`1024 × 768` 验证：

- 一级导航、业务头栏、标题区和账号区域无重叠。
- 页面容器、KPI、卡片、表单、按钮组和多栏工作区对齐。
- 表格、长文本、空状态和滚动区域不溢出、不遮挡。
- 主要按钮、筛选、页签、弹窗和表单仍产生原有可见结果。
- 登录和会员购买冻结区域的截图与改造前保持一致。
- 控制台无新增错误，CSS、脚本和图标资源无 404。

### 10.3 功能回归

- 运行现有后台契约与浏览器测试，覆盖总览、科目、用户、反馈、消息、操作记录和系统设置。
- 保留成功、失败、空数据、权限拒绝、取消和重试路径的既有断言。
- UI 改造不得通过修改或放宽业务测试来规避失败。

## 11. 实施顺序

1. 建立 PC 端布局与冻结区域契约测试。
2. 新增共享 Focus / Vega 令牌、基础组件皮肤和后台 Lucide 图标基础设施。
3. 适配 6 个后台通用页面并完成三种 PC 视口验证。
4. 适配用户管理页面并重点验证三栏、表单、列表和操作区。
5. 适配基础系统设置页面并重点验证侧栏、设置面板和表单。
6. 遍历 8 页主要控件、空状态、长内容与权限状态。
7. 从 `new-legacy/` 生成候选并执行发布完整性校验；文件数与关键页面未通过时不得发布。

## 12. 完成标准

- 8 个后台页面在三个 PC 验收视口下使用同一套 Focus / Vega 视觉体系。
- 三个页面族仍保留原有业务结构，但组件规格、内容宽度、间距和对齐一致。
- 已知的按钮挤压、卡片高度不齐、标题区错位、表格溢出和多栏比例问题得到修复。
- 后台非冻结操作图标统一为本地 Lucide SVG。
- 登录、账号操作内部、会员购买和支付区域无视觉或交互变化。
- 不新增移动端设计或移动端验收范围。
- 新增契约测试和目标浏览器回归通过，现有后台功能测试不增加失败。
- 候选 release 内容完整并通过正式发布流程后，才可视为已交付。
