# Lucide 图标系统与业务页面专业化设计

## 目标

将非图谱业务页面改造成克制、可靠的专业运营台，并把所有可操作的 UI 图标统一到 `lucide-react`。修复图标大小、笔画和按钮内垂直/水平对齐不一致的问题，同时不改变任何接口、权限或业务流程。

## 已确认的设计方向

- 图谱编辑器继续使用现有的博思白板式无限画布体验；不修改 `legacy/` 源文件。
- 非图谱页面采用“专业运营台”：浅灰工作背景、白色有边界的工作区、蓝色唯一主操作、紧凑的 6–8px 圆角、有限且短促的阴影。
- 不使用大面积渐变、玻璃拟态、超大圆角、无语义的彩色统计卡片或营销页式装饰。
- `lucide-react` 是唯一的操作图标库。图标不能再由手写 SVG、Unicode 符号或混杂库承担。
- 文件封面中的知识网络、回忆页面的关系连线/节点、图谱编辑器中的原版引擎图形属于业务内容图形，不在替换范围。

## 页面范围

| 路由/区域 | 设计处理 | 图标处理 |
| --- | --- | --- |
| `/files` | 收敛为文件工作台：固定顶部工具区、窄侧栏、明确的列表/网格工作区 | 将手写操作 SVG 换成 Lucide；文件封面网络 SVG 保留 |
| `/question-bank` | 题库/题目/组卷采用标题栏、上下文栏、主工作区、检查栏的稳定栅格 | 为导入导出、创建、删除、导航和空状态补充 Lucide |
| `/training` | 保持学习专注，减少大卡片和装饰性标签，让题干与训练操作成为主层级 | 字号、返回、标签、状态操作均用 Lucide 或文本，不使用符号代替图标 |
| `/recall` | 保持回忆画布为学习区域，工具与缩放控制改为紧凑的标准工具条 | 保留知识关系 SVG，统一外层操作按钮图标 |
| `/users`、`/settings` | 改为紧凑的管理控制台，统计为数据摘要而非彩色营销卡 | 新建、导入导出、返回、状态与菜单使用 Lucide |
| `/member`、`/login` | 以表单/权益信息为核心，去除装饰性卡片叠层与渐变 | 关闭、确认、权益、输入辅助使用 Lucide |
| 全局快捷入口 | 保持已落地的中性工作台视觉 | 统一为 Lucide 尺寸、笔画与按钮对齐 |

## 图标系统

新建一个小型 `AppIcon` 组件作为唯一图标入口，内部仅从 `lucide-react` 取图标并提供有限语义名称，例如 `add`、`back`、`search`、`settings`、`refresh`、`grid`、`list`、`more`、`delete`、`upload`、`download`、`folder`、`user`、`logout`、`close`、`zoomIn`、`zoomOut`。

图标尺寸规则：

- 16px：紧凑输入框、菜单项、行内辅助操作。
- 18px：默认图标按钮、导航和工具栏。
- 20px：空状态、主操作旁的强调图标。
- 图标按钮统一使用 `inline-flex`、`align-items:center`、`justify-content:center`、`line-height:0`；SVG 使用 `display:block`、`flex:0 0 auto`。
- 可点击的图标必须有语义 `aria-label`/`title`；纯装饰图标带 `aria-hidden`。

## 组件和样式边界

- `frontend/src/components/AppIcon.tsx`：语义图标映射、尺寸、无障碍属性。
- `frontend/src/styles/design-system.css`：补充标准控制尺寸、图标尺寸和图标按钮令牌。
- `frontend/src/styles/boardmix-overrides.css`：只处理跨页面的运营台视觉和图标对齐，不承载具体业务布局。
- 各路由既有样式文件：仅放置该页面的网格、信息层级与响应式修正。
- 不改 `legacy/`；图谱 iframe 仅保留现有派生主题所需的兼容样式。

## 不变量

- API 调用、数据读写、角色权限、导航目标、弹窗/确认流程、导入导出及题库训练逻辑必须保持不变。
- 图标替换不得移除任何可点击控件，也不得把可访问的文本标签变成无标签图标。
- 深色模式（文件页已有）仍可切换，统一图标应继承现有语义色。

## 验收与测试

1. 设计契约测试扫描业务路由：除已登记的内容 SVG 外，不得存在手写操作 `<svg>`；不得以 `+`、箭头等 Unicode 作为图标按钮内容。
2. 测试 `AppIcon` 映射覆盖每个允许的语义名，并拒绝未知名称。
3. 真实登录态截图覆盖 `/files`、`/question-bank`、`/training`、`/recall`、`/users`、`/settings`、`/member`、`/login` 与图谱首页；检查图标无裁切、无偏移、无浏览器错误。
4. 运行 `pnpm test:design`、`pnpm exec tsc -b`、`pnpm build`；运行后端 `pytest tests/ -q`，确保视觉改造没有影响业务接口。
