# 答题、评论和共享画布交互调整

用户于2026-10-20明确要求六项修改。基线为UAT v369、77148607；这次沿用已有平台配色和权限/保存/API行为，开发检查后进入UAT，不能因此视为前轮业务验收或授权main。

| 编号 | 设计与验收 | 边界 |
|---|---|---|
| R1 | 关闭实时对错时仍显示单选/多选/配对的“我的选择”，选中选项中性色；答题卡按当前/已答/未答/标记建立层次并显示用户选择摘要 | 不透露正确选项、评分、错误筛选或正确性颜色；切题/语言/恢复保留 |
| R2 | 同一道题切语言只更新文本，保留弹幕DOM与动画进度；弹幕两轨下移，动态避开语言工具区域 | 换题、关闭解析、退出、切账号仍清理； reduced-motion不覆盖工具 |
| R3 | 默认关闭的浮层表情选择器，分组/中文名称，键盘/外点/Esc关闭，选中后写入当前光标、不丢草稿 | 不挤压评论内容；微信原图素材许可尚待确认，已向用户询问MIT Fluent替代素材方案，不安装表情框架 |
| R4 | 公共Promise弹窗alert/confirm/prompt；统一平台样式、焦点约束与还原、队列、危险默认取消、账号变更取消 | 显式异步迁移原生调用及依赖；绝不覆盖window.confirm为Promise使旧同步条件自动通过；保留取消与权限校验 |
| R5 | 临时图谱/多题归纳/深度回忆画笔入口图标正确，顶部选择、绘制、撤销、主题/背景和保存分组 | 共用图标/工具栏模块，窄屏可达，不恢复表格，不改已有笔迹/历史持久化 |
| R6 | 深度回忆与多题归纳共用主题面板，主题装饰整卡背景、正文、边框及文字可读性 | 模式与账号偏好独立，文档画布背景独立，取消/刷新/旧数据兼容 |

方案比较：完全重画页面会扩大对保存/权限的回归面；仅加CSS不能解决弹幕生命周期及同步confirm语义。采用共享模块+调用边界局部迁移，保持现有DOM标识与业务入口并增加真实用户回归。

验证覆盖桌面、390/320窄屏与触屏；每项有正向、取消/关闭或失败、重复、恢复/切账号场景。原生弹窗清单扫全权威源、适配层及Prep源，排除controller同名业务方法；真实浏览器检测不得触发系统dialog。最终显式sync public、构建不可变release、对齐旧路径与数量、官方full门禁及UAT线上字节核验。大厅/成人模板仍暂缓，main与正式环境不动。
