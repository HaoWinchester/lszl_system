# PMP 图文运营独立工具：设计草案

日期：2026-11-02。状态：用户已批准开发，首版生成、审核及发布链路已完成真实联调，定时仍暂停。模型使用 Claude 配置中的 GLM；知识依据从官方公开资料获取。

## 目标与使用方式

仅供用户本人使用的独立工具，自动完成知识选题、图文生成、审核、发布排队、结果核验，以及已授权范围内的评论和私信处理。用户无需逐篇确认。预览和编辑入口保留，但不是正常运行的必经步骤。

初版以一个产品官方账号为范围。发布知识讲解、真实平台功能与对应练习；不虚构学员经历或成绩。账号身份须在发送前核对，身份不符立即停止。

## 运行架构与替代方案

推荐先在用户 Mac 上运行独立服务、独立 SQLite 数据库和持久化浏览器配置。开发目录拟为工作区内 tools/xhs-operator，具有独立启动与测试入口，不接入做题系统业务路由或数据库。Python 服务负责流程、任务存储和调度，浏览器渲染 HTML/CSS 卡片并执行经验证的发布操作。本地管理页默认仅监听回环地址。

只做素材导出不能满足本次无人值守需求；立即部署整套云端浏览器会增加登录迁移与维护成本。初版采用本机运行，若需要电脑关机后仍运行，再将执行服务迁移到用户指定的常开设备。Mac 休眠、关机或网络断开时不能保证准点发布，恢复后不集中补发错过的时段。

模型服务通过显式配置接入，不读取无关项目的密钥。运行前验证模型连接、使用额度预算、资料完整性、浏览器登录和账号身份。初次授权或平台再次要求扫码、验证码时需要账号本人完成；不承诺绕过验证实现永久无人干预。

## 输入与内容依据

候选输入已发现：内置数据/PMP8知识图谱、PMP 科目级联想库，以及上级目录中的第八版 PMP 试卷。知识树作为选题索引，现有题库作为配题候选，文件名及 PMBOK8 标签不代表内容已经核验。

每个可发布知识点保存版本、资料标识、章节或页面定位、依据摘要、核验状态。每篇文案的重要结论必须关联具体来源。用户已明确本地没有教材，采用网上官方资料；公开资料仅支持其明确覆盖的内容，不据目录推导完整讲解。以原创讲解和案例组织内容，避免成页复刻教材。

平台能力、题目数量、练习入口使用独立的产品事实配置。未核实功能、售价、权益、题库规模不进入推广文案。不将 PMBOK 版本直接等同于适用考试大纲。

## 自动内容流程

1. 从有依据的知识点选择未覆盖或需巩固的主题，轮换概念解释、易混对比和情境分析。
2. 在允许读取的公开资料范围内参考同类笔记的表达形式，记录观察依据；不抄正文、图像或虚构竞品效果。竞品读取失败时使用已有内容模板。
3. 生成标题、短正文及约 6 张竖版卡片：问题封面、概念、情境、易错点、练习与解析、对应平台练习推荐。必要时合并卡片。
4. 从核验后的题目中配题，保持题干、选项、正确答案与解析的一致性。首版没有采用未经核实的现有“真题”，改用依据官方公开资料编写的原创知识自测，并明确标注非考试真题；不伪造平台已有专项练习。
5. 用 HTML/CSS 排版文字及信息图，导出 PNG，自动检查溢出、遮挡、安全边距、字号与图片完整性。模板风格与产品真实品牌配置一致。
6. 使用独立审核步骤检查知识出处、答案一致性、产品事实、重复内容、平台当前发布要求和渲染结果。自动审核降低错误风险，不能保证零错误；证据缺失必须阻断发布，不能仅凭模型自评通过。
7. 有限次自动修订，初版最多两轮。仍不合格的草稿隔离，不进入发布队列；可以选用另一份已通过审核的稿件。

## 发布与队列

拟定初始排期为北京时间每天 09:00、20:00，每个时段最多一篇，配置可调整。上线前排期处于禁用状态；实际启用新工具时不恢复旧 Codex 自动任务。

状态流转：待选题 → 生成中 → 审核中 → 待发布 → 提交中 → 待核验 → 已发布；异常进入待修订、登录失效、结果未知或已取消。平台审核中与公开发布成功分别记录。

审核结果绑定稿件版本及图片哈希，修改内容后必须重新审核。账号与稿件版本组合形成唯一任务标识；执行器使用数据库租约，防止多个进程重复处理。提交前先持久化提交状态，提交后保存平台笔记标识和可见结果。

点击发布不能作为成功依据。提交超时、程序崩溃或结果不明时，先核验账号笔记列表；无法确定时冻结该项，禁止盲目重发。生成和提交前的读取错误允许有限重试，可能已产生外部结果的操作不能直接重试。

小红书个人账号发布 API 的可用性尚未确认。已有技能引用的发布脚本在本机不存在，因此浏览器适配器必须独立实现、验证；真实账号发布验证成功前不得宣称可全自动运行。平台要求的声明按实际要求处理，不以绕过限制作为方案。

## 评论、私信及效果记录

仅处理目标账号推广笔记、PMP 学习和平台使用直接相关的新增咨询；常规问题基于已核实资料自动回复。公开内容沿用不放网址的偏好，对方在私信询问入口时发送经过核验的正式地址；不群发、不绕过平台链接限制。

费用承诺、退款投诉、未核实答案和商务问题进入异常队列通知用户。私信仅保存必要标识、摘要和处理状态，不读取无关私人会话。每轮最多处理 5 条，正常巡查窗口拟为 08:00—22:00。发送结果不明时先核验，不能重复回复。

效果记录仅采集实际可读取的浏览、收藏、评论及咨询数据；网站注册或付费转化若无可靠追踪，不推断归因。不以机器人评论、点赞或多号互刷制造效果。

## 停止与异常机制

管理页显示全局启停、各任务状态、下次计划时间、最近成功记录和异常原因。调度器以数据库 enabled 字段为准，领取任务和每次外部发送前重新检查开关。

暂停后不领取新任务，也不提交新的发布或回复；已向平台提交的操作无法撤回，允许仅核验并记录结果。暂停状态在进程重启后保持。停止命令与管理页开关使用同一实现，并实际测试。旧的 pmp、pmp-2、pmp-3 自动任务保持原状态。

登录失效暂停对应账号；预算耗尽暂停生成；资料不足隔离草稿；平台页面不兼容暂停发布适配器。正常运行不逐篇打扰，异常首次出现与恢复时通知，相同故障去重。管理页是必备告警入口，外部通知通道在用户配置后启用。

## 验证与交付标准

- 可在模型服务已配置且资料充分时，生成带依据的完整图文及关联练习；缺失配置时显示阻碍，不用占位文案冒充生成成功。
- 缺失来源、题目答案冲突、图片溢出和重复稿件能够阻断发布。
- 用模拟适配器验证崩溃恢复、租约争用、跨时区排期、错过时段、暂停与重启、结果未知不重发。
- 用真实浏览器预览验证上传与填写，再按用户已授权的推广范围验证一次实际发布和笔记结果。开发测试与真实账号实测分别报告。
- 一键启动、暂停和查看状态；单用户设置、素材预览、队列与异常记录齐全；启动前检查清楚列出缺失资料、模型配置和登录条件。

## 首版范围与剩余工作

本机服务、自动审核后直接发布和异常暂停的设计已获用户批准。GLM、官方账号登录、图片上传和真实发布均已验证。当前只覆盖四个公开资料主题；资料抓取受限时使用有期限的已核验快照，过期停止。还需补充持续知识扩库、竞品采集、评论/私信浏览器适配、外部通知和常驻部署。现阶段交付生成＋审核＋发布队列供 UAT，不将尚未接入的互动功能描述为已运行。
