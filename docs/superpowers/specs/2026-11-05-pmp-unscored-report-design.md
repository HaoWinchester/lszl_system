# PMP整卷10道不计分题

用户已确认：仅180题PMP整卷模拟启用；短练、其他科目、学霸和复仇模式以及既有会话和成绩不变。

新建会话时由服务端从180个题目中无放回随机选10题，固定在scoring_snapshot；仅practice/challenge且实际抽取180题、整卷总量180、subject=PMP适用。客户端不能指定名单；活动会话响应不包含名单，交卷后冻结报告才返回。

模拟分、满分、PASS/FAIL和领域成绩排除这10题，同时保留全部180题的作答统计、全卷正确率、经验及错题事实。不计分不是扣10分，也不等于删除题目。已有冻结报告不重算，旧活动会话没有新规则时沿用旧规则。

成绩单复用现有样式，在统计后增加“不计分题说明”，显示180题/170道计分题/10道不计分题、计分口径和本次题号。题号可回看正确、错误或未答题；题目回顾标注“不计分”。报告刷新、交卷重试、历史打开都使用同一冻结名单。

接口仅增加报告实际使用的unscoredQuestions数组（questionId、number），不携带重复题干、答案或大快照；列表和大厅接口无新增字段或资源。

依据：[PMI July 2026 ECO第17页](https://www.pmi.org/-/media/pmi/documents/public/pdf/certifications/new-pmp-examination-content-outline-2026.pdf)：180题、170计分、10预试不计分。本平台名单为模拟抽样，现有非官方成绩声明保留；本次不调整领域配比、及格线或考试时长。

验证：适用/不适用边界、10题唯一且属于会话、隐私、按170题计分（答对/错误/未答排除）、领域排除、全卷错题不丢失、续做和重复交卷幂等、跨账号隔离、旧会话/旧报告、桌面和手机题号回看。通过正式发布链路部署UAT后等待用户验收，不合入main。
