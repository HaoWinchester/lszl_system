# 做题大厅按需加载与布局稳定

用户已明确要求实现并部署 UAT：接口只返回当前前端所需数据，所有数据按需读取，大厅首屏不加载后续功能，修复页面跳动且保留原有功能。

采用现有原生页面和 API 的局部改造。目录改为字段白名单摘要并支持学习模式过滤；大厅首次只取一页，更多、搜索、科目与免费/会员筛选走服务端分页，禁止循环读完整目录。既有发布详情与题目接口仍在使用时获取。目录不携带题目、答案、冻结快照或发布元数据。

复用现有发布构建能力，把大厅脚本拆为首屏、答题、成绩、账号、评论/收藏、帮助等功能组。新共享资源加载入口支持并发去重、依赖顺序、版本 URL、失败重试。动态模块在 DOMContentLoaded 之后也必须初始化。首屏保留认证和大厅所需接口，用户操作后加载其他模块；不改变后端认证、owner 隔离和权限判定。

初始 HTML 指定 lobby 视图，首屏试卷区和配置区采用固定空间的加载占位；目录、权益、进度返回时只更新相应内容，不让顶栏和练习卡片上下跳动。允许目录内容区域内部切换，不隐藏整个页面掩盖问题。

验收覆盖：无非必要脚本/数据预取；摘要字段与响应范围；分页、搜索、筛选；点击登录/退出、会员、账号、帮助、收藏、记录；开始/继续/提交/成绩/评论/音效；网络失败、重复点击、重试、切换用户；桌面和手机布局偏移；原有卡牌 more 导航。通过现有检查及发布管理器全量校验后合入并推送 uat、部署，停止等待用户验收，不合入 main。
