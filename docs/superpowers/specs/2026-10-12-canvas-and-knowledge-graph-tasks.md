# 画布与知识图谱开发任务清单

日期：2026-10-12

状态：待实施。需求核查、推荐设计、计划编写已经完成；以下复选框只表示未来开发／验收任务，不表示本轮工作遗漏。

依据：[原始需求与 55 条验收标准](2026-10-12-canvas-and-knowledge-graph-requirements.md)、[实现核查和推荐设计](2026-10-12-canvas-and-knowledge-graph-design.md)、[详细开发计划](2026-10-12-canvas-and-knowledge-graph-plan.md)。

## 1. 执行规则

- 以详细计划中的同编号任务为执行单元。本清单用于进度追踪，不另写一份不同实现方案。
- 单项完成要求：对应代码完成、定向测试通过、必要浏览器证据可查、相关数据往返和权限已验证；只完成 UI 不勾选。
- 有既有失败时先记录并判断影响，不用删断言或跳过关键权限测试使其变绿。
- 分组发布只交付该组已完成能力；R06 图片／表格／题目关联、R04 新文字／表格等跨组验收要等联调后才能整体通过。
- T21、T22 对每个准备发布的里程碑执行一次并分别记录。开发自检与用户本人 UAT 验收分开，未确认不推进 main。

## 2. 开发任务

### M0 基线与设计采用版本

- [ ] **T00** 核对执行时基线，校准失败测试，准备真实 XMind／Excel／图谱样本，记录尚未复现问题。依赖：无。产物：基线报告和固定 fixtures。

### M1 稳定交互与学习准确性

- [ ] **T01** 统一输入焦点和全屏浮层，修复文字删除误触发对象删除。依赖：T00。验收：AC09-1/2、AC11-1/2/3。
- [ ] **T02** 分离多题背景与主题色，按复现结果修复水滴颜色面板。依赖：T01。验收：AC13-1/2、AC14-1/2/3。
- [ ] **T03** 精确匹配关键词，未匹配／多候选创建自定义根卡，保护旧自定义内容。依赖：T00。验收：AC15-1/2/3。
- [ ] **T04** 文字渲染实测并修复，统一三页 1%—400% 缩放保存范围。依赖：T00、T01。验收：AC04-1/2/3；新增文字／表格后在 T20 再覆盖。

### M2 图谱编辑与临时画布

- [ ] **T05** 曲线上手柄反解、节点组拖动路线同步、取消与历史恢复。依赖：T01。验收：AC01-1/2/3。
- [ ] **T06** 连线两端 auto／上下左右预设，保存、重绑与缩放稳定。依赖：T05。验收：AC02-1/2/3。
- [ ] **T07** 片段协议、内部关系复制、ID重映射、切文件保留剪贴板。依赖：T06。验收：AC06-1/2/3/4 的基础图形路径；完整资源在 T20 验证。
- [ ] **T08** 一跳相关内容的独立临时上下文，可编辑、关闭丢弃、零正式回写。依赖：T07、T01。验收：AC03-1/2/3。
- [ ] **T09** 三页共用画笔文字及图谱原位文字失焦保存、四边调框与字号、换行和失败保留。依赖：T01、T04。验收：AC12-1/2/3/4，回归 AC04、AC11。
- [ ] **T10** 四种布局、稳定生成树与跨边保留、六种系统主题。依赖：T06。验收：AC07-1/2/3。

### M3 图片与 XMind 导入

- [ ] **T11** 图谱图片资源及权限、卡片图片显示、内容／资源保存复制往返。依赖：T00、T07 协议。验收：R05、R06、R08 的图片前置检查。
- [ ] **T12** JSON／XML XMind 解析、多工作表预览、图片备注样式映射和事务导入。依赖：T10、T11。验收：AC05-1/2/3/4。

### M4 题目练习与模板分发

- [ ] **T13** 跨题库搜索、权威卡片题目绑定、快照、练习记录、资源／解析鉴权和普通入口回归。依赖：T11。验收：AC10-1/2/3/4/5 的 API 路径。
- [ ] **T14** 教师搜索勾选追加、学生作答解析的右侧抽屉及全屏交互。依赖：T01、T13。验收：AC10-1/2/4/5 的 UI 路径、AC09-3。
- [ ] **T15** 模板目录、管理员／教师发布、免费／会员属性、不可变版本和独立加载副本。依赖：T07、T11、T13。验收：AC08-1/2/3/4。
- [ ] **T16** 学生模板副本练习、受控跨文件绑定继承、失败原子性和无越权。依赖：T07、T13、T14、T15。验收：AC06、AC08、AC10 的组合路径，尤其 AC10-3。

### M5 表格与整体验证

- [ ] **T17** 共享表格模型、合并拆分、HTML／TSV 粘贴及前后端一致校验。依赖：T00。验收：AC16-2/3 数据规则。
- [ ] **T18** 三页 tables 字段保存、回忆迁移、重置、冲突与历史恢复。依赖：T17。验收：AC16-5 的存储路径。
- [ ] **T19** 三页表格工具、行列选择、编辑、移动、调大小、合并与 Excel 粘贴。依赖：T01、T04、T17、T18。验收：AC16-1/2/3/4/5 的 UI 路径。
- [ ] **T20** 完整内容复制／导出／模板／重新导入、三页清晰度与持久化、跨账号和异常场景联调。依赖：T01—T19。验收：全部 55 条，输出逐项记录。

### 各阶段 UAT

- [ ] **T21** 当前里程碑构建候选、核对清单、合入推送 uat、部署并记录真实版本。依赖：该里程碑自检通过；最终版本依赖 T20。
- [ ] **T22** 用户本人 UAT 验收，未通过回到对应任务；明确授权后才开展 main 集成。依赖：T21。
