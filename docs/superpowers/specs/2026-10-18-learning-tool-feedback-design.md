## 1. 已确认的需求边界

- 对外分享定位是个人学习工具。分享卡片及浏览器回退标题不出现“做题”“刷题”等字眼。官网醒目做题入口保留；知识图谱中的做题入口沿用现状。这两个入口必须独立验证。
- 模板预览参考用户已打开的博思白板：实际图形预览、拖动查看、放大缩小、全屏、退出。预览不直接改动或加载当前图谱。
- 思维导图布局面板过重，需要图像生成设计参考；布局、主题、范围与高级设置分层呈现，保留必要功能。
- 现有连线虽可拖动，但部分不能重合，不能在附近上下拖动；应对照博思处理线段与曲线中部手柄。
- 蓝色选中框遮挡工具栏是视觉层叠与点击命中问题，不是父子节点层级错误。
- 同一卡片向右连接两个对称位置的卡片时，默认两条线应具有镜像一致的弯曲程度。
- 画布文字框高度远大于文字。应贴合实际排版尺寸，打字过程中可拖动位置并保留编辑状态。
- 大厅、试卷选择和答题页简洁化；桌面试卷区及“更多”采用三列紧凑卡片；手机自适应。
- 用户进一步明确：四种模式需保留原有独立呈现与入口，不可压成一排选择器；设计师应提出产品主次与审美判断，不能机械地按“简洁”删减核心模式。
- 大厅不再显示底部“最近学习”预览，避免与左侧历史入口及右上角“继续上次”重复；不以其他辅助面板填补该区域。
- 用户进一步要求移除大厅科目筛选与试卷科目展示标签；试卷选择保留名称、题量和免费/会员标识。此为界面展示调整，不删除后端科目数据或改变权限。
- 答题卡默认收起，以浅色圆形悬浮入口打开；进度与保存控件轻量化。四模式、既有会员权限、续练与成绩规则保留。
- 学霸模式补充简短说明，并提供可靠的鼠标悬浮、键盘聚焦、点击与触屏帮助。
- 原始反馈中的画笔面板关闭、临时画布笔迹/文字/右键退出、红框闪烁及缩放掉帧继续纳入本次范围。

短期变现与扩大知识领域作为方向：本轮保留现有科目与收费规则，不据此新增未经要求的收费功能或内容迁移。

## 3. 推荐方案与取舍

推荐在现有模块增量实现：公共图谱几何、浮层、文字编辑与画笔模块统一修改，原业务控制器接入。这个方案能复用既有存储、撤销、权限与续练测试。

仅修改 CSS 的成本最低，但无法解决模板接口、连线行为和文字尺寸；整套重写编辑器成本与回归范围过大，也不符合保留现有 DOM 和业务契约的要求。

## 5. 功能设计和验收标准

### 对外分享与入口

推荐分享主标题“个人学习工具”，描述“用知识图谱、笔记与主动回忆，构建自己的知识体系。”覆盖官网、图谱及用户可能直接分享的练习页元信息；页面内部“做题模式”等功能名称继续清楚显示。若存在分享图片/渠道标题覆盖，沿真实生成链路一并核查。

官网公开链接采用根路径；图谱分享采用 /graph，必要时将别名改为同源直出，保留旧 /index.html 书签和合法 fileId/mode/auth 参数。禁止笼统删除查询串。核验原始 HTML 与页面运行后的 document.title，避免适配器覆盖。分享平台是否立即刷新旧缓存不作为代码成功保证。

### 模板预览

列表卡片展示实际缩略预览。点击图进入独立只读详情：大预览区、名称/描述、免费或会员标识、加载按钮；图片区支持拖动、滚轮或按钮缩放、适应窗口、全屏、Esc/关闭。放大以预览区中心或鼠标位置为锚点，防止内容消失；限制平移范围，退出全屏返回原弹窗。

预览不改当前正式文件、不创建副本，关闭后清理事件与请求。点击“加载为新图谱”才沿现有幂等服务创建副本。后台返回受控预览投影/资源，显示获准的标题、配色、连线与布局；不暴露题目答案、私有备注、个人学习数据或源文件权限。未授权/下架/请求失败需有明确状态和重试，迟到响应不得重新打开已关闭窗口。

### 图谱连线、布局和浮层

- 默认曲线根据端口和局部方向计算；目标相对源对称时曲线控制长度一致。保留用户手工调整，不为获得对称强制重置历史文件。
- 曲线中段主手柄用于调弯，固定两端卡牌连接；折线在线段中点显示手柄，移动整段并保持正交。拖动方向根据被选线段的几何确定，手势过程中不随整体跨度突然换轴。
- 小范围移动即可生效；不引入“拖出很远才换轴”的门槛。允许线段重合，重合处仍能选中目标线；端点调整与解除绑定通过明确手柄/操作完成。
- 拖动取消恢复原形；一个手势对应一次撤销；布局、切换线型、保存/刷新不漂移。多选应用布局可撤销，取消选择后原工具状态恢复。
- 工具栏与弹层进入统一浮层上下文；蓝框装饰本身不截获点击，仅缩放手柄具有命中区。逐个点击菜单项验证，包含缩放、全屏、多选和画布边缘位置。
- 六种主题应有真实结果；保留手工样式时明确提示，避免用户误以为点击无效。显式覆盖仍可撤销。
- 性能先用同样节点/边数记录基线，缩放期间合帧更新视口和必要控件，停稳后处理必要的局部清晰化；禁止仅凭一个 FPS 数值宣布修复。

### 回忆与临时画布

- 文字框根据实际字体、字号、行高、换行与缩放测量，只加必要内边距；删除文字/换行后允许缩小。用户主动输入的换行保留，不用 trim 粗暴删掉真实内容。
- 编辑框边框提供拖动区域，文本内部继续用于选字/输入；拖动保留文本草稿、焦点、选区与中文输入法状态。移动/缩放后坐标不漂移。
- 画笔面板右端增加关闭按钮，统一退出到选择状态。右键取消沿现有手势策略核查；与关闭/Esc 一致清理临时手势，不丢已保存笔迹。
- 临时画布空白绘制、文字插入、取消和关闭均走共享画笔能力；只读状态明确禁用，关闭不把临时内容写回正式图谱。
- 画笔状态统一卡片悬浮/选中视觉，避免红框与阴影交替；移动鼠标、持续写字、切工具均无闪烁。

### 大厅、试卷与答题页

- 桌面主试卷区与“更多”三列紧凑展示；窄屏两列或单列，不强行挤三列。名称可换行，科目/权限/题量可读；搜索、筛选、选卷、会员限制保持有效。
- 模式切换保留各自题量、错题池与启动条件；无卷/无错题/无权限时明确说明；配置变化不得误开旧试卷。
- 答题卡默认关闭，浅色圆形按钮不遮正文/下一题；关闭返回原作答位置。交卷及未答提示继续可达，复仇模式说明不再指向已移位的“右上角”。
- 顶部保存状态轻量显示；失败提供重试，退出仍有保存退出/结束结算原流程。挑战/学霸保留必要计时血量提示。
- 学霸帮助 hover/focus/click 均可打开；鼠标移入帮助正文不误关闭，Esc/外点可关闭，手机可点击，浮层不越界。

## 6. 实施顺序与验证要求

批准设计后拆成三个连续工作组，均包含原始需求，不因分组遗漏：
1. 分享定位/入口兼容 + 图谱几何、工具栏、模板预览。
2. 共享文字、画笔、临时画布与缩放性能。
3. 大厅、试卷选择/更多、答题页、学霸说明与整体回归。

实现前先复现并补充主要用户操作的失败用例，再局部修复；复用现有 Node、pytest 和浏览器脚本，不安装无关依赖。至少覆盖：
- 标题/链接的游客与登录 HTML、旧链接、参数保留、官网做题入口及图谱入口分别验证。
- 预览零写入、加载幂等、免费/会员/下架、网络失败与关闭迟到响应。
- 曲线镜像、小范围上下左右拖动、折线重叠、线型切换、撤销/重做、保存刷新、多选及命中。
- 工具栏实际按钮点击/菜单选择；多缩放与全屏命中、混合选择、只读权限。
- 文字一行/多行/删空行/不同字号/中文输入与保持编辑拖动；临时画布绘画、文字、关闭和右键恢复。
- 四模式、题型、过滤、更多、选择、收藏、报告、保存失败/重试、续练和交卷；390px 无溢出。
- 缩放同场景前后测量，记录耗时/全量重绘次数与清晰化结果；视觉参考与实际截图核对。

正式验证命令沿用项目：pnpm --dir frontend test、pnpm --dir frontend test:design；涉及服务端预览/路由时执行后端 pytest 及相应专项。发布使用 manage-new-legacy update，核对 active 文件数与缺失文件；自检后仅合入、推送和部署 uat，等待用户本人验收，未经明确同意不合入 main。
