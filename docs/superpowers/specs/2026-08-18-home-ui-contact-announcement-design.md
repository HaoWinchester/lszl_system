# UAT 首页 UI、联系我们与系统公告设计

日期：2026-08-18
分支：`uat`

## 目标

在 UAT 测试环境完成以下五项变更，不合入 `main`，不夹带 `origin/main` 的其他更新：

1. 移除“从这里开始学习”弹层右上角关闭按钮。
2. 修正做题模式顶部退出按钮的视觉对齐。
3. 修正“全部试卷”抽屉右上角关闭按钮的视觉对齐。
4. 在公开首页导航栏增加“联系我们”，复用最新版本的客服二维码与交互。
5. 在站内消息中发布“服务器维护与会员补偿公告”，面向所有用户；不增加首页强制公告弹窗。

## 实施策略

采用“选择性移植 + 局部修复”，不整体合并 `origin/main`：

- 从 `origin/main` 仅提取学习入口关闭按钮移除逻辑，以及首页“联系我们”所需的 HTML、CSS、JavaScript 和 `assets/客服二维码/1.jpg`。
- 对做题模式两个关闭按钮仅调整现有 DOM/CSS，继续使用项目现有图标与按钮规范。
- 公告通过现有 engagement/announcement 正式数据链路创建并发布，不以内联首页弹窗代替站内消息。
- 源文件修改完成后，通过项目正式同步/发布脚本生成 UAT 所需派生产物；发布前核对文件数与关键页面，避免内容回退。

## 组件与行为

### 学习入口

- 同时处理静态 `index.html` 骨架及 `src/31-learning-entry-chooser.js` 动态创建路径。
- 删除右上角关闭按钮、焦点列表项和相应事件绑定。
- 保留学习入口卡片及原有底部稍后选择/进入方式，避免形成无法退出的弹层。

### 做题模式退出按钮

- 保留现有 `#practiceExitBtn` 业务行为和可访问名称。
- 修正按钮内部图标居中，以及按钮与进度条在 `.practice-game-topbar` 中的垂直对齐。
- 不改变退出确认流程、生命值、计时或答题状态。

### 全部试卷关闭按钮

- 保留 `#practicePaperDrawerClose` 和关闭抽屉行为。
- 使用统一的居中图标结构/样式，确保按钮在标题栏右上角不偏斜。
- 同步检查同类学习记录抽屉按钮，避免共享样式造成回归，但不扩大功能范围。

### 首页“联系我们”

- 在公开首页 `landing.html` 主导航加入“联系我们”页签，并保持与现有导航链接同一视觉层级。
- 点击后打开二维码弹窗；支持关闭按钮、点击遮罩关闭和 `Escape` 关闭。
- 复用最新版本图片 `assets/客服二维码/1.jpg`，不重新制作或替换图片内容。
- 同步保留页脚“联系我们”入口，使两个入口调用同一弹窗逻辑。

### 系统公告

标题：`服务器维护与会员补偿公告`

正文：

> 由于我们近期正在集中筹备并上线中英试题，平台部分功能正在进行维护与升级。由此给您的学习体验带来的不便，我们深表歉意。
>
> 如您是会员用户，感谢您一直以来的支持：维护完成后，所有会员将统一获赠半个月会员时长，请您放心使用。感谢理解与陪伴，我们会持续优化服务，尽快为您带来更稳定的学习体验。

- 受众为所有用户。
- 状态为已发布，发布时间为实施时的当前时间。
- 用户在“消息”中可查看并标记已读，未读徽标沿用现有机制。
- 不在首页增加强制公告弹窗。

## 数据流与错误处理

- “联系我们”完全使用静态本地资源；若图片加载失败，保留明确 `alt` 文本，页面其余功能不受影响。
- 公告通过后端 announcement API/服务保存；若发布失败，不以仅写本地缓存冒充成功，保留错误并报告。
- UAT 发布失败或校验不通过时停止，不推进到 `main`，不宣称完成。

## 验证

1. 运行现有相关单元/契约测试，并补充或更新学习入口、关闭按钮、联系我们交互的测试。
2. 启动 UAT 应用进行浏览器验证：
   - 学习入口无右上角关闭按钮，其他退出路径可用。
   - 做题模式退出按钮在常见桌面宽度下居中、不偏斜。
   - 全部试卷关闭按钮在抽屉标题栏中居中、不偏斜且可关闭。
   - 首页导航“联系我们”可打开二维码；关闭按钮、遮罩和 `Escape` 均可关闭。
   - 所有用户可在消息中看到指定公告，标题、正文、受众和发布状态正确。
3. 对关键页面截图留证，并与用户提供的三张问题截图逐项对照。
4. 执行正式同步/发布前校验：当前 active release 与待发布 site 文件数对齐，关键页面和客服图片存在。
5. 最终核对 Git 状态，只提交本任务文件；保留用户原有未跟踪部署文件，不覆盖、不删除。

## 边界

- 只在 `uat` 分支工作。
- 未经用户明确命令，不合入或推送 `main`。
- 不整体合并 `origin/main`，不引入与本需求无关的 13 个提交。
- 不修改会员补偿实际发放逻辑；本任务只发布公告。实际赠送半个月会员时长需另行执行运营/数据操作。
