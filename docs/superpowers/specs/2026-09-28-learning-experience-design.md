# 学员使用分析、移动学习与教师操作体验

用户已选择 A1—A5、S5—S7，并要求优化教师工作台相关页面。基线 main c2c636b7（v256），清理分支修改已等价进入 main；不带入根目录未跟踪文档。

## 范围与验收
- A1：网页图谱、文件、题库、刷题、回忆、多题归纳、解析等实际功能接入统一统计；小程序接入。旧 training/learning_path 保留用于历史查询，明确覆盖范围。
- A2：分段上报新增时长，后台暂停，恢复不重复，单次长停留不截成 30 分钟；事件幂等、失败重试、账号隔离、多窗口抑制。
- A3：分别展示前台时长与估算有效使用时长。最近 120 秒有交互或刚进入的前台时间计为有效；文字说明阅读思考可能被低估，绝不称为真实专注。15 秒采样提交，无操作时间仍计入前台时长。
- A4：有效人数、访问次数、使用天数、再次使用比例、总有效时长、人均时长、单次有效时长中位数；按人数、频率、时长切换排序。
- A5：默认学员，可筛选终端和日期；v1 历史单独查看，不混算；样本量、启用时间、采集覆盖及估算规则可见。仅管理员聚合，无个人行为轨迹。
- S5：检查微信无密码账号首次设密、移动网页登录与小程序入口。首次设密必须近期微信认证，不能绕过已有密码验证；既有登录与绑定不回退。
- S6：复用服务端会话和已有题量设置，清楚显示继续上次与下一未答题；短练习入口与未答题续做；任意题号区间不纳入本轮。
- S7：解析入口明确一致，缺失解析可发出关联题目/试卷/版本的反馈；不自动修改题目答案。给出只读内容完整性检查。
- 教师布局：默认工作台、题目/训练配置、试卷管理；统一主要导航，减少重复导航和引导占屏，突出实际任务与主要动作，保持原业务契约。不新增未选 T1—T5 的学情/任务功能。

## 结构
复用 FastAPI analytics 服务与共享网页适配器，新增版本化时长事件契约和数据库字段，客户端只提交固定功能与时段，不保存业务正文。服务端绑定当前登录身份、校验时间、幂等写入。新旧口径分开查询。小程序复用统一生命周期适配层。
学生功能复用既有认证、练习会话、解析组件与反馈服务。教师布局沿用品牌和原生 DOM，不换框架，不重写业务页。

先以可控时钟复现统计问题，再覆盖分段、后台、空闲、返回、重试、跨账号、重复事件、日期和权限。学生路径验证登录/退出、短练习、恢复、解析及失败恢复。教师端验证桌面/窄屏主要操作与导航，真实后端数据。
运行后端 pytest、前端 pnpm test/test:design、小程序 npm test 与相应浏览器回归。按受管发布脚本构建不可变 release，核对当前版本文件不丢失；合入/推送 uat，部署并核验公网资源，等待用户业务验收，不合入 main。
