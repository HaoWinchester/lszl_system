# 弹幕设计图落地

用户明确要求用 GPT 生图设计弹幕并开发，已于 2026-10-16 选择“按这版开发”。权威原图 docs/design/danmaku-2026-10-16/concept.png，由内置 image_gen.imagegen 生成，工具不公开模型标识；原始提示及 provenance 同目录保存，不能伪称返回了可验证的模型 ID。

视觉：浅色圆角弹幕条、紫色首字头像、正文及点赞数；悬停/键盘聚焦/点击暂停显示淡紫边框与暂停提示。互动浮层白底细边、头像/作者/时间/关闭、原文、四个一致线性图标操作（点赞、回复、不喜欢、更多），更多继续提供收藏/复制。引用背景虚化仅为生成图语境，不应用于真实题目。

像素分析：生成图实际 1254×1254；浮层约 x198,y585,w860,h589，条约 x205,y240,w846,h134。按组件 3x 设计导出解释，CSS 浮层约286×196、条高44—45、头像30—32、正文14。实现以286—320px弹性宽度、14px文字、14—16px圆角、细灰边框和紫色#7651ee为起点；按钮实际可点区域不小于44px。不得把图中放大组件照搬成覆盖全屏的大卡片。

交互：保留短留言≤30字/最多8条/他人优先、18秒滚动、已有设备显示与隐藏偏好、解析可见后才展示、题目/账号切换清理、已有点赞/回复/收藏/复制/不喜欢的 API 和权限。点击弹幕暂停并打开浮层；关闭/空白处继续播放；Esc关闭。浮层优先出现在条下方，空间不足上翻，箭头对齐触发条并夹在视口内，更多展开、刷新状态和窗口变化重新定位。手机不溢出，减少动态偏好显示静止可读条。

架构：只在119-question-comments.js共享模块与question-comments.css扩展；线性图标复用107-learning-ui-icons.js与lucide-learning.svg，禁止跨页面复制实现。后端不新增接口或数据。

验收：真实渲染单点与API正/负/恢复/权限流程，桌面1440及手机390、边界/更多/resize、显示开关与答题前抑制；固定时间和动画帧，在相同数据下提供原图/实现/差异图及真实差异指标，明确位图字体/情境背景与动态内容差异，不能用源/发布一致性替代UI稿对比。完成后标准发布UAT等待用户验收，不合main。
