# 答题后全屏弹幕与抽屉评论

用户已确认范围并授权实施：只在答题后解析、报告页展示全屏弹幕；回忆、归纳画布不增加弹幕。与教师导入助手一起开发，完成后多轮浏览器测试，先 UAT 验收。

复用现有题目评论数据、点赞服务和共享前端模块；无需迁移历史内容到第二套弹幕存储。新增评论收藏和回复、稳定分页。弹幕使用全视口多轨移动，设置开关并记忆；点击时暂停该条，出现点赞、收藏、回复。空白区域允许点击原页面，弹幕避开关键操作；切题和关闭解析清理计时器与节点，报告页一次仅播放当前聚焦题目，未交卷不显示讨论。

手机留言区采用底部抽屉，支持拖动展开/下滑关闭；桌面使用侧边抽屉。固定输入栏、点赞与展开回复、关闭后返回阅读位置。收藏保存在数据库，个人收藏可重访对应题目，不会被另一用户看到。点赞收藏重试幂等，发送失败保留输入；空列表、加载失败、权限失效分别反馈。

后台校验题目访问权限、评论归属和父子回复同题，分页有限量；隐藏评论不再出现在弹幕和收藏中。浏览器验证桌面与移动、历史弹幕、开关、滚动点击、点赞取消/收藏取消、回复、抽屉手势、网络失败恢复、切题清理、刷新持久化、跨账号隔离，以及回忆/归纳画布没有弹幕。
