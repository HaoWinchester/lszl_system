# 微信与注册账号关联

用户已确认：密码注册后提示绑定微信；首次微信登录先绑定已有账号或明确创建新账号；已绑定微信直接登录；重复账号提供验证原账号后的恢复入口。

会员和学习数据继续以 users.username 为归属。禁止昵称、头像、联系方式自动匹配，禁止隐式合并会员或学习记录。

## 实现与边界

- 新增数据库一次性网页微信账号选择凭证。浏览器 session 只保存随机凭证；数据库保存摘要、微信资料、有效期、消费时间、错误次数和恢复来源账号。有效期十分钟，五次密码错误后重新扫码。
- OAuth 回调未找到用户时不创建账号，跳回原页展示选择框。绑定已有账号要求原账号密码；创建新账号需要明确点击。重复请求只允许消费一次。
- 已登录用户从账号中心发起找回，重新微信扫码验证当前绑定后再输入原账号密码。事务内转移微信登录身份，不删除任一账号或迁移业务记录。原微信账号的学习记录保留，界面明确告知不自动合并。
- 自助恢复限定学员账号。来源微信账号存在小程序绑定、非免费订阅或任何历史订单时交由人工核对，避免误操作导致权益不可访问。目标已经绑定不同微信时拒绝覆盖。
- 网站微信资料更新保留已有小程序标识，不用空 unionid 覆盖已知 unionid。绑定、登录、恢复均写审计日志。
- 密码注册通过公共认证事件触发一次绑定提示；普通登录、微信注册、刷新不触发。提示处理完再显示学习入口，稍后绑定不阻断注册。
- UI 使用现有共享微信模块、用户中心和弹窗样式，错误后可重试或取消。
