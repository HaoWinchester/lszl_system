# 深度回忆案例题阅读布局

用户截图与要求：案例放在题目左侧、材料区域加宽，桌面整个题框采用16:9构图。本轮先提供本地效果，与已经确认的知识星空视觉无关。

- 同时调整深度回忆和多题归纳中带案例材料的卡片。复用现有共享材料DOM和CSS，在现有材料样式文件中限定页面作用域；普通题、纯图片题与知识星空不改。
- 桌面案例/题目约48:52，题框按16:9，宽度随可用宽高适配、上限1360px。案例标题与正文放左，题干/选项放右；长材料和长题目可独立滚动，不裁掉内容。
- 窄屏解除固定比例，案例在上、题目在下，保留案例折叠、图表放大和题目作答/解析行为；手机卡片高度受视口约束，完整内容可滚动。
- 用真实样式和共享renderCardContent验证桌面/短屏/手机的左右关系、比例、滚动、折叠、无案例回退与纯图片兼容；再运行现有材料浏览器回归与前端/设计契约。
- 同步生成产物后提供本地预览截图，记录已验证范围。当前不修改后台/数据库/知识星空，不切换active release，不合入main。

多题归纳首次将旧默认尺寸案例卡扩宽，保存布局版本标记，后续手动宽度保持；批量加入时按大卡尺寸留位。所有画布布局继续由现有服务器持久化适配器保存。

执行顺序：检查现有布局（已完成）→新增布局浏览器断言并复现失败→局部CSS修改→截图检查与交互验证→同步/契约检查→本地效果交付。
