# 三页画笔入口与当前视口截图实施计划

**目标：**实现用户六项交互要求，三页共享画笔和截图能力，先部署 UAT。
**实现：**在现有 KGCanvasInk 中增加可折叠入口、独立设置面板状态、颜色图标及橡皮擦双击清空；图谱通过现有图谱文件保存笔迹。共享截图模块克隆可见画布为带内联样式的 SVG，再输出 PNG，不请求屏幕共享权限，不安装依赖。
**边界：**外部点击关闭颜色/粗细设置，不中断该次画布绘制。总入口关闭退出绘画；学生不增加强制入口弹出。清空仅笔迹，保留节点、卡片、连线，能撤销。截图只取当前视口，保留背景/内容/笔迹，去掉操作浮层，失败提示且按钮恢复，禁止重复并发截图。

- [x] 共享画笔：先扩展控制器浏览器测试覆盖默认折叠、重复/外部点击、独立颜色和图标、双击无确认清空/撤销；运行旧版本失败，修改 `new-legacy/src/canvas/94-canvas-ink.js` 与 `styles/canvas-ink.css` 后通过。
- [x] 两页入口：修改 `knowledge-recall.html`、`question-workspace.html` 右上浮栏；现有初始化传入入口元素，保留保存/只读/切页防护；修改现有真实数据库浏览器测试，从入口展开开始，移除旧清空确认流程。
- [x] 图谱：在 `19-home-toolbar-registry.js` 注册画笔和截图；`00-config-state.js` 保留经过 normalize 的 strokes；通过新 `canvas/95-home-canvas-tools.js` 连接图谱 state/save/render 与共用笔迹控制器；在图谱历史快照包含 strokes，并在切文件 reset/render 时同步，验证文件隔离和撤销顺序。
- [x] 截图：新 `canvas/96-canvas-capture.js` 提供 `capture(viewport, options)` 与 `bind(button, viewport, options)`，克隆视口样式、内嵌图片、排除操作控件，下载 PNG。先用真实浏览器夹具测试缩放、可见区尺寸、图片/中文/笔迹、界外内容裁剪、重复点击和资源失败恢复，再接入三页。
- [x] 自检：三页真实浏览器检查按钮位置、默认隐藏、画笔/荧光笔、颜色、空白/单笔/全部擦除及撤销重做、保存刷新、切文件、只读、截图内容/尺寸与失败提示；运行既有契约、单元、完整受管发布校验。
