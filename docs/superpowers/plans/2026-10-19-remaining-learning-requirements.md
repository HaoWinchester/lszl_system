# 剩余学习体验需求开发计划

基线：UAT v364、`b1bcd7b3`。用户要求核对剩余事项并继续开发。大厅模式合并、科目入口、分类与整体重设计、学习搭子、邮件提醒保持暂缓；main 与正式环境不动。开发自检后按仓库纪律进入 UAT，业务验收仍由用户完成。

## 设计与全局约束

- FastAPI、原生 HTML/CSS/JS，前端权威源仅 `new-legacy/`；复用已有模块和 API，不安装依赖，不在生成物或 release site 手工改代码。
- 新能力各自覆盖成功、失败、恢复、权限、刷新及账号切换。数据看板和邀请关系由数据库提供，设备音效/弹幕显示参数可沿用批准的设备偏好机制。
- 弹幕继续与真实题目评论关联，去头像、仅顶部两排；数量/速度/透明度即时可调；举手动作复制当前短评论并进入后续播放队列，不重复发布评论，不自动点赞或收费。表情入口默认折叠，插入已有文字草稿，不丢焦点、回复关系和失败输入。
- 音效只对新作答反馈播放，静音时无播放；关闭实时对错时不泄漏答案。使用 Web Audio 原生合成短音，避免外部音频下载及版权依赖；浏览器不支持/未解锁时不影响答题。
- 知识看板采用星空网络，读取本人真实已保存作答，按考点聚合，做题点亮、久未练习逐渐变暗。亮度表示练习新鲜度，不声称医学或学习科学意义的掌握程度；无数据、失败、重试、账号隔离可用。入口置于独立学习导航动作，不重构大厅布局。
- 已向用户询问奖励和书单；可选澄清未收到答复，按已说明的默认实施推荐码注册绑定/统计，不设置会员奖励、折扣或返佣；模板采用原创知识框架，不代入具体现代书籍正文。公开课属于运营内容规划。
- Git 只在功能分支开发，推送用命令级代理，UAT 发布前备份并验证，禁止合入 main 或删除永久分支。

## 顺序与任务

- [x] T1 扩展共享评论/弹幕模块：顶部两排、移除暂停图标、设置面板、举手重播、折叠预设表情；新增可复现 200/600 条输入的压力验证，报告真实渲染上限与结果，不能用截断为 8 条冒充压力测试。
- [x] T2 新增共享答题音效模块与可见开关，接入新作答边界；覆盖静音、关闭实时反馈、恢复旧题不播放、浏览器不支持、重复作答与账号变化。
- [x] T3 新增本人考点学习数据聚合 API 和星空看板，利用原练习会话/题目知识引用；数据按 owner 隔离，不读他人私题、不新增伪造学习缓存。覆盖时间衰减、未知考点、空数据、网络失败与跨账号迟到响应。
- [x] T4 调整答题视图功能菜单：深灰圆形入口、默认收起、保存/设置与已有功能可达、外点/Esc/动作后自动收回；保存失败重试及原退出确认不退化，不改大厅布局。
- [x] T5 按已说明的默认范围实施推荐码基本链路和权限测试；奖励规则未确认，不实现付费权益自动发放。
- [x] T6 按已说明的默认原创框架范围补成人管理与多元模板，通过已有发布服务与可信内容种子提供；不得把用户文档、私有题目或未授权书籍正文作为公共模板。
- [x] T7 用 164 卡图谱和 20 卡学习画布记录缩放/高清工作量与帧时间基线，找到实测瓶颈才局部优化；缺少原设备/数据时保留该原场景未验收状态，不虚报性能已解决。已完成有效合成基线，真实wheel P95 16.7–16.8ms，无证据支持本轮额外优化；原场景仍待用户提供或验收。
- [ ] T8 分域复查、定向/完整测试、同步生成物、官方 full release 门禁、备份和 UAT 发布核验；更新需求追踪和发布记录，等待用户验收。

## 文件职责与实施方式

T1 主要扩展 `src/119-question-comments.js`、`styles/question-comments.css` 及职责清晰的弹幕队列公共模块；T2 拥有新的 `src/practice/practice-sound.js` 和练习作答接入；T3 拥有新的后台聚合服务/路由以及 `src/practice/knowledge-dashboard.js`。T4 在 T2/T3 接入完成后由控制器统一调整现有菜单，避免同文件并发写入。版本递增、同步、构建、提交和部署仅由主执行者统一完成。

先补失败回归，再写实现；分域任务完成后提供测试证据及差异包复查。可并行的独立领域使用 dispatching-parallel-agents，禁止并发改同一文件。
