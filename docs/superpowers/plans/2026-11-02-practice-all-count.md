# 做题题量“全部”实施计划

用户明确要求在10、20、60、180之外新增“全部”，使93/99题试卷可以一次做完。按该要求实施，无需另行选择设计。

## 设计与边界

- 保留固定题量，新增单选项“全部（N题）”，N取当前发布试卷题数；空卷禁用，切换试卷后更新N，已选“全部”保持选中。
- 请求使用`count: "all"`表达整卷，由后端在检查发布版本、模式与权限后从冻结题目表读取真实数量。固定数字仍遵循原1–180限制；“全部”支持185题等现有整卷，不允许用于全局复仇入口。
- 继续旧会话仍使用其冻结题数和题序；新开一轮保留原有确认行为。案例组使用现有完整选择逻辑，全部题目不遗漏、不重复。
- 不改试卷、题库、权限、分类、其他页面布局或作答统计。
