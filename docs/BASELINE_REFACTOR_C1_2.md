# 基线重构 C-1.2：右上角账号菜单

本轮在 C-1.1 修复版基础上调整首页右侧登录区域，只改变首页入口与交互，不修改用户、角色、订阅、图谱文件和自动保存的数据结构。

## 界面调整

1. 保留右上角账号胶囊。
2. 已登录时只显示用户显示名，不再显示“已登录”前缀和角色名称。
3. 未登录时显示“访客只读”。
4. 取消工具栏外置的“使用说明”和“退出”按钮。
5. 点击账号胶囊打开下拉菜单，不再直接弹出用户中心。

## 下拉菜单

已登录状态：

```text
用户中心
帮助中心
────────
退出登录
```

访客状态下，底部会显示“登录”；点击“用户中心”也会进入原有登录流程。

## 新增文件

```text
src/41-account-menu.js
styles/account-menu.css
```

`KGAccountMenu` 提供：

```js
open()
close()
toggle()
refresh()
```

## 兼容处理

- `authLoginBtn`、`authLogoutBtn`、`tutorialBtn` 继续作为隐藏兼容触发器保留，避免已有登录、用户中心和引导逻辑失效。
- 首页 `authStatus` 使用 `data-account-menu-trigger="true"` 标记，由账号菜单接管。
- 其他页面未设置该标记，仍保留原来的“点击登录状态进入用户中心”行为和角色状态展示。
- 原有 `KGUserCenter`、`KGAuthRuntime`、`KGRolePermissions` 对外能力保持兼容。

## 验证

- 全部 `src/*.js` 通过 Node.js 语法检查。
- 首页资源引用检查通过。
- 活跃 HTML 页面重复 ID 检查通过。
- 账号菜单独立交互测试通过：打开/关闭、用户中心、帮助中心、访客登录、已登录退出。
