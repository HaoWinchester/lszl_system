# 第七步补充：订阅权益与价格配置确认调整

本补充基于现有订阅模型和 UI 基础层完成，不接入真实支付，不改变角色权限边界。

## 调整内容

1. 新增 `quarterly` 季度会员，默认有效期 90 天。
2. 季度会员权益与半年会员保持一致：包含标准题库训练、学习包导入/导出、高级深度回忆，相关数量限制为不限。
3. 所有学员套餐均包含学习包导入和学习包导出权益。
4. 免费学员不再限制学习包导入/导出次数；免费学员首页图谱卡牌上限为 50。
5. 学员订阅权益移除“发布试卷”，发布试卷属于教师/教研角色职责。
6. 套餐价格配置改为：只填写原价 `originalPriceText` 和折扣系数 `discountPercent`，现价 `priceText` 自动计算展示。
7. 用户中心“我的订阅”不再展示价格，只展示套餐、状态、精确到秒的有效期、倒计时天数和续费入口。
8. 用户中心续费入口会打开“会员权益”弹窗，展示各套餐权益和购买入口预留。

## 价格字段说明

- `originalPriceText`：原价文案，例如 `¥129 / 季`。
- `discountPercent`：折扣系数百分比，例如 `80` 表示按原价 80% 计算现价。
- `priceText`：现价展示值，由订阅核心根据原价和折扣系数自动计算。
- `discountText`：折扣标签，例如 `-20%`，由订阅核心自动计算。

## 兼容性

- 历史 `priceText` 配置仍会作为兜底值保留。
- 如果只配置原价、未配置折扣系数，现价默认显示为原价。
- 历史套餐 ID 仍会自动映射到当前模型。


补充：免费学员深度回忆单题知识点回顾上限为 30；付费会员不限。学习包导入/导出所有学员均可使用且不按次数限制。
