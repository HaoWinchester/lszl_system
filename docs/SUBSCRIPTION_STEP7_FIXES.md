# 订阅第七步补充修复记录

本次基于 `kg_graph_modularized_subscription_step7_supplement2_fix` 继续修复订阅 UI 基础层。

## 修复内容

1. 用户中心点击「续费 / 升级」后，先自动关闭用户中心弹窗，再打开会员权益弹窗，避免两个弹窗层级互相遮挡。
2. 会员权益弹窗层级提高为高优先级，保证从不同入口打开时都不会被用户中心或其他全局浮层盖住。
3. 首页顶部「使用说明」右侧新增「升级会员」按钮，点击可直接打开会员权益弹窗。
4. 未登录状态也可以查看会员权益；点击购买按钮时会提示先登录学员账号。
5. `KGUserCenter` 对外新增 `openSubscriptionDetail()`，后续其他页面可复用同一个会员权益弹窗入口。

## 第八步前置评估

当前订阅数据模型、套餐配置、用户中心快捷入口、用户管理页手动开通/续期、系统设置套餐配置已经具备基础条件，可以进入第八步的正式订阅功能开发。

建议第八步优先做：

- 学员订阅购买/开通流程的前端状态流转；
- 订阅权益对具体功能入口的限制接入；
- 到期、停用、游客、管理员/教师绕过订阅的统一提示；
- 支付接口暂时保留占位，正式商业化前必须接后端校验。
