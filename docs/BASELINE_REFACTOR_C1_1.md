# 基线重构 C-1.1：顶部文件页签布局稳定性修复

## 问题

旧布局把当前图谱完整名称与文件页签放在同一横向排版流中。文件名称长短变化时，后续文件页签的起始位置会随之移动，产生明显跳动。

## 方案

参照成熟白板软件，顶部拆分为两层：

1. 第一层只显示图谱文件页签和新建入口。
2. 第二层为画布浮动工具栏，独立显示当前文件名称、保存状态和账号操作。

## 新增文件

```text
src/25-graph-file-tabs.js
styles/graph-file-tabs.css
```

## 交互与布局

- 文件页签固定为统一宽度，标题过长时单行省略。
- 完整文件名通过浏览器原生悬停提示显示。
- 页签区独立横向滚动，文件名变化不会推动相邻页签。
- 切换文件只更新激活状态，不按“最近打开”重排页签。
- 当前文件完整名称移至画布左上角浮动工具栏，并在固定宽度区域内省略。
- 画布右上角账号与会员操作独立定位，不受当前文件名影响。
- 当前页签高亮；点击页签先保存当前 dirty 图谱，再切换文件。
- `+` 入口新建空白图谱文件。
- 保存状态图标显示“已保存 / 有未保存修改 / 保存中 / 保存失败”。
- 删除原首页顶部提示文字“单击知识点查看详情……” 。

## 保持不变

- 不改变节点、关系线、闪卡和学习记录的数据结构。
- 不改变订阅、用户、权限、题库、训练等业务流程。
- 不删除或重命名旧 localStorage key。
