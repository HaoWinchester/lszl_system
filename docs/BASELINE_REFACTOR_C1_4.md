# 基线重构 C-1.4

本版本基于 C-1.3，调整首页画布顶部信息区布局。

## 调整内容

1. 移除承载左右工具模块的整行 `toolbar app-header` 容器。
2. 当前图谱信息模块作为 `.stage` 的直接子元素，独立定位在画布左上角。
3. 会员与账号模块作为 `.stage` 的直接子元素，独立定位在画布右上角。
4. 中间区域不再存在横跨画布的背景、边框或模糊层，画布背景可以连续显示。
5. 保留 `topToolbar` ID 在左侧图谱信息模块上，兼容悬浮工具箱的安全顶部边界计算。
6. 小屏设备隐藏右侧悬浮模块，避免生成空白胶囊或遮挡画布。

## 兼容性

本次只调整首页 DOM 包装层和对应 CSS 定位，不修改图谱数据、文件页签、自动保存、账号菜单、订阅或权限逻辑。
