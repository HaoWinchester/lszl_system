# 基线重构 C-1.4.2：悬浮模块交互稳定性修复

## 已确认问题

项目以 ZIP 解压或 `file://` 方式运行时，不同目录可能被浏览器视为新的本地存储环境。旧版会在首次加载后自动启动全屏新手引导，透明遮罩层位于左右悬浮模块上方，因此升级会员、图谱信息和账号菜单会表现为“鼠标点击失效”。

## 修复内容

1. 取消首页加载后的自动新手引导。
2. 保留账号菜单“帮助中心”手动启动引导的能力。
3. 左右悬浮模块增加显式事件隔离，`pointerdown`、`dblclick` 和 `wheel` 不再冒泡到画布。
4. 加强悬浮模块层级和 pointer-events 规则。
5. 引导层仅在 `.show` 状态下接收鼠标事件。
6. 更新引导完成提示，不再引用已移除的外置“使用说明”按钮。

## 保持不变

- 图谱文件、页签、自动保存和旧数据兼容逻辑不变。
- 画布空白区拖拽、滚轮缩放、双击新增节点不变。
- 主动打开帮助中心后，引导遮罩仍会正常显示，并可通过“跳过”、完成按钮或 Esc 关闭。
