> 本文档基于对现有全部源码的逐文件分析整理，作为**重构前的功能冻结基线**和**后端 SQL 数据建模依据**。
> 用途：① 重构验收清单（逐条对照，不丢功能）；② 数据库表结构设计输入；③ localStorage → SQL 迁移映射。

> ⚠️ 个别细节（如大图模式触发阈值、快捷键边界条件）在逐页迁移时需以源码二次确认为准。

### 0.2 横切能力（每个页面共享）

- **认证**：`KGAuthCore`（用户/会话/密码/日志）
- **角色权限**：`KGRolePermissions`（4 角色 + 权限矩阵 + 主题色）
- **订阅**：`KGSubscription`（套餐/权益/用量/订单/卡密）
- **存储**：`KGAppStorage`（统一 localStorage 封装）
- **全局组件**：微信登录、用户中心、全局快捷栏、账号菜单

### 0.3 当前架构特征（重构约束）

- 纯前端，**所有数据在浏览器 localStorage**，无后端、无数据库。
- 非 ES Module，靠 `<script defer>` 顺序加载 + 全局变量通信（重构为 React 后此约束消失）。
- 数据按用户隔离：多数业务 key 带 `__<scope>` 后缀（`public` 或 `user__<urlEncodedUsername>`）。
- 认证为**前端伪安全**（FNV-1a hash、本地会话），迁移后端后必须替换为服务端认证。

## 1. 首页 · 图谱编辑器

### 1.1 功能清单

**图谱编辑**
- 新增知识点（N）、双击编辑、Delete 删除、Ctrl+C/V 复制粘贴、Shift 拖拽框选、框选批量删除、四向生长点快速建邻接节点
- 节点字段：标题、分类、难度（基础/中等/重点/难点/易错点）、关键词、说明、学习提示、颜色、尺寸（小/默认/大）
- 多套模板：空白、PMP、P2、ACP、CSPM、NPDP

**关系线**
- 双击节点设起点→单击目标节点连线；单击关系线出圆弧菜单（实线/长虚/短虚、T 文字、颜色、曲线/直线/折线路径）
- 双击关系线就地编辑文字；选中后 Delete 删除；关系类型：关联/前置/包含/属于/对比/易混淆/因果/应用/例题支撑

**画布交互**
- 拖拽平移、滚轮/双指/按钮/滑块缩放（4%–400%）、居中（含选中卡牌居中、平滑过渡）、全屏、缩放百分比点击回 100%
- 箭头编辑模式（默认）/ 手型演示模式（按住空格或右键临时切换，V 长切）
- 心流模式（L）、重点聚焦（F）、主干线/骨架线（G）、只看相关（R）

**大图模式**
- 性能策略：拖动时延迟刷新连接线、悬浮延迟详情（650ms）、关系文字按需显示、根节点 `kg-perf-*` class 统一降级
- 超大图谱缩放下限到 0.035，全画布适配留白

**记忆闪卡（艾宾浩斯）**
- 节点转闪卡、内置示例闪卡库、CSV/TSV 导入（自动识别表头）、模板下载
- 筛选：当前图谱/示例库/导入/到期复习/只看重点；左滑记不清、右滑记住
- 8 级间隔算法（20m/1h/1d/2d/4d/7d/15d/30d），复习历史（最近 60 条），5 档滑动速度
- 闪卡翻面、加入画布、定位原节点、批量加入未在画布的卡

**导入导出**
- 导出学习包（ZIP：manifest.json + graph.json + README.txt）、导出 PNG/PDF
- 导入 ZIP/JSON（自动新建图谱文件，不覆盖当前）

**偏好设置**
- 性能预设（精致/平衡/高性能/自定义）、单独开关：阴影/玻璃模糊/动画/关系线标签/卡牌渐变/大图模式/拖动延迟刷新

**其他**
- 搜索定位（带缓存索引）、文件页签（拖拽排序、关闭会话记忆）、新手引导（16 步）、移动端底部操作栏与手势、账号菜单、手动保存 Ctrl+S

### 1.2 数据模型

**node**：`id, title, x, y, color, category, level, keywords, summary, notes, size, highlightTerms`
**link**：`id, from, to, type, note, lineStyle(solid/dashed/dotted), pathStyle(curve/straight/elbow), color`
**graph state**：`meta{title,subject,audience,description}, viewport{x,y,scale}, defaults{nodeSize,nodeColor,linkStyle,linkPathStyle,linkColor,flashSwipeSpeed}, focusMode, selectedNodeId, selectedLinkId, linkSourceId, nodes[], links[], importedFlashcards[], flashReviews{}`

**flashReview**：`cardKey→{lastResult, stage(0-7), reviewCount, rememberCount, unclearCount, lastReviewedAt, nextReviewAt, history[]}`

### 1.3 localStorage key
`通用知识点关系图谱工具_多科目重点聚焦版_v2`（旧单图谱镜像）、`kg_graph_user_preferences_v1`、`通用知识点关系图谱工具_新手引导已看_v1`、`通用知识点关系图谱工具_悬浮菜单位置_v1`、`kg_global_shortcuts_position_v1`、`kg_global_shortcuts_layout_v1`

## 2. 文件管理 + 图谱文件存储 v2

### 2.1 功能清单
- **视图**：网格/列表、侧栏折叠、浅色/深色主题、桌面/移动响应式（移动端只读）
- **导航**：最近打开/我的收藏/回收站/全部文件、多级文件夹树 + 面包屑、标签筛选、实时搜索（Ctrl+K）、5 种排序
- **文件操作**：新建/打开/内联重命名（Enter/Esc/失焦）/复制（自动序号）/拖拽或菜单移动/导出 ZIP|JSON/软删除/永久删除
- **文件夹**：多级创建/重命名/移动/删除（递归）/恢复
- **批量**：Ctrl/Shift 多选、批量移动/导出/打标签/删除（失败回滚）
- **标签收藏**：标签 CRUD + 颜色、每文件最多 1 标签、有标签即进收藏、卡片圆点入口
- **回收站**：30 天保留、恢复（原位或根目录）、永久删除、清空、自动清理
- **统计**：容量进度条、活跃/回收站分类、节点/关系总数、完整性校验、浏览器配额估算
- **缩略图**：基于节点位置/颜色/关系线生成 SVG（≤18 节点 ≤30 关系）、structureHash 避免重复、IntersectionObserver 懒加载

### 2.2 存储数据模型（v2 核心，SQL 建模关键）

**设计要点**：轻量索引（元数据 + preview，列表用）与完整正文（graphData + learningState，按需加载）分离。

**file（索引）**：`schemaVersion, id, owner, name, description, tags[], favorite, folderId, restoreFolderId, createdAt, updatedAt, lastOpenedAt, order, status(active/trashed), deletedAt, nodeCount, linkCount, byteSize, revision, source, sourceFileId, preview{version,graphRevision,structureHash,palette[],nodes[],links[]}`
**file content（正文）**：`schemaVersion, graphData(完整 state), learningState{flashcards,deepRecall,questionTraining}, revision, savedAt`
**folder**：`schemaVersion, id, owner, name, favorite, parentId, restoreParentId, createdAt, updatedAt, order, status, deletedAt`
**tag**：`id, name, color`

**localStorage key**：`kg_graph_file_index_v2`、`kg_graph_file_content_v2__<owner>__<fileId>`、`kg_graph_current_file_v2`、`kg_graph_file_tags_v2`、`kg_graph_folders_v1`、`kg_graph_file_migration_v2`、`kg_graph_closed_tabs_v1`(session)、`kg_file_manager_theme/layout/sort/details_open_v1`

### 2.3 导入导出格式与安全限制
ZIP = manifest.json + graph.json + README.txt。限制：ZIP 50MB / JSON 30MB / 单条目 30MB / 总解压 60MB / ≤50 条目 / 节点 ≤2500 / 关系 ≤5000。校验：EOCD、CRC32、结构（必含 nodes/links）。

### 2.4 自动保存与页签
3 分钟 dirty 定时保存、手动 Ctrl+S、切换前保存（失败取消切换）、pagehide/beforeunload 保存。页签：关闭只记会话不删文件、拖拽排序持久化。

### 2.5 重构注意点
软删除/级联恢复、30 天清理定时、缩略图生成时机、容量字节统计、v1→v2 历史迁移逻辑——SQL 设计时分别对应（status 列 + 定时任务 + preview JSON 列 + 聚合统计 + 一次性迁移脚本）。

## 4. 深度知识回忆

### 4.1 功能清单
- 从考题页/题库页经 localStorage payload + URL `?questionId=` 进入；权限校验（未登录访客只读、非授权题拒绝）
- 中心题目卡（题干/选项 + 关键词高亮胶囊），点击关键词生成首个节点
- 三维球形节点按钮（首字 + 全称、按深度着色）、弹出动画、智能避让布局
- 引导面板：prompt + hint + choices 分支 + "添加我的回忆"自定义 + "居中此节点"；面板可拖拽、智能定位
- 选择分支→子节点 + 自动连线（虚线流动动画）；自定义节点可续建下级
- 无限画布：拖拽、滚轮缩放（0.45–1.75x）、双击回中心、工具栏（回题/缩放/重置）、自动居中跟随、焦点脉冲
- 7 主题（持久化）、随机高亮色、进度自动保存与恢复

### 4.2 数据模型
预设知识网 `KNOWLEDGE_RECALL_MAP{roots, nodes}`；动态 rootMap 扩展题目的 clues/concepts。
**recall node**：`instanceId, dataId, rootKey, title, x, y, parentId, depth, createdAt, custom`
**recall edge**：`id, from, to`
**页面状态**：`nodes[], edges[], customNodes{}, activeKeywords[], lastNewEdgeId, lastNewNodeId, activeNodeId, transform{x,y,scale}`
**进入 payload**：`{question, savedAt, source, sourceBankId, sourceQuestionId}`

### 4.3 localStorage key
`kg_deep_recall_current_question_v1`、`kg_deep_recall_progress_v1__{questionId}`、`kg_deep_recall_theme_v1`、`kg_deep_recall_theme_platform_migrated_v1`

### 4.4 重构注意点
订阅限制（免费学员单题知识点 ≤30）、访客只读事件拦截、节点/连线去重与环路检测、主题迁移、KGAppStorage/KGRolePermissions 降级 fallback。

### 5.5 安全机制（迁移必须替换）
当前密码 = salt + FNV-1a hash 变种（强度不足）；会话 = localStorage（易伪造）；权限 = 仅前端拦截；日志 = 前端可篡改。**后端必须**：bcrypt/argon2、服务端 session + HTTP-only cookie、所有写操作服务端二次鉴权、服务端审计日志。

## 6. 统一数据模型（SQL 实体总览）

> 具体方言 DDL 待数据库选型后产出。以下为实体清单与归属，供建表设计。

**身份与权限域**：users、sessions、user_admin_logs、role_themes、（role_permissions 可前端常量或建表）

**深度回忆域**：recall_progress（按 username × questionId 存 nodes/edges/customNodes/activeKeywords）

**关键设计取舍**：
- 图谱 nodes/links、题目 clues/concepts 等"整体读写、少按子项查询"的数据 → 用 JSON 列（PostgreSQL JSONB 尤佳）。
- 文件元数据（folderId/status/nodeCount/updatedAt 等）→ 拆成独立列，支持筛选/排序/索引。
- 轻量索引 vs 正文分离的设计在后端体现为 `files`（轻）+ `file_contents`（重）两张表，列表查询只 join files。

## 8. 重构风险与注意点汇总

1. **易丢的边缘功能**：框选删除、连线就地编辑、关系线圆弧菜单、生长点、艾宾浩斯 8 级算法、闪卡滑动动画、缩放百分比恢复、大图延迟刷新、移动端手势、侦探笔记四阶段推理、深度回忆球形节点与避让布局——需逐项列入验收清单。
2. **前端伪安全全替换**：密码 hash、会话、权限校验、日志——后端重做。
3. **数据隔离**：从 key 前缀隔离改为数据库 `owner_username` 外键 + 服务端鉴权。
4. **历史迁移**：v1→v2、旧套餐 ID、旧字段名兼容——一次性迁移脚本 + 之后可放弃兼容。
5. **UI 逐像素一致**：重构前对 7 个页面分别截图/录屏冻结基线，逐页对照验收。
6. **大文件**：`65-question-bank-admin`(109KB)、`27-graph-file-manager`(107KB)、`10-graph-editor`(148KB)、`20-flashcards-toolbar`(60KB)——迁移时按功能域拆组件。
