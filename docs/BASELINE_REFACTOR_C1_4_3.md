# 基线重构 C-1.4.3：会员权益弹窗布局优化

## 修改内容

1. 会员方案卡片取消固定最小高度，权益说明、用量说明和按钮按实际内容自然排列，避免后台文案较少时出现大面积空白。
2. 所有启用的会员方案固定为单行展示，超出弹窗宽度时可横向滚动或触摸滑动查看。
3. 卡密区域标题由“已有会员卡密？”调整为“卡密使用”。
4. 删除卡密区域说明文字。
5. 卡密区域改为紧凑横向布局并降低内边距；窄屏下自动切换为纵向排列。

## 保持不变

- 会员套餐数据结构、后台配置字段和 localStorage key 不变。
- 套餐点击、订阅申请、卡密兑换和会员权限逻辑不变。
- 管理员后台会员配置界面不变。
