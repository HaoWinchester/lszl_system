# 基线重构 C-1.3

本版本基于 C-1.2，完成以下改动：

1. 首页图谱文件页签高度调整为原来的约 80%。
2. 鼠标悬停或键盘聚焦页签时显示关闭按钮。
3. 关闭页签不会删除图谱文件；关闭当前页签前先保存，并自动切换到相邻页签。
4. 至少保留一个已打开页签，避免首页失去当前图谱。
5. 访客可在全局快捷栏看到并进入“考题训练”和“深度回忆”。
6. 考题训练继续使用既有访客只读拦截。
7. 深度回忆新增访客只读模式：直接进入时加载内置示例题，允许查看题目、已有地图和进行画布浏览，但禁止关键词展开、节点操作、新增回忆和重置进度。

说明：关闭页签只影响当前页面运行期，刷新页面后文件会重新出现在页签栏；图谱文件数据不会被删除。
