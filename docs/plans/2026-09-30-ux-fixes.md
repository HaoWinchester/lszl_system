# 用户体验修复计划

依据：2026-09-30 UX 审查，用户已要求开始修改。复用当前 FastAPI、原生页面、小程序及现有公共模块；不部署、不推送、不修改用户数据。前端只编辑 new-legacy 权威源及适配器，生成物由同步脚本更新。保持游戏玩法、角色权限、短练未做题优先和发布确认语义。

- [x] A / UX-01、02、06：公共未保存保护；试卷切换提供保存/放弃/取消，保存失败不离开；助手文字与待上传附件在新建、切换、离开前提醒；醒目上传按钮、限制说明与填入话语反馈。不实现额外草稿数据库。覆盖切换、取消、失败、刷新保护。
- [x] B / UX-03：catalog 在授权过滤后按名称/描述/科目和访问等级筛选，再分页；返回可用科目；PC 可见搜索与科目筛选，小程序搜索整个目录，保留分页与加载/失败/空状态；防旧请求覆盖。第 21 条以后可搜索到，权限不能回退。
- [x] C / UX-07、11：小程序退出先提供继续/保存，结束本次通过独立明确入口并确认；配置摘要与底部固定启动按钮；旧进度单独说明。保留防重复提交与保存失败恢复。
- [x] D / UX-04、05、07、08、09、10：桌面试卷目录/编辑并列且当前试卷与保存可见；工作台任务入口及按最近草稿的建议；修正 PC 退出说明；统一导航/功能名称、增加学习模式任务说明；深度回忆空态提供符合角色的下一步。不删除高级功能与游戏玩法。
- [x] E / 集成验证：定向逻辑测试、前端全套、必要后端和小程序测试、真实浏览器复测输入保护/搜索/导航/布局/退出；同步版本与生成物。明确未验证的真机项目，保存本地验证记录。
