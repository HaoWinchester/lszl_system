# V9.0-P4.0.2 做题危险反馈与前端导航修复报告

## 开发目标

本版本基于 V9.0-P4.0.1，完成三项前端体验与权限修复：

1. 学霸模式低时间红色视野由突然出现改为渐进增强；
2. 恢复首页、多题画布和深度回忆的原始页面导航，做题模式只保留首页入口；
3. 收紧游客、游客账号和学生账号的全局快捷栏，避免偶发显示用户管理。

## 1. 学霸模式危险视野渐进增强

危险区仍从剩余 20 秒开始，但不再立即显示固定强度效果。

实现规则：

- 剩余时间高于 20 秒：危险视野强度为 0；
- 刚进入 20 秒危险区：仅出现非常轻微的红色边缘；
- 时间持续减少：红色边缘透明度、内阴影范围和呼吸感连续增强；
- 越接近 0 秒：呼吸周期略微加快，危险感更明显；
- 时间因答对恢复到 20 秒以上：效果平滑淡出；
- 启用“减少动态效果”时：取消呼吸动画，只保留渐进静态提示。

强度使用剩余毫秒实时计算，而不是按整数秒切换，避免阶梯式跳变。

## 2. 恢复原始前端导航

取消以下强制跳转：

- `index.html → practice-mode.html`；
- `question-workspace.html → practice-mode.html`；
- `knowledge-recall.html → practice-mode.html`。

当前导航关系：

- 首页：进入知识图谱画布；
- 多题画布：进入原多题画布页面；
- 深度回忆：进入原深度回忆页面；
- 做题模式：通过首页右上角“做题模式”按钮进入独立页面。

做题模式页面中的“自由”切换按钮也直接返回 `index.html`。

本次没有恢复或修改仍处于冻结状态的其他学习流程入口。

## 3. 全局快捷栏角色收紧

游客、未登录访客和学生账号现在严格只显示：

```text
首页｜多题画布｜深度回忆
```

同时完成：

- 快捷栏名称由“多题归纳”统一为“多题画布”；
- 移除“系统尚无管理员时显示用户管理”的快捷栏例外；
- 用户管理仅对具备正式后台权限的角色显示；
- 即使角色权限模块尚未完成加载，快捷栏也只回退到三个公共入口，不暴露后台入口。

用户管理页面自身的管理员初始化和直接访问规则未在本版本修改。

## 数据与兼容性

本次仅修改页面入口、快捷栏权限显示和视觉反馈，不改变：

- 题目 ID、题库 ID 或题目内容；
- 题目分类与安全删除状态；
- 试卷引用和不可变发布快照；
- 做题数量、经验值、血量和倒计时奖惩；
- 做题历史数据结构；
- 教师工作台与后台数据。

浏览器本地数据无需迁移。
