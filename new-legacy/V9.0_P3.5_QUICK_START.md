# V9.0-P3.5 快速使用说明

## 进入试卷管理

从后台顶部导航点击“试卷管理”，或直接打开：

```text
paper-management.html
```

旧地址 `course-admin.html?view=papers` 会自动跳转到新页面。

## 创建试卷

1. 点击“新建试卷”；
2. 填写试卷名称、科目和说明；
3. 在题库选题器中选择题库或输入关键词；
4. 勾选当前页题目；
5. 点击“加入试卷”。

候选题默认每页 20 道，“全选当前页”不会选择整个筛选结果。

## 批量移除试卷题目

1. 在“试卷题目预览”中勾选一道或多道题；
2. 查看批量操作栏中的已选数量；
3. 点击“批量移除”；
4. 确认后，所选题目只会从当前试卷中移除。

该操作不会删除题库原题，也不会改变题目 ID。

## 调整题序

在题目右侧点击上移或下移。移除题目后，试卷顺序会自动连续重排。

## 发布到学习模式

在发布范围中选择：

- 深度回忆；
- 多题画布；
- 单题深学。

点击“发布新版本”。学员端只读取发布版本，教师后续修改草稿不会立即改变当前发布内容。

## 更新已发布试卷

修改草稿后再次点击“发布新版本”，系统会生成 v2、v3 等新版本。发布历史保留，当前公共目录指向最新发布版本。

## 归档

归档后，试卷从学员当前可选目录中移除，但历史发布版本和相关数据仍保留。
