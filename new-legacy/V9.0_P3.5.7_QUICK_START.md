# V9.0-P3.5.7 快速使用说明

## 一、打开科目级联想库

进入：

```text
管理后台 → 科目与知识树
```

从左侧选择科目，然后点击右侧：

```text
科目级联想库
```

页签会自动读取当前科目的草稿和正式版本。

## 二、查看或编辑联想库内容

默认进入“内容列表”：

1. 使用搜索框查找关键词、别名或知识点；
2. 点击关键词进入右侧编辑区；
3. 可修改名称、别名、关联知识点、提示内容和联想目标；
4. 点击“保存到草稿”；
5. 全部检查完成后点击“发布启用”。

学习端只读取正式版本，未发布草稿不会影响学员。

## 三、导入 TXT / JSON

1. 点击“导入 TXT / JSON”；
2. 选择文件后进入“导入记录”视图；
3. 查看解析和差异结果；
4. 选择“合并到当前草稿”或“替换当前草稿”；
5. 点击“确认加入草稿”；
6. 回到内容列表检查；
7. 点击“发布启用”。

“替换当前草稿”需要二次确认。导入不会直接覆盖正式版本。

## 四、查看关系图谱

点击：

```text
关系图谱
```

可以浏览关键词之间的关联。输入关键词可缩小范围；点击节点会切回内容列表并打开该节点。

图谱用于整体理解，精确维护建议在内容列表中完成。

## 五、查看知识点题量

进入：

```text
当前知识树
```

页面默认显示题量。每个知识点旁边会显示：

```text
本节点 N｜含下级 M
```

- 本节点：直接归属该知识点的题目；
- 含下级：该知识点及全部下级知识点的题目合计。

顶部可切换：

```text
全部知识点｜零题量｜题量不足
```

也可以修改“题量不足”的参考阈值。

## 六、查看某个知识点的题目

点击知识点旁的题量数字，右侧会打开题目明细：

- 切换本节点或含下级；
- 搜索题干、题号或题库；
- 查看题目来源；
- 点击编辑链接进入原题编辑页面。

此操作只查看和跳转，不会复制题目或修改题目归属。

## 七、待分类题目在哪里

“科目与知识树”不再提供重复的待分类页签。请进入：

```text
题库管理 → 题目 → 题目状态：待分类
```

在题库管理中进行批量分配知识点、移入待分类或其他分类操作。
