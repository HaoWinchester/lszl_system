# v8.6.2 P2.2.26 深度回忆稳定性、性能与渐进式重构报告

## 目标

本版本基于 P2.2.25 的复查结果，优先修复数据正确性和跨账号隔离问题，同时进行低风险、高收益的性能优化。按产品决定，取消“最长链”的计算与展示。重构采用渐进式方式，不对深度回忆主控制器做一次性大重写。

## 正确性修复

1. **账号、题库、题目三级隔离**
   - 新增 `src/97-recall-storage.js`。
   - 当前题目上下文按账号保存。
   - 回忆进度按账号、来源题库和来源题目 ID 生成 v2 存储键。
   - 不同账号无法读取彼此的当前题目或节点进度；不同题库中的相同题目 ID 也不再共用记录。

2. **旧进度受控迁移**
   - 保留 v1 数据兼容读取。
   - 只有在旧上下文可确认属于当前账号及当前题目时才迁移到 v2，避免把无归属旧数据错误认领给其他账号。
   - 成功迁移后使用 v2 作用域继续保存。

3. **取消全局 PMP 示例关键词污染**
   - 关键词映射从空集合开始。
   - 只加入当前题目 `stemParts`、`clues` 和 `concepts` 明确声明的线索。
   - 示例节点库继续可作为被题目明确引用后的内容来源，但不再作为每道题的全局关键词词典。

4. **单击与双击删除解耦**
   - 卡牌单击使用短延时判定。
   - 双击删除会取消待执行的单击动作，不再先打开引导、增加 `nodeOpens` 或额外保存一次。
   - 删除动画加入题目会话代次校验，避免动画完成回调误删切题后的新状态。

5. **删除后的图结构规范化**
   - 删除节点后重新校正剩余节点的父子关系和 `depth`。
   - 孤立子节点按现有产品规则提升为根节点，后代层级随之重算。

6. **取消最长链**
   - 从底部统计栏移除“最长链”。
   - 删除最大深度统计代码。
   - 等级判断不再依赖最大深度。
   - 不是仅用 CSS 隐藏，因此不会继续产生无意义的计算和维护负担。

7. **主题与移动端补齐**
   - 账号菜单改用深度回忆场景变量，暗夜主题不再显示白色菜单。
   - 620px 以下不再隐藏场景入口；触摸设备可点击图标打开固定定位色板。

## 性能优化

1. **题源缓存**
   - `src/96-recall-question-source.js` 缓存归一化后的题库列表。
   - 仅在本地题库原始 JSON 发生变化或主动失效时重新解析。

2. **轻量探索索引**
   - 题目库不再为每道题逐条读取和解析完整图谱进度。
   - 每个账号、题库维护已探索题目 ID 集合，筛选已探索题目时一次读取即可。

3. **防抖写入与强制刷新**
   - 图谱进度写入增加 180ms 防抖，减少同步 `localStorage` 全量序列化次数。
   - 切题、`pagehide` 和页面进入后台时执行 `flush`，兼顾性能与数据安全。
   - 题目搜索增加 130ms 防抖。

4. **事件委托**
   - 卡牌单击、双击和按压反馈统一委托到节点容器。
   - 题目列表点击统一委托到列表容器。
   - 每次渲染不再为每张卡牌、每道题反复创建事件闭包。

5. **连线查找优化**
   - 渲染连线前建立 `instanceId -> node` 的 Map。
   - 边端点查找从逐边线性扫描改为常数时间查找。

## 渐进式重构边界

本版本已完成第一阶段拆分：

- `src/97-recall-storage.js`：存储作用域、迁移、探索索引。
- `src/96-recall-question-source.js`：题源归一化、缓存、激活上下文。
- `src/86-knowledge-recall.js`：保留页面编排、画布渲染和交互控制。

没有把主控制器一次拆成多个新模块，原因是当前页面已有多轮补丁和大量浏览器行为，一次性拆分会显著扩大回归范围。后续可在稳定运行后继续抽离纯图模型和渲染器。
