# V9.0-P3.4：题目归属、批量移动与安全删除开发报告

## 1. 版本目标

本版本在 V9.0-P3.3.5 的正式题目录入与分类能力上，补齐题目存量治理能力：高效批量重新归类、删除不破坏历史数据、可恢复、安全永久清理，并保证所有变更可审计。

## 2. 已完成范围

### 2.1 题库列表与当前页选择

题目列表新增复选框、当前页全选和批量操作栏。选择集合始终与当前页交集同步：翻页、切换状态筛选或切换题库后，不会继续保留上一页选择。当前分页大小为 20，避免把整个筛选结果误当成操作范围。

单题列表操作包括：编辑题目、修改主要知识点、移入待分类、删除题目；已删除视图提供恢复和永久删除。

### 2.2 批量归属与标签

支持：

- 批量移动到同一主要知识点；
- 批量移入待分类；
- 从待分类视图批量分配知识点；
- 批量增加或移除普通标签。

知识点选择复用现有层级单选逻辑，目标限定为题库当前科目、该科目当前知识树及状态为可用的节点。`deprecated`、`disabled`、`inactive`、`archived` 节点均不能成为新目标。

所有批量操作原地更新题目元数据，不创建副本，也不修改题目 ID。

### 2.3 安全删除

题目新增 `lifecycle` 生命周期字段。安全删除只将状态改为 `deleted`，并记录删除时间、操作者和批次编号；题目实体仍保存在原题库中。

安全删除后：

- 正常题库列表和默认筛选隐藏；
- 新组卷候选、普通训练题集和默认深度回忆列表排除；
- 已有试卷、课程/任务可继续按原题目 ID 解析；
- 历史答题、成绩和统计数据不被改写；
- 可在“已删除题目”视图恢复。

删除确认弹窗按“被引用的题目数”汇总试卷、课程/任务、答题/成绩/统计引用。已有引用不阻止安全删除。

### 2.4 永久删除保护

永久删除仅针对已删除题目，并在执行前及真正删除时各做一次引用检查。以下任一引用存在时，该题自动跳过：

- 试卷；
- 课程、学习任务或作业；
- 答题、成绩、统计、尝试或学习会话。

批量永久删除逐题处理：无引用题目删除，受保护题目保留。永久删除需要勾选不可恢复确认；成功与受保护跳过均写入审计。

### 2.5 审计记录

以下动作接入 `kg_admin_audit_log_v1`：单题/批量知识点变更、移入待分类、标签变更、安全删除、恢复和永久删除。

每条记录包含题目 ID、题库 ID、原值、新值、操作者、时间、批次编号、状态和引用检查摘要。批量动作中的各题共享同一批次编号，便于追踪。

### 2.6 学员端边界

学员默认题库、题目导航、训练列表和深度回忆列表均过滤已删除题目。历史场景通过题目 ID 直接解析时仍可读取被安全删除的原题数据。

本版本没有在学员端增加知识树、主要知识点、分类路径或内部标签管理信息。

## 4. 数据兼容策略

旧题目没有 `lifecycle` 时自动规范化为 `active`。安全删除不会迁移或重写已有试卷、课程和历史记录；恢复也不生成新题目。只有通过引用检查的已删除题目才从题库数组物理移除。
