# V8.6.2 P2.2.28 知识图谱悬浮与拖拽连线优化报告

## 目标

在保持现有知识图谱快速生长能力的前提下，补充直观的拖拽连线方式，并统一知识图谱和多题画布的卡牌悬浮反馈。

## 完成内容

1. 知识图谱卡牌在精细指针设备上悬浮时显示红色边框。
2. 多题画布卡牌在精细指针设备上悬浮时显示红色边框。
3. 选中知识图谱卡牌后，四向连接点支持两种操作：
   - 单击：继续快速创建相邻知识点；
   - 按住并拖到其他卡牌：直接建立关系线。
4. 拖拽过程中显示单条轻量 SVG 草稿线，目标卡牌使用绿色边框反馈；松开后立即清理临时节点。
5. 新建关系线默认不显示文字；模板中已有的关系类型和用户主动填写的文字保持不变。
6. 关系类型编辑器增加“无文字”选项，用户可以随时添加或取消关系文字。

## 性能与可维护性

- 新增 `src/09-graph-connector-drag-controller.js`，将 Pointer 事件生命周期、移动阈值和 `requestAnimationFrame` 节流从主控制器中抽离。
- 拖拽过程中只更新一个 SVG path，不重绘全部卡牌或关系线。
- 默认无文字连线不创建 SVG text 元素，减少文本测量和标签布局工作。
- 悬浮边框使用 outline，不触发布局变化。

## 兼容性

- 原有单击四向点快速创建功能保留。
- 原有双击卡牌设置连线起点、单击目标卡牌建立关系的方式保留，但新关系默认无文字。
- 旧图谱中已有关系文字不被删除。
- 触摸设备不应用鼠标悬浮样式。
