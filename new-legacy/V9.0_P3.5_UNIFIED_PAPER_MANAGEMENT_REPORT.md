# V9.0-P3.5：统一试卷管理、手动选题与学习模式发布

## 1. 本轮目标

本版本将试卷定义为“正式题库题目的有序引用集合”，统一教师组卷、发布与学员学习模式的读取链路。

本轮追加完成两项界面调整：

1. 将试卷管理从题库工作区中的页签/栏目拆分为独立页面 `paper-management.html`；
2. 在“试卷题目预览”中增加逐题复选、全选和批量移除。

## 2. 独立试卷管理页面

新增 `paper-management.html`，页面包含：

- 试卷列表；
- 试卷基本信息；
- 正式题库选题器；
- 当前页复选与批量加入；
- 试卷题目预览；
- 题目顺序调整；
- 发布模式设置；
- 保存草稿、发布新版本、归档试卷。

导航调整：

- 后台顶部“试卷管理”直接进入独立页面；
- 题库管理中的“试卷管理”改为独立页面入口；
- 原 `course-admin.html?view=papers` 自动跳转到独立页面；
- 原配置中心不再展示第二套可操作的试卷管理页签，避免两套试卷模型继续并存。

## 3. 试卷题目预览批量移除

“试卷题目预览”新增：

- 每道题的复选框；
- “全选”复选框；
- 已选择题目数量；
- “批量移除”按钮；
- 单题移除及上移、下移继续保留。

安全边界：

- 批量移除仅修改当前试卷中的题目引用；
- 不删除题库原题；
- 不改变题目 ID；
- 重新渲染后题序连续；
- 发布版本不会因草稿批量移除而被直接修改。

## 4. 统一试卷模型

正式试卷继续使用稳定题目引用：

```js
{
  bankId: "bank-001",
  questionId: "q-001",
  order: 1,
  score: 1
}
```

试卷增加：

- `enabledModes`：深度回忆、多题画布、单题深学；
- `publishedVersion`；
- `publishedReleaseId`；
- `purpose`；
- `archivedAt`。

发布时生成不可变发布版本，并保存题目解析快照。教师继续编辑草稿时，学员当前读取的发布版本保持不变；再次发布时生成下一版本。

## 5. 手动选题

独立试卷管理页支持：

- 按题库筛选；
- 按关键词搜索；
- 每页 20 道题；
- 默认仅选择当前页面；
- 批量加入当前试卷；
- 自动跳过重复题目；
- 按配额补充时保留已手动选择的题目。

## 6. 学习模式发布链路

建立公共发布试卷目录与发布历史：

- `kg_exam_papers_published_v1`；
- `kg_exam_paper_release_history_v1`。

三个学习模式统一读取发布试卷：

- 单题深学：按 `single_deep_study` 过滤；
- 多题画布：按 `multi_question_canvas` 过滤；
- 深度回忆：按 `deep_recall` 生成试卷题目源。

发布版本携带必要题目快照，因此学员账号无需拥有教师私有题库，也能解析发布试卷中的题目。

## 7. 引用与删除保护

本版本继续遵守 P3.4 的安全删除原则，并补充：

- 公共发布试卷及发布历史进入题目引用扫描；
- 整个题库存在试卷、课程、任务、答题、成绩或统计引用时，禁止直接永久删除；
- 删除试卷题目仅移除引用，不影响题库原题；
- 已发布版本保留稳定题目解析能力。

## 8. 兼容处理

- 旧用户级试卷草稿继续保留；
- 旧试卷入口自动迁移到独立页面；
- P3.4 的题目安全删除与恢复流程继续有效；
- 原单题深学与多题画布中的试卷选择交互继续可用，但数据源升级为统一发布目录。

## 10. 部署说明

当前工程仍是浏览器本地数据原型，公共发布目录通过浏览器存储模拟。若部署为多设备、多浏览器或真实多人系统，需要将试卷草稿、发布版本、权限范围和题目快照迁移到服务端 API；本版本的数据结构与读取边界已经为该迁移做好统一模型。
