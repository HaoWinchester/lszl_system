# v8.6.0 Bug Audit

Audit target: `kg_graph_v8_6_0_activity_schema_v1_bilingual_pulse_fix.zip`

## Confirmed issues found and fixed in v8.6.0.1

1. **Pulse ring after full course completion**
   - When every node was completed, `currentNode()` fell back to the last node.
   - Path rendering treated that completed node as `is-current`, so the final completed node kept pulsing.
   - Fix: `is-current` now requires both the unique current ID and `available` status.

2. **Malformed import package could crash validation**
   - `validatePackage()` recorded an error when `activities` was not an array, but still called `.forEach()` on the invalid value.
   - Fix: malformed values are normalized safely and returned as structured validation errors.

3. **Import integrity checks were incomplete**
   - Empty packages, invalid activity entries, duplicate IDs, and modified content hashes could be accepted.
   - Fix: package version, non-empty activity arrays, object shape, stable IDs, duplicate IDs, and `contentHash` are now checked.

4. **Required activity content could be blank**
   - A choice activity with an empty stem and empty option text could pass the JavaScript validator.
   - Fix: type-specific required fields, IDs, answer counts, pair/card orders, open-response lengths, and concept rules are now validated. The JSON Schema was strengthened to match.

5. **Partial English translations could render blanks or lose rules**
   - English mode selected the entire English payload as soon as any English field existed. Untranslated fields then appeared blank.
   - A partial English open-response concept list could remove untranslated concepts from evaluation.
   - Fix: content and explanations now fall back field by field using stable IDs; missing concepts are retained. Partial translations generate warnings.

6. **Bilingual line breaks were visually collapsed**
   - Materialized bilingual strings used newlines, but normal HTML whitespace collapsed them into a single line.
   - Fix: question stems, options, keyword segments, matching items, and memory cards preserve line breaks with `white-space: pre-line`.

- Deep recall, multi-question induction, knowledge graph, and part challenge still use the compatibility adapter rather than dedicated canonical editors.
- The current built-in activity library contains Chinese source content; English mode intentionally falls back to Chinese until translations are supplied.
