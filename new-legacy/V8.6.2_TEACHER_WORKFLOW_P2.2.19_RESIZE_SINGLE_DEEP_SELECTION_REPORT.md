# v8.6.2 P2.2.19 多题画布卡片缩放线与单题深学选题修复

基线：P2.2.18。

## 1. 卡片右侧尺寸调整线加长一倍

多题画布卡片右侧宽度调整控件保持原交互不变：

- 命中区域宽度仍为 10px；
- 鼠标仍为横向 resize；
- 悬停、选中、调整尺寸时显示逻辑不变；
- 只把可见竖线从 40px 调整为 80px。

因此视觉上更容易发现，但不会扩大鼠标命中范围，也不会改变卡片 resize 算法。

## 2. 修复“单题深学优先打开当前选中题目卡”失效

P2.2.18 的实现主要依赖 DOM-backed `selectedRecords()` 和在多题页内先修改当前题状态，再立即跳转。

这个路径存在两个脆弱点：

1. 工具栏获得焦点、分组隐藏或局部重渲染时，DOM-backed records 可能不能稳定代表当前 selection ID；
2. 仅依赖共享当前题状态跳转，在不同发布试卷上下文中可能再次被单题页自己的题目导航上下文覆盖。

P2.2.19 改成两层保证。

### 第一层：直接从 selection ID 解析目标卡

`preferredQuestionNodeForSingleDeep()` 现在直接读取：

- `state.selectedNodeIds`
- `state.workspace.nodes`

优先顺序：

1. 当前选中的题目卡；
2. 当前选中的归纳卡所关联的原题；
3. 当前画布第一张题目卡。

不再依赖卡片 DOM 是否当前可见。

另外，按下“单题深学”靶心按钮时，在 `pointerdown` 阶段先捕获目标 node ID；即使按钮获得焦点期间 selection UI 发生变化，click 阶段仍使用刚捕获的题目。

### 第二层：使用稳定 ID deep link

跳转到单题页时现在携带：

- `questionId`
- `bankId`
- `paperId`
- `source=multi-question`
- `return=<当前多题画布>`

例如：

`question-training.html?questionId=...&bankId=...&paperId=...`

单题页面的 `QuestionNavigator` 新增 incoming target 处理：

- 页面初始化后读取上述稳定 ID；
- 在当前试卷中找到则直接切题；
- 若目标题属于另一套已发布试卷，则先切换到对应 `paperId` 再打开该题；
- 成功应用后从地址栏移除 question/bank/paper 参数，避免重复切题。

这样“选中哪张题目卡 → 点击靶心 → 进入该题单题深学”不再依赖前一页的临时当前题状态。

## 数据影响

本版本没有修改：

- workspace ID；
- 卡片数据结构；
- 原题数据；
- 学习进度；
- 成绩；
- 课程；
- 解锁条件；
- 连线和分组结构。

只修改卡片 resize 可见线长度，以及多题 → 单题的导航目标解析。
