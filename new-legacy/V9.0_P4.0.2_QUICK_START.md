# V9.0-P4.0.2 快速使用说明

## 进入做题模式

1. 打开 `index.html`；
2. 首页会直接显示知识图谱画布；
3. 点击右上角“做题模式”进入 `practice-mode.html`。

做题模式不再替代首页，也不会通过全局快捷栏自动进入。

## 全局快捷栏

游客、游客账号和学生账号只显示：

```text
首页｜多题画布｜深度回忆
```

- 首页：知识图谱画布；
- 多题画布：原多题画布页面；
- 深度回忆：原深度回忆页面。

用户管理不会再因系统没有管理员而偶发出现在游客或学生快捷栏中。

## 学霸模式危险时间提示

- 剩余时间高于 20 秒：无红色视野；
- 进入 20 秒以内：边缘轻微淡红；
- 越接近 0 秒：红色边缘和呼吸效果越强；
- 答对恢复到 20 秒以上：红色视野自动淡出。

该效果不遮挡题目和按钮，也不拦截鼠标或触控操作。

## 部署提示

直接用本版本完整包覆盖上一版静态文件即可。题目、试卷、发布快照和练习历史不需要迁移。
