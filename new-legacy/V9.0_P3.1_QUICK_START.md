# V9.0-P3.1.1 快速使用

1. 启动本地服务器，打开 `admin-console.html`。
2. 在“总览”查看科目、当前知识树、题目、试卷与任务的业务摘要。
3. 进入“科目与知识树”，从左侧选择科目。
4. “当前知识树”用于查看当前结构与进入教师知识树工作区。
5. “待分类题目”用于查看尚未设置主要知识点的题目。
6. “历史版本”用于重大导入、切换当前、回退、归档、恢复和安全删除。
7. 完整审计和知识树生命周期记录在“操作记录”。
8. 仓库、引用索引、快照和权限诊断在“系统设置”。
9. P3.1.1 尚未开放当前知识树直接编辑和科目 CRUD；这些能力分别在 P3.3 和 P3.2 实施。
