# V9.0-P4.0 独立做题模式与轻量游戏化练习开发报告

## 目标

在服务器部署前暂时关闭尚未继续优化的旧学习模式前端，新增完全独立的做题页面。新页面只读取正式发布试卷及其不可变题目快照，不复用深度回忆、多题画布或单题深学的界面与运行状态。

## 前端入口隔离

新增独立页面：

```text
practice-mode.html
```

默认前端入口现在进入做题模式；自由图谱仍可通过 `index.html?mode=free` 使用。以下旧学习页面打开后统一转入做题模式：

- `learning-path.html`
- `question-training.html`
- `question-workspace.html`
- `knowledge-recall.html`
- `guided-learning-node.html`
- `guided-learning-placement-test.html`

旧页面代码和历史数据没有删除，后续恢复学习模式开发时仍可继续使用。

## 数据来源与隔离

做题模式读取公共发布目录：

```text
kg_exam_papers_published_v1
```

题目优先读取发布版本中的 `questionSnapshots`，并保留对公共发布题库的兼容解析。教师草稿、教师私有题库和旧学习模式运行状态不会进入做题页面。

一场练习开始后固定使用当时选中的发布版本。练习过程不会：

- 修改题目或题目 ID；
- 修改试卷或发布快照；
- 写入教师草稿；
- 写入旧学习模式进度。

## 练习大厅

题目数量固定为：

```text
10 / 20 / 60 / 180
```

当试卷可用题量不足时，对应数量自动禁用。支持：

- 按试卷原顺序练习；
- 随机题目顺序；
- 挑战模式；
- 学霸模式；
- 当前账号最近六次已完成练习记录。

练习历史按账号隔离，存储键为：

```text
kg_practice_history_v1__user__<账号>
```

## 统一经验值

- 答对基础经验：`+10`；
- 答错或超时：`+0`；
- 连续答对 3–4 题：额外 `+2`；
- 连续答对 5–7 题：额外 `+5`；
- 连续答对 8 题以上：额外 `+10`。

页面不常驻显示经验值，只在答题反馈、检查点和最终结算中显示。

## 挑战模式

### 规则

- 初始血量 3 点；
- 答错扣除 1 点血量并清空连胜；
- 血量归零立即结束；
- 连续答对 5 题时恢复 1 点血量，最高仍为 3；
- 每完成 5 题进入检查点；
- 不允许暂停、返回上一题或修改答案。

### 页面

练习开始后隐藏大厅顶栏，顶部仅保留：

```text
退出按钮 / 无文字进度条 / 血量
```

连胜不常驻。达到连胜经验条件时，在进度条上方短暂弹出；选择下一答案或渲染下一题时自动消失。

检查点只显示：

- 当前连胜；
- 当前经验值；
- 从练习开始到当前的总耗时；
- “继续”按钮。

## 学霸模式

### 规则

- 初始共享时间池 80 秒；
- 时间跨题继承，上限为 80 秒；
- 答对：增加经验并恢复 20 秒；
- 答错：扣除 20 秒、扣除 1 点血量并清空连胜；
- 自然超时：当前题判错并扣除 1 点血量；
- 超时后仍有血量时，下一题从 40 秒继续；
- 答错扣时导致时间归零时只扣一次血；
- 不允许暂停、返回上一题或修改答案。

### 页面

顶部仅保留：

```text
退出按钮 / 做题进度 / 血量 / 连胜 / 倒计时
```

倒计时同时使用细进度条表示：

- 41–80 秒：正常；
- 21–40 秒：紧张；
- 0–20 秒：危险。

倒计时使用截止时间计算，打开退出确认、切换标签页或发生短暂渲染延迟时都不会暂停。

## 题目卡与反馈

- 页面只展示完整题干和选项；
- 点击选项立即提交；
- 提交后立即锁定当前题，防止重复点击；
- 学霸模式答对时选项短暂闪绿；
- 学霸模式答错时选项短暂闪红；
- 颜色动画结束后恢复，不持续标注答案；
- 约 0.52 秒后自动进入下一题；
- 不显示题目导航、上一题、下一题或确认答案按钮；
- 作答过程中不显示解析、知识点、标签或题库信息。

## 退出与结算

两种模式都不允许暂停。进度条左侧提供关闭图标，退出确认打开时学霸倒计时继续运行。主动退出、刷新或关闭页面会把本次练习记录为未完成，不进入最佳成绩或最近完成列表。

结算页面只显示：

- 正确率；
- 从开始到结束的总耗时；
- 获得经验值。

挑战模式不显示评级，学霸模式不显示称号，也不显示题目地图、最高连胜或分题用时。

## 后台兼容调整

试卷管理仍沿用现有发布模型和发布快照，不重构后台学习配置。页面说明调整为“发布后供独立做题模式使用”；旧学习模式范围复选框暂时隐藏但保留默认值，避免改变现有发布数据结构和历史测试链路。

## 部署说明

本项目当前发布试卷、账号和练习记录仍使用浏览器存储。部署为同一浏览器数据域时可直接使用；需要跨设备同步时，应把公共发布目录和练习历史迁移到服务端存储。
