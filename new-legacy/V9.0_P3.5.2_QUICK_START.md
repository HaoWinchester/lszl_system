# V9.0-P3.5.2 快速使用说明

## 悬浮预览题目

1. 在“从题库选择题目”或“试卷题目预览”中双击一道题；
2. 悬浮卡片会出现在题目附近，箭头指向对应列表行；
3. 卡片打开时，单击另一道题即可切换预览；
4. 再次双击当前题目、点击关闭图标或按 Esc，可关闭预览；
5. 点击编辑图标，可在新标签页打开该题目的精确编辑页面。

## 管理试卷分类

1. 点击试卷列表右上角“＋ 新建分类”；
2. 输入分类名称；
3. 在自定义分类中创建新试卷时，新试卷自动归入当前分类；
4. 使用分类右侧图标重命名或删除分类；
5. 删除分类只会把试卷移入“未分类”。

## 批量管理试卷

1. 勾选试卷，或点击“选择当前页”；
2. 使用批量栏进行移动分类、批量归档或删除草稿；
3. 删除草稿只处理未发布草稿，已发布和已归档试卷自动跳过；
4. 这些操作不会删除题库中的原题。
