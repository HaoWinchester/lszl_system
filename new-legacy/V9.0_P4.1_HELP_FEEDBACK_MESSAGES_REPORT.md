# V9.0-P4.1 帮助中心、需求反馈与站内消息开发报告

## 一、P4.0.3 缺陷复查

本轮先对 P4.0.3 的三个学习页面统一题源、发布版本定位、异常快照、旧工作区兼容和首页临时菜单进行了复查。

复查结果未发现阻断部署的问题，并修复两个版本解析边界：

1. 使用 `paperId` 定位发布试卷时，如果目录中意外同时存在多个版本，改为优先选择版本号和发布时间最新的发布版本；
2. 发布目录读取不再把 `draft`、`withdrawn` 等非发布状态记录强制规范为 `published`。

上述修复不修改现有发布快照或试卷数据，只收紧读取行为。

## 二、用户端支持中心

首页账号控件右侧新增问号图标入口，包含：

- 帮助中心；
- 需求反馈；
- 消息。

未读消息会在问号按钮和消息菜单中显示数字角标。支持单条标记已读和全部标记已读。

### 帮助中心

新增独立页面 `help-center.html`，首版覆盖：

- 图谱首页；
- 多题画布；
- 深度回忆；
- 单题深学；
- 做题模式。

支持关键词搜索和页面间快速跳转。帮助内容集中在 `src/102-help-content.js`，后续新增页面说明时可继续扩展文档条目。

### 需求反馈

用户可以提交：

- 问题反馈；
- 功能建议；
- 内容问题；
- 其他反馈。

表单支持标题、详细描述、联系方式和不超过 2MB 的图片附件，并自动记录当前页面、账号角色和应用版本。

“我的反馈”可以查看处理状态和管理员回复。

## 三、后台反馈管理

新增 `feedback-management.html`，仅管理员可使用。

支持：

- 按标题、用户和页面搜索；
- 按反馈类型和状态筛选；
- 查看用户、页面、时间、联系方式和截图；
- 更新为待处理、处理中、已解决或已关闭；
- 回复用户；
- 将状态变更和回复写入操作记录。

## 四、后台消息管理

新增 `message-management.html`，仅管理员可使用。

支持：

- 创建和编辑消息草稿；
- 立即发布或设置计划发布时间；
- 设置失效时间；
- 撤回已发布消息；
- 删除未发布或已撤回消息；
- 设置全部用户、指定角色或指定用户名；
- 设置业务跳转链接；
- 查看本地演示环境中的已读数量。

反馈管理和消息管理已经加入后台统一一级导航及管理后台常用工作入口。

## 五、本地与服务器适配

新增统一仓库：

```text
src/101-engagement-repository.js
```

默认配置为：

```text
local-demo
```

该模式用于静态部署、离线演示和浏览器回归，数据保存在当前浏览器：

```text
kg_user_feedback_v1
kg_announcements_v1
kg_user_message_reads_v1__<账号>
```

正式跨设备部署时，应将 `KG_APP_CONFIG.engagement.mode` 设置为 `remote`，并按以下接口契约实现服务端：

```text
SERVER_ENGAGEMENT_API_V1.md
```

远程适配器已经覆盖反馈提交、我的反馈、后台处理、消息发布、用户消息和已读状态。服务端仍必须自行完成身份鉴权和权限校验。

## 六、安全与兼容性

本轮没有修改：

- 题目 ID、题库 ID 或题目正文；
- 试卷草稿和不可变发布快照；
- 深度回忆、多题画布和单题深学的统一题源规则；
- 做题模式经验、血量、倒计时和历史记录；
- 安全删除和历史引用保护。

消息正文和反馈内容在页面输出时进行 HTML 转义；消息跳转链接拒绝 `javascript:` 等不安全协议；图片附件限制类型和大小。
