# V9.0-P3.5.2 试卷目录管理与悬浮题目预览开发报告

## 版本目标

本版本继续优化独立试卷管理页面：

1. 题目预览改为锚定列表项的非模态悬浮卡片；
2. 试卷数量增长后，可通过分类、搜索、状态筛选、分页和批量操作进行维护。

## 一、题目悬浮预览

- 双击题库候选题或试卷题目，打开悬浮预览；
- 悬浮卡片显示方向箭头，指向对应的题目列表行；
- 预览打开后，单击另一道题即可切换内容并重新定位；
- 再次双击当前同一道题会关闭预览；
- 支持关闭图标和 Esc 键关闭；
- 页面滚动、窗口缩放、左右分栏拖动、区域放大或收起时自动重新定位；
- 当前锚定题目行保持高亮。

预览继续显示题目标题、教师题号、来源题库、题型、难度、知识点、标签、题干、选项、答案和解析。

编辑图标打开精确的 `bankId + questionId` 编辑入口，不复制题目，也不改变题目 ID。

## 二、试卷分类与目录管理

### 分类目录

试卷列表左侧新增：

- 全部试卷；
- 未分类；
- 自定义分类；
- 分类试卷数量；
- 新建、重命名和删除分类。

删除分类时，分类中的试卷只会移入“未分类”，试卷本身不会被删除。

### 查找与分页

- 按名称、科目、说明和分类名称搜索；
- 按草稿、已发布、已归档筛选；
- 每页显示 18 张试卷；
- 支持上一页和下一页；
- 默认只选择当前页，避免误操作整个筛选结果。

### 批量操作

选择当前页试卷后支持：

- 批量移动分类；
- 批量移入未分类；
- 批量归档；
- 批量删除草稿。

安全边界：

- 批量归档会把已发布试卷从学员端下架，但保留历史发布记录；
- 批量删除只删除草稿；
- 已发布或已归档试卷会被保护并自动跳过；
- 批量操作只改变试卷配置，不删除题库原题；
- 题目 ID、题库 ID 和已发布版本快照保持不变。

试卷基本信息新增“所属分类”。分类数据按当前账号保存在：

```text
kg_exam_paper_categories_v1__<账号范围>
```

## 三、兼容性

本版本保持：

- 正式题库手动选题；
- 当前页批量加入题目；
- 试卷题目批量移除；
- 左右双栏拖拽、放大和收起；
- 不可变发布版本；
- 深度回忆、多题画布、单题深学统一读取；
- P3.4 安全删除和历史题目 ID 解析；
- 编辑草稿不影响学员当前发布版本。
