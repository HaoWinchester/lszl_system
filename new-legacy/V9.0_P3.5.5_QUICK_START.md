# V9.0-P3.5.5 快速使用说明

## 训练配置

打开：

```text
question-bank.html?mode=simple&step=training
```

1. 在页面顶部点击 PMP、ACP 等科目按钮。深灰色按钮表示当前科目。
2. 左侧“选择题库”只会列出当前科目的题库。
3. 在题目列表中选择题目，列表下方会完整显示题干、全部选项、正确答案和解析。
4. 拖动题目区与训练配置区之间的分隔条，可调整两侧宽度。
5. 在右侧维护当前题目的可点击关键词和“关键词 → 知识联想入口”，然后保存当前配置。

当前科目没有题库时，请返回题目管理创建题库；训练配置不会自动新建题库。

## 管理科目级知识联想库

进入：

```text
管理后台 → 科目与知识树 → 当前知识树
```

在知识树工作区下方找到“科目级知识联想库”：

1. 顶部切换需要管理的科目；
2. 点击“载入当前库”；
3. 编辑知识链文本，或导入 TXT / JSON；
4. 点击“解析检查”；
5. 选择“按稳定节点合并”或“替换当前科目联想库”；
6. 点击“保存联想库”。

常用格式：

```text
A -> B | C | D
A ➡️ B ➡️ C
```

“替换”会覆盖当前科目的联想库，保存前会再次确认。“合并”会按稳定节点 ID 合并，适合日常维护。

## 单题配置范围

训练配置只维护当前题目的关键词和入口。科目级联想关系统一在知识树页面维护；节点配置和学员效果预览不再显示在单题页面。
