# V9.0-P2.1 快速使用

## 启动

在解压目录运行：

```bash
python -m http.server 9000
```

Windows 也可以使用：

```bash
py -m http.server 9000
```

浏览器打开：

```text
http://localhost:9000/admin-console.html
```

## 管理员权限

“发布为当前”和“设为当前”只对管理员开放。若按钮呈禁用状态，请先从管理端右上角进入“登录 / 切换账号”，使用管理员账号登录；账号角色可在“账号管理”中查看。

## 发布知识树

1. 使用管理员账号进入 `admin-console.html`。
2. 找到目标草稿版本。
3. 点击“查看 / 编辑”进入内容中心检查。
4. 返回管理端，点击“发布为当前”。
5. 确认后，该版本成为科目的当前知识树。

## 修改已发布知识树

已发布版本为只读：

1. 在管理端点击“复制为新草稿”。
2. 打开生成的新草稿编辑。
3. 编辑完成后由管理员发布为当前。

## 回退到旧版

在管理端找到历史已发布版本，点击“设为当前”。旧版会立即重新成为该科目的当前知识树，其他版本仍保留。
