# v8.6.2 P2.2.13 多题当前画布文件栏与保存状态

基线：P2.2.12。

## 已完成

1. 删除多题页面标题旁重复显示的当前画布名称。
   - 顶栏只保留“多题归纳”。
   - 当前画布名称只在页签和画布左上文件栏中显示。

2. 画布左上当前文件名栏支持单击直接编辑。
   - 单击文件名进入行内编辑；
   - Enter / 失焦保存；
   - Esc 取消；
   - 保存后活动页签同步更新名称；
   - workspace ID 保持不变。

3. 文件名栏左侧加入知识图谱同款云朵保存状态图标。
   - SVG 路径与知识图谱 `graphSaveState` 一致；
   - 已保存：绿色；
   - 有未保存变化：橙色；
   - 保存中：蓝色并轻微脉冲；
   - 保存失败：红色；
   - 点击图标立即保存；
   - Ctrl+S / Command+S 立即保存。

4. 保存状态接入现有 CanvasWorkspaceStore。
   - 视图平移/缩放的延迟保存显示 dirty → saving → saved；
   - 卡片布局保存显示 saving → saved；
   - 工作区写入事件成功后恢复 saved；
   - 手动保存复用现有 Workspace Store，不改变题目、学习记录和 workspace ID。

## 关于“云端保存”

本版复用了知识图谱页面的云朵保存状态图标、状态颜色与手动保存交互。多题画布底层仍然使用当前 `CanvasWorkspaceStore` 持久化层，本版没有伪造新的远程服务器同步能力。
