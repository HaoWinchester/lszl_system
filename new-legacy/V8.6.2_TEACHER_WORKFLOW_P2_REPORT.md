# v8.6.2 教师工作流 P2 开发与回归报告

## 1. 基线与范围

本轮以 `kg_graph_v8_6_2_teacher_workflow_p1.zip` 为直接基线，在 P0 的教师三步工作流和 P1 的大型课程导航之上，完成教师日常批量操作与课程质量检查。

P2 只增加效率工具，不改变 Activity Schema、Knowledge Taxonomy Schema、Course Configuration Schema、既有稳定 ID、学员学习进度、课程成绩和解锁规则。

本轮没有开发科目新增/删除，也没有开发知识树导入/导出。

## 2. 批量粘贴多道原题

题目管理的快捷粘贴新增：

- 单题粘贴；
- 批量粘贴多题。

批量模式支持：

- 按题号、完整 A/B/C/D 选项序列或 `---`、`===`、`***` 分隔线拆题；
- 识别常见选项、答案和解析格式；
- 逐题显示题干摘要、答案、错误和提醒；
- 只导入解析有效的题目；
- 跳过当前题库中题干完全重复的题目；
- 题目 ID 冲突时生成新的稳定 ID，不覆盖原题；
- 导入后自动定位到最后一条新增题目，继续结构化校对或配置训练。

批量粘贴不会直接绕过校验写入无效题目。

## 3. 批量学习模板

课程设置新增“批量工具”，内置三套第一版模板：

1. 原题基础四步：题干观察、关键词识别、原题作答、选项复盘；
2. 知识串联三步：关键词回忆、知识图谱、多题归纳；
3. 完整七步学习：基础原题训练和知识串联组合。

模板可应用到：

- 当前章节；
- 当前阶段全部章节；
- 全课程尚无学习步骤的章节。

系统按“步骤名称 + 节点类型”检查已有内容，仅补充缺失步骤；不会删除、覆盖或重新生成已有学习步骤 ID。

## 4. 批量复制课程结构

支持复制：

- 当前章节；
- 当前阶段。

每次可复制 1～20 份，并可选择是否保留题目与训练内容引用。

复制规则：

- 阶段、章节和学习步骤全部生成新稳定 ID；
- 名称自动追加“副本”序号；
- 复制后重新规范同级显示顺序；
- 原结构和原稳定 ID 保持不变；
- 关闭“保留内容引用”时，仅复制课程骨架。

## 5. 规则化课程生成

教师可粘贴课程大纲文本：

```text
# 阶段一
## 章节一
- 题干观察 | standard
- 关键词回忆 | deep_recall
## 章节二
- 知识图谱 | knowledge_graph
```

同时支持中文形式：

```text
阶段：阶段二
章节：综合练习
步骤：多题归纳 | multi_question
```

解析器先显示阶段、章节、学习步骤数量以及未识别行，不会直接写入课程。确认后以“追加”方式生成新结构，所有生成项使用新 ID，并记录 `generatedBy: outline-p2`。

## 6. 最近编辑

课程设置新增按课程隔离的最近编辑面板，记录：

- 新增阶段、章节和学习步骤；
- 编辑课程信息或课程结构；
- 添加、移除或调整题目与训练内容；
- 批量套用模板；
- 批量复制结构；
- 按大纲生成结构。

每个课程最多保留 30 条最近编辑记录。点击记录可直接切换阶段、展开章节并定位对应项目。记录存储在独立工作区键中，不写入课程 Schema。

## 7. 课程检查面板

新增统一课程检查面板，分为：

- 错误：空名称、重复 ID、父级缺失、内容引用不存在及核心课程校验错误；
- 待配置：空阶段、空章节、尚未添加题目或训练内容的学习步骤；
- 提醒：核心课程校验返回的非阻断性提醒。

面板支持全部、错误、待配置和提醒筛选；点击阶段、章节或学习步骤问题可直接返回编辑位置。

课程检查只读取现有草稿并帮助定位，不自动修改课程数据。

## 8. 代码结构

新增独立纯逻辑服务：

```text
src/98-teacher-workflow-p2-services.js
```

集中提供：

- 单题解析；
- 多题拆分和批量解析；
- 规则化课程大纲解析；
- 学习步骤类型别名规范；
- 内置课程学习模板。

题库和课程页面只负责界面、保存及跳转，避免继续在页面控制器中重复解析规则。
