# v8.6.0.3 修复与收尾报告

## 本次目标

完成 Activity Schema v1 第一阶段封口，并按确认方案将英文限定为展示内容，作答与判定固定为中文。

## 已完成

- 学员端只开放中文和中英对照；纯英文旧偏好自动迁移。
- 所有活动明确 `assessment.language: "zh"`。
- `type` 成为唯一权威，未知类型和适配器不一致会被阻止。
- 新增标准独立排序题及运行插件。
- JavaScript 校验器与 JSON Schema 对齐。
- 新增活动包解析、冲突分析和合并接口。
- 保留早期 Activity Schema v1 导入兼容。

- 75 个源代码 JavaScript 文件通过语法检查。
- 82 个现有活动与 108 个节点通过数据回归。
- 当前活动库及导出活动包通过 Draft 2020-12 JSON Schema 校验。
- 学习路径、管理员入口、进度定位、跳级测试、单选、关键词、连线、独立排序、混合题、提示、综合挑战、翻牌、深度回忆、知识图谱和多题归纳浏览器回归通过。
- 桌面入口矩阵回归通过。
