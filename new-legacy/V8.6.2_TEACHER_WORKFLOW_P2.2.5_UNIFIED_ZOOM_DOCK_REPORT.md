# v8.6.2 P2.2.5 统一画布缩放栏报告

基线：P2.2.4。

## 统一方案
单题深学、多题归纳、深度回忆统一采用知识图谱左下角风格缩放栏：`−  当前比例  ＋  |  适应/定位`。点击比例展开轻量滑杆。

- 单题：适应按钮全览五张学习卡。
- 多题：适应按钮全览当前画布。
- 深度：定位按钮回到中心题目。

## 顶部清理
- 单题、多题删除顶部“视图”缩放菜单。
- 深度“视图”改为“场景”，仅保留学习场景主题。

## 单题字体
单题左上角 Aa 移到右上角工具栏，顺序为：指针 → Aa → 当前卡 → 重置。原 A- / A / A+ / A++ 逻辑和存储不变。

不改题目、课程、进度、成绩、解锁、联想节点和关系数据。
