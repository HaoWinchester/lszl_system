# v8.6.2 教师工作流 P2.1.1 UI 维护报告

## 范围

本轮以 `kg_graph_v8_6_2_teacher_workflow_p2_1_bilingual_entry_rebuilt.zip` 为基线，仅处理教师题目工作流的三处界面与交互问题，不进入 P2.2 功能范围。

## 已完成

### 1. 快捷录题顶部轻量化

原先分为三层的：

- 快捷粘贴 / 手动填写；
- 模板选择、下载、复制、示例；
- 单题粘贴 / 批量粘贴多题；

已合并为一个统一工具栏。1366px 桌面宽度下保持单行；125% / 150% 缩放及窄屏下按可用宽度响应式收缩或换行，不产生页面横向溢出。

### 2. 批量导入复选项

两个选项改为稳定双列布局，复选框固定在文字左侧并保持一致间距：

- 存在错误时，仅导入解析通过的题目；
- 跳过题干完全相同的重复题。

移动端自动切换为单列。

### 3. 快速回忆说明与状态卡

删除容易误解的“右侧可填写”说法，改为明确格式：

`关键词 -> 联想入口`

箭头后填写知识点名称或联想库节点 ID；留空时使用关键词本身。

蓝色状态卡现在明确用于展示：

- 关键词；
- 在题干 / 选项中的命中位置；
- 当前联想入口；
- 联想库是否收录；
- 是否已有后续分支。

每张卡新增“编辑入口”按钮。点击后会自动聚焦“关键词 → 知识联想入口”文本框，并选中该关键词对应的入口值，教师可直接输入新入口，再点击“同步关键词与入口”保存。

分支状态进一步区分：

- 联想库未收录；
- 已存在知识点，但暂无后续分支；
- 已配置 N 个后续分支。

前两种情况均明确提示学员仍可自由输入。

## 数据完整性

本轮没有修改：

- 题目稳定 ID；
- 活动 ID；
- 知识点 / 联想节点稳定 ID；
- 课程阶段、章节或学习步骤 ID；
- 学习进度；
- 成绩；
- 解锁规则。

所有修改均为 HTML / CSS / 教师端交互层增量维护。
