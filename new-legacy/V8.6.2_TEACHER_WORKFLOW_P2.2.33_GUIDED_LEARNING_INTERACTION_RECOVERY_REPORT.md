# V8.6.2 P2.2.33 学习路径交互恢复报告

本版本针对 P2.2.32 发布包中的交互回归进行修复。

## 已确认根因

1. `learning-path.html` 未同步到 P2.2.32 的 CSS/JavaScript 版本，页面仍渲染旧模式图标，也没有账号菜单中的默认模式开关。
2. 路径滚动区使用 `flex:1`，但父容器只有 `min-height`，没有确定高度，导致滚动区展开到全部内容高度；外层页面同时设置 `overflow:hidden`，因此无法滚动。
3. 默认模式设置行与原生 label 点击同时修改 checkbox，造成一次点击发生两次翻转。
4. 账号菜单图标使用 `<span>`，与通用账号菜单控制器“首个 span 为标签”的约定冲突。

## 修复

- 学习路径应用壳层改为固定视口高度的 Flex 布局，滚动区获得明确可用高度。
- 模式切换使用原生链接的分段滑动样式。
- 账号菜单补齐用户中心、帮助中心、默认学习模式和退出登录，并修正标签结构。
- 默认模式开关区分 label 点击与整行点击，确保每次只翻转一次。
- 新增 P2.2.33 专项浏览器回归测试。
