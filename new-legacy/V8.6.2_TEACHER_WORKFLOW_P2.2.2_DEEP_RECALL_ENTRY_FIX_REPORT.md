# v8.6.2 P2.2.2 Deep Recall Entry Fix

Baseline: `kg_graph_v8_6_2_teacher_workflow_p2_2_1_bugfix.zip`

## Fix 1 — Deep Recall question-library button

`#krQuestionListBtn` is inside `#krViewport`. The canvas `pointerdown` handler did not exclude the P2.2 question-library overlay. A normal mouse/touch press therefore started the canvas-pan gesture and captured the pointer before a browser click could reach the button.

P2.2.2 excludes the question-library overlay and ordinary interactive controls from canvas pan capture. The same controls are excluded from canvas wheel/double-click behavior.

## Fix 2 — Built-in demo question bank

`PMP_QUESTION_MVP` is declared as a global lexical variable (`let`), so it is not guaranteed to exist as `window.PMP_QUESTION_MVP`. The question-source service now resolves either form, so a fresh installation still shows the built-in PMP demo bank.

## Regression quality improvement

The inherited P2.2 / P2.2.1 tests use synthetic click dispatch, which is why they did not catch this issue. P2.2.2 adds a dedicated real `locator.click()` regression.

New coverage verifies desktop and mobile real pointer opening, search focus, built-in demo bank, Escape closing, and focus return.

## Data safety

No question data, activity data, knowledge taxonomy, course structure, progress, score or unlock data is migrated or rewritten.
