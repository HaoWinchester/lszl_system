# V9.0-P3.3.3.1 批量录题默认分类优化报告

本版本基于 V9.0-P3.3.3，仅优化“题目管理 → 题目内容 → 批量粘贴多题”的分类效率，不改变题型、单题录入、知识树生命周期、试卷题目 ID 或历史数据规则。

## 本次实现

- 批量模式新增“本批次默认分类”。
- 科目始终跟随当前题库，不允许跨科目批量写入。
- 可一次设置默认主要知识点和默认普通标签。
- 单题模板明确填写的知识点/标签优先于批次默认值。
- 未填写对应字段的题目自动继承批次默认值。
- 批量解析结果每题增加“修改分类”，可单独覆盖该题。
- 单题覆盖只保存与自动规则不同的字段；未修改字段继续跟随模板或批次默认规则。
- 可恢复单题的“模板 / 批次规则”。
- 批量默认知识点继续使用当前科目当前知识树、稳定节点 ID 和最多 9 层结构。
- 批量默认标签复用现有层级标签与自定义标签选择方式。
- 下载的批量模板保留科目、知识点和标签字段，但默认留空，避免示例分类阻止批次默认值生效。

## 优先级

主要知识点与普通标签均采用：

1. 解析后人工单题覆盖；
2. 单题模板显式字段；
3. 本批次默认分类；
4. 无匹配时保持待分类 / 无标签。

## 不在本版本范围

- 不根据题干语义自动猜测知识点。
- 不开发多主要知识点。
- 不改变现有题型区域。
- 不实施 P3.4 题目批量移动。
- 此前确认的“管理标签 → 双击改名”仍保留为后续独立小版本，不混入本次批量录题优化。
