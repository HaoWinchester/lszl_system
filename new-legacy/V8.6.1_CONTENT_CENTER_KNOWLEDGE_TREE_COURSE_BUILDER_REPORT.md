# v8.6.1：统一活动库、科目知识树与课程配置后台骨架

## 版本定位

- 学习程序：v8.6.1
- Question Studio：v0.2.0
- 活动数据标准：Activity Schema v1
- 知识树数据标准：Knowledge Taxonomy Schema v1
- 课程配置标准：Course Configuration Schema v1

## 已完成

### 内容中心与统一活动库

- 新增 `content-center.html`，作为日常内容管理入口；
- 现有 82 个课程活动自动进入统一活动库，不复制正文；
- 旧 `question-bank.html` 保留为高级兼容编辑器；
- 活动库支持科目、知识点、归类状态、活动状态、作者和文本筛选；
- 显示创建教师、最后修改者、课程引用次数和活动生命周期；
- 支持 Activity Schema v1 活动包导入、冲突处理和筛选导出；
- 支持单个或批量设置主知识点和相关知识点。

### 多科目知识树

- 每个科目拥有独立默认知识树；
- 内置 PMP、CSPM、P2、ACP、NPDP 五个科目及其主知识树；
- 单棵知识树最大支持 6 层，不要求每个分支达到第 6 层；
- PMP 内置六层示例路径：PMP → 项目需求管理 → 规划需求管理 → 输出 → 需求跟踪矩阵 → 双向可追溯特点；
- 知识节点使用稳定 ID 和 `parentId`，活动只引用知识点 ID；
- 支持新增、编辑、改名、移动、停用和搜索知识节点；
- 阻止创建第 7 层以及父节点断裂、循环引用等错误结构；
- 历史活动统一标记为 `mappingStatus: "unmapped"`，不自动猜测知识点。

### Question Studio v0.2.0

- 新增科目、知识树和主知识点选择；
- 支持为批量题目设置默认知识点并一键应用；
- 新活动提交前强制校验主知识点；
- 导出活动保存 `subjectId`、`taxonomyId`、`taxonomyVersion`、`primaryNodeId` 和路径快照；
- 新增“提交到活动库”按钮；
- 当前静态版本使用同源浏览器活动库直连，不再必须选择 JSON 文件；
- 已预留服务器接口适配：配置活动导入 API 后自动改用 HTTPS 提交；
- 创建者和最后修改者由活动库同步层根据当前登录账号写入；
- 继续保留 JSON 导入、导出和离线备份。

### 课程配置后台骨架

- 新增 `course-admin.html`；
- 支持课程、阶段、部分和节点的新增、编辑及删除；
- 节点仅保存 `activityIds`；
- 可从统一活动库搜索、筛选并引用活动；
- 支持活动顺序调整、课程结构预览和知识覆盖统计；
- 支持课程草稿本地保存、结构校验、版本发布和发布记录；
- 现有 3 个阶段、9 个部分和 108 个节点自动迁移为课程草稿，不改变学员端当前运行数据。

## 数据迁移规则

- 历史活动：`createdByUserId = "system-legacy"`，创建者显示为“历史活动库”；
- 历史活动知识映射：默认为待归类；
- 新活动：由 Question Studio 或活动库根据当前账号记录作者；
- 新课程：引用统一活动 ID，不保存活动副本；
- 本版本发布的课程配置保存为独立版本快照，暂不自动替换学员端内置课程。

## 当前服务器边界

本版本仍可完全离线运行。Question Studio 的“提交到活动库”在同源部署时使用浏览器活动库，已消除日常文件选择步骤。真正的多人服务器数据库、服务端会话鉴权和跨设备同步，需要部署后端 API 后启用；前端同步适配接口已经预留。
