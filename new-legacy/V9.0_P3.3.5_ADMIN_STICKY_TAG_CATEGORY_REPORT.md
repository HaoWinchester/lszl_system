# V9.0-P3.3.5 标签分类名称维护与后台常驻顶栏报告

## 基线

- 基线版本：V9.0-P3.3.4
- 本版本：V9.0-P3.3.5
- 本轮不进入 P3.4 题目批量移动。

## 完成内容

### 1. 标签管理继续保持轻量

现有“管理标签”弹窗不增加独立管理页面。除具体标签名称外，现在可以直接双击修改：

- 一级标签分类，例如“用途标签 / 质量标签 / 来源标签”；
- 二级分类，例如“训练阶段 / 使用场景 / 题目特征”；
- 原有具体标签名称。

Enter 或失焦保存，Esc 取消。一级分类禁止与其他一级分类重名；二级分类禁止与同一一级分类下的其他二级分类重名；具体标签继续执行全局预设标签重名保护。分类名称只影响显示和选择器层级标题，不改变题目已经保存的具体标签值。

### 2. 后台顶部导航常驻

以下页面的统一八项后台一级导航改为滚动常驻：

- 总览；
- 科目与知识树；
- 用户管理；
- 操作记录；
- 系统设置。

总览、科目与知识树、操作记录、系统设置的业务头栏继续固定在一级导航下方，因此账号入口在长页面滚动时仍可使用。用户管理保留统一一级导航常驻，但不固定体积较大的用户管理业务头部。

### 3. 用户管理页去除重复入口

用户管理页面移除：

- 左侧返回箭头；
- 右上角账号胶囊；
- “管理后台 / 题库管理 / 系统设置”三个重复快捷按钮。

“+ 新用户 / 导出用户 / 导入用户”继续保留。模块切换统一通过最上方八项后台导航完成。

### 4. 后台账号胶囊统一

总览、科目与知识树、操作记录、系统设置右上角移除“教师端 / 切换账号”，改为单一账号胶囊。点击后提供：

- 用户中心；
- 帮助中心；
- 退出登录。

帮助中心为后台专用说明，说明当前后台页面和主要管理模块，不复用学员端/练习端帮助。
