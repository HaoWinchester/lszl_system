# V9.0-P3.3.1 教师工作流导航外壳修复报告

## 一、修复目标

本补丁解决两个界面问题：

1. 课程设置页教师主导航重复显示“管理端”；
2. 教师工作台未挂载统一管理后台顶部导航，进入工作台后“总览”等入口消失；滚动时教师工具栏还可能覆盖顶部导航。

## 二、实现内容

### 1. 移除重复管理端入口

`teacher-workbench.html` 和 `course-admin.html` 的教师主导航统一为：

```text
工作台 / 题目管理 / 训练配置 / 课程设置
```

管理后台入口统一由上方八项顶部导航承担，不再在教师主导航中重复出现。

### 2. 工作台接入八项顶部导航

`teacher-workbench.html` 新增与其他管理模块一致的顶部导航：

```text
总览 / 科目与知识树 / 题库管理 / 试卷管理
课程与任务 / 用户管理 / 操作记录 / 系统设置
```

工作台使用 `data-admin-context="overview"`，因此“总览”会正确高亮。

### 3. 修复吸顶覆盖

新增 `teacher-admin-shell` 页面外壳，仅应用于：

- 教师工作台；
- 题目管理与训练配置；
- 课程设置。

在该外壳中：

- 管理后台顶部导航固定在 `top: 0`；
- 桌面端教师工具栏固定在 `top: 42px`；
- 两层导航不会互相覆盖；
- 移动端教师工具栏继续保持原有普通文档流，顶部管理导航仍保持可见。

该规则不修改普通管理后台页面的吸顶位置，避免影响科目列表等现有内部布局。
