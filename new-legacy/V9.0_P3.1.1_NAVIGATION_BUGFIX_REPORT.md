# V9.0-P3.1.1 顶部导航一致性与缺陷复查报告

## 1. 修复范围

本修正版基于 `V9.0-P3.1`，不改变 P2.2 的数据服务、知识树生命周期、事务快照、审计、引用检查或安全删除规则。

## 2. 已确认问题

1. `admin-console.html`、`admin-subjects.html`、`admin-operations.html`、`admin-settings.html` 在桌面端使用左侧一级导航。
2. `question-bank.html`、`course-admin.html`、`user-management.html`、`system-settings.html` 使用顶部一级导航。
3. 原顶部导航同时包含“管理后台”和“总览”两个指向同一页面的入口，存在重复。
4. 两套导航分别由不同样式控制，导致页面切换时主导航位置、宽度和激活反馈发生跳变。

## 3. 修复内容

- 八个管理页面统一使用 `admin-context-nav` 顶部一级导航。
- 一级导航固定为八项：总览、科目与知识树、题库管理、试卷管理、课程与任务、用户管理、操作记录、系统设置。
- 移除四个 P3.1 页面中的桌面左侧一级导航结构。
- `admin-app-shell` 改为稳定的全宽内容容器；科目列表、题库编辑器、系统设置页签等业务内部侧栏保持原样。
- 删除重复的“管理后台”入口，保留“总览”作为唯一后台首页入口。
- 桌面与移动端均使用同一顶部导航；窄屏时仅横向滚动，不切换回左侧布局。
- 页面当前项继续由 `data-admin-page` 或 `data-admin-context` 自动高亮，试卷页面仍根据 `view=papers` 高亮“试卷管理”。

## 4. 缺陷复查结论

本轮没有发现会破坏知识树、题目、试卷、课程或历史记录的数据层缺陷。关键服务回归均通过。另发现并修复顶部导航重复入口问题；未修改各业务页面内部原有布局和操作流程。

## 5. 回归范围

- 八个管理页面顶部导航结构一致性；
- 桌面 1440px 页面几何位置；
- 窄屏横向导航行为；
- 当前导航激活状态；
- P0 管理服务基础；
- P2.1 知识树发布与唯一当前版本；
- P2.2 归档、恢复、安全删除、快照与审计；
- P3.1 总览、科目工作区与历史版本入口。
