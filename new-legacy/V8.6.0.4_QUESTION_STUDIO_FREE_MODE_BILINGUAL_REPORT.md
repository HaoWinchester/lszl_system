# v8.6.0.4 开发报告

## 开发范围

本版本完成 Question Studio v0.1.0 第一版，并把展示型双语能力扩展到自由模式的多题画布和深度回忆页面。

## Question Studio v0.1.0

入口：`question-studio/index.html`。

已实现：

- 单项选择、关键词识别、开放表达、排序、连线配对；
- 中文必填、英文展示选填；
- `===== 下一题 =====` 批量分隔；
- 规范标签与常见中英文标签解析；
- 结构化字段编辑和稳定子项 ID；
- Activity Schema v1 错误与警告；
- 中文和中英对照交互预览；
- 单活动 JSON 与标准活动包 JSON 导入导出；
- 自动草稿、本地保存、历史备份与恢复。

深度回忆、多题归纳和知识图谱未加入通用录入器，继续留给后续专用可视化编辑器。

## 自由模式双语展示

### 多题画布

题目卡片、选项、题目抽屉、答案解析和关键路径可在中文与中英对照之间即时切换。英文来自 Activity Schema `content.en` 或旧题目的 `translations.en`，缺失字段回退中文。

### 深度回忆

中心题目、选项、知识节点标题、引导问题和选择项可即时切换。切换只重新渲染文字，不改变节点 ID、连接关系、画布坐标和当前回忆进度。

### 判定边界

两个页面均不开放纯英文作答模式。英文只作为对照展示，答案、评分和学习记录仍使用中文规则和稳定 ID。
