# V9.0-P3.5.3 题库双栏工作区与悬浮题目预览开发报告

## 版本目标

把试卷管理中已验证稳定的两项交互能力同步到题库管理页面：

1. “题库”和“题目”区域支持手动拖拽调整大小；
2. 题目列表支持锚定题目行的非模态悬浮预览。

## 一、题库与题目双栏工作区

题库管理页中的“题库”和“题目”现在位于同一个可调整工作区。

支持：

- 拖动中间分隔条调整两侧宽度；
- 题库区宽度限制为 25%–75%，避免任一侧被完全挤压；
- 使用方向键调整分隔比例；
- Home 键恢复到最小题库区比例；
- End 键调整到最大题库区比例；
- 单独放大题库区或题目区；
- 单独收起题库区或题目区；
- 再次点击对应按钮恢复左右分栏；
- 自动保存上次拖拽比例；
- 两侧内容独立滚动，减少长页面上下往返。

布局比例保存在：

```text
kg_question_library_workspace_layout_v1
```

窄屏设备自动切换为上下排列，并隐藏分隔条和区域控制按钮。

## 二、题目锚定悬浮预览

### 交互规则

- 双击题目列表中的题目，打开悬浮预览；
- 悬浮窗显示箭头，指向当前对应的题目行；
- 预览打开后，单击另一道题即可切换内容和锚点；
- 再次双击当前同一道题可关闭悬浮窗；
- 支持右上角关闭按钮；
- 支持 Esc 键关闭；
- 页面滚动、窗口缩放和双栏比例变化时自动重新定位；
- 当前预览题目行保持高亮；
- 切换题库、筛选后题目不再可见，或离开题库工作区时自动关闭。

### 预览内容

悬浮窗显示：

- 教师题号；
- 来源题库；
- 题型；
- 难度；
- 主要知识点；
- 普通标签；
- 题干；
- 选项；
- 正确答案；
- 解析。

点击编辑图标会在当前页面进入该题目的“题目基本信息”编辑区域。题目仍使用原 `bankId + questionId`，不会复制题目，也不会改变题目 ID。

已安全删除题目仍可预览历史内容，但不会提供编辑入口。

## 三、兼容性与安全边界

本版本保持：

- P3.4 当前页批量选择边界；
- 批量修改知识点和标签；
- 安全删除、恢复与永久删除引用保护；
- P3.5 统一试卷管理和不可变发布版本；
- 深度回忆、多题画布和单题深学读取统一发布试卷；
- 题库切换、题目筛选和分页；
- 精确题目编辑跳转；
- 学员端不显示知识树和题目分类管理信息。

本次布局和预览操作不会：

- 删除题库或题目；
- 修改题目 ID；
- 修改试卷题目引用；
- 改变已发布试卷快照；
- 绕过安全删除和永久删除保护。
