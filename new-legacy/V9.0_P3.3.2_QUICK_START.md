# V9.0-P3.3.2 快速检查

## 题目管理

1. 打开 `question-bank.html`。
2. 确认页面显示“题库与题目”和“录入中心”两个业务页签。
3. 点击“录入中心”，确认 Question Studio 在当前题目管理页面内加载。
4. 确认嵌入区域不重复显示旧教师顶部导航和流程导航。
5. 返回“题库与题目”，确认原题库、题目编辑与训练配置功能正常。

## 科目与知识树

1. 打开 `admin-subjects.html`。
2. 选择左侧科目，确认“当前知识树”页签下直接显示知识树工作区。
3. 切换科目，确认知识树工作区同步切换。
4. 在“历史版本”中点击“查看 / 维护”或“查看”，确认返回本页工作区并加载指定版本。
5. 确认当前版本可维护，历史或归档版本保持只读。

## 兼容入口

- 访问 `question-studio/index.html`，应归位到题目管理的录入中心。
- 访问 `content-center.html`，应归位到科目与知识树的当前知识树页签。
- 需要独立检查旧页面时，可增加 `?standalone=1`。
