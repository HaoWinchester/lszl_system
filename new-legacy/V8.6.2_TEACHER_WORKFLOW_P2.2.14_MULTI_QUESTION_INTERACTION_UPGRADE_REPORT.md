# v8.6.2 P2.2.14 多题画布交互增强

基线：P2.2.13。

## 1. 多题画布纳入统一文件管理

- 多题页面左上“画布列表”按钮改为进入 `file-manager.html?type=workspace`。
- 文件管理新增“知识图谱 / 多题画布”文件类型切换。
- 多题画布文件可在统一文件管理中：
  - 搜索；
  - 双击打开；
  - 新建；
  - 重命名；
  - 复制；
  - 删除。
- 打开后使用现有稳定 workspace ID：`question-workspace.html?workspace=<id>`。
- 知识图谱文件仍使用原 `KGGraphFileStore`，多题画布仍使用 `KGCanvasWorkspaceStore`，没有强行合并底层 Store。

## 2. 文件名改为双击原地编辑

- 单击文件名不再进入编辑。
- 双击文件名后直接在原文字位置进入 `contenteditable`。
- Enter / 失焦保存，Esc 取消。
- 不创建新的 input 文本框。
- 保存后页签名称同步，workspace ID 不变。
- 云朵保存状态栏继续保留。

## 3. 卡牌四点快速连线

- 单选卡牌后显示上 / 右 / 下 / 左四个连接点，样式对齐知识图谱节点连接点。
- 鼠标左键按住连接点并拖到另一张卡片，松开后直接建立关系。
- 拖动过程中显示临时关系线，并高亮目标卡片。
- 禁止自己连接自己；已有同类关系不会重复创建。
- 快速连线默认 `type=同类`，但 **label 默认为空字符串，不显示任何文字**。
- 需要文字时，用户点击连线后再使用现有“T / 编辑文字”功能自行添加。

## 4. 多卡排列功能迁入多选悬浮菜单

画布顶部中间不再放置多选排列、分组、连线控件，仅保留：
- 撤销 / 重做；
- 新增归纳卡；
- 智能整理；
- 布局检查。

多选 2 张及以上卡牌时，悬浮菜单提供：
- 对齐：左 / 中 / 右 / 顶 / 垂直居中 / 底 / 横向等距 / 纵向等距；
- 分组：加入现有分组 / 新建分组；
- 归纳；
- 快速连线；
- 颜色；
- 删除。

## 5. Delete / Backspace 删除

- 选中一张或多张卡片后按 Delete / Backspace：立即从当前多题画布删除。
- 删除卡片时同步删除当前画布中与其相关的关系，并从分组成员中移除。
- 点击关系线后按 Delete / Backspace：直接删除该关系。
- 键盘删除不弹确认框，可通过 Ctrl/Command+Z 撤销。
- 输入框、textarea、select、contenteditable 编辑过程中不会触发画布删除。
- 删除多题卡片不会删除原题和单题学习记录。

## 数据兼容

- workspace ID、原题 ID、学习进度、课程、成绩、解锁条件保持不变。
- `CanvasWorkspaceStore` 仅调整新关系的默认 `label`：未显式填写时保存为空字符串。
- 旧关系如果已经保存了文字，仍完整保留。
