# V8.6.2 P2.2.29 连接点预览与选中状态优化报告

## 目标

解决知识图谱连接点的“悬浮创建预览”与“按住拖拽连线”同时出现的问题，并明确多题画布选中态优先于悬浮态。

## 完成内容

1. 知识图谱卡牌四向连接点的虚影预览改为延迟 280ms 显示，快速经过连接点时不再频繁闪现虚影。
2. 鼠标按下连接点后立即取消待显示的虚影，并清除已经显示的虚影卡牌与预览折线。
3. 拖拽连线期间只显示临时关系线和目标卡牌反馈，不再同时展示“创建新卡牌”虚影。
4. 松开且未发生拖拽时，继续保留原有单击连接点快速创建卡牌的能力。
5. 多题画布卡牌选中后以蓝色边框为唯一主反馈；鼠标继续悬浮时不再叠加红色边框。

## 性能与可维护性

- 虚影预览使用单个可取消定时器，连接点切换、离开、按下、滚动和窗口失焦时都会统一清理。
- 进入拖拽模式时仅移除两个预览 DOM 元素，不重绘整张知识图谱。
- 多题画布通过 CSS 状态排除实现反馈优先级，不增加 JavaScript 监听器。

## 兼容性

- 知识图谱连接点单击快速创建功能保持不变。
- 拖拽到其他卡牌建立无文字关系线的功能保持不变。
- 卡牌选中、移动、缩放及多选逻辑未改变。
- 触摸设备不应用鼠标悬浮边框规则。
