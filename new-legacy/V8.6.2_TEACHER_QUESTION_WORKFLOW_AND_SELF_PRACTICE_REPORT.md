# v8.6.2 教师工作流重构与完整版自由练习报告

## 发布定位

本版以 **v8.6.1.2.1** 为稳定基线。上一轮已经验证的关键词配置、知识联想库、深度回忆增强和学习路径自由练习入口继续保留；本次重点补齐此前未真正完成的教师工作台和课程设置工作流。

教师默认工作路径现在统一为：

```text
管理题目 → 配置训练 → 设置课程
```

知识树导入、导出仍不在本版范围内。

## 一、教师工作台重构

`teacher-workbench.html` 已从旧的四中心流程改为三个教师任务：

1. **管理题目**：维护完整考试原题、选项、答案和解析；
2. **配置训练**：维护关键词、知识联想入口和可用训练方式；
3. **设置课程**：选择内容、安排学习顺序、检查并发布。

首页仅显示四项概览：完整原题、待配置训练、课程草稿、已发布课程。系统根据本地数据给出建议下一步，但不会自动修改或发布内容。

旧录入中心、内容中心、高级题库编辑、学习任务和试卷保留在折叠的“高级工具与兼容入口”中，新教师默认不会看到这些底层对象。

## 二、题目管理与训练配置简化模式

`question-bank.html` 默认进入简化教师模式，并保留 `?mode=advanced` 高级兼容模式。

### 题目管理

入口：

```text
question-bank.html?mode=simple&step=questions
```

默认只显示：

- 题库与题目列表；
- 题目标题、题型、难度和标签；
- 完整题干；
- A/B/C/D 选项；
- 正确答案；
- 解析与复盘说明。

快速操作提供“新建题目、编辑当前题目、下一步配置训练”。训练标注、组卷和高级推理不会在此步骤干扰录题。

### 训练配置

入口：

```text
question-bank.html?mode=simple&step=training
```

默认只显示：

- 当前题目列表；
- 可点击关键词输入；
- 关键词到知识联想入口的绑定；
- 科目级 TXT/JSON 知识联想库；
- 同步配置；
- 完整版深度回忆预览。

高级关键词、知识点和推理面板仍保留在高级模式，不删除原有能力。

## 三、课程设置五步工作流

`course-admin.html` 默认进入简化课程模式，并保留 `?mode=advanced` 高级模式。

页面提供五步导航：

1. 课程信息；
2. 学习顺序；
3. 选择题目与训练内容；
4. 检查预览；
5. 发布。

教师界面中的概念调整为：

| 底层对象 | 教师界面名称 |
|---|---|
| part | 章节 |
| node | 学习步骤 |
| activity | 题目与训练内容 |

知识树选择、底层稳定 ID、导出、删除草稿、学习任务和试卷默认隐藏，但数据结构、稳定 ID 与高级模式均保留。

课程页新增 1366×768、1440×900、1920×1080 在 100%、125%、150% 缩放下的响应式回归；简化模式没有页面级横向溢出。

## 四、学习路径自由练习入口视觉精简

每个学习部分继续保留：

- 完整版深度回忆；
- 完整版多题画布。

本次按确认方案取消入口中的：

- “自由练习 · 不计成绩”文字；
- 标题和说明；
- 白色卡片背景；
- 外层边框与卡片阴影。

路径中只显示可点击的 GIF 图片；减少动态效果时继续使用 PNG 静态备用图。键盘聚焦保留清晰轮廓，入口仍有无障碍名称和鼠标提示。

自由练习仍然：

- 不计入课程成绩；
- 不改变节点完成状态；
- 不控制后续解锁；
- 退出后返回原阶段、章节和横向位置。

## 五、继续保留的深度回忆能力

本版继续保留并回归：

- 教师直接输入关键词，无需 `[[关键词]]`；
- 关键词自动定位题干和选项；
- 关键词到知识联想入口绑定；
- 科目级 TXT/JSON 知识联想库；
- 一对多、连续链条与网状关系；
- 每次最多四个候选和“换一组”；
- 没有预设分支时使用原有自由输入卡牌；
- 题集和题目列表；
- 学员个人探索统计与等级；
- 题库“仅教师自己 / 发布给学员”。

## 六、模块边界

新增教师工作流模块：

- `src/97-teacher-question-workflow.js`；
- `styles/teacher-question-workflow.css`；
- `src/97-teacher-course-workflow.js`；
- `styles/teacher-course-workflow.css`。

这些模块只控制教师视图、导航和简化模式，不修改活动 Schema、知识树 Schema、课程 Schema 或学习进度格式。

## 七、回归结果

通过的核心数据回归：

- 82 个活动；
- 5 棵知识树、16 个知识点；
- 108 个课程节点；
- 9 个学习部分；
- 每个学习部分 2 个自由练习入口，共 18 个；
- 既有简化深度回忆、知识图谱和简化多题归纳节点。

通过的专项回归：

- 教师首页只有三项主要工作；
- 题目管理简化模式；
- 训练配置简化模式；
- 高级模式兼容入口；
- 课程五步引导和教师术语；
- 课程简化模式九组分辨率与缩放；
- 自由练习入口仅渲染图片；
- 入口与原学习节点无重叠；
- 学习路径无页面级横向溢出；
- 关键词自动定位、联想库解析、题库发布；
- 深度回忆四候选、题目列表和个人统计；
- v8.6.1.2.1 内容中心九组布局视觉基线。

## 八、完整性结论

保持不变：

- Activity Schema v1；
- Knowledge Taxonomy Schema v1；
- Course Configuration Schema v1；
- 活动 ID 集合；
- 知识点 ID 集合；
- 课程节点 ID 集合；
- 题集、试卷和学习任务既有数据；
- 正式课程学习进度和成绩规则。

当前版本可以作为后续教师工作流迭代基线。下一阶段应先邀请未参与开发的新教师完成“录入一题 → 配置关键词 → 加入课程 → 发布”的可用性测试，再决定是否进一步合并题库和课程页面。
