# V9.0-P3.2 快速使用

## 进入科目管理

打开 `admin-subjects.html`，使用管理员账号进入“科目与知识树”。顶部一级导航仍固定为八个业务入口。

## 新增科目

1. 点击左侧“新增科目”。
2. 填写唯一科目编号、中文名称、可选英文名称和说明。
3. 保存后，新科目自动成为当前选中科目。
4. 新科目没有知识树和内容时，可以永久删除。

## 编辑与排序

- 点击“编辑科目”修改名称和说明。
- 科目编号创建后保持不变。
- 使用“上移”“下移”调整科目在列表中的顺序。

## 停用与恢复

- 点击“停用科目”后，已有知识树、题目、试卷、课程、任务和历史记录均保持不变。
- 已停用科目仍可在管理页面查看，并可点击“恢复科目”重新启用。
- 已停用科目不再进入总览中的“缺少当前知识树”待办提醒。

## 永久删除

页面会显示当前科目的知识树版本、题目、试卷、课程与任务数量。

- 完全没有任何内容的科目：可以永久删除。
- 已有知识树、题目、课程、试卷或任务的科目：删除被阻止，只能停用。
- 删除空科目需要二次确认并输入科目编号。
- 删除操作会自动创建恢复快照并记录审计。

## 当前阶段边界

P3.2 只完成科目管理。当前知识树的新增、改名、移动、排序和节点停用将在 P3.3 开放；题目批量移动与待分类操作将在 P3.4 开放。
