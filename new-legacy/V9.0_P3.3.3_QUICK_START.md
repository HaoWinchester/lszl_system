# V9.0-P3.3.3 快速使用说明

## 正式录入一道题

1. 打开“题目管理”。
2. 选择目标题库。
3. 进入“题目内容”。
4. 点击新建题目，或将模板粘贴到快捷录入区域。
5. 检查题干、选项、答案和解析。
6. 在题目基本信息顶部设置分类。
7. 保存题目并继续录入下一题。

## 设置主要知识点

1. 点击顶部分类栏中的“选择知识点”。
2. 在悬浮选择器中逐层展开知识树，或使用搜索。
3. 单击目标节点。
4. 检查完整路径。
5. 点击“确认选择”。

主要知识点只能选择一个。暂时无法确定时，点击“设为待分类”。

## 设置普通标签

1. 点击“选择标签”。
2. 依次选择标签组和标签分类。
3. 勾选一个或多个标签。
4. 必要时添加自定义标签。
5. 点击确认。

## 使用带分类的粘贴模板

```text
【科目】PMP
【知识点】敏捷方法/迭代规划
【标签】易错题、阶段测试
【题目】……
【选项】……
【答案】A
【解析】……
```

系统只根据明确填写的编号、名称或路径进行匹配，不根据题干语义自动猜测。出现同名节点或无法匹配时，题目会提示人工选择或进入待分类。

## 旧录入中心

旧 Question Studio 已退出正式题目录入流程。普通旧链接会自动转到题目管理的粘贴入口。仅在兼容检查时使用 `?standalone=1` 打开旧学习活动设计器。
