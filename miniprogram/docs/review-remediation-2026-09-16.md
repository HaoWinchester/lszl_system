## 整改范围

- 正式提审包的 trial/release 均使用 `https://lszl.aihuanpu.com`。
- 只有明确的 develop 环境可以读取本机 `kg_api_base_url`；环境信息缺失、异常或未知时使用正式服务，避免误用 localhost。

## 微信后台仍需保存的声明

入口：设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引。
以下为实际代码对应的填写文案；按后台当前提供的分类分别填写，不虚构未使用的权限。服务内政策和本文档不能替代微信后台的保存操作。

| 信息 | 收集场景、用途（可直接填写） |
| --- | --- |
| 微信身份标识 | 用户同意隐私政策并主动使用微信登录时，通过临时登录凭证获取 OpenID，以及微信平台返回时的 UnionID，用于识别微信身份、关联学习账号和维持登录状态。 |
| 用户填写的账号资料 | 用户注册或绑定账号时，处理其填写的用户名、密码及注册时自愿填写的显示名称，用于创建账号和验证身份。服务端以不可逆密码哈希保存密码。 |
| 设备信息 | 用户登录、注册或绑定账号时，收集设备型号、操作系统、运行平台及微信版本，成功登录后随会话保存，用于记录登录设备环境和排查兼容性问题。 |
| 学习记录 | 用户练习、提交答案、保存进度及设置学习目标时，处理作答内容、作答时间与用时、成绩、进度、错题和学习目标，用于恢复练习、生成学习报告、错题复习和跨端同步。 |
| 操作与安全日志 | 用户注册、绑定或退出账号时，记录相关操作、请求 IP 和客户端信息，并保存协议同意及会话时间记录，用于账号安全审计、会话管理和问题排查。 |
| 剪贴板（写入） | 仅在用户主动点击“复制用户名”时，将该用户名写入剪贴板，方便用户联系支持人员时提供账号；不读取剪贴板原有内容。 |

联系渠道填写运营主体实际使用并有人处理的邮箱或电话，不得用占位联系方式。
当前没有主动获取微信头像、微信昵称、手机号、定位、通讯录、相册、摄像头或麦克风的代码。用户手动填写的显示名称与微信昵称授权不同。
