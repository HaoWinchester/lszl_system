# 微信做题小程序发布检查清单

这份清单区分“自动化可验证”和“必须在微信平台/真机完成”两类证据。两类都完成后才能标记 UAT 通过。

## 1. 后端与 AppID

- [ ] 在 UAT 后端配置 `WECHAT_MINI_APP_ID` 与 `WECHAT_MINI_APP_SECRET`；AppSecret 只存在服务器密钥管理中，不写入代码、小程序包或日志。
- [ ] UAT 设置 `WECHAT_MINI_ENABLE_DEMO=false`，并确认 `ENV=prod`时演示代码无法绕过微信 `jscode2session`。
- [ ] 当前联调项目导入仓库根目录，使用根目录本地 `project.config.json`（`miniprogramRoot: miniprogram/`）及已注册的小程序 AppID。不要误用 `miniprogram/project.config.json` 里的历史配置；游客 AppID 不可用于微信登录验收。
- [ ] 本地项目配置不覆盖 PC 配置；AppSecret 不进入任何小程序文件。打包前核对所选 AppID 和体验版环境。

## 2. 服务器域名与网络

- [ ] 微信后台的 `request` 服务器域名包含 `https://uat.aihuanpu.com`（体验版）和正式所需的 `https://lszl.aihuanpu.com`。
- [ ] 证书链、TLS 版本和 DNS 均通过微信检查；不使用 IP、HTTP 或自签证书。
- [ ] 体验版请求 UAT，正式版请求正式域名；开发版才允许本机 API 覆盖。
- [ ] 题目图片均为 HTTPS，其下载域名已加入微信后台白名单；非 HTTPS 题图不进入渲染列表。

## 3. 隐私与合规

- [ ] 微信小程序后台已配置并发布“隐私保护指引”和用户协议。
- [ ] 指引如实说明：微信身份标识用于登录/绑定，账号与学习数据用于跨端同步，设备型号/系统/微信版本用于登录安全记录。
- [ ] 用户未勾选同意时不调用微信登录；隐私政策和用户协议从登录页与“我的”页都可打开。

## 4. 开发者工具与真机

- [ ] 开发者工具 TypeScript 编译无错，页面路由和组件均无“未找到”警告。
- [ ] 在 390×844 模拟器检查首页、试卷、设置、做题、结果、记录、错题复仇和“我的”页；题干是视觉主体，无横向滚动。
- [ ] 至少用一台 iPhone 和一台 Android 真机检查状态栏、底部 Home Indicator/导航的安全区，并检查大字体下按钮不遮挡。
- [ ] 前台、后台、锁屏、弱网切换后计时和本地草稿状态符合页面提示。

## 5. UAT 业务用例

- [ ] 首次微信登录进入绑定：可绑定现有账号，也可创建账号；重复绑定和无效密码显示真实错误。
- [ ] 退出登录会调用服务器注销、清理本账号本机草稿并回到登录页。
- [ ] 启动、暂停、重启后恢复同一练习；网页端和小程序的已提交进度一致。
- [ ] 单选选中即锁定；多选在“下一题”确认前可增删，确认后锁定；均可回看/跳题。双语题干、双语选项和 HTTPS 图片显示正常。
- [ ] 普通练习仅保留显示答案开关，控制答案与解析；挑战模式、学霸模式即时给出正误但不显示解析；全部答完自动交卷，保存退出后已答恢复。
- [ ] 挑战生命归零仍可继续；学霸共享倒计时，答对加20秒（最多60秒）、答错扣20秒和生命、超时扣生命后余40秒，五连对回血，生命归零结束；换题不重置时间。
- [ ] 错题复仇按“重答原题 → 阅读纠错 → 变式验证”推进，没有可用变式题时给出明确文案。
- [ ] 断网提交显示“离线草稿”，重试使用同一幂等键；多端修改产生冲突时，可明确选择服务器进度或本机草稿。
- [ ] 答案泄露与权限检查：会话响应与 PC 一样提供本地判题所需的冻结答案字段；挑战/学霸活动会话不包含解析。未授权/跨用户仍拒绝访问；保存与交卷只提交选择，服务器重算正误，不信任客户端 `correct`。
- [ ] 免费学员进入会员试卷时被服务器拒绝，页面仅说明当前账号权限；小程序不展示套餐销售、价格、支付按钮或外部购买引导。会员信息页只显示当前状态、到期时间与已有权益，网站支付保持独立。
