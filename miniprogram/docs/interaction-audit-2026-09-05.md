# 小程序点击、跳转与业务链路检查

范围：本地开发工具与本地真实后端。配置、PC 登录、PC 支付、UAT 和正式环境均不修改。

## 已修复

- 页面跳转失败不再静默，统一由 `domain/navigation.ts` 处理。
- 试卷库、练习设置、会员中心直接打开时，返回失败可回到对应主页面。
- 创建练习后跳转失败保留会话 ID，恢复按钮，再次点击仅打开原会话。
- 绑定成功后首页跳转失败只重试跳转，不重复消耗绑定凭证。
- 交卷、保存退出已写入服务端但跳转失败时，显示独立重试入口，不重复提交。
- 底部页签切换失败恢复选中状态并提示重试。
- 退出登录后跳转失败隐藏个人内容并允许重试，不重复注销或清理草稿。
- 答题卡、报告解析弹层补上主题变量，避免深色页面出现浅色弹层。
