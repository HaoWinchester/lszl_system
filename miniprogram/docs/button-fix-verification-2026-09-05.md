## 修复范围

| 问题 | 修复 | 验证 |
| --- | --- | --- |
| 多选 A/C 已选择却标为未答 | 答题卡区分已选/已答，当前题仍有独立边框；“检查并交卷”提交当前选择后定位真正未答题 | 实际 Page 回归及原生工具实点 |
| 多选未点下一题就保存会丢选择 | `runtimeState.pendingSelections` 独立存储；不放入已锁定答案，不提前增加判题/经验/错题；冻结题目和选项白名单校验 | 数据库 API、两客户端恢复、修改/取消选项、重复保存 |
| 后台保存只存位置、忽略已答题 | `/state` 有答案载荷时复用已有草稿校验/锁定保护，无载荷时保留原行为 | 新增先失败的数据库测试；10 账号真实后台保存再 GET |
| 同版本及冲突恢复覆盖本机暂存 | 统一草稿合并规则：本机暂存优先，服务端锁定答案不可改写 | 同版本取消选项、409 后保留本机再重试 |
| 答题卡/上一题绕过多选提交流程 | 离题时记录选择；学霸生命归零立即交卷，禁止再切题拿额外经验 | 实际 Page 模拟学霸剩余 1 生命，并独立只读复核 |
| 切换模式仍打开旧模式 | 修改模式/题量/顺序使旧查找结果失效，重新向后端查找；不自动放弃旧练习 | 三项设置回归、原生普通→挑战实点 |
| 绑定步骤撤回协议仍能提交 | 绑定和注册入口都校验当前勾选状态，保留输入并支持重新勾选重试 | 页面处理函数反向/恢复测试，无真实微信绑定 |
| 暂停会员显示待确认 | 公用会员视图显示“已暂停”、到期时间和说明 | 会员视图测试及第 10 个真实测试账号 |
