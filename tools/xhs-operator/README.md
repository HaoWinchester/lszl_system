# 知习 · 内容工作台

供本人使用的本机独立工具，完成 PMP 知识图文的生成、自动审核、六张图片排版、定时队列和小红书发布结果核验。与做题系统的数据库、静态发布和服务完全分离。

## 2026-11-02 增量开发状态

知识库已扩充为 4 份官方公开资料、19 个初始主题，并具备每周最多 4 个新主题的独立审核扩题、7 天冷却轮换和卡片重复检查。本机真实 GLM 扩题新增 3 个，当前运行库共 22 个主题。旧年论文明确标注为补充学习资料，不冒称第八版教材。

评论和私信已接入主站公开页面：按账号、笔记/会话与消息 ID 绑定目标，首次扫描建立历史基线，后来加载的旧消息也不会触发回复。发送前检查原文、人工回复、当前会话和暂停状态；提交一次后读取新回复 ID，结果不明冻结并只读核验。

竞品采样已从真实 PMP 搜索结果取得 12 篇笔记，排除当前账号自己的笔记，保存标题、作者、链接、可见点赞数和采集时间。分析标题结构与需求词，48 小时内用于生成与审核；不把点赞当作获客效果，不把竞品知识主张当权威依据。目前分析以搜索卡片为范围，不读取整篇图文图片内容。

主站和创作中心已分别用同一“幻谱知习”账号登录并核对。首次使用其他机器仍需本人扫码，后续复用工具专用浏览器。完整运营启用前必须读通评论、私信并取得近期竞品样本。2026-11-03 用户明确验收通过，已完成 main 集成并开启本机自动运营。用户随后选择自行处理评论、私信，当前本机已关闭自动巡查和回复，仅保留自动内容生产与发稿。开关和队列实时状态以工作台为准。

## 当前交付范围

- GLM 从 `~/.claude/settings.json` 的 Anthropic 兼容配置接入；密钥只在调用时使用，不复制到本工具配置、网页或日志。
- 使用 PMI 第八版官方公开简介，初始主题现扩展为第八版简介和历史论文中的方法选择、相关方与裁剪等主题。来源不足时停止生成，不凭模型记忆补教材。
- 一篇包含标题、短正文、四张讲解卡和两张原创自测/解析卡；每张 PNG 为 1080 × 1440。公开正文不放网址。
- 独立模型审核与程序校验结合：来源、题目答案、产品事实、重复文案、文字溢出、图片哈希。最多三次生成尝试（初稿加两轮修订）。人工审核不是日常必经步骤。
- 持久队列按北京时间默认 09:00、20:00 执行。支持暂停、取消未执行排期、改稿后重新审核。错过超过十分钟的排期不会补发。
- 专用浏览器保存登录状态；每次提交核对账号 ID。实际发布后按笔记 ID、标题、提交前列表和平台标签核验，不把点击按钮或“审核中”当作公开发布成功。
- 提交超时或执行中断后冻结任务，只读核验，不自动再次提交。运行目录单进程锁和 SQLite 领取事务阻止重复执行。
- 2026-11-02 已在官方账号完成一篇真实发布；2026-11-03 用户验收通过后开启定时运营。旧预览稿重新审核可能转为待修订，实际状态以工作台为准。

**运行范围：** 主页前 12 篇自己的 PMP 笔记（含置顶），每篇前 100 条已加载评论；最近 20 个会话中的相关咨询，每个会话最近 80 条已加载消息。未折叠的根评论及私信最后一条未回答咨询可自动回复；子楼层、未展开回复和无法核验时间的消息不自动发送。私信只按 PMP/产品语境或已有评论/会话关联读取；不会遍历无关私人聊天。每小时最多 5 条，08:00–22:00 内每 6 小时巡查一次，上次巡查时间持久保存，重启不会立刻重复扫描；夜间到期顺延至回复时段。只有对方在相关私信里主动索要入口才给正式地址。

**尚未验证或交付：** 本轮没有新的未回答咨询，因此未实际发送评论或私信；用户已于 2026-11-03 接受 UAT；真实回复发送仍等待新的符合条件的咨询验证，长时运行持续观察。没有自动发现新文献、站外通知、效果归因、系统开机自启或云端常驻服务。登录过期、验证码和平台页面变化仍可能需要处理。

## 启动

在本目录双击 `start.command`，或执行：

```sh
python3 -m operator_app serve
```

访问 <http://127.0.0.1:8877>。默认仅监听本机，不能直接部署成公开网站。

当前 Mac 已具备所需运行依赖和 Playwright Chromium。新机器才需要准备独立环境：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python -m operator_app serve
```

GLM 配置要求 `ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/anthropic`，以及已有的 `ANTHROPIC_AUTH_TOKEN` 或 `ANTHROPIC_API_KEY`。模型来自 `ANTHROPIC_MODEL`，去除 Claude 的上下文后缀；当前实际验证模型为 `glm-5.3-flash`。不要在文档、命令参数或聊天里粘贴密钥。

首次使用工具自己的浏览器需要登录，后续复用 `.runtime/browser-profile`。登录状态不与用户的 Chrome 或小红书客户端混用；平台要求再次验证时仍需本人完成。默认绑定“幻谱知习”账号，配置不提供多账号切换。

## 日常运行与暂停

“启动自动运营”通过资料、账号、发布适配器、两种互动通道和竞品资料检查后，自动生成并保持最多两篇待发布队列，到点发布，同时巡查相关咨询。来源每日检查，主题每周审核扩充，竞品资料过期后自动刷新。Mac 必须保持运行、联网和未休眠；本工具不是云端常驻服务。退出服务后没有后台触发，也没有恢复以前的 Codex 定时任务。

“发布页面预检”仅上传、填写并检查；“发布这一篇”会实际提交所选稿件，完成后恢复暂停。“核验结果”只读取平台状态。

管理页“暂停自动运营”或以下命令均持久化同一开关，重启不会自动取消暂停：

```sh
python3 -m operator_app pause
python3 -m operator_app status
```

暂停不会撤回已发出的提交，只允许继续读取结果。默认数据在本目录 `.runtime/`；如果启动时用了 `--data /absolute/path`，暂停和查看状态时必须带相同的 `--data`。停止服务使用运行终端的 Ctrl+C。

## 资料与限制

依据：[PMI PMBOK 第八版官方介绍](https://www.pmi.org/standards/pmbok)，2026-11-02 开发时核验。中文术语为学习用意译。公开简介不等同完整教材或考试大纲，自测题不冒称考试真题或平台已有专项练习。

运行时检查官方页面的依据。如果网站返回 403，可用截至 2026-11-09 00:00 UTC 的已核验快照，并在界面明确标注；过期后阻断使用该简介的稿件，自动选用仍有效的其他主题。每个主题生成后冷却七天，轮换四种表达角度并检查重复。每周可从已核验资料自动扩充最多四个独立审核通过的主题，总量上限 200。扩题不是自动发现新文献，资料范围仍有边界。历史论文的静态概念可保留原始核验日期，作为明确标注年代的快照；不据此给出现行考试要求。页面关键词匹配只能检测部分变化，不能替代知识来源复核。

初始产品事实只确认“提供 PMP 题目练习”。2026-11-03 当前本机运行库已根据正式发布记录补充 3 份综合模考、5 份专题与会员权限；不将跨卷重用题目累计为独立题量，不把平台卷名或题数当成官方考纲或考试规格。未经核实的价格、通过率和功能不进入宣传。草稿审核同时绑定来源和产品事实摘要；二者变更会阻断旧审核内容的提交。

模型预算根据输入 UTF-8 字节上界、输出上限和固定开销保守预留，每请求至少 6,500 tokens，不是精确计费或服务商剩余额度；每天默认最多 12 次、80,000 tokens。失败请求也消耗预算。模型和平台服务费用沿用用户已有账户。

## 数据与维护

`.runtime/` 包含 SQLite、生成图片、来源检查记录、发布回执截图及浏览器登录数据，已排除 Git。目录含登录会话，应视为私密数据；迁移或归档前先停止服务并完整备份，不仅备份 SQLite 主文件。不要删除当前工作树导致丢失此目录。

发布 DOM 契约位于 `operator_app/browser-contract.json`。平台页面变更或账号不匹配时应暂停修复并重新预检，不能打开隐蔽接口或绕过平台验证。闭合 Shadow DOM 中的提交按钮通过 Chromium 无障碍树读取可见角色、禁用状态和布局后点击一次。证据存于 `assets/evidence/<note-id>.png`。

模块职责：`store.py` 持久状态；`sources.py` 知识依据；`content.py` 模型与审核；`render.py` 卡片；`browser.py` 创作中心适配；`community.py` 主站评论/私信/竞品适配；`replies.py` 回复队列；`research.py` 竞品统计；`worker.py` 调度；`server.py` 本机 API；`static/` 管理页。没有对学习系统增加路由、数据库表或生产部署步骤。
