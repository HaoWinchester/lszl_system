# 知习 · 本地备稿工作台

2026-11-03 起，按用户确认改为 **本地生成与审核、官方客户端人工发布**。原因是账号收到第三方脚本、AI 自动浏览或发布运营的违规通知。

当前服务不实例化小红书浏览器适配器，不自动访问、上传、发布、读取评论私信或采集竞品。旧平台操作接口统一返回 410；即使旧网页仍开着，也不能恢复这些操作。启动时关闭原运营/回复开关，并取消未提交的旧排期。历史回执和结果不明记录保留，但不会自动登录核验。

## 日常使用

1. 启动工作台，进入“内容工坊”，生成或打开一篇稿件。
2. GLM 根据已核验资料生成正文和知识卡片，经独立事实审核后渲染六张 PNG。
3. 点击“下载正文与六张图片（ZIP）”，在官方客户端人工检查并发布。

设置中可开启“按时生成到本机”，默认时段为北京时间 09:00、20:00；到点只备稿，不发布。每个时段只尝试一次，重启不会重复执行，错过超过十分钟不补生成；生成失败仍计入预算。该功能需要 Mac 开机、联网且服务运行。没有系统开机自启、云服务或 Codex 定时任务。

正文编辑会撤销原审核；下载前重新验证审核摘要、六张图片的文件路径与哈希。压缩包仅包含 `正文.txt`、`发布说明.txt`、`01.png` 至 `06.png`，不打包账号登录数据、私信、模型配置或密钥。下载不会把稿件标记为已发布。

事实审核不代表平台合规保证。请按平台要求声明 AI 辅助内容；自行核对推广方式和资质，移除违规导流、虚假经历与未经支持的承诺。新的生成提示不引导私信索要入口；保留的历史稿件不会被静默改写，人工发布前仍需检查。

## 启动与暂停

双击本目录 `start.command`，或在本目录执行：

```sh
python3 -m operator_app serve
```

访问 <http://127.0.0.1:8877>。只监听本机，不能直接作为公网网站部署。

设置里取消“按时生成到本机”并保存，可暂停定时备稿；也可执行：

```sh
python3 -m operator_app pause
python3 -m operator_app status
```

`--data /absolute/path` 指定独立运行目录时，serve/pause/status 均须使用同一路径。已在执行的模型请求可能完成，暂停会阻止后续定时任务。停止服务可在运行终端按 Ctrl+C；当前后台服务 PID 和日志保存在 `.runtime/service.pid`、`.runtime/service.log`。

## 模型、来源与历史资料

- 模型读取 `~/.claude/settings.json` 的 GLM Anthropic 兼容配置，限智谱官方接口；密钥不复制到工作台或日志。当前验证模型为 `glm-5.3-flash`。
- 每日默认最多 12 次模型请求和 80,000 预留 tokens，预留量不是实际计费；生成、修订、独立审核和扩题共享预算。
- 4 份 PMI 官方公开资料，初始 19 个主题，本机此前审核扩充至 22 个。资料并非完整 PMBOK 教材，历史论文明确标注年代，不等同现行考试要求。
- 第八版公开简介快照有效至 2026-11-09 00:00 UTC；到期后若不能在线核验，停止使用该来源，自动选择仍有效的其他主题。
- 已保存的竞品搜索卡片只作历史参考；超过 48 小时不参与新稿生成，不再自动采集。
- 当前本机产品事实根据正式发布记录确认 3 份综合模考、5 份专题与会员权限；不把跨卷题目相加为独立题量，不把平台卷名当官方考纲依据。

`.runtime/` 含稿件、SQLite、生成图、历史回执和之前保留的浏览器登录目录，全部排除 Git。当前服务不打开该登录目录；迁移或清理前先停止服务并完整备份。不要删除运行工作树丢失数据。

历史 `browser.py`、`community.py`、`worker.py` 的平台代码留作开发记录，不接入当前 server 或 CLI 的运行链路。当前定时逻辑是 `drafting.py`，只调用内容生产；`render.py` 使用无头浏览器渲染本地 HTML，不访问小红书。
