# V9.0-P3.5.8 后台导航与教师工作台统一开发报告

## 目标

统一后台页面的信息架构和教师工作流，避免“题库管理、试卷管理、课程设置”在一级导航和教师工作台中重复出现。

## 完成内容

### 后台一级导航

一级导航统一为七项：

```text
总览｜科目与知识树｜教师工作台｜课程与任务｜用户管理｜操作记录｜系统设置
```

“教师工作台”替换原“题库管理”主入口；原一级“试卷管理”入口取消，试卷管理进入教师工作台内部流程。教师工作台、题目管理、训练配置和试卷管理页面均高亮同一个一级入口。

### 教师工作台流程

内部页签统一为：

```text
工作台｜题目管理｜训练配置｜试卷管理
```

三步流程统一为：

```text
1 管理题目 → 2 配置训练 → 3 管理试卷
```

教师工作台首页第三张任务卡、建议下一步和工作概览全部改为试卷状态。工作概览读取当前教师账号的试卷草稿和已发布版本，不再把课程配置作为教师三步流程的第三步。

### 试卷管理

试卷管理页面增加与题目管理、训练配置一致的教师工作台顶栏和三步流程栏，并将“试卷管理”标记为当前页签及第三步。原有选题、分类、批量操作、发布版本和三种学习模式发布逻辑未改变。

### 课程与任务

课程与任务保持独立后台页面：

- 移除教师工作台二级导航；
- 移除教师三步流程和课程步骤提示条；
- 页面标题统一为“课程与任务”；
- 只保留“课程配置”和“学习任务”两个业务页签；
- 删除页面内隐藏的旧活动型试卷管理区域；
- 保留 `course-admin.html?view=papers` 跳转到正式 `paper-management.html` 的兼容逻辑。

## 数据安全

本版本仅调整导航、页面外壳、入口关系和教师工作台统计：

- 不修改题目 ID 或题库 ID；
- 不修改试卷题目引用和发布快照；
- 不修改课程、任务或历史发布数据；
- 不修改题目安全删除与永久删除保护；
- 不迁移或删除浏览器本地业务数据。
