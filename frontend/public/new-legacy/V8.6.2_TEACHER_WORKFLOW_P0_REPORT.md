# v8.6.2 教师工作流 P0 开发与回归报告

## 1. 基线与范围

- 开发基线：`v8.6.1.2.1` 布局维护版之上的 v8.6.2 教师工作流分支。
- 本轮范围：教师题目管理、训练配置和课程设置的 P0 可用性修复。
- 未开发：知识树导入/导出、P1 大型课程搜索与虚拟滚动、挑战任务成绩化、复杂学习任务编辑器。
- 数据约束：不修改既有活动 ID、题目 ID、知识点 ID、课程节点 ID、题集、试卷、学习任务、课程发布版本、学习进度和成绩。

## 2. 教师页面统一

题目管理、训练配置和课程设置统一使用教师工作台外壳：

- 相同的 KG 品牌区、版本说明和教师导航；
- 相同的“管理题目 → 配置训练 → 设置课程”流程提示；
- 相同的背景、面板、边框、按钮和响应式规范；
- 高级工具继续保留，不删除原有高级编辑能力。

题目页面不再使用独立的浅蓝工具页头，课程页也不再成为另一套视觉系统。

## 3. 快捷粘贴录题

题目内容页新增两种录入方式：

1. 快捷粘贴（默认）；
2. 手动填写。

快捷粘贴支持识别：

- 完整题干；
- `A.`、`A、`、`A：`、`A)`、`（A）` 等选项格式；
- “答案 / 正确答案 / 参考答案”；
- “解析 / 答案解析 / 参考解析 / 复盘说明”。

处理流程：

```text
粘贴完整题目
→ 解析预览
→ 检查题干、4 个选项、答案和解析
→ 确认并进入编辑
→ 保存当前题目
```

解析前不写入题库。以下情况会阻止确认：

- 未识别题干；
- 不是 A/B/C/D 四个选项；
- 存在空选项；
- 未识别答案；
- 答案不在选项中。

未识别解析只给出提醒，不阻止教师进入结构化编辑补充。

## 4. 训练配置双栏工作区

桌面端改为：

```text
左侧 38%：题目搜索、题目列表、当前原题与答案解析
右侧 62%：关键词、知识联想入口、共享知识联想库和效果预览
```

左侧题目区独立滚动并保持当前题目可见；右侧专注训练增强。宽度不足时自动切换为单栏，不产生页面级横向滚动。

## 5. 课程设置 P0

### 5.1 三栏对齐

课程编排稳定为：

- 左侧：课程结构导航；
- 中间：当前阶段、章节或学习步骤编辑；
- 右侧：题目与训练内容库。

三个面板使用相同起点、标题区和卡片规范。125% 与 150% 缩放时按实际可视宽度自动切换为两栏或单栏。

### 5.2 三级显示序号

课程结构新增自动显示序号：

```text
阶段：01
章节：01.01
学习步骤：01.01.01
```

序号根据当前排序实时计算，只用于教师定位，不写回数据，也不替代稳定 ID。

### 5.3 默认折叠

- 所有阶段标题保持可见；
- 只展开当前阶段；
- 只展开当前章节的学习步骤；
- 教师可手动展开或收起其他阶段、章节；
- 新增阶段、章节或步骤后自动展开其所在路径。

### 5.4 当前章节预览

页面底部不再渲染完整课程树，只预览当前位置对应的一个章节。知识覆盖最多显示 12 项摘要，发布版本最多显示最近 8 个版本，避免课程规模扩大后形成超长页面。

## 6. 响应式与缩放

通过以下组合：

- 1366×768：100%、125%、150%；
- 1440×900：100%、125%、150%；
- 1920×1080：100%、125%、150%。

检查内容包括：

- 题目快捷粘贴无横向溢出；
- 训练配置桌面双栏、窄屏单栏；
- 课程设置三栏顶部对齐；
- 浏览器缩放后按实际可视宽度重新布局；
- 课程导航序号与折叠保持正常；
- 当前章节预览不恢复成全课程长列表。
