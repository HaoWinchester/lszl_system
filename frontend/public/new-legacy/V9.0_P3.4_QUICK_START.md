# V9.0-P3.4 快速开始

## 进入题目管理

打开 `question-bank.html`，选择题库后进入题目列表。

## 批量重新分类

1. 在“题目状态”中选择“正常题目”或“待分类”。
2. 勾选本页题目，或使用“选择当前页”。每页最多选择 20 道题。
3. 使用“修改知识点”“移入待分类”或“设置标签”。
4. 知识点选择只显示当前科目、当前知识树中的未停用节点。

批量操作只更新分类字段，不复制题目，也不会修改题目 ID。

## 安全删除与恢复

1. 选择题目后点击“删除”。
2. 确认弹窗会汇总试卷、课程/任务及答题/成绩/统计引用。
3. 确认后题目进入“已删除题目”，不再参与新组卷或普通训练。
4. 切换到“已删除题目”即可恢复。

已有试卷、课程和历史记录仍按原题目 ID 读取，不受安全删除影响。

## 永久删除

在“已删除题目”中执行永久删除。系统会逐题检查引用：

- 有试卷引用：保留；
- 有课程或任务引用：保留；
- 有答题、成绩或统计记录：保留；
- 无任何业务引用：二次确认后永久删除。

批量永久删除中，受保护题目会跳过，不影响其他可删除题目。
