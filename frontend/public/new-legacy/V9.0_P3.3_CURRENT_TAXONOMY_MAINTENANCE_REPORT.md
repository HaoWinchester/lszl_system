# V9.0-P3.3 当前知识树直接维护实施报告

## 1. 开发基线与范围

- 直接基线：V9.0-P3.2。
- 原始长期基线：V9.0-P2.2。
- 本批范围：P3.3 当前知识树直接维护。
- 继续保留：P3.1 信息架构、P3.1.1 顶部导航、P3.2 科目管理及 P2.2 知识树生命周期和安全删除。
- 未提前实施：P3.4 题目批量移动与待分类、P3.5 版本功能进一步简化。

## 2. 编辑模式重新定义

知识树编辑权限现在按版本角色判断：

- 当前已发布版本：`current` 运营维护模式，可进行日常节点维护；
- 草稿版本：`draft` 重大调整模式，继续可编辑；
- 历史已发布版本：只读；
- 已归档版本：只读。

当前知识树的日常修改不改变版本号、发布状态、默认版本身份或科目关联，也不要求复制草稿和重新发布。

## 3. 已实现的节点维护能力

### 3.1 新增与编辑

管理员和教师可在当前知识树中：

- 新增一级或下级知识点；
- 修改中英文名称；
- 修改知识点说明；
- 修改编号和别名；
- 保持知识点稳定 ID 不变。

新节点和修改节点都会记录创建/更新时间、创建/更新操作者，以及知识树维护修订号和最后维护信息。

### 3.2 移动与层级校验

支持通过属性面板选择父节点，以及在图形视图中拖动节点。移动时：

- 自动重新计算被移动节点及全部后代的层级；
- 禁止移动到自身或后代节点下；
- 禁止移动到已停用父节点下；
- 继续限制最大 9 层；
- 进入第 10 层的操作在提交前被拒绝并自动回滚。

### 3.3 同级排序

属性面板提供“上移”和“下移”。排序会规范同级 `sortOrder`，交换相邻节点位置，并保存两个受影响节点完整的修改前后信息。

### 3.4 停用与恢复

知识点状态限定为 `active` 或 `deprecated`：

- 停用叶节点不会删除题目关系、试卷内容、课程内容或历史记录；
- 有启用子节点的父节点不能直接停用，必须先移动或停用子节点；
- 已停用节点不能作为新节点的父节点；
- 恢复子节点前，其父节点必须处于启用状态；
- 停用和恢复均记录操作者及时间。

### 3.5 安全删除

永久删除遵循以下规则：

- 有任何子节点：阻止删除；
- 有直接题目引用：阻止删除，并提示先移动题目、设为待分类或停用节点；
- 无题目且无子节点：允许在二次确认后永久删除；
- 不使用级联删除；
- 删除审计明确保存 `before` 节点和 `after: null`；
- 自动恢复点可用于找回误删内容。

## 4. 操作留痕与恢复

以下操作均通过 `AdminTransactionService`：

- `taxonomy.node.create`
- `taxonomy.node.update`
- `taxonomy.node.reorder`
- `taxonomy.node.deprecate`
- `taxonomy.node.restore`
- `taxonomy.node.delete`
- `taxonomy.save`（界面撤销/重做）

每次事务在提交前创建轻量恢复点；校验或提交失败时恢复原数据；审计保存科目、知识树、编辑模式、操作者、时间和修改前后信息。

## 5. 页面与交互调整

继续复用现有“教师内容工作台 → 内容中心”的知识树编辑器，不新建第二套编辑页面：

- 当前版本显示“当前知识树 · 运营维护模式”；
- 草稿显示“重大调整草稿模式”；
- 历史和归档版本显示只读说明；
- 属性面板新增知识点说明和同级排序；
- 已停用节点不能新增子节点；
- 节点删除入口根据子节点和题目占用情况决定阻止、停用或永久删除；
- “科目与知识树”页面的当前版本入口改为“维护当前知识树”。

管理后台一级导航继续固定在顶部，页面外壳和科目管理布局不变。

## 6. 数据兼容

旧知识树节点缺少说明或维护字段时会安全补为空值，不要求迁移脚本。新增字段包括：

- 节点 `description`；
- 节点创建、更新、停用、恢复时间及操作者；
- 知识树 `maintenanceRevision`；
- 知识树最后维护时间及操作者。

题目仍只保存一个主要知识点，试卷仍保存稳定题目 ID。节点移动或改名不会重写已有试卷、课程、答题记录或成绩。

## 7. 缺陷检查与修正

本轮开发和复查中处理了：

1. 当前已发布知识树被服务层完全只读的问题。
2. 历史已发布版本可能被通用保存入口误修改的风险。
3. 节点移动后后代层级需要统一重算的问题。
4. 已停用父节点仍可能接收新子节点的风险。
5. 非法节点状态可能进入服务层的问题。
6. 排序审计只记录排序值、没有保存完整节点状态的问题。
7. 已停用空节点点击删除时缺少统一二次确认的问题。
8. 旧版浏览器测试仍把当前已发布版本视为只读的问题。

## 8. 验收覆盖

已覆盖以下核心场景：

1. 当前知识树可以直接新增、编辑和移动节点。
2. 当前知识树可以修改说明和同级顺序。
3. 第 6 至第 9 层可维护，第 10 层被阻止。
4. 循环移动、停用父节点接收子节点和非法状态被阻止。
5. 有子节点的知识点不能删除或直接停用。
6. 有题目引用的叶节点不能删除，但可以停用和恢复。
7. 空叶节点可以删除。
8. 历史已发布和归档版本保持只读。
9. 草稿版本继续可编辑。
10. 所有关键写入都有审计和恢复点。
11. P0、P2.1、P2.2、P3.1、P3.1.1、P3.2 能力保持兼容。
