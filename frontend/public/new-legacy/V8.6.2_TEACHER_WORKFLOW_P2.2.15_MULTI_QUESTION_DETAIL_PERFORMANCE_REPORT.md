# v8.6.2 P2.2.15 多题画布细节与拖拽性能优化

基线：P2.2.14。

## 本轮完成

### 1. 左上角当前画布文件栏重新对齐
- “题目库”按钮与“云朵保存 + 当前画布名称”文件栏统一为 40px 外部高度。
- 两者使用同一顶部基线、同一垂直居中方式。
- 文件名与云朵图标继续保持在同一个文件栏内。
- 双击原地编辑文件名、保存状态功能保持不变。

### 2. 预设颜色增加白色
白色 `#ffffff` 已加入：
- 多选悬浮工具栏颜色面板；
- 归纳卡颜色预设；
- 分组颜色预设；
- 多题画布内部 `CARD_COLORS` 预设列表。

白色颜色块增加灰色描边，避免与面板白底混在一起。

### 3. 拖拽卡牌 / 分组 / 画布时隐藏多选悬浮工具栏
为减少拖动过程中的 DOM 测量和定位计算：
- 单卡拖动时隐藏悬浮工具栏；
- 多卡整体拖动时隐藏；
- 分组容器整体拖动时隐藏；
- 画布平移时隐藏；
- 缩放期间继续隐藏；
- 拖动结束后只重新计算和显示一次。

同时 `scheduleSelectionToolbarPosition()` 在拖动抑制状态下会直接返回，不再执行 requestAnimationFrame 定位计算。

拖动期间连接点也临时隐藏，减少视觉干扰。

### 4. 所有卡牌统一四点连线
四个连接点不再只依赖某一种卡牌样式，而统一作用于所有 `[data-node-id]` 卡牌：
- 原题卡；
- 原则归纳卡；
- 套路归纳卡；
- 陷阱归纳卡；
- 笔记归纳卡；
- 后续使用同一节点容器的其他卡牌类型。

现有拖拽连接逻辑和“默认连线无文字”规则保持不变。

### 5. 四个连接点完全移到卡牌边缘外部
- 上点：完全位于卡牌上边缘外；
- 右点：完全位于右边缘外；
- 下点：完全位于下边缘外；
- 左点：完全位于左边缘外。
- 卡牌容器允许连接点溢出显示，卡牌头部和主体继续保持圆角。

外部连接点更接近知识图谱页面的节点连接方式，也避免连接点压在卡牌边框上。

## 数据影响

本版本没有修改：
- workspace ID；
- 题目 ID；
- 关系数据结构；
- 课程；
- 学习进度；
- 成绩；
- 解锁条件。

仅调整 UI、连接点表现、预设颜色和拖拽期间的运行策略。
