# V9.0-P3.5.1 快速使用

## 调整左右区域

进入 `paper-management.html`，在“从题库选择题目”和“试卷题目预览”之间拖动分隔条即可调整宽度。分隔条获得焦点后，也可使用左右方向键微调，Home/End 快速切换到最小或最大比例。

## 放大或收起

每个区域右上角有两个图标：

- 四角图标：放大当前区域；再次点击恢复左右分栏。
- 减号图标：收起当前区域；收起后点击箭头恢复。

## 预览题目

在左侧题库题目或右侧试卷题目上双击，打开题目预览窗口。窗口内可查看题干、选项、答案和解析。

## 编辑题目

在预览窗口右上角点击铅笔图标，会在新标签页打开对应题目的“题目基本信息”编辑页面。原试卷管理页面保持不变。

## 批量移除

在右侧试卷预览中勾选题目，点击“批量移除”。该操作仅从试卷中移除引用，不会删除题库原题。
