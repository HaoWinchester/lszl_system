# V9.0-P4.0.3 快速使用说明

## 深度回忆

1. 打开 `knowledge-recall.html`；
2. 左上角返回按钮会返回 `index.html` 知识图谱首页；
3. 题目库只显示试卷管理中已发布且启用“深度回忆”的试卷；
4. 选择器会显示发布版本和可用题量。

页面不会再混入私人题库、整库发布题库或演示题库。

## 多题画布

1. 打开 `question-workspace.html`；
2. 从已发布试卷中选择并拖入题目；
3. 选中画布上的题目后点击“进入单题深学”；
4. 页面会携带当前试卷、发布版本和题目 ID 进入 `question-training.html`。

## 单题深学

单题深学可通过多题画布或带参数的业务链接进入。它只读取已发布试卷的冻结题目快照，不读取教师草稿或演示题。

示例参数：

```text
question-training.html?paperId=...&releaseId=...&bankId=...&questionId=...
```

## 题目快照异常

发布试卷中某一道快照缺失时：

- 该题会被安全跳过；
- 页面显示配置题量、可用题量和异常数量；
- 其他可用题目仍可正常学习。

## 首页画布

移动、缩放、双指缩放或适配画布时，卡牌和连线临时悬浮菜单会自动隐藏。当前选择和图谱内容不会被清除。

## 部署提示

直接使用本版本完整包覆盖 V9.0-P4.0.2 静态文件即可。题目、题库、发布试卷、安全删除和做题历史数据无需迁移。
