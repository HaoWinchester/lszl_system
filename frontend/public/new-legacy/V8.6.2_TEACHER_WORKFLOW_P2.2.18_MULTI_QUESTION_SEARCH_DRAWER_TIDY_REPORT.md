# v8.6.2 P2.2.18 多题画布搜索 / 题目库 / 单题入口 / 局部整理

基线：P2.2.17。

## 1. 修复全局搜索弹窗超出屏幕

当前画布文件名右侧的全局搜索面板改为 viewport fixed 定位，并由 JS 动态计算位置：

- 水平始终保留至少 10px 屏幕边距；
- 最大宽度 390px，小屏自动压缩；
- 若搜索按钮下方空间不足，会自动翻到按钮上方；
- 面板最大高度受当前视口限制；
- 搜索结果区域单独滚动；
- 浏览器 resize / scroll 时重新计算位置。

因此搜索面板不再因为文件栏靠近屏幕边缘或屏幕高度较小而溢出视口。

## 2. 多题题目库与单题题目库尺寸统一

多题页面 `#qwQuestionDrawer` 现在直接对齐单题深学 `#qtQuestionDrawer`：

- 顶部：紧贴 64px 平台顶栏下边缘；
- 左侧：0；
- 底部：0；
- 宽度：`min(360px, 100vw - 8px)`；
- 高度：占满顶栏下方可用高度；
- 圆角：右上 / 右下 12px；
- z-index：5000；
- 保留左侧滑入动画。

题目库内容结构仍保持多题页面自己的题目加入逻辑。

## 3. 右上工具栏新增“单题深学”目标按钮

在 `Aa` 字体按钮右侧新增狙击目标 / 靶心图标按钮。

点击逻辑：

1. 若当前选中了题目卡，优先进入该题的单题深学；
2. 若选中归纳卡，会尝试从该归纳卡 `sourceNodeIds` 找到关联原题；
3. 没有选中时，使用当前多题画布中的第一张题目卡；
4. 若题目来自发布试卷，调用现有 `qbOpenPaperQuestion()` 同步单题训练上下文；
5. 否则尝试按题库 / question ID 设置当前题；
6. 然后进入 `question-training.html`。

不新增第二份题目数据。

## 4. 卡片检查取消“超出画布”项目

按照本轮要求，多题画布布局检查不再检查卡片是否超出 8000×5000 逻辑画布。

布局检查现在只关注：

- 卡片重叠；
- 卡片异常尺寸；
- 卡片超出所属分组。

同时：

- “卡片超出画布”不再进入问题总数；
- 诊断列表不再显示该项目；
- “修复越界”按钮从诊断面板取消；
- 检查按钮提示文字同步修改。

旧的边界辅助函数暂时保留以兼容历史测试/未来其他用途，但 `runLayoutDiagnosis()` 不再调用它们。

## 5. 多选悬浮栏新增“局部整理”

框选 2 张及以上卡片后，悬浮栏新增四宫格“局部整理”按钮。

局部整理特点：

- 只调整当前选中的卡片；
- 不整理整个多题画布；
- 从所选卡片当前左上区域开始；
- 最多 4 列，按选中数量自动计算列数；
- 保留每张卡片原尺寸；
- 固定 36px 横向 / 纵向间距；
- 关系线、分组、原题引用不改变；
- 整理后保持这些卡片继续被选中；
- 支持 Ctrl/Command+Z 撤销。

这是轻量局部网格整理，不引入新的复杂自动布局引擎。

## 数据影响

本版本未修改：

- workspace ID；
- 题目数据；
- 卡片 / 连线数据结构；
- 分组数据模型；
- 课程；
- 学习进度；
- 成绩；
- 解锁条件。

本轮仅调整多题页面 UI、搜索面板定位、题目库尺寸、单题导航入口、布局诊断范围和选中卡片的局部布局操作。
