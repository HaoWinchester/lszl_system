# V9.0-P3.5.5 开发报告

## 版本主题

**训练科目切换、完整题目预览与科目级知识联想库迁移**

本版本基于 V9.0-P3.5.4，继续优化题库管理中的“训练配置”工作区。重点是把科目、题库和题目三层选择关系理顺，确保教师在左侧能完整核对原题，同时将不属于单题配置范围的科目级知识联想库迁移到知识树页面集中维护。

## 一、训练科目与题库选择

训练配置顶部的科目按钮现在是唯一科目切换入口：

- 当前科目使用深灰色底纹和白色文字；
- 按钮保留 `aria-pressed` 状态；
- 切换科目后自动选择该科目的第一个可用题库；
- 当前科目没有题库时只显示提示，不会在训练配置中自动创建题库；
- “选择题库”下拉框只显示当前科目的题库，不再使用跨科目分组；
- 切换题库后继续刷新题目列表、当前题目和训练配置。

该调整避免在科目按钮和题库下拉框中重复选择科目，也降低选错题库的概率。

## 二、完整题目预览

左侧原有小型预览升级为完整题目预览，持续展示：

- 题目名称；
- 完整题干；
- 全部选项；
- 正确选项标识；
- 明确的正确答案文本；
- 完整题目解析。

布局调整包括：

- 题目列表区域保留独立滚动；
- 预览区域最小高度提升至 350px；
- 预览占用左侧剩余空间，不再限制为 150px；
- 预览正文独立滚动，长题干、长选项和长解析均可完整查看；
- 题目切换、题干编辑、选项变化、答案变化和解析修改都会即时刷新预览；
- 窄屏时自动恢复上下布局，并增加预览可视高度。

原有题目区域与训练配置区域的拖拽分隔条、键盘调整和比例记忆继续保留。

## 三、科目级知识联想库迁移

科目级知识联想库已从单题训练配置移至 `content-center.html` 的知识树工作区，教师可从“科目与知识树”页面进入当前知识树后集中管理。

新管理区域支持：

- 跟随知识树页面顶部当前科目切换；
- 载入当前科目的既有联想库；
- 导入 TXT 或 JSON；
- 解析检查知识点、关系和行数；
- 按稳定节点合并；
- 替换当前科目联想库；
- 显示当前科目、知识点数、关系数及更新时间。

迁移只改变管理入口，不迁移或复制数据。仍然复用原存储规则：

```text
kg_recall_association_library_v1__subject__<科目代码>
```

已有 PMP、ACP 等科目联想库会在新页面直接读取。

## 四、单题训练配置收敛

训练配置右侧现在只维护当前题目的：

- 可点击关键词；
- 关键词到知识联想入口的绑定；
- 关键词命中位置与当前联想库状态。

以下区域已从单题配置页面移除：

- 科目级知识联想库编辑器；
- 节点配置；
- 候选节点排序；
- 学员效果预览。

页面保留一张轻量提示卡，可直接打开知识树管理页面。节点双语信息和候选关系的数据模型仍然保留，没有删除历史数据。

## 五、联想库数据修复

修复 `normalizeLibrary()` 对空结构对象的识别问题。此前 `{schemaVersion, nodes: [], edges: []}` 可能被误当成邻接表，从而生成 `schemaVersion`、`nodes`、`edges` 等无效节点。

现在只有真正的非结构化邻接表对象才会进入兼容转换逻辑。首次保存空联想库后再合并知识链时，不会再产生无效节点。

## 六、安全边界

本版本没有改变：

- 题目 ID；
- 题库 ID；
- 试卷题目引用；
- 已发布试卷快照；
- 题目安全删除和恢复规则；
- 永久删除引用保护；
- 训练工作区分栏比例存储键；
- 科目级联想库原存储键。

科目按钮切换只改变当前筛选与选择状态，不复制题目，也不会修改题目所属科目。
