# v8.6.2 P2.2.16 多题画布对齐图标 / 布局诊断 / 底部统计 / 账号菜单

基线：P2.2.15。

## 1. 多选悬浮栏“对齐”图标统一为通用图形

原来的字符箭头全部替换为标准 SVG 对齐 / 分布图标，共 8 项：

- 左对齐；
- 水平居中对齐；
- 右对齐；
- 水平等间距；
- 顶部对齐；
- 垂直居中对齐；
- 底部对齐；
- 垂直等间距。

图标结构参考常见图形编辑器的“基准线 + 元素块”表达方式，减少识别成本。原 `data-qw-arrange` 操作值保持不变，因此不改变现有排列算法。

## 2. 修复“卡片超出画布”误报

旧诊断直接使用持久化 node 的 x / y / width / height，并严格比较 0~8000 / 0~5000。卡片刚完成缩放、字体变化或 DOM 尺寸变化时，持久化尺寸与实际渲染尺寸可能存在短暂差异，导致视觉上仍在画布内却被提示越界。

P2.2.16 调整为：

- 布局诊断读取 `liveCardLayout()` 的实际渲染几何；
- 画布边界读取实际 `#qwCanvasWorld` 尺寸，并保留 8000×5000 作为最低逻辑尺寸；
- 增加 28~64px 的容差，只在卡片真正明显伸出逻辑画布时才报告“卡片超出画布”；
- 轻微像素舍入、边框和 resize 差异不再触发误报。

真正越界的卡片仍会保留诊断与“修复越界”功能。

## 3. 画布统计移到底部中间

原右上角：

`5 卡 · 3 题 · 2 归纳`

从顶部操作区移除，改为画布底部中间的轻量统计胶囊。

- 与左下缩放工具栏使用相同 bottom=12px；
- 外层高度按缩放栏 52px 对齐，视觉中心位于同一水平线；
- 仍实时显示卡片 / 题目 / 归纳 / 已选数量；
- 移动端继续隐藏，减少小屏占用。

## 4. “退出”整合进账号胶囊

多题页面不再显示独立“退出”按钮。

账号区域改用与知识图谱页面相同的：

- `account-menu-shell`
- `account-menu-trigger`
- `account-menu`
- `accountMenuSessionBtn`

账号胶囊点击后提供：

- 用户中心；
- 帮助中心；
- 升级会员（按既有响应式规则）；
- 登录 / 退出登录。

底层仍保留隐藏的 `authLoginBtn / authLogoutBtn` 作为统一认证运行时的兼容触发器。

帮助中心在多题页面会打开现有轻量帮助浮层；完整帮助仍可通过浮层中的“…”进入。
