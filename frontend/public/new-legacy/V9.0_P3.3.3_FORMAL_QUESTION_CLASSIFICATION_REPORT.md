# V9.0-P3.3.3 正式题目录入与分类交互报告

## 1. 版本目标

本版本基于 **V9.0-P3.3.2**，将正式考试题目的录入入口统一到“题目管理 → 题目内容”，取消面向用户的重复“录入中心”页签，并在不挤占题目编辑宽度的前提下完成科目、主要知识点和普通标签的分类操作。

本版本不实施 P3.4 的题目批量移动；批量移动仍作为下一阶段独立能力开发。

## 2. 唯一正式录题入口

题目管理不再并列展示“题库与题目 / 录入中心”。正式题目的标准入口统一为：

```text
题目管理
→ 选择题库
→ 题目内容
→ 粘贴模板或手动录入
→ 校对
→ 设置分类
→ 保存
```

旧 Question Studio 不再作为正式题目入口，仅保留兼容页面：

- 普通访问会跳转到题目管理的粘贴录入区域；
- 显式使用 `?standalone=1` 时仍可检查旧学习活动设计器；
- 学习活动内容库与正式题库不再在同一导航中混淆。

## 3. 顶部分类信息栏

分类字段位于题目基本信息顶部，不增加右侧属性栏。默认以紧凑形式展示：

- 所属科目；
- 主要知识点；
- 普通标签；
- 分类状态；
- 展开 / 收起控制。

分类栏支持折叠并记住本地显示状态。题型继续使用现有字段和交互，本版本未调整题型布局。

## 4. 主要知识点选择

每道题只允许设置一个主要知识点。知识点选择器采用可缩放悬浮对话框，并提供：

- 当前题库科目锁定；
- 当前科目的当前知识树；
- 最多 9 层的逐列级联浏览；
- 节点名称、编号、别名和完整路径搜索；
- 完整层级路径展示；
- 单选确认；
- 明确设为“待分类”；
- 停用节点不可作为新选择；
- 选择非叶节点时提供“优先选择更具体节点”的提示，但不强制阻断。

正式题目保存稳定的知识树 ID 与节点 ID，不以节点名称作为关联键。节点改名、排序或移动后，题目仍指向同一个节点。

## 5. 普通标签选择

普通标签与主要知识点分离。标签选择器采用层级多选结构：

```text
标签组
→ 标签分类
→ 可选标签
```

内置标签组包含用途、质量和来源等分类，同时允许录入自定义标签。已选标签以标签块展示，可直接移除。

## 6. 模板显式字段解析

单题和批量粘贴模板支持以下显式字段：

```text
【科目】PMP
【知识点】敏捷方法/迭代规划
【标签】易错题、阶段测试
```

匹配规则按以下优先级执行：

1. 知识点编号精确匹配；
2. 完整路径精确匹配；
3. 当前科目内唯一名称或别名精确匹配；
4. 多个同名候选时要求人工选择；
5. 无法匹配时明确进入待分类。

系统不根据题干语义自动猜测知识点。模板解析结果只有在教师执行“确认并进入编辑”或批量确认导入后，才写入正式题目。

当模板科目与当前题库科目不一致时，系统保持当前题库科目并给出警告，避免在同一题库内混入其他科目的题目。

## 7. 正式题目分类数据

正式题目的知识点信息保存在 `metadata.knowledge`，核心字段包括：

- `taxonomyId`；
- `taxonomyVersion`；
- `primaryNodeId`；
- `mappingStatus`；
- `mappingSource`；
- `pathSnapshot`；
- `confirmedAt`；
- `confirmedBy`。

普通标签继续保存在题目的 `tags` 数组中，并在元数据中保存层级标签路径。题目分类调整会追加轻量分类历史，记录操作来源、操作者、时间及修改前后值。

## 8. 引用保护

正式题库现已纳入 V9 引用索引：

- 科目删除保护会识别正式题库和正式题目；
- 知识点永久删除会识别正式题目的主要知识点引用；
- 有正式题目引用的知识点不能永久删除；
- 停用知识点不会自动修改已有题目关联；
- 已停用关联会在题目分类栏中明确显示，并允许重新选择或移入待分类。

## 9. 兼容性

以下能力保持不变：

- 试卷保存确定的题目 ID；
- 修改题目知识点不会修改已有试卷；
- P3.3 当前知识树日常维护；
- P3.2 科目管理；
- P2.2 知识树归档、恢复和安全删除；
- 八项管理后台顶部导航；
- 桌面端和移动端原有页面外壳。

- 模板科目、知识点和标签显式识别通过；
