# v8.6.2 教师工作流 P2.2 开发与回归报告

## 基线

基于 `kg_graph_v8_6_2_teacher_workflow_p2_1_1_ui_maintenance.zip` 开发。

## 已完成

### 1. 三个完整版学习页面统一 UI

统一深度回忆、多题归纳、单题深学三个页面。桌面端共享顶栏为 64px，标题 18px；删除标题下说明文案，可见的“自由练习 · 不计成绩”标签移除但内部语义保留。

新增共享层：

- `styles/learning-practice-shell.css`
- `src/99-learning-practice-shell.js`

### 2. 统一“视图”菜单

深度回忆包含学习场景主题、缩放、回到题目、重置地图；多题归纳和单题深学包含缩放、全览、重置。排列、选择、字体、当前卡等页面专属工具继续留在画布浮动工具区。

### 3. 深度回忆场景主题边界修复

羊皮纸、极光、霓虹、樱花、海盐、拿铁继续属于学习场景，只影响深度回忆画布、节点和弹窗。共享平台顶栏不再继承这些主题变量，因此主题切换不再改变顶栏结构或颜色。没有把这些场景主题升级为全局系统主题。

### 4. 深度回忆题目库

“题集 / 题目”移至画布左上角并统一命名为“题目库”。抽屉新增题集选择、搜索、全部/未探索/已探索筛选、当前题高亮和探索状态。点击题目继续加载该题自己的独立回忆地图。

### 5. 单题深学双语显示

新增“中文 / 中英对照”切换。作答卡和旧渲染回退均读取 P2.1 双语字段；英文只做中文对照，不改变答案判定、评分和流程。

### 6. 科目级知识联想节点可视化配置

保留原 TXT/JSON 批量联想库，同时新增“节点配置与学员预览”。节点支持中文/English 名称、提问、轻提示；候选知识点支持增加、删除、上移/下移和拖动排序，学员效果实时预览前 4 个候选。

已有节点编辑继续保持原稳定节点 ID；候选顺序通过关系 priority 保存。

### 7. 数据兼容

联想节点仅增量增加 `titleEn`、`promptEn`、`hintEn` 可选字段。旧 TXT、旧 JSON、旧本地存储继续可读。题目 ID、活动 ID、课程节点 ID、成绩、进度和解锁规则没有修改。

## 回归

新增 P2.2 静态/数据模型回归和浏览器回归，并继续执行 P2、P2.1、P2.1.1、教师深度回忆既有回归。
