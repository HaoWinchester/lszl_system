# V9.0-P3.5.8 快速使用说明

## 教师日常入口

从后台顶部点击“教师工作台”，按以下流程工作：

```text
管理题目 → 配置训练 → 管理试卷
```

教师工作台内部可直接切换：工作台、题目管理、训练配置和试卷管理。

## 课程与任务

课程与任务不属于教师三步流程。需要维护课程结构或学习任务时，从后台顶部单独点击“课程与任务”。

该页面只包含：

- 课程配置；
- 学习任务。

正式试卷请始终从“教师工作台 → 试卷管理”进入。旧的课程试卷地址会自动跳转到正式试卷管理页面。

## 数据说明

本次升级不改变任何题目、试卷、课程或任务数据，可直接覆盖上一版静态文件使用。
