## 对“绿色框画布功能改成知识图谱式页签”的评估
可行，而且建议实施，但本版暂不改动数据和切换模型。

推荐下一步把当前：
`画布 + 下拉选择 + 新建 + 改名 + 删除`
改为：
`[画布A] [画布B] [画布C] [+]`
并把重命名、删除放入当前页签的“…”菜单。

优势：
- 与知识图谱文件页签一致，学习成本更低；
- 多画布之间切换更直接；
- 当前画布状态更明显；
- 顶栏高度可进一步降低。

技术上仍可保留现有 `workspaceId / loadWorkspace / createWorkspace / renameWorkspace / deleteWorkspace`，只替换 UI 层，因此数据风险较低。建议作为 P2.2.12 单独实施并补充大量画布页签的溢出/滚动测试。
