# V9.0-P3.3.3.2 批量粘贴与解析导航修复报告

基线：V9.0-P3.3.3.1。

## 修复范围

1. 修复“本批次默认分类”区域在题目解析右栏较窄时出现横向溢出的问题。
2. 批量分类弹窗改为严格受视口约束，正文区域内部滚动，底部操作按钮始终可见。
3. 批量题目分割改为逐行识别 `===== 下一题 =====`，兼容 Windows 换行及全角等号写法，避免整段结构化模板被当成单题。
4. 批量解析结果新增上一题、下一题和题号快速切换；解析区一次聚焦展示一题，但保留整批总数、通过数和问题数。
5. 单题分类覆盖、批次默认分类、重复题跳过及正式题库写入规则保持不变。

## 分割规则

推荐每道题之间单独一行使用：

```text
===== 下一题 =====
```

系统按独立分割行拆题，不会把分隔线内容带入题干或解析。

## 验证

- 5 道结构化模板使用标准分割线可完整解析，首题和末题均保留。
- 解析预览支持上一题、下一题及题号跳转。
- 1366×768 与 390×844 下默认分类区域无横向溢出，分类弹窗和底部操作区均在视口内。
- P3.3.3.1 批次默认分类回归通过。
