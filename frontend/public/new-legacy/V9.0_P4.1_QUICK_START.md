# V9.0-P4.1 快速使用说明

## 用户端

在图谱首页账号右侧点击问号图标：

- **帮助中心**：查看图谱首页、多题归纳、深度回忆和刷题说明；
- **需求反馈**：提交问题或建议，并在“我的反馈”中查看处理进度；
- **消息**：查看管理员发布的通知。未读消息会显示数字角标。

## 管理后台

后台一级导航新增：

```text
反馈管理｜消息管理
```

### 反馈管理

1. 选择一条用户反馈；
2. 查看描述、页面、账号和附件；
3. 更新处理状态；
4. 填写回复并保存。

### 消息管理

1. 点击“新消息”；
2. 填写标题和正文；
3. 选择全部用户、指定角色或指定用户；
4. 可设置发布时间、失效时间和跳转链接；
5. 保存草稿或发布。

## 服务器部署

当前默认是浏览器本地演示适配器。跨设备正式部署需要：

1. 实现 `SERVER_ENGAGEMENT_API_V1.md` 中的接口；
2. 将 `src/01-runtime-config.js` 中 `engagement.mode` 改为 `remote`；
3. 设置 API `baseUrl`；
4. 在服务端校验当前账号及管理员权限。
