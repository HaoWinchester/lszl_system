# V9.0-P3.5.3 快速使用说明

## 调整题库区和题目区大小

1. 打开“题库管理”；
2. 在“题库”和“题目”中间找到分隔条；
3. 左右拖动分隔条调整宽度；
4. 分隔条获得焦点后，也可以使用：
   - 左右方向键：小幅调整；
   - Home：题库区调整到最小比例；
   - End：题库区调整到最大比例。
5. 点击区域顶部按钮，可放大或收起对应区域；
6. 再次点击对应按钮恢复左右分栏。

系统会自动记住上次拖拽比例。

## 悬浮预览题目

1. 在题目列表中双击一道题；
2. 悬浮窗会显示题干、选项、答案和解析，箭头指向对应题目；
3. 悬浮窗打开时，单击另一道题即可切换；
4. 再次双击当前题目、点击关闭按钮或按 Esc，可关闭预览；
5. 点击编辑图标，可进入当前题目的“题目基本信息”编辑区域。

## 安全说明

- 预览不会修改题目；
- 调整区域大小不会改变题库数据；
- 编辑仍使用原题目 ID；
- 安全删除和永久删除保护规则保持不变。
