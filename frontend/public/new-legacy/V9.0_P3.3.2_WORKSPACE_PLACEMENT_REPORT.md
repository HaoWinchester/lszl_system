# V9.0-P3.3.2 业务工作区归位报告

## 一、调整目标

本版本基于 **V9.0-P3.3.1**，解决旧“录入中心”和“内容中心”仍以独立页面存在、与新的管理后台信息架构重复的问题。

目标结构为：

```text
题目管理
├─ 题库与题目
└─ 录入中心

科目与知识树
├─ 当前知识树（直接包含知识树工作区）
├─ 待分类题目
└─ 历史版本
```

旧页面仅作为兼容组件保留，不再作为主要导航入口。

## 二、实现内容

### 1. 录入中心归入题目管理

`question-bank.html` 新增页面级业务页签：

- 题库与题目；
- 录入中心。

录入中心复用现有 Question Studio，不复制解析器、草稿、备份或知识点选择逻辑。首次打开页签时才加载嵌入组件，避免默认进入题库时增加无意义的页面负担。

直接访问旧地址 `question-studio/index.html` 时，会归位到：

```text
question-bank.html?workspace=entry
```

保留 `?standalone=1` 作为兼容调试入口。

### 2. 知识树工作区归入科目与知识树

`admin-subjects.html` 的“当前知识树”页签中直接加载现有知识树编辑器，管理员无需再跳转到旧内容中心。

工作区随左侧科目切换自动更新，并支持：

- 当前知识树直接维护；
- 草稿版本编辑；
- 历史和归档版本只读查看；
- 从历史版本列表打开指定版本；
- 保留 P3.3 的新增、编辑、移动、排序、停用、恢复、9 层限制、事务快照与审计。

### 3. 拆分旧内容中心职责

知识树嵌入模式只显示“知识树工作区”，隐藏旧页面中的：

- 教师工作流顶部外壳；
- 科目切换条；
- 统一活动库；
- 标签、题集与收藏整理区。

题目与活动的维护入口统一归到题目管理，知识树维护统一归到科目与知识树。

直接访问旧地址 `content-center.html` 时，会归位到：

```text
admin-subjects.html?tab=current
```

同时保留 `?standalone=1`，用于兼容检查旧页面能力。

### 4. 旧入口清理

以下入口已更新：

- 教师工作台“录入中心” → 题目管理的录入页签；
- 教师工作台“知识树管理” → 科目与知识树；
- 训练配置“管理知识树” → 科目与知识树；
- 课程设置中的旧内容中心/活动库入口 → 题目管理；
- 历史知识树版本“查看” → 科目与知识树当前工作区。

### 5. 嵌入工作区尺寸同步

新增父子页面高度通信：

- 嵌入组件通过 `postMessage` 上报内容高度；
- 父页面根据内容动态调整 iframe 高度；
- 设置最大高度保护，避免异常内容撑破页面；
- 桌面与移动端保持同一页面结构。
