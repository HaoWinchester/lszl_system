# V9.0-P3.5.6 快速使用说明

## 打开训练配置

```text
question-bank.html?mode=simple&step=training
```

## 使用左侧题目筛选

训练配置进入后，题库、搜索、题目状态和归集方式默认收起为一条摘要。

- 点击题目面板标题栏中的“筛选”图标展开；
- 也可以直接点击摘要行展开；
- 再次点击筛选图标收起；
- 页面会记住上次的展开或收起状态。

摘要会显示当前题库、题目状态、归集方式以及搜索词，收起时仍能确认当前筛选上下文。

## 查看题目

1. 在顶部选择科目；
2. 必要时展开筛选区切换题库或搜索题目；
3. 在题目列表中点击题目；
4. 下方预览只显示完整题干和全部选项；
5. 长题干或长选项可在预览内部滚动查看。

预览不会显示正确答案、解析、知识点、标签或其他元信息。

## 调整左右区域

拖动题目区和训练配置区之间的分隔条，可调整左右宽度。方向键、Home 和 End 仍可用于键盘调整，比例会自动保存。
