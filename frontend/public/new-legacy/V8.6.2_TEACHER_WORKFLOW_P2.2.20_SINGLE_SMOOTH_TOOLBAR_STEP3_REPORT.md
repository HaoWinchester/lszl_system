# v8.6.2 P2.2.20 单题切题动画 / 工具栏统一 / 第三卡精简

基线：P2.2.19。

## 单题切题动画
切换题目时，在第一张“独立作答”卡上增加三点读取动画 + 浅色渐变 shimmer。旧题内容轻微淡出，新题完成同步后淡入。没有人为延迟数据切换，只用短暂视觉过渡覆盖 DOM 重绘。

从多题页面 deep-link 进入时，只要 URL 带 questionId，页面在主脚本初始化前就进入 pending loading 状态，避免先显示旧题再硬切。

## 顶部画布工具栏
单题画布左侧题目库组合栏与右侧工具栏，尺寸和工具文字字号对齐多题画布：
- 左侧整体 40px；
- 题目库内部按钮 38px；
- 右侧按钮最小 38×38px；
- Aa 与普通工具文字 13px；
- 指针/重置图标 18px；
- 外层 3px padding、12px 圆角、相同边框与阴影。

## 第三张卡三个旧按钮
确认可以取消并已从当前 UI 删除：

1. `生成本题图谱`：进入第 3 步时 GuidedLearningCanvas 已自动把 graph 打开并渲染，按钮重复。
2. `加入总图谱`：旧函数在独立单题页本身就提示“暂不直接加入总图谱”，继续显示会产生错误预期。
3. `生成闪卡`：旧入口依赖知识图谱页全局 state，与当前单题深学架构不一致。

旧 JS 函数暂时保留用于历史兼容，当前单题 UI 不再暴露。

## 数据
不修改原题、题目 ID、发布试卷、学习进度、成绩、workspace、连线、分组或解锁规则。
