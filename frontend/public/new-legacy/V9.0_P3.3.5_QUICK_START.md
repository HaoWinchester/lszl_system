# V9.0-P3.3.5 快速使用

## 修改标签分类名称

进入“题目管理 → 题目内容 → 普通标签 → 选择 → 管理标签”。

- 双击“用途标签”等一级分类即可修改；
- 双击“训练阶段”等二级分类即可修改；
- 双击具体标签继续按原方式修改；
- Enter 或点击其他位置保存；
- Esc 取消。

分类名称只是标签选择体系的显示名称，不会重写题目已有的具体标签。具体标签改名仍会同步现有题目并保留旧名称兼容映射。

## 后台顶部导航

总览、科目与知识树、用户管理、操作记录、系统设置在向下滚动时，最上方八项后台导航持续可见。除用户管理外，其余四页的账号胶囊也固定在导航下方。

## 后台账号菜单

点击右上角账号胶囊，可进入：

- 用户中心；
- 后台帮助中心；
- 退出登录。

用户管理页面不再显示重复账号胶囊和模块快捷入口。
