# v8.6.2 P2.2.17 多题画布文件一致性 / 文件名宽度 / 全局搜索

基线：P2.2.16。

## 1. 顶部页签栏取消“…”按钮

P2.2.12 曾保留“当前画布操作 …”菜单，里面只有重命名和删除。

现在：
- 重命名已经可以通过双击当前文件名原地完成；
- 删除和文件管理已经统一进入文件管理页面；
- 因此顶部页签栏右侧“…”属于重复入口。

P2.2.17 删除：
- `qwWorkspaceActionsMenu`
- `qwRenameWorkspaceBtn`
- `qwDeleteWorkspaceBtn`

保留：
- 文件管理入口；
- 页签；
- `+` 新建画布。

## 2. 修复文件管理与实际多题画布文件不一致

根因是多题画布 Store 原来只通过 `KGLearningSessionStore.currentUserId()` 判断当前用户。

在完整多题页面中，学习会话运行时通常已经拿到了登录用户；但文件管理页面的加载上下文不同，在某些情况下学习会话运行时会退回 `guest`，于是：

- 多题页面读取登录用户的 workspace catalog；
- 文件管理页面却读取 guest catalog；
- 两边看到的文件自然不一致。

P2.2.17 将 `KGCanvasWorkspaceStore.currentUserId()` 调整为：

1. 优先 `KGAuthCore.currentUsername()`；
2. 再尝试 `KGAuthRuntime.currentUsername()`；
3. 再使用非 guest 的 `KGLearningSessionStore.currentUserId()`；
4. 最后才退回 `guest`。

因此文件管理与实际多题页面现在使用同一个认证用户作为 workspace catalog key。

本次没有合并知识图谱 Store 和多题画布 Store，也没有迁移 workspace ID。

## 3. 当前文件名最多显示 12 个文字

画布左上当前文件名栏现在：

- 只显示前 12 个 Unicode 字符；
- 超出部分直接不显示，不使用额外省略号；
- `title` 和 `aria-label` 仍保留完整文件名；
- 双击编辑时恢复显示完整原始文件名；
- 编辑结束后重新回到最多 12 字显示。

例如：

`新建解题范德萨放到沙发沙发的沙发沙发`

显示为：

`新建解题范德萨放到沙发沙`

但完整名称仍保存在 workspace 数据中。

## 4. 文件名右侧新增画布全局搜索

文件名栏右侧新增紧凑蓝色放大镜按钮。

点击后打开当前画布搜索面板，搜索范围包括：

- 题目卡标题；
- 题干摘要；
- 主题；
- 难度；
- question ID；
- 标签；
- 归纳卡标题；
- 归纳卡正文；
- 归纳卡标签。

搜索结果点击后：

1. 选中目标卡片；
2. 将主画布聚焦到该卡片；
3. 自动关闭搜索面板。

搜索只针对当前多题画布，不跨文件搜索。

## 数据影响

本版本未修改：
- workspace ID；
- 题目 ID；
- 卡片与连线结构；
- 课程；
- 学习进度；
- 成绩；
- 解锁条件。

`CanvasWorkspaceStore` 仅修改“当前用户身份解析顺序”，目的是让多题页面与文件管理访问同一份 workspace catalog。
