# V9.0-P4.0.3 学习页面路由与发布试卷数据统一报告

## 开发目标

本版本基于 V9.0-P4.0.2，完成部署前的学习页面收口：

1. 修复深度回忆返回首页和多题画布进入单题深学的路由；
2. 让深度回忆、多题画布、单题深学统一读取试卷管理正式发布的不可变版本；
3. 移除私人题库、整库发布和演示题库等混合数据源；
4. 在首页画布移动、缩放和适配时关闭临时悬浮菜单，减少无效渲染。

## 1. 统一发布试卷仓库

新增：

```text
src/59-published-paper-repository.js
```

该仓库只读取：

```text
kg_exam_papers_published_v1
```

并提供统一只读接口：

```text
listPublishedPapers(mode)
getPublishedPaper(paperId, releaseId)
resolvePublishedPaper(paperId, releaseId)
resolvePaperQuestions(paperId, releaseId)
findQuestion(paperId, releaseId, questionId)
listCollections(mode)
```

学习页面使用发布时冻结的 `questionSnapshots`，不再回退到教师草稿、当前账号题库、公共整库发布数据或演示题库。

发布范围仍按试卷配置过滤：

```text
deep_recall
multi_question_canvas
single_deep_study
```

## 2. 深度回忆

- 左上角返回按钮改为返回 `index.html` 知识图谱首页；
- 题集选择器只显示允许用于深度回忆的正式发布试卷；
- 显示试卷名称、发布版本以及“可用题量 / 配置题量”；
- 使用发布版本和题目快照建立学习进度上下文；
- 缺失或损坏快照会安全跳过，并在题目库区域显示异常数量；
- 切换试卷时清理上一试卷的题目和页面状态。

## 3. 多题画布

- 题目库只读取允许用于多题画布的发布试卷；
- 试卷列表显示发布版本及可用题量；
- 拖入画布的题目引用保留 `paperId / releaseId / bankId / questionId`；
- 修复工作区标准化过程丢失 `releaseId` 的问题；
- “进入单题深学”会携带完整发布版本和题目上下文，不再跳转做题模式。

旧工作区没有 `releaseId` 时仍可正常读取，不需要迁移。

## 4. 单题深学

- 移除 `question-training.html` 到做题模式的强制重定向；
- 只读取允许用于单题深学的正式发布试卷；
- 支持从多题画布传入：

```text
paperId
releaseId
bankId
questionId
```

- 路由命中时直接打开指定发布版本中的指定题目；
- 无匹配发布试卷时显示空状态，不加载私人或演示题目；
- 退出单题深学返回多题画布。

单题深学没有重新加入首页或全局快捷栏，仍通过明确业务入口进入。

## 5. 发布快照异常处理

统一仓库会分别计算：

```text
配置题量
可用题量
缺失快照数量
被阻止题量
```

某一道发布快照损坏不会阻断整套试卷。页面会跳过异常题目，并显示例如：

```text
已发布 20 题，当前可用 19 题，1 题快照异常
```

教师后续修改或安全删除原题，不会改变已经发布的冻结内容。

## 6. 首页临时菜单性能优化

卡牌、连线等临时悬浮菜单会在以下操作开始时自动关闭：

- 鼠标拖动画布；
- 触控移动或双指缩放；
- 滚轮缩放；
- 平滑放大或缩小；
- 适配全部内容；
- 代码设置画布缩放。

该行为只关闭临时菜单，不清除当前选中的卡牌或连线，也不修改图谱内容。

## 数据与兼容性

本版本没有修改：

- 题目 ID、题库 ID、题目正文或分类；
- 试卷草稿和不可变发布版本的数据结构；
- 发布题目快照内容；
- 安全删除和历史引用保护；
- 做题模式规则及练习历史。

多题画布的新题目引用会保存 `releaseId`；旧工作区继续兼容，浏览器数据无需迁移。
