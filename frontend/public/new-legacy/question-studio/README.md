# Question Studio v0.2.1.2（录入中心）

本维护版本增加批量文本、结构化修改、运行预览和校验结果四个工作区的放大与侧栏收起能力。题目结构、草稿兼容和知识点查找器保持 v0.2.1 规则。

## v0.2.1 基线

独立运行的 Activity Schema v1 录入工具。支持单项选择、关键词识别、开放表达、排序和连线配对；中文负责作答和判定，英文仅用于对照展示。

## v0.2.1 新增

- 与教师工作台、内容中心和配置中心统一顶部页签与视觉风格；
- 知识点大下拉框替换为“知识点查找器”；
- 支持按名称、英文名称、编号、别名、稳定 ID 和完整路径搜索；
- 支持按层级浏览和面包屑返回；
- 支持最近使用、收藏和完整路径确认；
- 本批默认知识点可应用到全部活动，每道活动也可单独调整；
- 与内容中心共享当前科目和本机知识树数据；
- 草稿格式升级到 v0.2.1，并兼容读取 v0.2.0 与 v0.1.0 草稿。

## 已有能力

- 按科目加载独立知识树；
- 为每个活动选择主知识点；
- 最多六层知识路径；
- 提交前校验知识点归属；
- 同源部署时一键提交到统一活动库；
- 预留服务器活动导入 API；
- 记录创建账号和最后修改账号；
- 保留离线 JSON、自动草稿和历史备份。

直接打开 `index.html` 可离线使用。以 HTTP/HTTPS 部署时，“提交到内容中心”会写入同源浏览器活动库；配置服务器端活动接口后可切换为真正的多人在线保存。正式教师身份仍应由服务器登录会话写入。
