# V9.0-P4.0.1 做题模式入口与状态反馈优化开发报告

## 目标

在不改变 P4.0 练习规则和发布数据链路的前提下，进一步精简做题大厅，并统一挑战模式与学霸模式的连胜反馈。学霸模式增加更明确的倒计时识别和低时间危险视野反馈。

## 做题与自由模式切换

做题大厅账号菜单左侧新增轻量分段切换：

```text
做题｜自由
```

- “做题”为当前选中状态；
- “自由”进入 `index.html?mode=free`；
- 该切换只在做题大厅顶栏显示；
- 进入答题、检查点和结算后仍隐藏大厅顶栏，保持答题页面简洁。

## 大厅信息精简

移除标题下方以下说明性文字：

```text
只读取教师已经发布的固定版本。练习不会修改题目或试卷。
```

数据安全规则没有改变：做题模式仍只读取正式发布版本及其题目快照，不读取教师草稿，也不会修改题目或试卷。

## 连胜提示统一

挑战模式和学霸模式现在共用同一个连胜浮层，位置统一在做题进度条上方。

规则为：

- 连续答对达到 3 题时首次弹出；
- 后续继续答对时，浮层持续显示并更新当前连胜与额外经验；
- 渲染下一题不会自动隐藏；
- 检查点结束返回答题后继续显示；
- 答错或超时会打断连胜并立即隐藏；
- 再次达到 3 连胜时重新出现；
- 退出、完成练习或返回大厅时清理。

学霸模式移除了顶部常驻连胜数字，因此两种模式的信息密度和反馈方式保持一致。

## 学霸倒计时优化

倒计时细进度条左侧新增闹钟图标。图标颜色与倒计时状态同步：

- 41–80 秒：正常；
- 21–40 秒：紧张；
- 0–20 秒：危险。

顶部仍只保留退出按钮、做题进度、血量和倒计时数字；闹钟和细进度条位于其下方，不增加额外文字。

## 低时间红色视野

当学霸模式剩余时间进入 20 秒及以下时，页面外围显示红色渐变呼吸视野：

- 渐变从窗口边缘向中心减弱；
- 不遮挡题干、选项和退出按钮；
- 不接收鼠标或触控事件；
- 时间恢复到 20 秒以上后立即消失；
- 退出确认打开期间倒计时继续，危险视野也继续反映真实时间；
- 系统启用“减少动态效果”时停止呼吸动画并使用静态弱化效果。

## 数据与兼容性

本轮没有改变：

- 题目 ID、题库 ID 或题目内容；
- 试卷引用和不可变发布快照；
- 10 / 20 / 60 / 180 题数量规则；
- 每题 10 基础经验和连胜额外经验；
- 挑战模式血量、检查点及回血规则；
- 学霸模式 80 秒时间池、答对加时和答错惩罚；
- 练习历史数据结构及存储键；
- 旧学习模式入口门禁。
