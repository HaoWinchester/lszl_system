# V9.0-P3.5.4 快速使用说明

## 在训练配置中切换题库

1. 打开“题库管理 → 训练配置”；
2. 在左侧顶部找到“选择题库”；
3. 选择目标题库；
4. 题目列表会立即切换到该题库，并默认选中第一道可用题目。

可继续使用搜索、题目状态和归集方式缩小范围。

## 调整题目区和训练配置区宽度

1. 将鼠标移到两个区域中间的竖向分隔条；
2. 左右拖动调整宽度；
3. 分隔条获得焦点后，可使用左右方向键微调；
4. Home / End 可调整到允许的最小或最大比例；
5. 系统会自动记住上次比例。

窄屏会自动切换为上下布局。

## 使用题目操作图标

题目行右侧四个图标依次用于：

1. 编辑题目；
2. 修改主要知识点；
3. 移入待分类；
4. 删除题目。

将鼠标停留在图标上可查看文字说明。删除仍采用可恢复的安全删除。

## 安全说明

- 切换题库不会复制题目；
- 拖拽布局不会修改业务数据；
- 图标化不会改变原操作逻辑；
- 题目和试卷继续使用原稳定 ID。
