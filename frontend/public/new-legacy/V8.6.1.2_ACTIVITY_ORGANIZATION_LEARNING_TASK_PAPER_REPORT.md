# v8.6.1.2 开发报告

## 版本信息

- 主程序：v8.6.1.2
- 录入中心：Question Studio v0.2.1.1（本次未改变解析与录入协议）
- 活动标准：Activity Schema v1
- 知识树标准：Knowledge Taxonomy Schema v1
- 新增标准：Activity Collection Schema v1、Learning Task Schema v1、Assessment Paper Schema v1

## 本次目标

本版本解决“题目录入后如何分类、分组、收藏、形成学习任务和手动组卷”的问题，同时避免把活动正文复制到题集、试卷或课程中。

统一关系为：

```text
活动库：保存唯一活动正文
  ├── 标签：多维分类
  ├── 题集/收藏夹：引用 activityId
  ├── 学习任务：引用 activityId、旧题目引用或画布 ID
  ├── 试卷：引用 activityId，并保存分值和考试规则
  └── 课程：引用 activityId
```

## 内容中心

### 活动属性

活动 metadata 新增统一组织字段：

```javascript
metadata: {
  organization: {
    difficulty: "unset" | "easy" | "medium" | "hard",
    estimatedTimeSeconds: 90,
    usagePurposes: ["practice", "exam", "learning_task"],
    tagIds: [],
    reviewStatus: "unreviewed" | "reviewed",
    sourceType: "original" | "adapted" | "imported" | "legacy"
  }
}
```

支持单题或批量设置：

- 难度；
- 预计答题时间；
- 使用场景；
- 复核状态；
- 标签。

### 标签

- 按科目创建标签；
- 标签支持名称和说明；
- 活动可以拥有多个标签；
- 标签被活动引用时禁止直接删除，避免产生失效引用；
- 活动库支持按标签筛选。

### 题集与收藏

- 每个账号自动拥有“我的收藏”；
- 可创建普通题集；
- 题集只保存 activityIds，不复制题目正文；
- 活动可同时加入多个题集；
- 活动库支持按题集和收藏筛选；
- 删除题集不会删除原活动。

### 批量操作

选中活动后可执行：

- 设置知识点；
- 设置难度、时间、用途和标签；
- 加入题集；
- 收藏或取消收藏；
- 直接创建手动试卷。

### 引用追踪

活动详情现在统一显示：

- 课程节点引用；
- 题集引用；
- 收藏夹引用；
- 试卷引用；
- 学习任务引用。

## 配置中心

配置中心新增三个固定页签：

```text
课程配置｜学习任务｜试卷与测评
```

三个区域共享原有工作台顶部栏、流程提示和工作区放大/收起能力。

## 学习任务

深度回忆、单题深学和多题画布正式归入“学习任务”，不再与普通考试试卷混为一类。

支持：

- 新建、编辑、删除；
- 草稿、发布、归档；
- 选择科目；
- 引用活动库活动；
- 同步旧发布试卷；
- 同步已有且非空的多题画布；
- 保留旧题目引用和画布 ID，避免旧数据失效。

学习任务类型：

```javascript
"deep_recall"
"single_deep_study"
"multi_question_canvas"
```

### 深度回忆关键词接口

本版本尚未实现完整的关键词模板编辑器，但已正式预留：

```javascript
config: {
  keywordAnnotations: [],
  templateParserVersion: "reserved-v1"
}
```

v8.6.2 可直接接入 `[[关键词]]` 模板解析、自动高亮和人工确认，不需要再次迁移学习任务数据。

## 试卷与测评

本版本实现基础手动组卷：

- 从统一活动库选择题目；
- 调整题目顺序；
- 设置每题分值；
- 自动统计题量和总分；
- 设置时长；
- 设置通过分数；
- 设置允许尝试次数；
- 设置是否随机题序；
- 设置是否打乱选项；
- 设置提交后是否显示答案；
- 草稿、发布、归档和删除。

试卷只引用 `activityId`，不会生成活动副本。

## 数据与代码结构

新增独立数据层：

```text
src/93-content-organization-core.js
```

负责：

- 标签；
- 题集与收藏；
- 活动组织属性；
- 学习任务；
- 试卷；
- 旧数据迁移；
- 全部引用关系。

新增独立界面控制器：

```text
src/93-content-organization-app.js
src/93-assessment-config-app.js
```

这样没有继续把标签、题集和组卷逻辑堆入 `91-content-center-app.js` 或 `91-course-admin-app.js`，降低了后续技术债务。

新增 JSON Schema：

```text
schemas/activity-collection-schema-v1.json
schemas/learning-task-schema-v1.json
schemas/assessment-paper-schema-v1.json
```

## 当前阶段限制

以下内容不属于本版本已完成范围：

1. 新试卷尚未接入独立的学员考试运行器和成绩分析；本版本完成的是管理、预览、发布状态和数据标准。
2. 新学习任务尚未替换自由模式现有选择入口；旧入口继续运行，配置中心已能统一管理和迁移其来源。
3. 规则抽题、随机组卷和题库配额组卷尚未实现。
4. 深度回忆 `[[关键词]]` 模板解析、高亮编辑和校验将在 v8.6.2 实现。
5. 正式多人服务器数据库、登录会话和权限审核仍需服务器端接口。
