# V9.0-P2.2 知识树生命周期与安全删除报告

## 目标

补齐旧知识树的可控清理能力，同时避免误删当前知识树或仍被教学内容引用的版本。

## 生命周期

```text
草稿 → 发布为当前 → 历史已发布 → 归档 → 永久删除
                           ↑        ↓
                           └── 恢复 ┘
```

同一科目可以保留多个“已发布”历史版本，但仅一个版本标记为当前。旧版不再使用时，管理员先归档；归档并不删除数据，仍可恢复。

## 删除规则

1. 当前知识树不可归档或删除，必须先切换另一个版本为当前。
2. 历史已发布版本不可直接永久删除，必须先归档。
3. 草稿可直接删除。
4. 草稿或归档版本如果仍被活动、课程草稿或课程发布直接引用，永久删除被阻止。
5. 永久删除需要再次输入版本号确认。
6. 归档、恢复和删除均只允许管理员执行。

## 数据保护

- 操作通过管理端事务服务执行；提交前自动生成快照。
- 删除记录保存知识树 ID、名称、版本、节点数、操作者、时间和内容摘要。
- 发布与生命周期记录保留归档和恢复事件。
- 引用索引新增知识树级引用，稳定节点 ID 在版本间复用时不会造成跨版本误判。

## 页面入口

打开 `admin-console.html`，在“知识树版本”列表中使用：

- `归档旧版`
- `恢复历史版`
- `删除草稿`
- `永久删除`

当前版本只显示“当前使用”，不会出现删除操作。
