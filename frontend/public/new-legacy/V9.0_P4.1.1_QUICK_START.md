# V9.0-P4.1.1 快速使用说明

## 用户查看反馈回复

1. 管理员在“反馈管理”中填写回复并保存；
2. 用户回到图谱首页后，账号右侧问号按钮显示未读数量；
3. 点击问号，菜单中的“需求反馈”显示独立角标；
4. 打开“需求反馈”，进入“我的反馈”；
5. 带新回复的反馈会显示“管理员新回复”；
6. 查看后，该反馈回复按当前账号标记为已读。

顶部问号角标会汇总：

```text
未读站内消息 + 未读反馈回复
```

“需求反馈”和“消息”菜单分别显示自己的未读数量。

## 图标按钮

首页问号按钮和反馈/消息弹窗关闭按钮已统一为 SVG 图标按钮，在不同字体、系统缩放和浏览器中保持居中。

## 本地演示模式

反馈回复已读状态保存在：

```text
kg_user_feedback_reply_reads_v1__<账号>
```

每个账号互相隔离，不需要迁移旧题目、试卷或学习数据。

## 正式服务器部署

远程模式需要：

1. `GET /api/feedback/mine` 返回 `unreadReplyCount` 和 `lastReadAt`；
2. 实现 `POST /api/feedback/:id/read`；
3. 服务端校验反馈属于当前登录用户；
4. 按账号保存反馈回复已读状态。

完整契约见：

```text
SERVER_ENGAGEMENT_API_V1.md
```

## 模块化建议

当前版本不建议部署前进行全面重写。后续优先渐进抽取图标按钮、角标、弹窗、页面顶栏和领域仓库，每一步保持旧页面和数据兼容。
