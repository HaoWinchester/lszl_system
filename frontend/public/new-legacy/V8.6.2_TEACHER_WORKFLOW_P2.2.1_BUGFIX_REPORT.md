# v8.6.2 P2.2.1 Bugfix 报告

本维护版基于 P2.2 Bug Audit 的确认方案执行，目标是先封住数据安全和学习页交互问题，再进入下一功能阶段。

## 已修复

1. 单题深学中文/中英对照切换：中文模式不再渲染英文，对照模式实时显示英文。
2. 联想库 TXT 往返：按已有 ID / 中文名称 / alias 对齐节点，保留稳定节点 ID、双语字段、Prompt、Hint 与 metadata。
3. TXT 合并：自定义稳定 ID 节点不再因标题生成 ID 而产生重复节点。
4. 关系安全：文本往返与可视化候选排序保留既有 edge ID、label、metadata；排序仅更新 priority。
5. 场景主题：主题状态移到 `#krViewport`；`#krApp` 不再承载主题。
6. 正式英文：未配置英文时不再从内部 ID 生成伪英文标题/Prompt。
7. 移动端题目库：恢复全宽 bottom-sheet，小屏可全屏。
8. 键盘/焦点：题目库支持 Escape、Tab 循环和焦点返回。
9. 发布完整性：更新 P2.2.1 release file hashes，完整性回归重新纳入门禁。

## 不变项

- 题目稳定 ID、活动 ID、课程节点 ID 不做迁移。
- 学习成绩、进度、解锁规则不改变。
- 原 TXT/JSON 联想库入口继续保留。
