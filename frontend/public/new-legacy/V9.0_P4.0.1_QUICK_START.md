# V9.0-P4.0.1 快速使用说明

## 模式切换

打开 `practice-mode.html` 后，账号左侧显示：

```text
做题｜自由
```

“做题”留在练习大厅，“自由”进入自由知识图谱页面。

## 连胜提示

挑战模式和学霸模式均在连续答对 3 题后，于进度条上方显示连胜提示。提示会持续更新，直到答错或超时打断连胜。

## 学霸倒计时

倒计时细进度条左侧显示闹钟图标。剩余时间进入 20 秒及以下时，窗口外围出现红色渐变呼吸效果；答对恢复时间超过 20 秒后自动消失。

## 保持不变的规则

- 练习数量：10 / 20 / 60 / 180；
- 每题答对基础经验：10；
- 挑战模式：三点血量、五题检查点、五连胜回血；
- 学霸模式：80 秒共享时间池、答对加 20 秒、答错扣 20 秒并掉血；
- 点击选项立即提交；
- 不允许暂停或返回上一题；
- 结算只显示正确率、总耗时和经验值。
