# V9.0-P3.5.1 试卷管理双栏工作区与题目快速预览报告

## 本次目标

在 V9.0-P3.5 统一试卷管理基础上，优化教师连续选题与核题效率：修复窄区域文字被挤成垂直排列的问题，将题库选题和试卷预览放入同屏双栏工作区，并支持双击题目查看完整内容及跳转编辑。

## 已完成

### 1. 文字排版修复

- “全选”“选择当前页”“深度回忆”“多题画布”“单题深学”等短标签强制保持横向书写。
- 为操作标签设置最小内容宽度、禁止逐字断行，并重构学习模式区域为响应式网格。
- 窄窗口下学习模式自动换行成多列，不再把中文拆成单字竖排。

### 2. 左右双栏选题工作区

“从题库选择题目”和“试卷题目预览”已改为左右排列：

- 两侧列表在固定高度工作区内独立滚动，无需在两个区域之间上下翻页。
- 中间分隔条支持鼠标或触控拖拽，宽度比例限制在 28%–72%，避免任一侧被拖到不可操作。
- 分隔条支持键盘左右方向键、Home 和 End 调整，并提供无障碍数值描述。
- 分栏比例保存到浏览器本地，下次进入继续使用。
- 每个区域顶部提供“放大/恢复”和“收起/展开”图标按钮。
- 屏幕宽度小于 860px 时自动切换为上下排列，避免移动端过窄双栏。

### 3. 题目双击预览

以下两个列表均支持双击题目：

- 从题库选择题目列表；
- 试卷题目预览列表。

预览窗口展示：

- 题目编号、来源题库、题型、难度、主要知识点和标签；
- 完整题干；
- 选项及正确选项标识；
- 正确答案；
- 题目解析。

### 4. 精确跳转题目编辑

预览窗口右上角增加编辑图标：

- 在新标签页打开题库管理；
- URL 携带 `bankId`、`questionId` 和 `view=base`；
- 题库管理初始化后自动选中对应题库和题目，并进入“题目基本信息”编辑区；
- 不影响当前试卷草稿页面和未保存的界面状态。

## 技术评估

本次采用“拖拽分栏 + 放大/收起”的组合方案。相较只做固定左右栏，增加的开发代价主要是分隔条指针事件、键盘操作、布局状态和响应式回退；不涉及题目、试卷或发布数据模型变更，整体属于中等偏低的前端改造成本。收益是教师可根据题干长度、题目数量和当前任务自由调整空间，后续无需再次重构布局。

## 安全边界

- 双击预览只读取题目，不修改题目或试卷。
- 编辑按钮只跳转到原题编辑页，不复制题目，不改变题目 ID。
- 批量移除仍只删除试卷引用，不删除题库原题。
- 发布版本、学习模式可见性和 P3.4 安全删除逻辑未改变。
