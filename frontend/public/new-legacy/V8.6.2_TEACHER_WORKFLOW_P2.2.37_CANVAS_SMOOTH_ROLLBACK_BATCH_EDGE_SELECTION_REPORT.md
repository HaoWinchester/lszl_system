# V8.6.2 P2.2.37 画布流畅缩放回退与批量选线报告

## 目标

本版本优先恢复长时间缩放、平移时的视觉流畅性，并为知识图谱与多题画布补齐多条关系线的框选和批量删除能力。

## 缩放策略调整

- 移除 P2.2.36 引入的缩放结束双帧高清提交、设备像素重对齐和临时合成层退出流程。
- 恢复 P2.2.35 的持续合成路径，避免交互结束前后频繁切换渲染策略造成帧率波动和视觉眩晕。
- 数据结构、坐标模型、保存格式和撤销历史均未迁移。

## 批量选择关系线

知识图谱和多题画布现在支持：

1. 从画布空白处拖出选择框，同时命中卡牌与可见关系线。
2. 按住 Shift、Ctrl 或 Command 追加到现有选择。
3. Delete 或 Backspace 一次删除所选内容。
4. 仅选择关系线时直接删除关系，不影响两端卡牌。
5. 卡牌与关系线混合选择时，在同一事务内删除卡牌、显式选中的关系，以及因卡牌删除而失效的关联线。
6. Ctrl 或 Command + Z 一次恢复整批删除。
7. Escape 或空白点击清除选择状态。

## 实现维护性

新增 `src/canvas/84-canvas-edge-selection-geometry.js`，集中提供 SVG 路径外接矩形过滤、路径采样和线段—矩形相交判断。知识图谱与多题画布复用同一套几何判定，避免两套画布的选线规则分叉。

## 兼容性修复

知识图谱原有框选矩形坐标属于画布容器局部坐标，但旧逻辑再次按页面坐标扣除了画布偏移。本版本改为直接依据当前 viewport 位移与缩放换算世界坐标，修复不同页面位置下的框选偏移。

## 验证范围

- 共享几何模块单元检查。
- 知识图谱真实页面：框选两条线、批量删除、一次撤销。
- 多题真实工作区：框选两条线、批量删除、一次撤销。
- 既有图谱工具栏、连接点、多题布局、统一缩放与浏览器 smoke 回归。
