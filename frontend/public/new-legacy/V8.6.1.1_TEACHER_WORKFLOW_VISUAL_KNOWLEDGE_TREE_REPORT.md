# v8.6.1.1：教师工作流与可视化知识树优化报告

## 版本范围

- 学习程序：v8.6.1.1
- 录入中心：Question Studio v0.2.1
- 活动标准：Activity Schema v1
- 知识树标准：Knowledge Taxonomy Schema v1
- 课程配置标准：Course Configuration Schema v1

本版本基于 v8.6.1，重点解决教师在三个新模块之间迷失、知识树维护依赖大量弹窗，以及数百知识点难以选择的问题。底层活动、知识树和课程数据标准没有推倒重做。

## 一、统一教师内容工作台

新增 `teacher-workbench.html`，主程序的教师内容入口直接打开该工作台，并将教师端固定为四个顶部页签：

```text
工作台｜录入中心｜内容中心｜配置中心
```

三个中心共用相同顶部栏、账号位置、当前科目偏好、按钮风格和四步流程：

```text
录入活动 → 检查入库 → 配置课程 → 预览发布
```

每个页面都说明“当前在哪里、当前要做什么、完成后去哪里”，降低教师理解后台结构的负担。

## 二、可视化知识树编辑

内容中心增加“图谱视图 / 目录视图”。

图谱视图支持：

- 展开、折叠知识分支；
- 缩放、恢复适合比例；
- 在节点卡片上直接新增下级知识点；
- 双击名称直接修改；
- 拖动知识点到另一节点下调整父子关系；
- 拖到根目录区域调整为一级知识点；
- 右侧常驻属性栏修改中英文名称、编号、别名、父节点和状态；
- 最多 30 步撤销与重做。

目录视图适合数百节点场景，支持按中文、英文、编号、别名和完整路径搜索。两个视图操作同一份知识树数据，切换时保留当前选中节点。

## 三、知识树结构安全

知识树保存器补强以下约束：

- 单棵知识树最大六层；
- 节点不能成为自己的父节点；
- 节点不能移动到自己的后代下面；
- 阻止循环引用；
- 移动父节点后递归重算全部后代层级；
- 如果任意后代将超过第六层，整次移动会被拒绝；
- 稳定知识点 ID 不因改名或移动而变化。

## 四、Question Studio v0.2.1 知识点查找器

录入中心不再使用包含全部知识点的单一大下拉框。新的知识点查找器支持：

- 科目和知识树切换；
- 名称、英文名、知识点编号、别名、稳定 ID、完整路径搜索；
- 按层级逐步浏览；
- 面包屑快速返回上级；
- 最近使用知识点；
- 收藏常用知识点；
- 选择前显示完整路径；
- 本批默认知识点一键应用到全部活动；
- 每道活动单独调整主知识点。

中文内容和主知识点仍为正式数据；英文仍只作为展示，不参与作答判定。

## 七、当前边界

本版本仍是可离线运行的前端工作台。通过同源 HTTP/HTTPS 部署可使用浏览器活动库直连，但正式多人服务器数据库、登录会话、审核权限与教师身份强校验仍需后端接口接入。离线 JSON 导入导出继续作为备份和应急通道保留。
