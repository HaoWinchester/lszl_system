# v8.6.2 P2.2.3 Lightweight Question Library

## 目标
统一单题深学、多题归纳、深度回忆三个页面的题目库打开效果，降低面板空间占用。

## 统一后的面板

三个页面使用同一轻量外壳：

- 桌面端：左侧 360px 轻量面板；
- 移动端：底部轻量面板，高度最多约 62dvh；
- 无解释性标题区、无关闭按钮、无底部说明区；点击空白遮罩或 Esc 关闭；
- 遮罩透明，不做背景模糊或聚焦视觉；
- 打开后不自动聚焦搜索框，不做焦点陷阱，不做关闭后的焦点回跳。

面板只保留：

1. 题集 / 已发布试卷下拉框；
2. 搜索输入 + 文本“搜索”；
3. 三个状态筛选文本按钮；
4. 试题列表。

## 轻量化

- 搜索和筛选按钮全部取消边框、背景框、胶囊样式；
- 当前筛选仅用文字颜色 + 下划线表示；
- 试题列表改为紧凑行式布局，行间距接近 0；
- 隐藏主题、难度等次要说明，保留序号、题目标题、状态，以及页面原有必要操作图标；
- 单题深学移除题库面板中的“加入多题画布”目标选择、说明文字和上一题/下一题 footer；加入当前活动多题画布的题目行操作仍保留；
- 多题归纳移除抽屉解释文字和拖拽说明 footer；题目仍可加入画布；
- 深度回忆移除解释标题和题集说明。

## 数据

未修改题目、题集/试卷、课程、知识节点、学习进度、成绩或解锁数据。
