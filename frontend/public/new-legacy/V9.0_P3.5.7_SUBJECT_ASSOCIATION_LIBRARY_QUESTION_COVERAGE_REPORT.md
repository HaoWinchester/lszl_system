# V9.0-P3.5.7 开发报告

## 版本主题

**科目级联想库管理与知识点题量统计**

本版本基于 V9.0-P3.5.6，对后台“科目与知识树”页面进行信息架构整理，并补齐科目级联想库导入后的查看、维护、审查和发布能力；同时在当前知识树中增加知识点题量统计及题目明细联动。

## 一、页面页签重新整理

“科目与知识树”右侧页签统一为：

```text
当前知识树｜科目级联想库｜历史版本
```

原“待分类题目”页签已取消。该功能及题目数据没有删除，继续在以下位置集中管理：

```text
题库管理 → 题目 → 题目状态：待分类
```

后台概览中的“待分类题目”快捷入口也改为打开题库管理，避免同一业务在两个页面重复维护。

## 二、科目级联想库管理模式

### 2.1 按科目独立管理

联想库跟随左侧当前科目切换，每个科目维护独立数据，例如 PMP、ACP、CSPM 分别拥有自己的联想库。

学习端继续读取现有正式存储：

```text
kg_recall_association_library_v1__subject__<科目代码>
```

后台新增管理记录：

```text
kg_recall_association_management_v1__subject__<科目代码>
```

管理记录保存编辑草稿、导入批次和正式发布快照，不改变原学习端读取接口。

### 2.2 草稿与正式版本分离

后台编辑采用：

```text
编辑或导入 → 保存草稿 → 发布启用
```

- 内容列表中的修改先进入当前科目的编辑草稿；
- 学习端仍读取上一次正式发布版本；
- 点击“发布启用”后才写入正式联想库；
- 每次发布生成 v1、v2 等可追溯快照；
- 页面顶部显示草稿节点数、关系数、未关联知识点数量和当前正式版本。

### 2.3 内容列表

“内容列表”是日常管理主视图，支持：

- 搜索关键词、别名及关联知识点；
- 按启用、停用状态筛选；
- 按已关联、未关联或关联失效筛选；
- 新增、编辑和删除关键词节点；
- 编辑别名、提示语、说明和联想目标；
- 将关键词关联到当前知识树中的未停用知识点；
- 查看每个关键词的联想关系数量；
- 当前页复选与批量关联知识点；
- 批量启用、停用和删除；
- 每页显示 30 个节点。

关联知识点使用稳定的知识点 ID。知识点被停用或不再存在时，联想节点不会静默删除，而会显示为“未关联 / 已失效”。

### 2.4 关系图谱

“关系图谱”用于理解当前草稿中的整体关联结构：

- 显示关键词节点与联想关系；
- 支持按关键词或别名搜索聚焦；
- 点击图谱节点可返回内容列表编辑；
- 为保证浏览器本地应用性能，单次最多绘制 80 个匹配节点；
- 日常精确编辑仍以内容列表为主。

### 2.5 导入审查与记录

TXT / JSON 文件不再直接覆盖正式联想库，流程调整为：

```text
选择文件 → 解析检查 → 显示新增/更新/关系变化 → 选择合并或替换 → 确认加入草稿 → 发布启用
```

支持两种应用方式：

- 合并到当前草稿；
- 替换当前草稿，操作前二次确认。

每次导入记录文件名、操作者、时间、节点数、关系数、应用方式和差异信息。每次正式发布也保留版本、时间、操作者和节点/关系数量。

### 2.6 导出与审计

- 可以导出当前科目草稿的 JSON 备份；
- 保存草稿、导入和正式发布进入后台操作记录；
- 记录当前科目、数量、发布版本和导入批次信息。

## 三、知识点题量统计

### 3.1 统计口径

当前知识树中的题量按以下规则实时计算：

- 当前科目；
- 当前知识树；
- 正常状态题目；
- 按题目的主要知识点统计；
- 同一道题只归入一个主要知识点；
- 已安全删除题目不计入默认统计；
- 待分类题目单独计数，不归入任何知识点；
- 普通标签不参与主要题量统计。

正式题库存在时优先读取正式题库数据；仅在没有正式题库题目时保留旧活动数据的兼容统计。

### 3.2 本节点与含下级

每个知识点显示两种数字：

- **本节点**：直接归属于该知识点的题目数；
- **含下级**：本节点加全部后代知识点的题目总数。

叶子知识点只需关注本节点数字；父级知识点可以同时快速判断本层和整个分支的题量覆盖情况。

### 3.3 顶部概览与覆盖筛选

当前知识树顶部新增：

- 正常题目数；
- 已归类题目数；
- 待分类题目数；
- 零题量知识点数；
- 失效归属数量；
- 显示题量开关；
- 全部知识点、零题量、题量不足筛选；
- 题量不足阈值设置。

题量不足默认按照本节点题量判断，阈值可在页面中调整。

### 3.4 题目明细抽屉

点击知识点的题量徽标后，打开非模态题目明细抽屉：

- 可切换“本节点”和“含下级”；
- 显示当前知识点及统计范围；
- 支持搜索题号、题干和来源题库；
- 显示题目来源题库与主要知识点；
- 可精确跳转至原题编辑页面；
- 不复制题目，不改变题目 ID 或知识点归属。

关闭抽屉后仍停留在当前知识树，不中断教师的知识树浏览工作。

## 四、安全与兼容边界

本版本没有改变：

- 题目 ID 和题库 ID；
- 题目的主要知识点与普通标签；
- 待分类题目数据；
- 试卷引用、发布版本和题目快照；
- 题目安全删除、恢复与永久删除保护；
- 知识树版本和发布生命周期；
- 学员端对知识树和题目分类信息的可见性规则。

联想库发布只替换当前科目的正式联想库，不修改知识树节点。知识树历史版本不会自动覆盖或回滚联想库。
