# v8.6.2 P2.2.1 Re-audit

## Confirmed bug reproduced

The Deep Recall `题目库` button could not be opened by a real mouse/touch click.

The existing P2.2 / P2.2.1 regression falsely passed because it used JavaScript `dispatch_event('click')`, which skips the real pointerdown/pointerup sequence.

With a real pointer click, `#krViewport` handled the button's `pointerdown` as a canvas-pan gesture and called `setPointerCapture()`. The browser therefore did not deliver the normal click to `#krQuestionListBtn`.

This reproduces the reported symptom on both desktop and mobile.

## Additional bug found

When there are no stored question banks, the intended built-in PMP demo bank was also missing.

`src/96-recall-question-source.js` read only `window.PMP_QUESTION_MVP`, while `src/50-question-data.js` declares `PMP_QUESTION_MVP` as a global lexical `let`, so it is not a `window` property.

## Other P2.2.1 checks

- All existing Node regression tests passed before this patch.
- Single-question Chinese / bilingual real-click switching works.
- Multi-question `题目库` real click works.
- Multi-question and single-question `视图` zoom proxies work with real clicks.
- Deep Recall page initializes without a page-level JavaScript exception in the audited flow.
- The P2.2.1 stable-ID / bilingual recall-library fixes remain intact.

## Fix

P2.2.2 excludes canvas overlay controls from Deep Recall pan/zoom/double-click gesture capture, restores the built-in demo-bank fallback, and adds a dedicated real-pointer browser regression so this failure mode cannot be missed again.
