# V9.0-P3.3.4 轻量标签名称维护报告

基线：V9.0-P3.3.3.3。

## 本次调整

1. 在“选择普通标签”弹窗左下角，“清空标签”右侧增加轻量文字入口“管理标签”。
2. 点击后打开独立的小型标签管理弹窗，不新增后台页面、不新增一级或二级导航。
3. 管理弹窗沿用现有“用途标签 / 质量标签 / 来源标签”及其二级分类，只展示已有预设标签。
4. 双击标签名称进入原地编辑：Enter 或失焦保存，Esc 取消。
5. 空名称和与其他预设标签重复的名称会被阻止。
6. 标签改名后，当前用户全部正式题库中使用旧名称的题目会同步替换为新名称；题目 ID、知识点关联、试卷引用和历史答题数据不变。
7. 标签名称配置保存在 `kg_question_tag_names_v1`，同时保存旧名到新名的兼容别名；模板或后续重新导入的旧标签名会自动归一为当前名称。
8. 批量录题的本批默认标签、逐题覆盖和当前解析结果会响应标签改名事件，避免同一会话中仍显示旧名称。
9. 自定义自由文本标签继续保持原逻辑，不进入本次“管理标签”窗口。

## Bug 审计

- 未发现 P3.3.3.3 批量分割、完整预览、全宽布局、正式题目分类和知识树关联的阻断性业务问题。
- 发现并修复两个标签改名边界问题：
  - 标签在录题会话中改名后，已经存在内存中的“批次默认标签 / 单题覆盖 / 已解析标签”可能继续保留旧名称；现通过 `kg-tag-renamed` 事件同步刷新。
  - 标签改名后，如果从旧备份或旧题库再次载入带旧标签名的题目，旧名称可能重新出现；现题库规范化阶段会按兼容别名自动转换为当前标签名。
- P3.3.4 版本升级使少量历史回归脚本仍限定在 P3.3.3 补丁线；已仅放宽版本兼容断言，不改变历史业务断言。
