# v8.6.2 教师工作流 P2.1 开发与回归报告

## 1. 基线与目标

本轮以 `kg_graph_v8_6_2_teacher_workflow_p2.zip` 为直接基线，重新开发教师端双语快捷录题能力。P2.1 只扩展题目录入、校对和可选双语数据，不改变 Activity Schema 的既有必填结构，不修改课程、知识树、学习进度、成绩或解锁规则。

## 2. 简化录题模板

新增四种内置模板：

1. 标准双语单题模板；
2. 双语单题示例；
3. 双语批量录题模板；
4. 仅中文录题模板。

教师可下载模板、复制模板或在页面中直接查看示例。模板不要求填写内部 ID、阶段、部分、主题和标签；题型默认使用单选题。

标准双语字段包括：

```text
【题干-中文】
【题干-English】
【A-中文】～【D-中文】
【A-English】～【D-English】
【答案】
【解析-中文】
【解析-English】
【关键词】
```

## 3. 双语解析与校验

P2.1 解析服务复用 Question Studio 的结构化解析能力，并增加教师工作流所需的兼容与校验：

- 中英文题干、A-D 选项、答案和双语解析识别；
- A-D 完整性、答案合法性和英文内容完整性校验；
- 中文普通文本录题继续兼容；
- 缺少解析作为提醒，不阻断保存；
- 检测到部分英文内容但缺少英文题干或选项时阻断导入；
- 批量模式使用 `===== 下一题 =====` 拆分，也继续兼容原有题号和分隔线拆题。

## 4. 关键词与回忆入口

关键词支持两种格式：

```text
关键相关方 | key stakeholder
关键相关方 | key stakeholder -> 关键干系人
```

系统分别检查中文关键词和英文关键词在对应题干、选项中的位置。未找到关键词只显示提醒，不阻断题目保存。导入后关键词会转为现有线索结构，并保留英文名称、回忆入口和匹配位置。

## 5. 题号与数据模型

- 内部稳定 ID 继续由既有题库服务生成；
- 新增教师可见题号，例如 `PMP-000128`；
- 题号按科目生成，并在保存前执行全题库唯一性修正；
- 中文内容继续保存在现有主字段；
- 英文内容保存在可选的 `translations.en`；
- 翻译状态保存在 `metadata.translationStatus`；
- 旧题目没有这些字段时仍可正常读取和编辑。

## 6. 编辑体验

题目编辑区新增：

- 中文；
- English；
- 中英对照。

三个视图使用同一题目对象，不创建重复题目。标题改为可选；难度、领域、主题和标签收纳到“更多信息”，减少快捷录题后的必填负担。解析通过后，若当前项目是未完成占位题，则直接填充该题；否则新增题目并进入编辑。

## 7. 兼容性与受保护数据

保持不变：

- 82 个内置活动及稳定 ID；
- 5 棵知识树、16 个知识点及稳定 ID；
- 1 门内置课程、108 个课程节点及稳定 ID；
- 学员学习进度、成绩、解锁规则；
- P0、P1、P2 已有教师工作流；
- 深度回忆和自由练习现有数据；
- 原有中文普通文本录题。

P2.1 没有实现 P2.2 的学习页统一、题集抽屉和联想节点可视化配置。
