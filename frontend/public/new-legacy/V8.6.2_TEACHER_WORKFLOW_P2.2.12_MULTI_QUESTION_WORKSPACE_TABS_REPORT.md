# v8.6.2 P2.2.12 多题画布页签化

基线：P2.2.11。

## 目标

把多题归纳顶部原来的“画布下拉框 + 新建 + 改名 + 删除”改成与知识图谱文件页签一致的操作模型，降低学习成本。

## 已完成

### 页签视觉

- 使用与知识图谱相同思路的灰色页签底栏。
- 当前画布使用白底高亮，并显示紫色底部指示线。
- 页签标题过长自动省略。
- 页签区域支持横向滚动。
- 切换画布后，当前页签自动滚动到可见区域。

### 页签操作

- 单击页签：切换画布。
- 双击页签：重命名该画布。
- `×`：关闭页签，但不删除画布。
- 拖动页签：调整页签顺序，并持久化画布目录顺序。
- `＋`：新建画布并自动打开。
- `…`：保留原“重命名 / 删除画布”功能。
- 左侧“画布列表”按钮：查看全部画布，并重新打开已关闭的页签。

### 关闭与删除明确分离

- 关闭页签：只影响当前浏览器会话中的页签显示，画布内容仍保留。
- 删除画布：才真正删除该多题画布中的题目引用、布局、归纳卡、分组和连线。
- 删除多题画布仍不会删除原题或单题学习记录。

### 与知识图谱页签保持一致

本版本对齐了知识图谱文件页签的核心体验：

- 当前页签高亮；
- hover 显示关闭按钮；
- 关闭不等于删除；
- 页签拖拽排序；
- `+` 新建；
- 左侧入口重新打开关闭页签；
- 当前页签自动保持可见。

### 数据层

`CanvasWorkspaceStore` 新增 `reorderWorkspaces()`。

它只调整画布目录顺序，不改变：

- workspace ID；
- 题目引用；
- 节点 ID；
- 边；
- 分组；
- viewport；
- 学习进度。

旧画布数据无需迁移，可以直接兼容。

## 最后一个页签保护

知识图谱在关闭最后一个文件页签后可以返回文件管理器。多题归纳目前没有独立的“画布文件管理器”，所以这里做了安全适配：

- 如果还有已关闭画布，则自动打开其中一个；
- 如果系统实际只有一个画布，则不允许关闭最后一个页签。

这样避免出现“画布仍在，但页面没有任何活动页签”的空状态。
