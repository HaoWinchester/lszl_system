# v8.6.2 P2.2.25 深度回忆场景、卡牌状态与主题一致性报告

## 本次优化

1. 保留知识卡鼠标按下反馈。即使指针仍停留在卡牌上，按下时仍会出现轻微下沉、缩放和中心图标压入效果；松开后恢复，卡牌悬浮本身继续保持静止。
2. 修复知识卡选中外边框被悬浮样式覆盖的问题。选中态、悬浮态和按下态现在分别处理，选中高亮环在悬浮和点击过程中不会消失。
3. 右上角“场景”入口改为纯图标按钮。桌面端将指针悬浮或键盘聚焦到图标时显示紧凑的场景色板；点击任一场景图标立即应用，无需额外确认。
4. 场景状态同步到应用外壳、画布和页面状态，修复此前主题变量只作用于画布、顶部栏仍保持白色的问题。
5. 题目库组合栏、重置按钮、缩放栏、底部统计栏、题目卡、选项、题目库抽屉和知识卡外壳均改为使用主题变量，不再固定使用白色背景。
6. 补齐极光绿、暗夜霓虹、樱花粉、海盐蓝和奶油拿铁主题中缺失的背景、强调色、知识卡层级配色及关键词高亮变量。
7. 修正暗夜霓虹等主题仍继承平台橙色光晕的问题，各主题的画布渐变光晕现在与自身色系一致。
8. 保留隐藏的兼容性主题选择器，使旧逻辑和已有存储数据继续可用；新的图标色板与存储值保持双向同步。
